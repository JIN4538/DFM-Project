# 절삭 검토를 처음 사용할 때

**STEP만 고르고 검토를 시작하세요.** 공구 치수를 모르면 형상에서 지름·날 길이·돌출 길이를 제안합니다. 가지고 있는 공구가 있다면 직접 지정할 수 있습니다.

1. **입력 → 절삭 시연용 형상**을 선택합니다. 절삭 공정도 함께 선택됩니다. 내 파일은 **업로드**에서 STEP/STP을 넣습니다.
2. **공구가 오는 방향**을 고릅니다. 처음에는 +Z 위쪽에서 시작해도 됩니다. 장비·재료·검토 중점은 선택 사항입니다.
3. **이 형상으로 절삭 검토 시작**을 누릅니다. 첫 화면 **종합 결론**에서 문제와 추천 치수를 확인합니다.
4. **문제 위치 보기**를 누르면 해당 홈·구멍이 바로 표시됩니다. 수치표와 강조된 위치를 함께 확인하세요.
5. 지원하는 날카로운 홈 코너라면 **추천 수정 적용·재검토**를 누릅니다. 실제 STEP의 코너를 수정하고, 저장한 파일에서 치수를 다시 확인합니다.
6. 전후 그림, 코너 반경, 유지된 홈 깊이, 재료 부피 변화를 확인한 뒤 **코너를 수정한 STEP 다운로드**를 누릅니다.

| 용어 | 쉬운 뜻 |
|---|---|
| 엔드밀 지름 | 회전하는 공구 날의 굵기. 들어갈 홈·구멍의 크기와 비교합니다. |
| 날 길이 | 실제로 재료를 깎는 날이 있는 구간의 길이. 홈 벽 높이와 비교합니다. |
| 돌출 길이 | 공구 끝부터 홀더 앞까지 밖으로 나온 길이. 닿아야 할 깊이와 비교합니다. |
| 안쪽 코너 반경 | 홈 안쪽 모서리가 얼마나 둥근지. 0 mm는 날카로운 코너입니다. |
| 치수 문제 3 → 0 | 검토한 치수 비교에서 발견한 문제 세 가지가 수정 후 해소됐다는 뜻입니다. |

**복수 포켓은 한 번에 수정합니다.** ‘살펴볼 수정 위치’에서 그림만 바꾸어 볼 수 있고, 다운로드 STEP에는 모든 지원 부위의 수정이 포함됩니다. 원래 구멍과 바깥 크기는 보호하며 홈 깊이를 유지하는지 재측정합니다.

자동 수정 범위는 검산된 볼록 삼각·사각·육각 홈의 안쪽 코너입니다. 섬·교차 특징·곡선 바닥·불완전 경계 등은 수정 대상으로 확정하지 않습니다. 남은 항목은 결론이나 위치 화면에서 확인합니다. 공구 경로·홀더·고정구의 간섭은 별도 항목이며 코너 수정만으로 계산한 것으로 표시하지 않습니다.

처음 시연할 때는 **3개 포켓 · 수정 전**과 **관통 구멍 3개 · 지름 6 mm**를 추천합니다. 공구 치수를 비워 둔 상태에서 결론→위치→수정 전후를 따라가면 됩니다.

형상·방향·조건을 바꾸면 **절삭 설계 검토**를 다시 누릅니다. 근거는 필요할 때만 펼치고, 결과는 **검토 보고서 저장**으로 보관합니다.
