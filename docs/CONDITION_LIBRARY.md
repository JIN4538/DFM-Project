# 장비·재료·공구 조건을 가져오는 방법

이 기능은 제조사 자료를 찾아 숫자를 직접 옮기는 수고를 줄여 준다. **자료에 없는 조건을 자동 추측하지는 않는다.** 장비가 없어도 특정 조건을 가정한 설계 비교에 사용할 수 있다.

## 사용하는 순서

1. 형상과 공정을 선택한다.
2. 왼쪽 **장비·재료·공구 조건 라이브러리**를 연다.
3. 장비명, 재료명, 공구 번호로 검색하고 **찾아볼 조건**을 고른다.
4. 가져오는 값과 적용 조건을 확인하고 **이 조건을 입력에 적용**을 누른다.
5. 필요하면 입력값을 수정하고 **설계 검토** 또는 **절삭 설계 검토**를 실행한다.

목록에서 선택만 하면 미리보기다. 적용하기 전에는 현재 검토 조건이 바뀌지 않는다. 적용 시 기존 장비·재료·숫자 조건은 새 자료와 탐색 기본값으로 교체되므로, 기존에 직접 넣었던 기준은 다시 확인한다.

## 지금 달라지는 계산

| 선택 사례 | 실제로 바뀌는 것 | 추가 확인할 것 |
|---|---|---|
| Prusa / Formlabs 장비 | 입력된 X·Y·Z 공간 | 크기 제한은 기본 꺼짐. 필요할 때 `장비 크기 제한 적용`을 켠다. 서포트·여유 공간은 별도 |
| MK4의 정확한 재료·노즐 프리셋 | 층 높이와 명목 선폭 | 실제 슬라이서 가변폭 경로, 온도·접착·강도는 이 계산으로 검증되지 않음 |
| Form 4 Grey V5 / 50 µm | 검토 층 높이 | 벽·구멍·배출구의 제조사 지침은 참고 자료로 확인 |
| Fuse / EOS의 수록 공정 조건 | 검토 층 높이 | 분말 제거·수축·열변형·서포트는 별도 |
| DATRON / Harvey 공구 번호 | 엔드밀 지름과 날 길이 | 실제 장착 후 돌출 길이는 직접 입력. 홀더·고정구 충돌은 미검토 |

가져오는 층 높이는 **DFM 검토의 층 조건**이며 프린터나 슬라이서를 자동 설정하지 않는다. 공구를 선택해도 해당 공구를 실제 보유한 것으로 간주하거나 가공 프로그램을 생성하지 않는다.

## 참고 자료는 왜 적용 버튼이 없나

재료의 인장강도를 알아도 하중·방향·제조 상태 없이 부품의 강도를 계산할 수 없다. 방향별 벽 권고도 이 툴이 측정한 법선 거리와 항상 같지 않다. 그런 자료는 수치와 원문을 보여 주지만 계산 입력으로 자동 사용하지 않는다.

예를 들어, 카탈로그의 **공구 전체 길이 63 mm**를 **장착 후 돌출 길이 63 mm**로 쓰면 잘못된 도달 판정이 생길 수 있다. 그래서 날 길이와 전체 길이를 분리하고, 모르는 돌출 길이는 비워 둔다.

## 결과에서 확인할 것

**가져온 조건·실제 적용값·출처 확인**을 열면 원자료 값, 계산에 사용한 값, 사용자가 바꾼 항목을 볼 수 있다. 원자료에 없는 직접 입력과 탐색 기본값도 별도로 표시된다. JSON/HTML 결과에도 이 기록이 포함된다.

조건 DB가 갱신되면 자료를 다시 적용하라는 안내가 나온다. **직접 입력으로 초기화**를 누르면 가져온 값과 출처 연결을 지우고 장비 미정 상태로 돌아간다.

표준·논문은 결과의 근거 화면에서 **표준·논문 근거 찾아보기**로 제목을 검색한다. 기존 전문 검토 날짜와 저장소 경로를 볼 수 있다.

이 기능이 제공하는 것은 **출처를 확인할 수 있는 조건별 기하 검토**다. 실제 제조 가능성·강도·공차 적합이나 출력 성공 확률을 새로 검증한 것은 아니다.
