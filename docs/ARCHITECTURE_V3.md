# AM-DFM 3.0 구조와 측정 계약

## 데이터 흐름

`app.py → amdfm.io.load_model → Model → amdfm.analysis.review → report`

STEP는 `cad_worker`의 별도 프로세스에서 처리한다. 벽·단면·층은 요청 시 `detail_worker`에서 계산하고 모델 지문·프로필·방향·배치 행렬이 같은 결과에만 연결한다. UI 캐시 키는 원본·배율·선택 솔리드·설정·코드 지문을 포함한다. 모델이나 조건이 바뀌면 이전 결과의 다운로드를 제공하지 않는다.

## 정확히 측정하는 것과 근사하는 것

변환된 CAD 단일 솔리드의 체적·면적은 OCCT B-rep 적분값이다. 원통 지름·축은 해석적 곡면 파라미터다. 원본의 PMI, 공차, 작업자 의도, 내부 채널 연결, 관통/블라인드 홀 의미는 복원하지 않는다. CAD 면 번호는 해당 입력과 변환 결과에 대한 식별자이며 수정 전후에도 유지되는 설계 특징 ID라는 보장은 없다.

복잡 곡면의 기본 비적응 적분 편차를 확인한 뒤 적응 Gauss 적분으로 바꿨다. 요청 상대 허용오차와 반환 수렴 추정치를 보존하며 인증 오차 상한으로 설명하지 않는다. UV 구간과 면적이 모두 정확히 0인 면은 별도 적분 복사본에서 제외하고 해당 CAD 면 번호를 기록한다. 메시 없는 일반 면을 누락시키지 않는다. 원본 B-rep가 유효하지만 테셀레이션이 비폐합·비일관·중복이면 기하를 복사한 후보에서 목표 편차를 줄여 재시도하고, 모든 위상 조건을 회복한 후보만 사용한다. 실패 후보와 원래 결함은 기록에 남는다.

곡면 전용 STEP은 별도 입력 종류이며, 메시가 우연히 닫혀 보여도 솔리드로 간주하지 않는다. 관측 치수·표면적과 재료 내부에 의존하는 체적·벽·공동·단면을 구분한다. 혼합 솔리드/자유 곡면 입력은 일부 형상을 버리지 않고 오류로 알린다.

하향면·현재 방향 외곽·바닥 접촉은 삼각형 메시 기반이다. 선형 편차·각도 편차는 테셀레이션에 요청한 값이고 인증된 전체 편차 상한은 아니다. B-rep와 메시 체적의 차이는 국소 형상 오류의 상한도 아니다. 기준 각도 근처의 곡면은 테셀레이션에 민감하며 더 조밀한 메시가 임계값 집계 오차를 단조롭게 낮추지는 않는다.

임의 방향은 모델 좌표의 유한·비영 벡터를 최대 절댓값으로 먼저 나눈 뒤 단위화한다. 기울기(모델 +Z 기준)·방위각(+X→+Y)으로도 정의한다. 현재 방향은 실제 단위벡터가 동일한 후보에만 합치며 작은 기울기를 임의로 0 처리하지 않는다. 강체 회전으로 적층축을 +Z에 맞추고 XY 중심 이동·바닥 Z=0·선택된 추가 yaw 0/90°를 한 행렬에 보존한다. 화면·STL·층간 작업은 이 행렬을 정점에 직접 적용한다. 층간 결과 좌표는 `build_mm`, 벽 관통거리 표본은 `model_mm`이며 상세 결과를 연결할 때 배치 행렬도 대조한다. [추가 검증 기록](project-knowledge/ORIENTATION_EXTENSION_2026-09-14.md).

구 r=10 mm, 수평 기준 45°의 이론적 하향 투영면적은 `π r² sin²45° = 157.0796 mm²`다. 이번 추가 진단에서 목표 편차 0.05/0.005/0.001 mm 메시의 결과는 156.1687/160.5022/158.6016 mm²였다. 상대차는 -0.58/+2.18/+0.97%였다. 이는 이 세 설정의 관측값이며 모든 형상에 적용할 오차 보증이 아니다. 방향 간 미세한 차이를 물리적 우열로 확대하지 않는다.

법선 관통거리는 표본 중심에서 안쪽 법선으로 보낸 첫 교차 거리다. 평행판 두께와 일치하는 반례를 시험한다. 비평행 곡면의 전역 최소 벽두께는 아니다. 최솟값·5백분위·유효/누락 표본·원본 면 번호·좌표를 보존한다. 여러 STL 표면 성분은 포함/교차 관계가 미확정이므로 벽 결과를 자동 확정하지 않는다.

공통 단면은 배치 높이를 N개로 균등 분할한 중간 높이에서 메시와 평면을 교차한다. 면적 A, 내부 경계를 포함한 둘레 P, A/P(mm), 재료 성분 수·내부 루프 수와 인접 표본의 대칭차/추가/제거 면적을 기록한다. 같은 면적의 이동 단면도 대칭차로 구분한다. 최초 단면 및 미확정 단면 직후의 변화량은 null이다. 부분 결과에는 관측 최대값만 남기며 총 적분 체적을 확정하지 않는다. 전체 표본을 확정했을 때도 중간점 적분 체적은 근사값이며, 표본 사이의 작은 특징을 놓칠 수 있다. 표본 수는 실제 출력 층 수가 아니며 힘·열·흡착컵·실제 신생 성분의 지지 실패로 환산하지 않는다. 구체적 공정 조건과 문헌은 [재조사 기록](research/AM_DFM_EVIDENCE_REAUDIT.md)에 있다.

추가 `event_sections.py`는 메시 정점 Z 사이의 모든 구간에 2점 Gauss 단면을 배치한다. 구간별 다면체 단면적이 2차식이라는 유도에 따라 체적을 검산하며, 균등 표본에서 누락된 얇은 판에 대응한다. 8,192개 단면·예상 교차 선분 150만 개를 사전 검사하고 초과는 unknown이다. 두 내부 높이를 표현할 수 없는 구간은 partial로 남기며 전체 체적을 만들지 않는다. 단면 최대는 계속 표본 최대이고 대칭차는 단위 높이 변화율이 아니다. [유도·수치 계약](EVENT_SECTION_METHOD.md).

## 상태 계약

- `attention`: 조치할 후보 또는 입력 조건 문제가 관측됨.
- `observed`: 측정값·입력 조건을 확인함. 제조 가능 PASS가 아님.
- `not_detected`: 명시된 검사 범위 안에서 후보 미검출. 전 영역 위험 없음이 아님.
- `unknown`: 미실행, 정보 부족, 실패, 자원 한도.
- `not_applicable`: 해당 공정에 적용하지 않는 항목.

JSON에서 계산할 수 없는 값은 `null`이다. G-code의 압출 경로가 실제로 0개인 경우의 지령량 0은 정당한 관측값이다. 지원하지 않는 명령이 있어서 일부만 읽었을 때는 전체 지령량을 0으로 채우지 않는다. 층 분석에서는 부분 합산과 전체 분모를 혼합하지 않는다.

## 시간과 자원

빠른 검토는 샘플 레이·전체 층·서포트 생성·열해석을 실행하지 않는다. CAD와 고비용 측정은 프로세스로 격리해 Python/네이티브 예외나 시간 초과가 UI 전체를 잃게 하지 않는다. 프로세스 시간과 입력/출력 크기는 제한하지만 운영체제 수준의 메모리 격리 한도를 설정한 것은 아니다. 600,000 면 가까운 최악 모델의 모든 조합을 벤치마크하지는 않았다.

Windows 작업자는 실행을 일시중지한 상태로 생성하고 전용 Job Object에 넣은 뒤 실행한다. Job 종료/닫기로 자식을 함께 정리하므로 venv 런처나 부모가 먼저 끝나도 작업자가 남지 않는다. 출력은 전용 임시 파일로 받고 정리 대기도 유한하다. 초기 격리/정리 오류는 OSError, 계산 한도는 TimeoutExpired로 API에서 미확정 사유에 연결한다. Unix는 별도 프로세스 그룹과 종료 처리를 사용한다.

한도 초과와 오류는 검사 미확정으로 보고한다. 이 상태를 제조 불가 또는 제조 가능으로 바꾸지 않는다. 로그와 최초 실패를 삭제해 성공한 재시험만 남기지 않는다.

## 버전과 보존

원본 `AM-DFM_v2_6.zip`의 계산 코드를 복사한 `src/`는 새 규칙의 근거 자체가 아니다. 새 기본 평가 경로는 `amdfm/`에 있으며 기존 점수·가중치·프로필 자동 판정은 여기서 호출하지 않는다. 기존 단면 엔진의 모든 문헌값을 새 공정의 표준값으로 주장하지 않는다.

기존 UI 회귀검사의 대상은 `run_legacy.py`로 이동했고, Windows에서 UTF-8 JSON을 읽는 한 검사의 인코딩을 명시했다. 기대값을 낮추거나 회귀검사를 삭제하지 않았다.
