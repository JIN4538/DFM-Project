# AM-DFM 3.0 구조와 측정 계약

## 데이터 흐름

`app.py → amdfm.io.load_model → Model → amdfm.analysis.review → report`

STEP는 `cad_worker`의 별도 프로세스에서 처리한다. 벽·층은 요청 시 `detail_worker`에서 계산하고 모델 지문·프로필·방향이 같은 결과에만 연결한다. UI 캐시 키는 원본·배율·선택 솔리드·설정·코드 지문을 포함한다. 모델이나 조건이 바뀌면 이전 결과의 다운로드를 제공하지 않는다.

| 모듈 | 책임 |
|---|---|
| `models.py` | Model, Finding, JSON의 null 보존, 원본·선택 솔리드 지문 |
| `io.py` | 입력 한도, STL 정확 좌표 공유, 배율 기록, CAD 프로세스 관리 |
| `cad_worker.py` | STEP 단위·전체 루트 전송·변환 B-rep 유효성, 체적·면적·원통면·면/바디 연결 |
| `profiles.py` | 공정, 사용자 조건, 수치 검증, 미평가 제조 조건 |
| `orientation.py` | 적층 좌표, 하향면·바닥·빌드 공간, 6/최대12 방향의 비지배 대안 |
| `analysis.py` | 입력·프로필·측정·설계 조치·근거의 결과 조합. 점수 엔진 미사용 |
| `detail.py`, `detail_worker.py` | 제한된 법선 거리 표본, 기존 MEX 층 계산, 시간 초과와 결과 연결 |
| `comparison.py` | 동일 조건의 변경 전후 수치. 비교 불가 조건을 먼저 확인 |
| `gcode.py` | Marlin 계열 단일 공구 G0/G1 읽기, 후퇴/리셋, 지원 범위 밖 총량 보류 |
| `presentation.py` | 3D 위치 강조, HTML, 방향 STL. 사용자 문자열 HTML escape |

| `src/core/layer_*`, `sections.py` 등 | v2.6의 검증된 단면 동작과 부분 결과 계약 보존 |

## 정확히 측정하는 것과 근사하는 것

변환된 CAD 단일 솔리드의 체적·면적은 OCCT B-rep 적분값이다. 원통 지름·축은 해석적 곡면 파라미터다. 원본의 PMI, 공차, 작업자 의도, 내부 채널 연결, 관통/블라인드 홀 의미는 복원하지 않는다. CAD 면 번호는 해당 입력과 변환 결과에 대한 식별자이며 수정 전후에도 유지되는 설계 특징 ID라는 보장은 없다.

하향면·현재 방향 외곽·바닥 접촉은 삼각형 메시 기반이다. 선형 편차·각도 편차는 테셀레이션에 요청한 값이고 인증된 전체 편차 상한은 아니다. B-rep와 메시 체적의 차이는 국소 형상 오류의 상한도 아니다. 기준 각도 근처의 곡면은 테셀레이션에 민감하며 더 조밀한 메시가 임계값 집계 오차를 단조롭게 낮추지는 않는다.

구 r=10 mm, 수평 기준 45°의 이론적 하향 투영면적은 `π r² sin²45° = 157.0796 mm²`다. 이번 추가 진단에서 목표 편차 0.05/0.005/0.001 mm 메시의 결과는 156.1687/160.5022/158.6016 mm²였다. 상대차는 -0.58/+2.18/+0.97%였다. 이는 이 세 설정의 관측값이며 모든 형상에 적용할 오차 보증이 아니다. 방향 간 미세한 차이를 물리적 우열로 확대하지 않는다.

법선 관통거리는 표본 중심에서 안쪽 법선으로 보낸 첫 교차 거리다. 평행판 두께와 일치하는 반례를 시험한다. 비평행 곡면의 전역 최소 벽두께는 아니다. 최솟값·5백분위·유효/누락 표본·원본 면 번호·좌표를 보존한다. 여러 STL 표면 성분은 포함/교차 관계가 미확정이므로 벽 결과를 자동 확정하지 않는다.

## 상태 계약

- `attention`: 조치할 후보 또는 입력 조건 문제가 관측됨.
- `observed`: 측정값·입력 조건을 확인함. 제조 가능 PASS가 아님.
- `not_detected`: 명시된 검사 범위 안에서 후보 미검출. 전 영역 위험 없음이 아님.
- `unknown`: 미실행, 정보 부족, 실패, 자원 한도.
- `not_applicable`: 해당 공정에 적용하지 않는 항목.

JSON에서 계산할 수 없는 값은 `null`이다. G-code의 압출 경로가 실제로 0개인 경우의 지령량 0은 정당한 관측값이다. 지원하지 않는 명령이 있어서 일부만 읽었을 때는 전체 지령량을 0으로 채우지 않는다. 층 분석에서는 부분 합산과 전체 분모를 혼합하지 않는다.

## 시간과 자원

빠른 검토는 샘플 레이·전체 층·서포트 생성·열해석을 실행하지 않는다. CAD와 고비용 측정은 프로세스로 격리해 Python/네이티브 예외나 시간 초과가 UI 전체를 잃게 하지 않는다. 프로세스 시간과 입력/출력 크기는 제한하지만 운영체제 수준의 메모리 격리 한도를 설정한 것은 아니다. 600,000 면 가까운 최악 모델의 모든 조합을 벤치마크하지는 않았다.

한도 초과와 오류는 검사 미확정으로 보고한다. 이 상태를 제조 불가 또는 제조 가능으로 바꾸지 않는다. 로그와 최초 실패를 삭제해 성공한 재시험만 남기지 않는다.

## 버전과 보존

원본 `AM-DFM_v2_6.zip`의 계산 코드를 복사한 `src/`는 새 규칙의 근거 자체가 아니다. 새 기본 평가 경로는 `amdfm/`에 있으며 기존 점수·가중치·프로필 자동 판정은 여기서 호출하지 않는다. 기존 단면 엔진의 모든 문헌값을 새 공정의 표준값으로 주장하지 않는다.

기존 UI 회귀검사의 대상은 `run_legacy.py`로 이동했고, Windows에서 UTF-8 JSON을 읽는 한 검사의 인코딩을 명시했다. 기대값을 낮추거나 회귀검사를 삭제하지 않았다.
