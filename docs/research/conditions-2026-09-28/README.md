# 출처 기반 조건 DB 구축 — 2026-09-28

요청: 정확한 공통 조건 데이터베이스를 구축하고 현재 코드에 연결해 검사한다. 현재 승인 범위인 **적층제조와 CNC 고정축 밀링**에서 진행했다.

## 수록 범위

공식 자료 **35개 출처 카드(서로 다른 URL 33개)**에 연결한 **62개 조건 묶음 / 270개 항목**이다. 70개 항목은 계산 입력, 200개는 참고 전용이다. 자동으로 적용할 수 있는 조건 묶음은 44개이고 나머지 18개는 참고 자료다.

| 공정 | 조건 수 | 자동 연결하는 항목 |
|---|---:|---|
| MEX | 11 | 일부 장비 공간, 정확한 Prusa 프리셋의 층 높이·명목 선폭 |
| VPP | 8 | 일부 장비 공간, 정확한 수지·공정 시나리오의 층 높이 |
| 고분자 PBF | 9 | Fuse의 명시된 층 높이 |
| 금속 PBF | 5 | EOS M290의 특정 재료·파라미터 세트 층 높이 |
| CNC | 29 | 19개 정확한 공구 번호의 지름·절삭부 길이 |

분류별로는 장비 15, 공정 설정 16, 재료 12, 공구 19개다. 숫자가 같아도 제품·재료·판본이 다르면 동일 조건으로 합치지 않았다. 기존 **43 PDF / 928쪽**은 2026-09-21 전문 검토 기록과 현재 파일 SHA를 연결한 별도 검색 색인으로 편입했다. 이번 색인 작업을 928쪽 신규 전문 재독해라고 설명하지 않는다.

## 조사와 채택 기준

- 전용 딥서치 스킬은 이번 설치 목록에 없었다. 공식 웹 검색·제조사 원문·고정 Git 커밋·데이터시트 PDF의 표/도해 대조를 사용했다.
- [AM 출처 감사](AM_SOURCES.md): Prusa INI 상속과 정확한 노즐/재료 조합, Formlabs 조건부 설계 지침, EOS 공정별 데이터시트.
- [CNC 출처 감사](CNC_SOURCES.md): 개별 SKU와 제품군 표의 일치 여부, 공구 길이의 정의, 정확한 소재 조질/시험조건.
- 표준·논문은 고려사항과 검토 범위의 근거다. 이를 보편적인 벽 두께·각도·깊이비·출력 성공률로 변환하지 않았다.
- 현행 제품과 과거 판본을 구분하고, 발행판이 없는 웹 자료는 확인일을 남겼다. 확인일만으로 최신 사양을 인증하지 않는다.

## 중요한 제외 결정

- DATRON 0068080E의 개별 상세 `.8 mm`와 제품군/PDF `8 mm`가 충돌해 제외했다.
- Fuse의 둥근 챔버와 재료 수축 보정, EOS의 플랫폼 포함 높이를 단순 허용 박스로 자동 대입하지 않았다.
- Form 4의 벽 권장 경계에는 같은 값 이하의 변형 경고도 있어 일반 자동 합격 기준으로 쓰지 않았다.
- 수직/수평 벽, 특정 시험 보의 각도, 소재 시험편 강도는 해당 조건의 참고값으로 보존했다.
- 공구 전체 길이·카탈로그 L3와 장착 후 돌출 길이를 구분했다. CNC 장비 이동량도 실제 가공 가능한 부품 공간과 구분했다.

## 코드 연결

`dfm/conditions.py`는 출처·단위·공정·값의 성격을 검사하고 허용된 필드만 엔진에 전달한다. 원문 값, 정규화한 실제 입력, 사용자 수정, 원자료에 없는 탐색값, 전체 입력 스냅샷, DB SHA를 보관한다. `amdfm/Profile`과 `MachiningProfile`의 출처 문맥을 결과 JSON/HTML까지 유지한다.

`dfm/conditions_view.py`는 미리보기와 적용을 분리한다. 새 시나리오가 이전의 벽·공구·돌출 기준을 물려받지 않도록 초기화한다. 장비 공간 제한은 자동으로 켜지지 않는다. 자료 변경 후에는 재적용을 요구한다. 조건과 입력값은 사용자 컴퓨터의 로컬 앱에서 처리하며 API 키나 외부 AI 호출은 추가하지 않았다.

사용법은 [조건 라이브러리 안내](../../CONDITION_LIBRARY.md), 자료 추가 규칙은 [데이터 구조](../../../data/conditions/README.md)에 있다. 테스트 기록은 [검증 폴더](../../../validation/conditions-2026-09-28/)와 [프로젝트 인수 기록](../../project-knowledge/CONDITION_DATABASE_2026-09-28.md)을 따른다.

## 미완료 범위

전 세계 모든 장비·재료·공구의 수록, 자동 슬라이서/CAM 실행, 강도·열변형·홀더 충돌·고정구 해석, 실제 제조 성공 확률은 이번 구현 범위가 아니다. 이번 DB는 확장 가능한 첫 검증 판이며, 현재 계산이 해석할 수 있는 항목과 참고 자료를 분리해 제공한다. 사출·프레스는 추가하지 않았다.
