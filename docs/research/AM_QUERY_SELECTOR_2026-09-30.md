# 적층 방향 제안: 새 regret 학습과 정확 기하 결합의 비교

2026-09-30. 이 문서는 적층 방향 제안 실험과 저장된 측정값의 실제 추천 코드 재생 결과를 기록한다. 제품 연결·바탕화면 배포의 완료 상태는 프로젝트의 통합 검증 기록을 따른다.

## 판단

**제품 연결 후보는 기존 신경망의 하향면 예측에 정확히 계산한 높이·바닥 접촉 면적을 결합하는 경로다.** 기존 26방향과 학습 제안 18개를 유지하고, 마지막 추가 6개를 선택하는 부분만 바꾼다. 선택한 방향의 결과 수치는 기존 기하 계산기로 다시 측정한다.

별도로 새 순위 앙상블을 실제 학습했지만, 이 결합 경로보다 성능이 낮아 새 가중치는 제품에 채택하지 않는다. 모델 파일·최초 실패·불리한 결과를 모두 보존한다.

**신경망의 추가 기여를 과장하지 않는다.** 실제 종합 추천 결과에서 결합 경로와 기하 계산만 사용하는 대조의 평균 차이는 -0.000656이지만, 그룹 bootstrap 95% 구간은 [-0.001980, +0.000549]로 0을 포함한다. 기존 검색보다 개선됐다는 결과와, 기하 계산 대비 신경망의 독립적인 우위가 확실하다는 주장은 다르다. 고분자 PBF의 이번 최종 선택은 정확 높이만 사용한다.

## 데이터와 학습

새 다운로드 없이 기존 공개 원본 DB를 사용했다. 원본 좌표를 중심 이동·최대 크기 100으로 정규화하고, 원본 ID의 해시로 고정된 회전을 적용했다. 같은 원본의 방향별 표본은 분할을 넘지 않는다.

| 원본 자료 | 가중치 학습 | 정책 선택 validation | 새 보류 test |
|---|---:|---:|---:|
| PBF-orientation | 100 | 15 | 25 |
| CadQuarry | 100 | 15 | 25 |
| Thingi10K | 100 | 15 | 8 |
| 합계: 원본 그룹 | 300 | 45 | 58 |

- 학습 후보·공정 사례 601,855개, validation 후보·공정 사례 90,250개다. 이를 서로 다른 부품 수로 부르지 않는다.
- 이전 공개·전수·잔차 검색 시험에 등장한 182개 그룹을 제외했다. Thingi10K에서 남은 적격 보류 그룹은 8개였다.
- 선택된 403개 원본 기록의 DB 바이트 SHA를 다시 계산했다. 색인과 불일치 0, 원본 그룹/SHA의 분할 교차 0, 이전 benchmark 그룹 겹침 0이다. 회전·근사 복제까지 완전히 독립임을 증명한 것은 아니다.
- 403개 모두 유한한 좌표, 닫힌 양의 체적, 일관된 면 방향 조건을 통과했다. 가장 큰 메시가 96,042면이며 실험 상한은 100,000면이다.
- 형상마다 MEX 균형·MEX 하향면 우선·VPP 균형·금속 PBF 균형·고분자 PBF 높이 우선의 5조건을 사용했다. 탐색 각도 45°, 빌드 공간 제한 없음이다.

새 모델은 원본 그룹 단위 bootstrap을 사용하는 HistGradientBoostingRegressor 3개다. 각 모델은 180개 트리, 최대 잎 31개, 학습률 0.06이다. 입력은 26방향 측정, 후보 방향, 기존 신경망 예측, 원본 꼭짓점의 convex hull로 계산한 높이와 평면 접촉이다. 정답은 공통 후보들의 실제 기하 측정으로 계산한 공개된 `.7 × 최악 상대값 + .3 × 가중 평균` 정책의 후보 regret다. 외부 전문가의 개선안 정답 라벨은 아니다.

학습 136초, 원본으로부터 표적 준비 154초. 내보낸 JSON과 학습기의 예측 차이 최대 0, 준비 단계의 독립 기하 대조 오차 최대 2.91e-16이다. 불확실성은 앙상블 예측의 표준편차를 이용한 탐색 지표이며 확률로 해석하지 않는다.

## 같은 추가 6회에서의 비교

모든 경우에 기존 측정 26+18개가 같고, 각 방법이 선택한 방향은 6회씩 `measure_orientation`으로 다시 측정했다. 384개 구면 방향·최대 24개 면 방향에 기존 v4의 연속 방향 제안을 합친 뒤 기측정 방향을 제외했다. 실제 공통 후보 수는 381~402개다.

| 방법 | 후보를 고르는 정보 |
|---|---|
| legacy | 기존 v4 신경망의 높이·하향면 예측 및 연속 탐색 |
| blind | 공통 후보에서 등간격으로 6개 선택 |
| geometric | 정확 높이·접촉 면적, 하향면 예측 없음 |
| height_neural | 정확 높이·접촉 면적 + 기존 v4 하향면 예측 |
| uncertainty05 | 새 regret 앙상블의 평균 - 0.5 × 표준편차 |

greedy·불확실성 0.5·불확실성 1·기존 제안 2개 유지의 네 학습 정책을 validation에서 비교하고 uncertainty05를 고정했다. 제품 검토 후보 height_neural과 적용 범위도 test 결과를 보기 전에 별도 JSON에 고정했다. test를 이용한 재학습·정책 재선택은 하지 않았다.

**6회가 같다는 것은 전체 계산량이 같다는 뜻이 아니다.** 결합 경로는 공통 후보 전체의 정확 높이·접촉도 계산한다. 이 비용과 공통 후보의 연속 탐색 생성 비용을 모두 시간에 포함했다. 보류 시험의 마지막 6개 경로 시간 중앙값은 legacy 0.634초, geometric 0.671초, height_neural 0.673초, 새 앙상블 0.898초다. 기존 26+18개 준비 시간은 이 값에 포함되지 않는다.

## 후보 품질과 실제 최종 선택

최초 평가는 각 방법의 측정 후보 중 가장 좋은 값을 비교했다. 이 결과를 실제 제품이 선택한 결과로 부르지 않는다. 독립 감사에서 validation의 학습 정책 4개와 test의 선택 정책 1개 때문에 정규화 합집합이 달라진다는 점도 확인했다.

따라서 원래 기록을 보존하고, 양 분할 모두 **기존 44개 + 고정된 네 대조 방법**으로 동일한 참조 집합을 만든 추가 분석을 수행했다. 참조 범위를 넘는 값은 잘라내지 않았다. 후보의 최선값, 각 방법의 자체 후보 집합으로 실제 `enhanced_planning.recommend_plan`이 고른 값, 공통 참조로 `verified_selection.arbitrate`가 고른 값을 분리했다.

아래는 실제 제품 추천 함수가 자체 후보 집합으로 정규화해 고른 방향을 공통 참조에서 평가한 **58개 원본·290조건**의 결과다. 점수 차이는 dimensionless 정책 손실 차이이며 정확도 백분율이 아니다. 음수가 개선이다.

| height_neural 대조 | 개선 | 동일 | 악화 | 평균 차이 | 원본 그룹 bootstrap 95% 구간 |
|---|---:|---:|---:|---:|---|
| 기존 legacy | 48 | 240 | 2 | -0.005392 | [-0.010894, -0.001440] |
| blind | 58 | 227 | 5 | -0.005706 | [-0.011218, -0.001887] |
| geometric | 38 | 240 | 12 | -0.000656 | [-0.001980, +0.000549] |

새 uncertainty05 앙상블은 height_neural보다 개선 11·동일 255·악화 24였다. 평균 차이 +0.002328, 95% 구간 [+0.000040, +0.006201]로 더 나빴다. 새 가중치의 미채택 이유다.

| 공정: legacy 대비 실제 추천 | 조건 수 | 개선 | 동일 | 악화 |
|---|---:|---:|---:|---:|
| MEX: 균형·하향면 우선 | 116 | 20 | 94 | 2 |
| VPP | 58 | 11 | 47 | 0 |
| 금속 PBF | 58 | 11 | 47 | 0 |
| 고분자 PBF | 58 | 6 | 52 | 0 |

VPP와 금속 PBF는 이번 방향 목적함수의 기하 항목이 같아 같은 결과가 나왔다. 서로 독립된 물리 검증 두 개로 세지 않는다. 신뢰구간은 290조건을 독립 표본으로 보지 않고 58개 원본 그룹을 4,000회 재추출했다.

legacy보다 악화된 실제 추천 두 사례는 모두 MEX 하향면 우선이다. Thingi10K `58938`의 차이 +0.005972, CadQuarry `threaded_462c9ef8_0836`의 차이 +0.000065다. 원자료와 선택 방향을 보존했다. test의 독립 높이·하향면·접촉 대조 최대 오차는 3.33e-16이다.

실제 추천 함수 재생은 저장된 방향 측정값, 빈 국소 findings, +Z 현재 방향, 사용자 선호 잔차가 없는 상태다. 전체 CAD 입력·화면·벽/구멍 수정 흐름을 시험한 것으로 확대하지 않는다.

## 제품 연결 인터페이스와 범위

`amdfm.geometry_guided_search.rank_geometry_guided_queries`는 공통 후보 방향에서 여섯 개를 반환한다. 호출자는 기존 26+18개를 보존하고 반환 방향을 다시 측정해야 한다. 원본 3그룹·5조건·current_only 유무의 30경우에서 기존 26기반 풀을 사후 필터링한 결과와 44기반 풀을 사후 필터링한 결과가 일치했다. **current_only를 포함한 모든 기측정 방향을 풀 생성 뒤에도 제외해야 한다.** descriptor는 항상 named26이다.

다음 범위 밖에서는 `None`을 반환해 기존 정책으로 돌아간다.

- 검증된 45°·5공정/중점 조합, 6회 예산, 고정 v4 모델 SHA.
- 빌드 공간 미지정. 장비의 빌드 제한이 있으면 기존 경로를 유지한다.
- 100,000면 이하, 신뢰 가능한 법선·닫힌 양의 체적, 현재 메시와 descriptor 면적·대각선 일치.
- 시간 제한 전후 검사. hull 계산 자체는 도중 중단되지 않으므로 호출자의 남은 시간 확인도 필요하다.

고분자 PBF는 높이만 비교하므로 선택 단계의 `learned_component`가 `None`이다. 이 개선을 새 신경망 가중치의 성과로 설명하지 않는다.

새 연구 모델 SHA256은 `20e02474872a7511cd40f6b19edd407d41b9d8173e81cd0ee41bed22202abf4a`. 기존 v4 SHA256은 `68ec8e2b1fd7c4ce13cc3ee669f75c2d6e91e599fdb095e0e6c93ef4e52ccd64`이며 기존 가중치는 바꾸지 않았다.

다음 학습에서는 후보 자체의 좋은 점수보다 **이미 측정한 44개와 중복되지 않으면서 추가 6회로 얻는 개선량**을 목표로 삼는 것이 적절하다. 이번 모델은 후보 자체의 평균 품질은 좋았지만 기존 후보 집합에 추가했을 때의 실익이 작았다. 이 후속 개발은 이번 test를 다시 학습·정책 선택에 사용하지 않는 새 실험으로 진행해야 한다.
