# 절삭 DFM 실무·공정 물리 문헌 조사

조회일: 2026-09-20. 현재 고정축 밀링·홀 검토의 개발 근거를 보강하는 조사다. 사출·프레스는 범위에 포함하지 않는다. 기능 코드와 기존 검증 결과는 수정하지 않았다.

기계 판독 목록은 [process.json](process.json)이다. 16건 중 5건은 기존 문서/코드 근거를 다시 확인했고, 11건은 이번에 보강했다. 학술 자료 5건 중 3건은 공개 원문에서 방법·시험·한계와 표/그림을 선별 확인했다. 나머지 2건은 저자/소속기관의 서지·초록 수준이며, 아래에서 이를 명확히 구분한다.

## 무엇을 구현할 근거가 보강되었나

핵심 결론은 **가공 가능/불가능 하나의 점수보다, 특정 공구·셋업에서 필요한 조건과 추가 작업을 알려주는 구조가 타당하다**는 것이다. 형상만으로 비교할 수 있는 것과 실제 절삭 조건이 있어야 판단할 수 있는 것을 나누어야 한다.

| 검토 내용 | 문헌 | 개발자가 적용할 방식 | 추가 입력 없이는 확정할 수 없는 것 |

| 내부 코너·포켓 폭 | P01, P02, P04 | 선택 공구 단면과 실제 국소 치수를 비교하고 다른 공구/반경/경로 제시 | 절삭력·진동·공구 수명 |

## 같은 L/D라도 서로 다른 값이다

아래 수치를 한 개의 '깊이비 기준'으로 합치면 오판한다.

| 값 | 정확히 구분할 대상 | 근거와 적용 제한 |
|---|---|---|
| D≤2R | 공구축과 평행한 오목 원통 코너와 이상적인 원통형 공구의 옆날 | 자체 원 단면 기하 필요조건. 바닥-벽의 직각이나 공정 전체의 충분조건으로 일반화하지 않는다. |
| D≤1.5R | 코너 최종가공에 대한 제조사 공구 선택 권고 | P01. 기하적으로 가능해도 물림을 줄이려는 권고이며 보편 불가 경계가 아니다. |
| >4D | 밀링 공구의 **장착 돌출 길이/공구 지름**과 진동 경향 | P07. 홀 깊이/홀 지름이 아니다. 감쇠·홀더·물림·장비 조건을 빼면 채터 한계가 되지 않는다. |
| >6D | Protolabs가 보간 가공하는 홀의 깊이/홀 지름 | P04. 전용 드릴이나 양면 작업이 필요해질 수 있는 서비스 조건이다. |
| >3D 내부 냉각 선호 | 드릴링 깊이/드릴 절삭 지름 | P06. 칩 배출을 위한 적용 권고이며 이 깊이부터 절삭이 불가능하다는 뜻이 아니다. |
| 70% | 나사밀 지름/나사 지름 | P09. 나사 윤곽 편차 감소 권고다. 일반 홀·엔드밀 조건이 아니다. |
| 원통면 V구간/D | 현재 앱이 측정하는 CAD 원통면의 축 방향 구간/지름 | 실제 입구부터 드릴 끝까지의 가공 깊이, 나사 유효 길이, 공구 돌출과 같다고 보장되지 않는다. |

길이를 표기할 때 최소한 **측정 시작점과 끝점, 분모의 지름, 공구 종류, 가공 방법**을 보여줘야 한다. 샹크 아래 길이 LBS는 감소 목부의 시작점부터 절삭 끝까지이며 목부만의 길이 또는 장착한 공구 끝~홀더 앞면 거리와 다르다. '긴 공구로 바꾸기'가 항상 개선도 아니다. 가공 깊이를 나누거나 감소 목부를 쓰는 대안은 절삭날 길이와 전체 돌출을 분리해야 제대로 설명된다. 이는 [Harvey의 공구 치수 정의(P03)](https://www.harveyperformance.com/in-the-loupe/end-mill-anatomy/)와 [Autodesk의 샤프트·홀더 검사(P05)](https://help.autodesk.com/cloudhelp/ENU/Fusion-CAM/files/GUIDD505C759-C325-4C99-BBDD-35FE39B3761F.htm)에 따른 개발 해석이다.

## 원문까지 본 연구가 요구하는 조건

- **P14 — Zeng·Teramoto·Matsumoto (2021)**: [원문 PDF](https://www.jstage.jst.go.jp/article/ijat/15/6/15_860/_pdf), *International Journal of Automation Technology* 15(6), 860–867, DOI 10.20965/ijat.2021.p0860. 알루미늄 A2017 고정 실험과 FEM을 연결한다. 논문 p.864의 표·사진을 직접 확인했고 마찰계수·고정력·고정 순서는 해당 사례 조건이다. §4에서 고정력 추정 평균 편차는 10% 미만이지만 변형 추정 평균 차이는 약 22%라고 보고한다. 국소 변형률 측정이 있는 연구이므로 '장비 없이 CAD만으로 이 정확도를 얻는다'는 근거가 아니다.
- **P15 — Teramoto (2017)**: [원문 PDF](https://www.jstage.jst.go.jp/article/ijat/11/6/11_978/_pdf/-char/en), 같은 학술지 11(6), 978–983, DOI 10.20965/ijat.2017.p0978. F=KU 탄성 관계에 국소 측정으로 추정한 경계조건을 결합한다. 다점·바이스 고정의 사례를 확인했다. 공작물의 정적 고정 변형과 절삭 중 힘/채터는 별도 문제다.
- **P16 — Sun 외 (2021), 공개 원고 v2**: [arXiv](https://arxiv.org/abs/2106.09719v2), DOI 10.48550/arXiv.2106.09719. 특정 장비·제어기의 실제 이송을 학습하여 시간을 예측한다. §3의 장비 조건, §4의 학습/검증 구분과 표 4를 확인했다. 결과표에는 학습에 쓴 포켓도 있으므로 전체 표의 작은 오차를 새 부품·새 장비 검증으로 읽으면 안 된다. 시간 오차와 제조 성공 확률은 다른 지표다.

**P12 — Altintas·Budak (1995)**, DOI 10.1016/S0007-8506(07)62342-7은 저자가 공개한 페이지의 초록으로 FRF·절삭계수·물림·날 수라는 필요 입력을 확인했다. **P13 — Budak (2006)**, DOI 10.1016/j.ijmachtools.2005.09.009은 소속대학 저장소의 초록/서지를 확인했다. 두 자료의 세부 수식을 구현 근거로 사용할 때는 원문과 적용 가정을 다시 확보해야 한다. 초록에 적힌 실험 검증을 우리 구현 검증으로 대신하지 않는다.

## 공급자 문서도 비판적으로 읽어야 한다

1. **문서 제목의 경고가 물리적 불가능을 뜻하지 않을 수 있다.** Protolabs Network의 [Resolve DFM warnings](https://www.hubs.com/help-center/reviewing-dfm-warnings/)를 직접 열어 CNC 절을 확인했다. 이 서비스는 'Un-machinable' 경고가 있어도 일반적으로 가공은 가능하되 가격에 영향이 있을 수 있다고 설명한다. 우리 UI는 같은 모호한 명칭을 복제하지 말고 공구 치수 조건, 추가 셋업, 비용·품질 확인을 구분해야 한다.
2. **기존 CNC_CORNER 링크는 재조회가 완료되지 않았다.** `https://www.hubs.com/knowledge-base/sharp-corners-in-cnc-machining/`는 직접 열기 두 번 모두 타임아웃이었다. 검색 색인에는 내용이 나타나지만 이번 직접 본문 확인과 구분한다. 현재 설명의 재확인 근거는 P01/P04다. 타임아웃만으로 문서가 삭제되었다고 판단하거나 임의 대체 URL을 만들어 넣지 않는다.
3. **지역·서비스 판본이 다르다.** 코드의 영국판 Protolabs toolkit(P04)은 0.5–1 mm 벽 관련 문구와 조건별 세장비를 제시한다. 미국판 검색 색인에는 최소 두께와 ±공차 표현이 섞인 다른 문구가 나타났다. 이번에는 영국판 직접 본문을 기준으로 썼고 미국판 색인의 모호한 수치는 규칙 후보에서 제외했다. 웹사이트의 모든 숫자가 정규화된 규칙 데이터인 것은 아니다.
4. **기계역학 용어를 그대로 복사하지 않는다.** Carr Lane(P11)은 각 축 이동의 양·음 방향을 따로 세는 설명에서 '12 degrees of freedom'을 사용한다. 앱의 독립 강체 자유도는 3병진+3회전의 6개로 설명하고, 한쪽 방향의 접촉 구속과 구분해야 한다. 이 용어 차이를 이유로 실무 고정 지침 전체를 버릴 필요는 없지만, 그대로 물리 모델의 자유도 수로 쓰면 안 된다.
5. **서비스 수치와 조립 기능 요구가 충돌하면 기능을 우선 확인한다.** 나사 길이를 짧게 하는 견적 권고가 있어도 재료·하중·피로·체결 규격 없이 유효 나사를 자동 삭제하지 않는다. 버 제거를 기본 서비스로 제공한다고 해서 기능적 모서리의 형상·공차 요구를 지워도 되는 것은 아니다. P09/P10의 적용 범위에 따른 개발 판단이다.

## 다음 구현 순서에 대한 제안

문헌을 추가하는 것과 기능을 당장 구현하는 것을 분리한다.

1. **기존 기능과 직접 연결**: 공구 형식과 길이 정의, 실제 홀 깊이/원통면 구간의 구분, 항목별 기하 필요조건·공급자 권고·미확정을 명시한다.
2. **검증 가능한 기하 확장**: 공구 어셈블리·원소재·클램프를 입력받아 고정축에서 유한 공구 간섭과 경로 후보를 CAM 결과와 대조한다. 소재명 입력만으로 힘·처짐이 계산되는 것처럼 보이지 않게 한다.
3. **제조 의도 입력**: 나사·공차·표면/모서리 요구·공정 순서를 구조화한다. STEP이 그 정보를 포함하는 것과 현재 파서가 읽는 것은 구분한다.
4. **물리 모델은 조건별로 도입**: 박벽/공구 처짐에는 힘·물성·구속과 허용 오차가, 채터에는 동특성이 필요하다. 외부 실험 데이터나 검증된 조건을 확보한 한정 프로필부터 비교하며 미확정 범위를 유지한다.
5. **원가는 근거별로 분리**: 작업 추가 이유와 상대적 비용 요인은 먼저 설명할 수 있다. 화폐 단위 견적이나 확정 시간은 실제 CAM 경로, 장비와 셋업/공구/검사/수량 데이터가 확보된 뒤 검증한다.

## 접근 기록과 남은 범위

- 원문 보관·렌더 경로: 저장소 옆 `study/machining-literature-2026-09-20/process/`. Zeng 2021, Teramoto 2017, Sun 2021 PDF와 읽은 표/그림의 페이지 렌더를 보존했다. 다운로드 성공과 실제 읽은 범위는 같지 않으므로 JSON의 `reviewed_sections`를 따른다.
- PDF 렌더 중 Poppler가 일부 폰트 경고를 냈으나 검토한 표/그림 페이지는 시각적으로 읽을 수 있었다. 웹 도구의 Altintas 1995 PDF 스크린샷은 이미지 내용이 모델에 전달되지 않아 시각 확인으로 세지 않았다. 직접 다운로드 403도 보존한다.
- Wang 외 2015, *FEM-Based Simulation for Workpiece Deformation in Thin-Wall Milling*, DOI 10.20965/ijat.2015.p0122는 출판사 서지·초록을 확인했으나 PDF 접근에 회원 절차가 있어 주요 16건에 중복 확장하지 않았다. 원문을 읽은 것으로 기록하지 않는다.
- MDPI 2025, DOI 10.3390/jmmp9050146과 ScienceDirect 일부 논문은 직접 열기 429/403 또는 접근 실패였다. 검색의 요약을 원문 검토로 승격하지 않았다.
- 이 목록은 밀링·홀·고정·설계 의도 중심이다. 선삭/보링/리밍/연삭, 전용 깊은 홀 공정, 버 발생의 정량 역학, 실제 툴 수명·가공시간의 여러 장비 외부 검증까지 망라했다는 뜻이 아니다. 그 기능을 구현할 때 해당 공구·공정 원문을 추가 확보한다.
- 원문 저작권을 가진 논문·가이드 전체를 보고서에 전사하거나 저장소 공개 배포용으로 복제하지 않는다. 사용자 전달 문서에는 자체 요약·서지·원문 링크와 실제 검토 범위를 싣는다.
