# 절삭 DFM를 위한 표준·제품정의·검증 문헌 조사

조사일: 2026-09-20. 범위: 절삭가공 제조성 검토의 입력 의미, 공구 데이터, 공차·표면 요구, 장비 및 검사 검증. 사출·프레스는 조사·구현 범위에서 제외했다. 앱 코드는 변경하지 않았다.

이 파일은 `standards.json`의 S01–S18 레코드를 해설한다. **18개 조사 레코드이며, ISO 286의 2부와 ISO 21920의 3부는 각각 묶음으로 정리했다.** 이 숫자를 서로 다른 단일 표준 18권으로 해석하면 안 된다.

## 이번 조사에서 가장 중요한 판단

현재 툴에서 먼저 확장할 것은 “공차와 공정의 통과 기준을 더 많이 넣기”보다 **어떤 형상을 읽었고, 어떤 요구사항이 입력되었으며, 어느 정보가 없는지 구분하는 체계**다. 이는 조사 내용을 바탕으로 한 개발 판단이다.

예를 들어 툴이 STEP의 원통에서 지름 10 mm를 계산했다고 해서 설계자가 10 H7을 요구했다는 뜻은 아니다. 또한 화면에 “10 H7” 주석이 그려져 있어도 그 주석이 계산 가능한 PMI와 연결되어 있는지는 별도로 확인해야 한다. AP242는 이런 정보를 담을 수 있으나 모든 파일에 반드시 담는다는 뜻이 아니다. [S01 공식 범위](https://www.iso.org/standard/84300.html), [S02 NIST 원문 §6.1·§6.2](https://doi.org/10.6028/NIST.AMS.200-12)

### 사용자가 읽을 수 있는 결과 구조로 바꾸면

아래는 표준의 직접 인용이 아니라 이 툴에 대한 구현 제안이다.

| 구분 | 화면에 보여줄 예 | 필요한 근거 |
|---|---|---|
| 읽은 형상 | “CAD 공칭 구멍 지름 10 mm” | 실제 형상 엔티티, 단위, 계산 방법 |
| 설계 요구 | “이 면의 표면 요구 또는 공차 정보 없음” | PMI·도면의 정보 유무와 가져오기 지원 범위 |
| 기하 조건 | “선택 공구와 반지름/폭 비교 완료” | 공구 형상과 치수 |
| 공정 수행 가능성 | “공구·홀더·지그와 경로 확인 필요” | 전체 조립과 경로, 장비 조건 |
| 완성품 적합성 | “실물 측정 데이터 없음” | 실제 측정값, 불확도, 설계 요구 |

이 다섯 상태는 하나의 초록색 “제조 가능”으로 합치지 않는다. 공칭 CAD를 얼마나 정확히 읽었는지와 실제 부품이 공차를 만족하는지는 다른 검증 과제다.

## 1. CAD/PMI: 장비 없이도 검증할 수 있는 우선순위

S01과 S02를 먼저 적용하면 “형상 측정 기능”에서 “설계 요구를 읽는 제조성 검토”로 넘어가는 기반을 만들 수 있다. NIST 문서는 관련 절의 공개 원문을 직접 열람했다. ISO AP242는 카탈로그의 범위와 상태를 확인했으며 유료 전체 본문을 읽었다고 주장하지 않는다.

NIST 원문 §6.1은 의미 PMI를, §6.2는 그래픽 PMI를 구분한다. §6.1.3은 치수의 유형·값·상하한·대상 형상 연결을 설명하고, §6.1.7 및 §6.6.1은 기대되는 주석과 검출 결과를 대조하는 검증 방향을 제공한다. 현재2021 문서의 설치 안내가 최신 프로그램 동작과 같다고 가정하지 말고 실제 도구 버전을 별도로 고정한다. [S02 원문](https://doi.org/10.6028/NIST.AMS.200-12), [현재 도구 공식 페이지](https://www.nist.gov/services-resources/software/step-file-analyzer-and-viewer)

권장 검증 과제는 자체 설계 제안이다.

1. 같은 형상의 PMI 포함 STEP과 형상만 있는 STEP을 함께 준비한다.
2. “치수 있음/없음”, “의미 PMI/그래픽 주석만 있음”, “대상 면 연결 성공/실패”를 독립 상태로 기록한다.
3. 단위가 다른 모델, 면이 나뉘어 내보내진 모델, 이름이 없는 면, 누락된 주석을 포함해 검증한다.
4. 가져온 공차를 해당 면에 표시하고 원본 엔티티 ID를 보고서에 남긴다.
5. 읽지 못한 요구는 삭제하거나0으로 채우지 않고 “미지원/연결 실패”로 보존한다.

## 2. 공차: 정의 표준과 가공 능력을 분리해야 한다

S03–S09, S16은 주로 요구사항을 정확히 표현하고 해석하는 체계다. **가공업체나 장비가 그 요구를 달성하는지 알려주는 보편적인 공정 능력 표가 아니다.** 공구가 들어가는지는 기하 검토이고, 지정 공차를 반복적으로 만족하는지는 재료·장비·공구·경로·고정·측정이 함께 필요한 다른 문제다.

- S03 ISO8015: 적용할 GPS 체계를 명시하는 기반.
- S04 ISO1101: 공차 종류·대상·기준·수식어를 누락하지 않는 구조.
- S05 ISO5459: CAD 좌표계, 설계 데이텀계, 실제 가공 셋업을 구분하는 기준.
- S06 ISO14405-1: 무엇의 “크기”를 지정했는지 확인하는 기준.
- S07 ISO286: 명시된 끼워맞춤/치수공차 기호를 해석할 때 필요한 체계.
- S08 ISO2768-1와 S09 ISO22081: 일반 요구의 적용 여부·범위·판을 명시적으로 처리.
- S16 ASMEY14.5: ASME 기반 도면을 지원할 때 별도 해석 체계로 관리.

위 적용은 개발 판단이며 세부 표준 조항의 완전한 구현 설명이 아니다. 전체 본문을 확보하기 전에는 공차표·기본 해석·수식어 계산을 추정하여 코드로 넣지 않는 것이 타당하다. 공식 적용 범위는 각 S레코드에 연결되어 있다.

사용자 경험 측면에서는 처음부터 “ISO/ASME 조항을 고르세요”라는 복잡한 입력보다, **“도면/PMI에 공차가 있나요 → 어떤 규격을 지정했나요 → 읽은 요구를 확인하세요”**라는 순서가 알맞다. 값이 없는 경우에는 기하 검토를 계속할 수 있지만 공차 만족 여부만 미평가로 표시한다.

## 3. 표면 요구: Ra 숫자만으로 판정하지 않는다

S10의3부는 표시, 매개변수 정의, 평가 연산의 역할을 나눈다. 개발 시에는 대상 면·요구값·단위·평가 조건·규격 판을 함께 보관하는 것이 타당하다. 매끈한 CAD 면이나 삼각 메시 해상도는 실제 절삭된 표면의 거칠기가 아니다. [ISO21920-1](https://www.iso.org/standard/72196.html), [ISO21920-2](https://www.iso.org/standard/72226.html), [ISO21920-3](https://www.iso.org/standard/72228.html)

특정 자료의 “통상 Ra3.2” 같은 값은 해당 공정·장비·조건의 정보로 취급해야 한다. 표준이 모든 재료와 형상에3.2µm를 가공 가능/불가능 경계로 지정했다고 설명하면 안 된다. 현 단계 권고는 요구의 정확한 수집과 필요한 후속 가공·검증 안내이며, 정량 거칠기 예측은 공정 데이터나 검증된 물리 모델을 별도로 확보한 뒤의 기능이다.

## 4. 공구: 현재 길이 비교를 실제 공구 조립으로 확장

S11 ISO13399-1은 공구 데이터와 관계를 교환하는 정보 모델의 근거다. 제조사의 치수 기호를 표준 사전과 대조하면 공구 라이브러리 입력 실수를 줄이는 방향으로 활용할 수 있다. 단, 이번에는1부 카탈로그를 확인했으므로 특정 속성 코드나 모든 하위부를 구현할 만큼 원문을 확보했다고 해석하지 않는다. [ISO13399-1](https://www.iso.org/standard/36757.html)

개발 제안은 다음과 같다.

- 공구 날 길이, 섕크 지름, 전체 길이, 목 아래 길이, 실제 장착 돌출 길이를 각각 저장한다.
- 공구 상품번호와 제조사 데이터 버전을 기록한다.
- 실제 공구·홀더 조립 형상으로 도달 및 충돌 검토를 확장한다.
- 필요한 값이 없을 때는 길이 하나를 다른 길이로 대체하지 않는다.

표준 데이터 형식은 물리적으로 좋은 절삭 조건을 보증하지 않는다. 강성·진동·마모·칩 배출의 조건은 별도 연구 문헌과 실제 조건 데이터가 필요하다.

## 5. 정확성: 수치 오차, 측정불확도, 공정 변동을 구분

아래는 서로 다른 의미다.

| 항목 | 이 툴의 예 | 근거 체계 |
|---|---|---|
| 수치 오차 | 회전 후8mm가8.000000000000675로 계산됨 | 알고리즘·부동소수점·CAD 커널 검증 |
| 형상 표현 차이 | 메시 근사와 B-rep의 차이 | 테셀레이션 설정·수렴·독립 치수 대조 |
| 측정불확도 | 실물 CMM 결과를 얼마나 확실히 아는가 | S14·S15와 실제 측정 자료 |
| 공정 변동 | 같은 조건으로 반복 가공했을 때 부품이 얼마나 달라지는가 | 반복 실물 자료와 공정 모델 |
| 설계 허용공차 | 부품이 만족해야 하는 상·하한이나 공차역 | 도면·PMI, S03–S10·S16 |

S14 ISO14253-1은 측정불확도를 고려한 규격 적합/부적합 판정의 표준이며, S15 ISO15530-3은 교정된 시편 등을 이용한 CMM 측정불확도 평가의 범위다. 코드의 작은 수치 비교대를 이들 표준의 인증된 가드밴드로 부르거나 제조 성공 확률로 바꾸면 안 된다. 기본 확률값과 상세 산식을 이번 카탈로그 조사로 확인한 것은 아니다. [ISO14253-1](https://www.iso.org/standard/70137.html), [ISO15530-3](https://www.iso.org/standard/53627.html)

S12 ISO230-2는 개별 기계축의 위치 정확도·반복성을, S13 ISO10791-7은 정삭 시험편의 절삭 정확도를 다룬다. 따라서 장비 카탈로그의 반복정밀도1개를 그대로 임의 부품의 허용공차로 옮기는 방법은 부적절하다. 장비가 없는 현재에는 외부 시험성적서·공개 실물 측정 자료를 평가할 때 어떤 조건을 요청해야 하는지 설계하는 데 사용한다. [ISO230-2](https://www.iso.org/standard/55295.html), [ISO10791-7](https://www.iso.org/standard/73814.html)

## 6. 확보·구현 순서

**P0는 즉시 필요한 개념·입력·검증 구조, P1은 기능 확장 시 읽어야 할 규범 원문, P2는 외부 장비/실측 자료가 있어야 실질적으로 적용할 수 있는 검증이다.** 우선순위는 표준의 공식 등급이 아니라 프로젝트 판단이다.

| 순서 | 문헌 | 구체적 산출 |
|---|---|---|
| P0 | S01·S02 | 형상/PMI/주석/미지원 정보 수준과 독립 PMI 검증 계획 |
| P0 | S11 | 공구 길이·조립 상태의 명확한 데이터 사전 |
| P0 | S14 | “수치 경계”를 실물 적합성으로 확대하지 않는 결과 구조 |
| P1 | S03–S09·S16 | 적용 규격/판과 공차·데이텀의 구조화; 원문 확보 후 지원 조항을 제한하여 구현 |
| P1 | S10 | 면별 표면 요구 입력 및 조건 누락 표시 |
| P1 | S17·S18 | 모델/주석/도면/개정의 연결과 추적성 |
| P2 | S12–S15 | 외부 장비 시험·실측 데이터의 적합성 및 불확도 검증 |

장비가 없어도 P0와 상당수 P1의 **입력·해석·검증 기반**은 만들 수 있다. 실물 증거가 필요한 부분을 숫자로 채우는 대신, 어떤 증거가 들어오면 어떤 결론을 낼 수 있는지 구조를 먼저 완성하는 것이 목표다.

## 원문 확보 수준과 조사 한계

- ISO 및 ASME 규정 본문을 무단 배포하거나 이 보고서에 복제하지 않았다. 이번 표준 조사는 공식 카탈로그의 범위·서지·판·상태를 직접 열어 확인한 수준이다. 범위 밖 세부 조항, 허용값 표, 수식, 예외 규칙은 미확인이다.
- NIST AMS200-12는 공개 원문 중 적용에 필요한 절을 선별 열람했다. “전체87쪽을 완전히 정독”하거나 “NIST 프로그램을 실행해 현재 앱과 대조”한 것은 아니다.
- 공식 기관의 소개 페이지도 개별 제품 페이지와 연도가 다를 수 있어 교차 확인했다. 개정 중과 발행 완료는 구분했다.
- 관련 표준이 존재한다는 사실만으로 현재 앱이 그 표준에 적합하다고 주장할 수 없다. 원문 확보, 지원범위 명시, 독립 검사 사례와 실제 적용 결과가 필요하다.
- 이 문서는 표준·데이터·검증 축의 조사다. 절삭역학, 특징 인식, 접근성, 고정 및 셋업, 가공 시간·비용의 연구 문헌은 별도 조사 파일과 함께 종합해야 한다.
