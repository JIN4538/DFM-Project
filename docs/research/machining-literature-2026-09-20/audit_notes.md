# 수치·공구 정의·확률 해석 최종 점검

점검일: 2026-09-20. 대상은 `foundations.json`, `geometry.json`, `standards.json`, `process.json`, `report_body.md`, `build_report.py`다. 아래는 중요한 과장·정의 혼동·집계 충돌을 찾는 한정 점검이며, 모든 문헌의 전문 재독·규정 검증 또는 앱 동작 시험은 아니다. 앱 코드는 수정하지 않았다.

## 타당

- **F05의 300,000개와 실물 사례 해석:** [arXiv v1 본문](https://arxiv.org/html/2601.06334v1) §3.3은 세 시나리오마다 100,000개를 자동 생성하고 DFM 규칙으로 라벨링한 자료라고 밝힌다. §6은 중간 설계의 실물 변형 사례와 마지막 설계의 제작을 제시한다. 실물 사례가 없다고 단정하지 않되, 출력 0.769를 새로운 장비·부품의 실제 성공률 76.9%로 표시할 근거가 없다는 현재 서술은 타당하다. 이 제작 사례는 다수 독립 부품의 성공 빈도나 확률 보정을 대신하지 않는다.
- **P04의 6D:** [Protolabs 영국 본문](https://www.protolabs.com/en-gb/resources/design-for-machining-toolkit/)의 Holes와 Material Left Behind를 다시 열었다. 6D는 엔드밀 보간·자사 표준 공구셋과 특수 드릴/양면 작업의 맥락이다. 일반 드릴링 한계 또는 현재 원통면 축 구간/D의 합격선으로 쓰지 않는 현재 구분은 타당하다.
- **공급자 수치의 범위:** P01의 D≤1.5R, P07의 돌출/공구지름 4D, P09의 나사밀 지름 70%는 각각 별개 적용 권고이며 보편 합격표로 합치지 않는다. P11의 12는 6개 강체 자유도의 양·음 방향 집계라는 주석도 유지된다.
- **표준 열람 범위:** ISO/ASME 카드들은 공식 카탈로그·제품 페이지와 유료 규정 본문을 구별한다. 공차표·시험편 허용값·가드밴드 식 미열람을 규칙 구현 완료로 표현하지 않는다. S02의 NIST 공개 보고서는 별도로 실제 읽은 절을 표시한다.
- **논문 접근 수준:** P12/P13은 초록·서지, G05는 검색 색인 발췌, G06은 저자 README, G09는 누락 의심 PDF로 제한한다. F01의 1997 학술지판과 1995 NIST 보고서판, G10의 1994 학회판과 1996 확장판을 같은 발행판으로 혼동하지 않는다.
- **집계:** F7+G16+P16+S18=57레코드이며 G08→F01, P05→G12를 묶은 55는 조사 카드 수다. 표준 여러 부를 묶은 카드도 있어 55편의 새 논문으로 세면 안 된다. 기존 코드 29항목=적층·공통 24+절삭 5, 최초 보관 목록 14도 별도 집계다. 기존 절삭 등록 5와 재감사 E01–E09 중 4개가 겹치므로 합집합 10이 맞다.
- **보고서 생성기:** 이 점검 시점 `build_report.py`의 Python 구문 검사가 통과했다. 본문·카드의 접근 수준과 별칭 집계가 출력되도록 되어 있다. Word/PDF 페이지 렌더 검사는 별도 담당 범위다.

## 수정 필요 또는 반영 확인

1. **LBS 번역을 명확히 할 것:** ‘목부 아래 길이’는 목부 길이만을 뜻하는 것으로 오해할 수 있다. [Harvey 원문](https://www.harveyperformance.com/in-the-loupe/end-mill-anatomy/)은 감소 목부 시작점부터 절삭 끝까지라고 정의한다. `process.json` P03과 `process_notes.md`는 ‘샹크 아래 길이 LBS’와 측정 양 끝점으로 수정 완료했다. `report_body.md`의 같은 문장도 동일하게 맞춰야 한다.
2. **D≤2R의 가정 한 번 명시:** `report_body.md`의 코너 설명은 ‘공구축과 평행한 오목 원통 코너를 이상적인 원통 옆날로 가공’하는 가정으로 한정하면 정확하다. 바닥과 벽의 직각까지 같은 불가능 규칙으로 확대하지 않는다. `process_notes.md` 표에는 이 조건을 반영했다.

위 두 문구 외에 이번 한정 점검에서 납품을 막을 중요한 수치·확률·서지 충돌은 발견하지 않았다. 실제 가공 성공 확률 모델, CAM 실행 및 물리 검증을 완료했다고 주장하지 않는 조건을 유지한다.

최종 반영: 본문에서도 LBS 측정 양 끝점과 D≤2R의 공구축 평행·원통 옆날 가정을 명시했다. 바닥–벽 코너에 같은 식을 그대로 적용하지 않는다고 덧붙였다. 해당 수정 후 보고서를 다시 생성했다.
