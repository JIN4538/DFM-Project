# 다음 독립 평가를 위한 절차

현재 완료한 것은 합성 CAD·기하 정답·실제 수정 STEP·자동 앱 흐름 평가다. **모집한 사용자 0명, 전문가 선호 라벨 0개**다. 아래는 앞으로 수집할 평가의 준비본이며 결과를 만들어 채운 것이 아니다.

## 전문가 선호

`validation/verified-improvements-2026-10-02/expert_pairs.csv`의 30개 쌍에 원본과 두 실제 수정 STEP, 반경·증가 체적·보호 조건을 연결했다. 후보 하나뿐인 경우는 비교 쌍에서 제외한다.

1. 평가자 2명 이상에게 원본, 수정 가능한 항목, 유지할 치수를 먼저 제공한다.
2. 방법 이름·모델 점수·기존 추천을 숨기고 A/B 순서를 평가자별 무작위로 바꾼다. CAD와 치수표는 같은 배율로 제공한다.
3. A/B/동률/둘 다 부적절 중 하나와 이유를 기록한다. 바뀌어도 되는 기능·조립 치수가 추가로 있으면 별도 기록하며 자동 추정하지 않는다.
4. 불일치와 판단 불가를 삭제하지 않는다. 일치도와 이유 범주를 보고하고, 평가자의 단독 선호를 보편적 정답으로 부르지 않는다.
5. 새 학습은 형상군 단위로 분할한다. 이번 개발에 진단으로 사용한 60개를 다시 손대지 않은 최종 시험으로 삼지 않는다. 별도 CAD와 별도 평가자를 최종 시험에 확보한다.

이 라벨은 후보 간 선호 학습에 사용할 수 있다. 현재 체적 회귀 모델의 라벨과 섞어 ‘전문가 최적안 학습’으로 보고하지 않는다.

## 첫 사용자 과제

기본값만 사용하는 적층 얇은 판, 절삭 복수 포켓, 절삭 반복 구멍의 세 과제를 제공한다. 처음 사용하는 참가자는 ‘결론 파악 → 문제 위치 → 제안 치수 → 수정 전후/보고서 저장’을 수행한다.

| 측정 | 수집 방법 |
|---|---|
| 결론을 이해했는가 | 현재 문제와 먼저 할 수정 한 가지를 본인 말로 답변 |
| 위치·수치가 이어지는가 | 표시된 위치와 수정 치수가 같은 항목인지 확인 |
| 필요한 입력 수 | 직접 입력한 수치·선택·클릭 수와 불필요한 반복 기록 |
| 과제 완료 | 도움 없이 완료 / 도움 받아 완료 / 중단을 구분 |
| 시간·오류 | 화면 기록의 실제 시작·종료 시간, 잘못된 항목 선택과 복구 |
| 전후 해석 | 바뀐 코너 반경과 유지된 깊이, 남은 확인 항목을 설명 |

툴에 알고리즘 설명을 더 붙여 참가자를 가르치지 않는다. 설명이 필요한 지점을 수정 후보로 기록한다. 적층·절삭 과제 순서를 교차 배정하며 개발자 AppTest 시간을 사람의 작업시간으로 대신하지 않는다. 화면·음성 수집은 참가자가 동의한 범위에서만 수행한다.

## 비교 원칙

같은 CAD·허용 치수·보호 조건·후보 질의 수로 규칙, 학습만, 학습+검산을 비교한다. 실제 코드의 초기 측정·특징 추출 비용도 포함한다. 수정 STEP 재측정, 새 문제, 보호 위반, 변경 치수 수·부피 변화, 미처리율을 따로 보고한다. 기하 검산의 개선을 신경망 재학습의 개선으로 합산하지 않는다.
