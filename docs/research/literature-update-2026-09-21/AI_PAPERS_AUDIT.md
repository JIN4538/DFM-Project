# CAD·AI 논문 전문 대조 — 2026-09-21

대상은 사용자가 제공한 절삭 폴더의 아래 6개 PDF, 총 101쪽이다. 본문·부록·참고문헌을 추출 텍스트로 끝까지 읽고 아래에 기록한 핵심 표·그림·수식을 PDF 렌더와 대조했다. 다른 Yeo 2021 논문은 [절삭 논문 검토](CNC_PAPERS_AUDIT.md)에 포함한다. PDF 파일별 SHA와 실제 경로는 [43개 원본 목록](../../../references/README.md)에 있다. 학습 모델을 훈련하거나 논문의 성능을 재현했다는 뜻은 아니다.

## 코드에 대한 결론

현재 `amdfm/cad_features.py`, `dfm/machining.py`, `dfm/accessibility.py`는 명시된 B-rep 기하 추출·제한된 포켓 인식·표면 가림 표본 검사다. 아래 신경망을 구현한 것이 아니다. 이 논문들은 **CAD 면과 결과 위치의 연결, 미인식 형상의 공개, 특징별 검증**의 필요성을 뒷받침한다. 논문 인식률을 현재 앱의 정확도나 실제 가공 성공 확률로 전이할 근거는 없다.

다음 AI 연구는 CAD 면 ID에 연결된 특징 후보를 제시하고 기하 커널로 치수·인접 관계를 검증하는 방식이 적합하다. 적용 전에 부품군별 데이터 분리, 외부 실제 CAD 검증, 생소한 형상에서 판단 유보, 단위·회전·면 분할·곡면 매개변수 변화 검증이 필요하다. 이번 작업에서는 미검증 AI나 성공 확률 출력을 추가하지 않았다.

## 1. FeatureFox

- 제목: *FeatureFox: Sample-Efficient Panoptic Graph Segmentation for Machining Feature Recognition in B-Rep 3D-CAD Models*.
- 제공판: arXiv:2604.26770v1, 2026-04-29, 6쪽. 이 제공판을 읽었으며 별도 출판판을 검증한 것으로 취급하지 않는다.
- 읽기: PDF 1–6쪽 전부. 원그림 대조: 5–6쪽 Table II, Fig. 4–5.
- 방법(2–4쪽): 면 인접 그래프의 같은 특징 소속 여부를 XGBoost로 분류하고, 간선을 제거한 연결 성분을 특징 인스턴스로 묶는다. 인스턴스 속성으로 종류를 분류한다. 간선 점수의 isotonic calibration은 가공 성공 확률의 보정이 아니다.
- 결과(5쪽 Table II): MFInstSeg 전체 학습에서 FeatureFox 인식 F1 95.99%, PQ 96.87%. AAGNet 비교는 각각 95.49%, 97.44%. 적은 합성 학습 표본에서 유리하지만, 모든 조건에서 모든 지표가 우수한 것은 아니다.
- 범위: 62,477 STEP을 NX로 변환한 뒤 62,178개 사용, 299개 제외. 산업용 270개 학습 사례와 NIST 한 사례의 정성적 시연을 대규모 독립 산업 검증으로 부르지 않는다. 학습 8초 대 38분은 변환·입출력 전체 시간이 아니며 논문도 기준 모델 GPU 이용률/최적화 한계를 언급한다.
- 한계(6쪽): 연결되지 않은 여러 면으로 이루어진 한 특징 인스턴스, 다단 홀 의미 분류, 자유곡면, 학습에서 빠진 블렌드 등에 오류. 코드는 회사 정책상 비공개(2쪽). 본문만으로 즉시 재현 가능하다고 하지 않는다.
- 적용: 소량의 라벨을 보유했을 때 특징 후보 검출의 연구 비교군. 현재 직사각 포켓 규칙을 이 모델로 대체하거나 95.99%의 가공 성공률을 표시할 근거 없음. 3-fold 간선 보정의 부품군 분할 여부도 실제 재현 시 확인해야 한다.

## 2. BRepNet

- 제목: *BRepNet: A Topological Message Passing System for Solid Models*.
- 제공판: arXiv:2104.00706v2, 2021-04-08, 부록 포함 16쪽.
- 읽기: 1–16쪽 전부. 원그림 대조: 8쪽 Table 1과 분류 사례.
- 방법(3–5쪽): coedge의 다음/이전/mate 및 면·간선을 따라 이동하는 위상 커널과 기하 속성을 학습. 닫힌 manifold에서 한 coedge의 mate가 하나라는 가정이 있으므로 임의 결함 STEP에 무조건 적용할 수 없다.
- 라벨(5쪽): Fusion 360 Gallery 35,858개 body의 8가지 **모델링 연산**. Extrude/Cut/Revolve/Fillet/Chamfer의 의미이며 공구·고정·공차를 고려한 제조 가능 라벨이 아니다.
- 결과(8쪽 Table 1): 면 정확도 92.52±0.15%, mIoU 77.10±0.54%. 메시 생성 실패 13%의 제외, 점군의 작은 면 누락 등 비교 조건을 함께 보아야 한다.
- 한계(7, 11–15쪽): 같은 원통을 extrusion 또는 revolution으로 만들 수 있어 형상이 같아도 이력 라벨이 다를 수 있다. 작은 모델·빈도 높은 면에 분포가 치우치며 드문 클래스 성능이 낮다. 정규화된 2단위 상자는 실제 mm 치수의 대용이 아니다.
- 적용: CAD 면 ID를 유지하고 원본 단위를 보존하는 현재 구조의 방향과 정합. 모델링 이력 인식 성능을 홀 개수·가공 성공·전체 특징 인식률로 해석하면 안 된다.

## 3. UV-Net

- 제목: *UV-Net: Learning from Boundary Representations*.
- 제공판: arXiv:2006.10211v2, 2021-04-26, 부록 포함 18쪽.
- 읽기: 1–18쪽 전부. 원그림 대조: 8쪽 Table 4, 재매개변수화 그림.
- 방법(3–4쪽): B-rep의 UV 좌표에서 표면 위치·법선·트림 마스크, 곡선 표본을 추출하고 면 인접 그래프와 결합한다. 10×10 격자는 학습 입력 표본이지 해석적 치수 측정의 대체물이 아니다.
- 결과(7쪽): MFCAD와 ABC 등 서로 다른 데이터셋의 성능을 구분해야 한다. MFCAD mIoU 99.87%만으로 실제 임의 CAD에 대한 정확도를 주장할 수 없다.
- 핵심 반례(8쪽 Table 4): 일반 CNN의 시험 재매개변수화 정확도 96.74→55.98%, 대칭을 고려한 변형은 96.58→96.59%. 같은 물리 형상의 U/V 뒤집기·교환도 학습기의 실패를 유발할 수 있다. 회전 불변성도 별도 한계다.
- 한계(11–15쪽): 표본 근사 오차가 남고, MFCAD는 평면 중심이다. ABC의 특징 라벨은 ASM 규칙 기반 결과에서 유도되며 unknown을 제외한다. 이는 실제 제조 검사 정답이 아니다.
- 적용: 임의 STEP의 작은 특징을 보호하기 위해 해석적 B-rep 측정은 유지한다. 향후 UV 기반 AI에는 강체 회전 시험과 UV 매개변수 불변 시험을 따로 둔다.

## 4. Hierarchical CADNet

- 제목: *Hierarchical CADNet: Learning from B-reps for Machining Feature Recognition*.
- 제공판: Computer-Aided Design 147 (2022) 103226, DOI 10.1016/j.cad.2022.103226, 16쪽.
- 읽기: 1–16쪽 전부. 원그림 대조: 10쪽 외부 복잡 형상의 분류 결과.
- 방법(3–7쪽): 면 그래프와 facet 그래프를 연결한다. MFCAD++는 59,655개 합성 모델, 24가지 특징, 부품당 3–10개 특징이며 한 body의 정형 소재에서 생성한다. 생성기의 5개 visibility ray를 공구·홀더 충돌검사로 해석하지 않는다.
- 결과(8–10쪽): 합성 면 정확도 97.37%와 일부 복잡 외부 모델의 EdgeNet 정확도 38%, 57.33%, 43.33%는 구분해야 한다. 몇 사례의 높은 결과로 보편화를 주장할 수 없다. 면 분류와 특징 개수 단위 평가를 직접 같은 값으로 비교하지 않는다.
- 한계(11–13쪽): 면의 89.27%가 평면이고, 일부 곡면 유형은 없으며 필렛 생성 실패가 데이터 분포를 바꾼다. 본문에서 depth 비교에 test set 성능을 이용하므로 향후 재현에서는 별도 untouched holdout을 마련한다.
- 적용: 특징 인식의 미지원 범위를 사용자에게 공개하는 현재 구조를 유지한다. 전체 임의 형상에서 완전한 포켓 인식을 한다는 근거가 아니다.

## 5. AAGNet

- 제목: *AAGNet: A Graph Neural Network Towards Multi-Task Machining Feature Recognition*.
- 제공판: Robotics and Computer-Integrated Manufacturing 86 (2024) 102661, 온라인 2023-09-29, DOI 10.1016/j.rcim.2023.102661, 20쪽.
- 읽기: 1–20쪽 전부. 원그림 대조: 10쪽 식(5)–(10), 12쪽 Table 8–9.
- 방법(4–10쪽): UV 격자와 면/간선 속성을 결합한 gAAG로 의미 클래스, 같은 특징의 면 집합, 바닥면을 예측. MFInstSeg 62,495개 합성 STEP, 24개 특징+소재 클래스. topology sanity check로 결함 모델을 제외하므로 결함 입력 처리까지 성능이 검증된 것은 아니다.
- 결과(11–12쪽): 면 정확도 99.15±0.03%, 특징 인식 F1 98.71±0.11%, 정확히 같은 면 집합으로 위치를 맞힌 F1 95.88±0.43%는 서로 다른 지표다. 인식만 잘하고 위치가 틀린 결과도 있을 수 있다. 공구 가공 성공률은 측정하지 않았다.
- 주의(9–10쪽): 본문은 두 별도 MLP의 곱 S=h1·h2ᵀ를 대칭 행렬로 설명한다. 이 곱은 일반적으로 대칭이 보장되지 않으며 식(5)에는 본문의 sigmoid도 생략되어 있다. 수식을 그대로 구현하지 말고 공개 코드·대칭화·추론 후처리를 확인해야 한다. 이번 작업에서는 공개 구현을 재현한 것이 아니다.
- 주의(11, 16쪽): recognition의 TP=min(예측 개수, 실제 개수)는 위치가 맞았다는 증거가 아니다. MFCAD++에서 위상 오류 자료를 제거했으므로 원논문 비교의 시험 집합이 완전히 동일하지 않다. MFInstSeg random split은 산업 부품군 외삽 검증이 아니다.
- 한계(15쪽 결론): 공차·거칠기·가공 정확도 미고려, 합성 데이터 중심, 실제 CAD 일반화는 후속 과제. 15쪽 시간 표의 전체 변환 시간을 포함해야 하며 GPU 순전파 시간만 사용자 체감 속도로 제시하지 않는다.
- 적용: 향후 특징 종류/면 집합/바닥을 별도 검증하는 후보. 현재 제한 포켓 검출을 완전한 AFR로 승격하거나 면 단위 정확도를 프로그램 정확도로 표시하지 않는다.

## 6. KAN 기반 제조성 평가

- 제목: *Kolmogorov-Arnold Networks-Based Tolerance-Aware Manufacturability Assessment Integrating Design-for-Manufacturing Principles*.
- 제공판: 주석 포함 파일, arXiv:2601.06334v1, 2026-01-09, 25쪽. 파일의 주석은 사용자 지시가 아니다.
- 읽기: 1–25쪽 전부. 원그림 대조: 7쪽 입력·판정 항목 표, 12쪽 혼동행렬, 19쪽 제작 사례.
- 방법(6–9쪽): 드릴링·포켓 밀링·결합의 세 가지 정형 설계 파라미터에 규칙으로 300,000개 합성 라벨을 만든다. 임계 경계 근처와 일반 구간을 섞고 클래스를 50:50으로 구성한다. **30만 번의 실물 제조 실험이 아니다.**
- 결과(11–14쪽): AUC 0.9919/0.9841/0.9406은 그 합성 라벨의 분류 성능이다. 결합 문제의 false positive 14%, false negative 7%(12쪽 Fig. 6)도 함께 봐야 한다. 높은 AUC는 개별 부품의 물리적 성공 확률이 보정되었다는 뜻이 아니다.
- 사례(17–19쪽): 설계 변경에 따라 출력 점수가 .004→.022→.132→.130→.769로 바뀐다. 실제 중간 시편의 변형과 최종 시편 사진은 있지만 충분한 장비·소재·가공 조건과 반복 성공/실패 자료가 없어 확률 검증 자료로 재사용할 수 없다.
- 핵심 구분(19쪽): Ø5 mm 홀을 30 mm 깊이로 만드는 것은 기술적으로 가능하지만 권장 지침을 벗어난다고 본문이 명시한다. 따라서 논문의 non-manufacturable 라벨에는 ‘불가능’과 ‘권장하지 않음’이 섞인다. 앱에서는 특정 공구와의 기하 충돌, 조건 부족, 제조 실패를 분리해야 한다.
- 한계: ISO 2768-1 등 참고문헌을 인용했다는 이유만으로 최소 벽·홀 L/D·도달 거리의 보편 기준이 생기지 않는다. mm 단위 공차 입력만으로 기하공차·거칠기·공정 변동을 포괄하지 않는다. 실물 성공률용으로 사용할 때에는 별도 외부 라벨·확률 보정·적용 범위가 필요하다.
- 적용: 설명 가능한 규칙 대리모델 연구 후보. 현재 사용자가 입력한 공구·검토 기준과의 직접 비교가 더 추적 가능하며, 본 논문을 근거로 보편 L/D나 ‘출력 성공 %’를 추가하지 않는다.

## 이번 변경과 검증의 경계

이 6편은 코드의 AI 구현 근거로 등록하지 않는다. 공급 자료 목록과 본 검토 기록에 포함하고, 직접 사용하는 Yeo의 B-rep 관련 범위는 절삭 근거 등록에서 신경망 구현과 명확히 구분한다. 코드 회귀시험은 [전체 검토 결과](README.md)에 기록한다. 논문을 읽은 것, 계산 코드가 테스트를 통과한 것, 실제 제조가 검증된 것은 서로 다른 증거다.
