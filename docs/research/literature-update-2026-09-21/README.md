# 적층·절삭 참고문헌 전문 검토와 코드 대조

검토일: 2026-09-21. 대상은 사용자가 바탕화면 `DFM 관련 자료`의 적층/절삭 참고문헌 폴더에 제공한 **43 PDF, 928쪽**이다. 같은 Kerbrat 논문이 양쪽에 있으므로 독립 논문 43편이라는 뜻은 아니다.

**현재 프로그램은 명시된 범위의 기하 검토와 설계 의사결정 지원 도구로 타당하다. 실제 출력·가공 성공, 공차 달성, 강도, 공구·홀더·고정구의 전체 충돌을 판정하는 도구로 검증된 것은 아니다.** 이번 문헌 대조에서 새로 입증한 계산 결함은 없었다. 새 원문을 확보한 뒤에도 특정 논문의 시험값을 보편 임계값으로 넣거나 기하 점수를 성공 확률로 표시할 근거는 나오지 않았다.

## GitHub에 반영한 원본

- 기존 루트의 KS 52902·52903-1·52903-2·52910 PDF를 새 캡처로 교체했다. 이전 파일은 Git 이력에 남는다.
- KS 52901 PDF를 루트에 추가했다.
- 절삭 폴더의 **28개 PDF 전부**를 [`references/machining/`](../../../references/machining/)에 원래 이름으로 추가했다. 그 폴더에 들어 있던 적층 관련 3편도 빠뜨리지 않고 적층 검토에 사용했다.
- 기존 적층 논문 10개는 바탕화면 파일과 같아 재작성하지 않았다.
- 모든 43개 파일에 대해 크기와 SHA-256을 확인했다. PDF를 재압축하거나 OCR 텍스트를 원본에 덮어쓰지 않았다.

[파일별 검토 문서·해시·페이지 범위 색인](reading-coverage.json)에서 43개 모두의 대응 관계를 확인할 수 있다.

제공 파일의 본문·부록·참고문헌을 추출 텍스트 또는 전 페이지 OCR로 읽고, 코드 판단에 쓰는 핵심 표·수식·도해를 원페이지 렌더로 대조했다. 이는 모든 글자를 독립 전사하거나 모든 실험·증명을 재현했다는 뜻이 아니다. 재사용 가능한 노트와 파일 SHA를 남겼으며, 이후 구현에서는 해당 원페이지와 조건을 다시 확인한다.

다음 제한은 남아 있다.

- 새 표준의 큰 페이지 누락은 해소됐지만 워터마크·흐림이 있다. 52902 PDF 44쪽 해설 하단 일부도 잘렸다. OCR만으로 정밀 수식·표 값을 자동 채택하지 않는다.
- 확보한 **KS 52902는 ISO 2019 기반판**이다. 기존 등록된 국제 ISO/ASTM 52902:2023의 전문을 확보한 것은 아니다.
- 기존 `Manufacturability of Parts with 3D-Annotated Model Generated by 3D-CAD.pdf`는 여전히 5쪽 한국어 편집본이다. 제공 파일은 읽었지만 원 논문 그림 1–33과 원본 전체를 읽었다고 주장할 수 없다.
- 표준·논문 안의 참고문헌 목록까지 읽었어도 그 외부 인용문헌의 전문까지 읽었다는 뜻은 아니다.

## 이번 코드 개선

1. `amdfm/evidence.py`: 52910의 오래된 ‘불완전 캡처’ 설명을 현재 열람 상태로 고쳤다. 제공된 KS 52902:2019와 기존 ISO 52902:2023 범위 안내를 별도 출처로 보존했다. 52901·52903-1/-2의 판본·원본 경로·열람 수준·사용 이유를 등록했다.
2. `amdfm/analysis.py`: 보고서에 구매 요구사항·실물 장비 검증 근거를 연결했다. MEX 원재료/장비 표준은 MEX 결과에만 포함하며, 이 표준을 기하 임계값의 근거로 붙이지 않는다.
3. `dfm/machining.py`: Yeo는 면 표현의 배경임을 명시하고 DNN을 구현했다는 오해를 막았다. Nelaturi/MRSEV를 가림·특징 검토의 범위와 연결했고, Budak/KS 8015는 물리·공차 미평가의 이유를 설명하도록 등록했다.
4. `dfm/machining_view.py`: 근거 제목뿐 아니라 적용 범위·페이지·열람 수준을 화면과 HTML 보고서에 표시한다. URL이 없는 제공 자료를 빈 링크로 만들지 않는다.
5. 인수 문서: 과거 캡처의 누락 상태와 현재 파일의 SHA를 혼용하지 않도록 최신 목록과 검토 기록을 연결했다. 과거 실행 로그와 기준선은 그대로 남겼다.

수치 계산식·제조 임계값은 이번 문헌 등록 때문에 변경하지 않았다. 문헌 수를 늘리는 것보다 어느 판단에 어떤 근거를 사용했는지, 어디까지 검증했는지 확인할 수 있게 했다.

## 다음 개발의 우선순위

1. **절삭:** 소재·공구 절삭부/샹크/홀더·고정구를 입력으로 받는 유한 공구 충돌과 제거 체적을 독립 CAM/해석 형상과 대조한다. 이후에야 현재 ray보다 강한 접근 가능 결론을 낼 수 있다.
2. **적층:** 장비·재료·품질 요구와 외부 실험/슬라이서 조건을 연결한다. 52901의 구매·검사 합의와 52903의 재료/공정 기록을 구조화하되 검증되지 않은 기본값을 만들지 않는다.
3. **AI:** 근거 검색·계산 결과 설명 또는 CAD 특징 후보 제안부터 분리해 평가한다. 제조 성공 확률은 실제 성공/실패와 조건을 가진 외부 데이터 및 확률 보정이 확보되어야 한다.

사출·프레스 구현은 재개하지 않았다. 새 문헌을 읽는 것만으로 장비 검증·산업 검증·표준 인증이 완료되지 않는다.
