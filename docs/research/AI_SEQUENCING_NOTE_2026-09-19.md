# AI 도입 순서와 연구 평가 — 2026-09-19 판단

추천 순서는 **절삭의 검증 가능한 핵심 기능 → 적층·절삭 공통 결과 → 공통 AI**다. 사출·프레스까지 모두 완성한 뒤에야 AI를 시작해야 한다는 뜻은 아니다. 처음부터 공정·조건·측정값/단위·위치·판단·근거·미확정·다음 행동을 명시하고, 두 공정의 결과를 같은 AI가 조회하도록 준비한다. 일정과 장비가 미확정인 이 프로젝트에 대한 개발 판단이며, 아래 문헌이 이 개발 순서를 직접 증명한다는 주장은 아니다.

추가 검색에서 나온 MIT 논문 PDF의 옛 `cfg.mit.edu` 주소는 현재 연구실 홈으로 이동했다. 해당 PDF를 읽었다고 기록하거나 본문 주장에 인용하지 않는다. 후속 조사에서 유효한 원문 주소를 확보해야 한다. 이 목록은 AI/CAD 문헌 전체 조사 완료가 아니다.

## 첫 AI의 범위

- **설명:** 계산된 측정값·단위·위치·규칙 적용 조건을 쉬운 말로 설명한다. 값이나 공정 한계를 언어 모델이 새로 만들어내지 않는다.
- **근거 조회:** 실제 문헌의 지원 주장과 조건을 함께 보여준다. 검색된 문장에 링크가 있다는 것과 현재 형상에 적용할 수 있다는 것을 구분한다.
- **비교 실행:** 사용자가 요청한 공구·방향·수정 형상을 기존 계산 함수로 재검토하고 실제 차이를 설명한다. 형상·코드·조건 식별자를 비교 결과와 연결한다.
- **보류:** 미확정 측정·미지원 특징·장비/재료 부재를 보존한다. 제조 성공 확률을 규칙 점수나 LLM 자신감으로 대체하지 않는다.

초기에는 학습용 실물 데이터 없이도 위 설명·검색·도구 호출의 유용성과 오류를 평가할 수 있다. 실제 제조 성공 확률 모델에는 성공의 정의, 외부 실물 자료의 조건·대표성, 독립 평가와 확률 보정이 별도로 필요하다.

## 미팅용 우선순위와 연구 후보

미팅에서는 같은 STEP에 대해 두 공정의 관측 차이와 **문제 위치 → 근거 → 수정 → 재검토** 한 흐름을 재현하는 것을 우선한다. 절삭 첫 범위는 고정축 밀링의 명시된 특징으로 두고 선삭·연속 5축·공구력/열·완전한 공정 계획까지 한 번에 주장하지 않는다. AI는 이 결과의 해석을 돕는 최소 기능부터 추가할 수 있다.

연구 후보는 ‘공통 근거 기반 AI가 템플릿 설명보다 사용자의 올바른 수정 결정을 돕는가’다. 같은 기하 결과와 문헌을 두고 **고정 설명 / 일반 대화 AI / 결과·근거·도구에 연결한 AI**를 비교한다. 오류율(수치·단위·출처·미확정 승격), 수정 결정의 적절성, 과제 시간, 수정 후 기하 충돌의 변화를 평가한다. 비교할 정답·전문가 기준과 참가자 조건을 먼저 정해야 하며 아직 실험하거나 독창성을 입증한 연구가 아니다.
