# 현재 DFM 툴에서 출발할 연구 주제

작성: 2026-10-01. 적층·절삭만 대상으로 한다. 아래 표본 수는 제안한 실험 규모이며 완료한 연구 결과가 아니다. 실제 제작 장비 없이도 CAD 정답, 수정 결과, 독립 계산 및 사용성으로 평가할 수 있는 과제를 우선한다.

## 추천: 기하 검산을 결합한 최소 수정 제조성 개선안 추천

**연구 질문:** 학습 모델이 제안한 수정안을 CAD로 재측정하고 수정 전후를 비교하면, 규칙만 사용하거나 AI만 사용하는 방법보다 적은 수정으로 더 많은 검토 문제를 해결할 수 있는가?

예를 들어 깊은 포켓의 문제가 발견되면 큰 공구를 쓰기 위해 코너 반경을 늘릴지, 작은 공구를 쓰고 깊이를 줄일지, 접근 방향을 바꿀지 선택해야 한다. 현재 툴의 특징 인식, 부위별 공구 조합, 검산된 복수 포켓 STEP 편집을 연구의 출발점으로 활용할 수 있다. 지금의 모든 추천이 전문가의 설계 판단을 학습한 결과는 아니므로 그 차이를 실험에서 분리한다.

첫 논문 범위는 3축 밀링의 평면 포켓과 원형 홀로 한정한다. 사용자가 수정 가능한 치수와 유지해야 하는 면·치수를 지정하고, 교수님 또는 협력 연구자가 수정안 쌍의 선호와 이유를 라벨링한다. AI는 후보 또는 순위를 학습하고, 별도 기하 검산은 충돌·기준 충족·원래 보존 조건을 판정한다. 기능 보존을 자동으로 추정하지 않는다.

| 항목 | 구체적인 실험 설계 |
|---|---|
| 데이터 | 우선 200–300 CAD로 절차와 라벨 품질을 시험한 뒤, 개발에 사용하지 않은 형상군을 별도 시험으로 고정. 공개 CAD와 독립 작성 CAD를 나눠 보고 |
| 비교 | 규칙+탐욕 수정, 정확 조합 탐색, 학습 후보만, 학습+검산, 필요하면 외부 LLM+같은 검산 도구 |
| 공정한 조건 | 후보 예산·벽시계 시간·수정 허용 영역을 맞춤. 같은 후보에서 최종 선택만 바꾼 효과와 새로운 학습 후보의 효과를 별도로 측정 |
| 주요 지표 | 검토 문제 감소, 새 문제 발생률, 변경 치수 수·정규화 변경량·부피 차이, 보호 치수 위반, 유효 STEP 비율, 전체 처리시간 |
| 독립 확인 | 수정 STEP을 다시 읽어 재측정. 해석 가능한 CAD에는 별도 수식 정답 사용. 검토 코드와 동일 함수를 정답으로만 쓰지 않음 |
| 전문가 평가 | 익명 수정안 쌍을 독립 평가하고 평가자 일치도·애매한 라벨을 보존. 같은 교수님의 선호 라벨을 같은 교수님의 단독 최종 평가로 대체하지 않음 |

**차별화 후보:** AI가 생성한 설명의 자연스러움보다, 바뀐 실제 CAD에서 문제 감소와 보존 조건을 재검증하는 체계 및 최소 수정 비용을 핵심 기여로 삼는다. 2019년의 모델 보정·방향 최적화와 2026년 AgentsCAD가 이미 관련 문제를 다루므로 “AI DFM 수정 최초”라는 주장은 하지 않는다. 해당 방법들과의 실제 재현 비교가 가능할 때만 우위를 주장한다.

## 후보 2: CAD 표현 변화와 새 형상에 강건한 절삭 특징 인식

**연구 질문:** 같은 형상을 회전하거나 STEP으로 다시 내보내고 원통면을 나누어도 같은 구멍·포켓과 치수가 인식되는가? 합성 데이터에서 학습한 모델은 작성 방식이 다른 CAD에도 일반화하는가?

현재 MF 계열의 이전 시험에서 높은 검출률을 얻어도, 별도 작성한 반복 원통 홀을 많이 놓친 사례가 있었다. 최신 원형 경계 검산으로 보완한 것은 일부 단순 홀의 기하 성과이며 신경망의 일반화 성과와 구분한다. 이것이 실제 개발 중 발견한 연구 문제다.

- 같은 원형 형상의 회전·이동·면 분할·특징 교차·STEP 재내보내기 변형을 만들고 정답의 특징 인스턴스와 공간 영역을 보존한다. 원본의 모든 변형은 같은 분할에 배치한다.
- 학습 모델 단독, 규칙 단독, 단순 합집합, 학습+기하 제약, 기하 제약과 표현 일관성 학습을 비교한다. 가능하면 저자 공개 AAGNet과도 비교한다.
- 면 번호는 내보내기마다 달라질 수 있으므로 원래 면 ID만으로 정답을 맞추지 않는다. 지원 가능한 표면·공간 대응을 확인하고 대응 실패는 별도 보고한다.
- 특징 인스턴스 정밀도·재현율·IoU, 지름·깊이 오차, 잘못 확정한 특징 수, 거부율 대비 오류율, 처리시간을 함께 측정한다. 확정한 것의 정밀도만 높이는 방법이 전체 검출을 개선했다고 해석하지 않는다.
- 학습/검증/시험을 CAD 계열과 작성원 단위로 나누고, 원본 SHA 외에 기하 중복도 감사한다. 기존 test를 여러 번 사용한 결과는 회귀시험으로 남긴다.

**차별화 후보:** 단순 면 분류 정확도 경쟁에서 벗어나, 동일 실제 형상의 표현 변화에 대한 인식·측정의 일관성과 독립 형상 일반화를 평가한다. BRepNet·AAGNet·BrepMFR가 이미 B-Rep 학습과 영역 적응을 다루므로, 새 네트워크 구조 자체보다 검증 가능한 강건성 문제를 먼저 정한다.

## 후보 3: 동일 계산 예산에서의 적층 방향 추천

**연구 질문:** AI가 방향 후보를 고르고 실제 기하량을 다시 측정하는 방법이, 같은 계산 횟수와 시간의 균등·무작위·베이지안 탐색보다 좋은 결론을 더 빨리 얻는가?

첫 범위는 MEX 또는 고분자 PBF 한 공정으로 고정한다. 구체적 목적은 사전에 정의한 기하 검토 정책이며 출력 성공률을 목표 라벨로 쓰지 않는다. 높이와 하향면 투영 합을 실제 출력 시간·서포트 체적이라고 바꿔 부르지 않는다.

- 출처·원작자·형상군이 다른 100–200개 보류 형상으로 시작한다. 같은 형상의 재메시·배율 변형을 분할 간 섞지 않는다.
- 6축, 26방향, 균등 구면, 무작위, 베이지안 최적화, 현재 모델, 기하 제안+모델의 방법을 같은 기하 평가 예산(예: 6·12·24회)과 시간으로 비교한다. 초기 후보와 추가 후보 예산을 모두 센다.
- 충분히 촘촘한 기준 탐색 대비 손실, Pareto 해 집합의 품질, 제약 위반, 최종 추천 악화, 시작 방향에 따른 추천 반전, 전체 처리시간과 모델 로딩시간을 기록한다. 촘촘한 기준도 연속 공간의 전역 최적 정답이라고 부르지 않는다.
- 가능하면 고정 슬라이서 설정으로 서포트량·레이어·경로 추정치와 기하 지표의 관계를 별도 대조한다. 슬라이서 설정을 형상마다 결과에 맞춰 바꾸지 않는다.

기존 개발 감사에서는 동일 예산에서 신경망의 독립 우위를 확정하지 못한 결과가 있다. 이를 연구의 출발점으로 사용하며, 개선이 없다면 어느 형상과 계산 예산에서 학습이 불필요한지도 결과로 남긴다. 베이지안 방향 최적화는 이미 발표되어 있으므로 “AI로 방향을 추천한다”만으로 차별점을 삼지 않는다.

## 후보 4: 결론·위치·수정안 중심 설계 지원의 사용자 평가

**연구 질문:** 결과를 많이 나열하는 화면보다 하나의 결론과 해당 위치·수정안을 먼저 보여주는 화면이 초보자의 정확한 설계 조치를 돕는가?

같은 검토 엔진과 같은 수치를 사용한 두 화면을 비교해 모델 성능과 UI 효과를 분리한다. 10–15명 파일럿으로 과제와 용어를 다듬고, 본 실험의 인원은 파일럿 분산과 목표 효과에 따라 정한다. 초보자와 CAD 경험자를 구분하고 과제·화면 순서를 교차 배정한다.

과제는 STEP 입력→중요 문제 찾기→문제 위치 선택→올바른 개선안 선택→수정 결과 저장이다. 정답 조치 비율, 완료시간, 클릭·필수 입력 수, 재검토, 용어 오해, 도움 요청을 측정한다. 만족도만 높아지고 정답률이 떨어지는 경우를 성공으로 보지 않는다. 교수님은 과제·정답·수정 허용 조건을 검토하고 평가자를 모집하는 데 기여할 수 있다.

이 과제는 위 알고리즘 논문을 보완하는 사용자 연구로 적합하다. 현 화면의 깔끔함이나 개인 사용 감상만으로 학술 기여를 주장하지 않는다.

## 교수님과 정할 첫 단계

가장 추천하는 주제는 **기하 검산을 결합한 최소 수정 제조성 개선안 추천**이다. 특징 인식 연구를 먼저 택하면 후보 2를 별도 논문으로 좁히는 것도 합리적이다. 적층·절삭 전체와 모든 AI 기법을 하나의 논문에 묶지 않는다.

1. 한 공정·2–3 특징·수정 허용 영역·평가 목표를 정한다.
2. 새 보류 CAD와 기준 방법을 먼저 고정한다. 교수님은 공학적으로 허용할 수정 조건과 전문가 평가 기준을 함께 정한다.
3. 독립 검산된 수정안 쌍을 수집하고, 전문가 선호 라벨과 기하 정답을 별도로 저장한다.
4. 동일 예산의 대조 실험을 수행하고, 학습을 뺐을 때 얼마나 성능이 달라지는지 보고한다.
5. 알고리즘 결과와 사용자 과제 결과를 구분해 논문과 툴 시연을 구성한다.

## 이번에 확인한 주요 선행자료

2026-10-01 공식 초록·저자 공개 구현·접근 가능한 본문을 확인했다. 아래 목록은 출발점이며 전 세계 선행연구의 전수 조사나 논문 독창성 확정을 뜻하지 않는다.

- Lambourne et al. (2021), [BRepNet: A topological message passing system for solid models](https://arxiv.org/abs/2104.00706). B-Rep 기반 학습 비교의 기초. 공식 초록 확인.
- Wu et al. (2024), [AAGNet: A graph neural network towards multi-task machining feature recognition](https://github.com/whjdark/AAGNet), DOI 10.1016/j.rcim.2023.102661. 의미·인스턴스·바닥 분할, MFInstSeg와 저자 평가 코드 확인. 우리 모델의 실행 수치와 저자 논문의 수치를 혼합하지 않는다.
- [BrepMFR: Enhancing machining feature recognition in B-rep models through deep learning and domain adaptation](https://doi.org/10.1016/j.cagd.2024.102318) (2024). 합성→다른 CAD의 영역 적응과 관련. 출판사 공식 초록 확인, 이번 작업에서 유료 전문을 확보한 것은 아니다. 검색 결과에 섞인 잘못된 arXiv 번호를 채택하지 않았다.
- [Manufacturability Oriented Model Correction and Build Direction Optimization for Additive Manufacturing](https://arxiv.org/abs/1909.11620) (2019). 형상 보정과 방향 탐색을 같이 다룬 선행. 공식 초록 확인.
- Goguelin, Dhokia and Flynn (2021), [Bayesian Optimisation of Part Orientation in Additive Manufacturing](https://researchportal.bath.ac.uk/en/publications/bayesian-optimisation-of-part-orientation-in-additive-manufacturi/), DOI 10.1080/0951192X.2021.1972466. 무작위·격자·베이지안 탐색과 기하 대리 지표 비교. 공식 연구기관 기록과 공개 출판사 본문 확인.
- George et al. (2026), [AgentsCAD: Automated Design for Manufacturing of FDM Parts via Multi-Agent LLM Reasoning and Geometric Feature Recognition](https://arxiv.org/html/2607.02448v2). STEP 분석→수정→보고와 시각 검증을 연결한 관련 선행. arXiv 사전논문이며 동료심사 여부를 이 기록으로 확정하지 않는다. 공개 본문의 방법·결과를 확인했다.
