# 절삭 제조성 검토의 공식 근거와 적용 한계

조회: 2026-09-19. 아래 5개 공식 원문 페이지의 본문을 실제 열어 확인했다. 제조서비스·공구 제조사·CAD/CAM 공급자의 조건별 안내이며 보편적 제조 가능/불가능 표준은 아니다. 페이지에 별도 판본이 명시되지 않은 웹 문서는 조회일과 절 제목으로 식별한다.

이 기록은 첫 CNC 기능의 구현 이유와 검증 계약이다. 특정 규칙이 이미 코드에 구현됐거나 CAM·실물 검증을 통과했다는 선언이 아니다. 출시·지원 범위는 현재 코드와 실행 보고서로 확인한다. 사출·프레스까지 포함한 전체 목표는 [4공정 방향 기록](../project-knowledge/FOUR_PROCESS_RESEARCH_DIRECTION_2026-09-19.md)을 따른다.

## M01 — 내부 코너의 반경과 공구

- 출처: Sandvik Coromant, [Milling inside corners](https://www.sandvik.coromant.com/en-us/knowledge/milling/milling-inside-corners).
- 확인한 절: Considerations; Solution — limit the arc of engagement; Roughing; Finishing.
- 확인 내용: 코너에서 공구 물림이 증가하면 진동·공구 손상 등이 문제가 될 수 있으며, 코너 반경과 공구 크기·경로·이송을 함께 검토한다. 최종가공 안내에는 공구 지름을 부품 코너 반경의 1.5배 이하로 권고하는 예가 있다.
- 적용 조건: 해당 밀링 작업의 안정성을 위한 공구 제조사의 적용 안내. 소재·공구·절삭 조건 전체가 고정된 성공률 자료가 아니다.
- 정당화하는 구현: 선택 공구와 내부 코너 반경의 비교, 더 작은 공구/더 큰 설계 반경 후보, 기하 경계와 공정 권고의 구분.
- 제한: `D ≤ 1.5R`를 공정 전체의 물리적 불가능 경계로 사용하지 않는다. 이상적인 원통 공구 단면의 단순 기하 필요조건 `D ≤ 2R`와도 구분한다. 후자는 자체 기하 유도이며 실제 접근·공구 경로·안정성까지 충분조건이 아니다. 문헌의 가공 중 반경 변경 예시는 사용자의 기능·공차를 무시한 자동 설계 변경 허가가 아니다.

## M02 — 홀·포켓과 공정 전략

- 출처: Sandvik Coromant, [Milling holes and cavities/pockets](https://www.sandvik.coromant.com/en-us/knowledge/milling/milling-holes-cavities-pockets).
- 확인한 절: Hole milling: creating openings; Widening a hole or a cavity; How to open up / widen a cavity or pocket.
- 확인 내용: 구멍·포켓 가공에는 드릴링, 램핑, 원호 밀링, 플런지, 잔삭 등 여러 방법이 있고, 긴 돌출 길이·깊은 공동·칩 배출·진동에 따라 전략이 달라진다.
- 적용 조건: 선택 공구와 작업 전략, 장비 안정성, 재료, 칩 배출 및 절삭유 조건을 고려하는 적용 가이드.
- 정당화하는 구현: 포켓/홀 깊이와 필요한 공구 길이 기록, 단순 형상과 작업 방법의 구분, 현재 조건을 바꿀 대안 제시.
- 제한: 지름이나 깊이/폭 비율 한 개만으로 모든 방법의 가공 불가를 판정하지 않는다. 이 문헌은 우리 알고리즘의 특징 인식 정확도나 포켓 도달성 계산을 검증해 주지 않는다.

## M03 — 제조서비스가 실제로 검토하는 항목

- 출처: Protolabs, [Design for Machining Toolkit](https://www.protolabs.com/en-gb/resources/design-for-machining-toolkit/).
- 확인한 절: Holes; Walls and Features; Radii; Navigating Critical Machining Advisories / Material Left Behind.
- 확인 내용: 홀·깊은 특징·내부 코너·얇은 벽·접근 제한을 CAD에 연결해 안내한다. 홀 깊이 6D 등의 조건은 자사 표준 공구와 빠른 제작 서비스의 제약·난이도 맥락으로 제시된다. 내부 형상은 별도 공구/방향으로 처리할 가능성이 있다.
- 적용 조건: Protolabs의 서비스·표준 공구·공정 구성. 다른 공급자, 전용 공구, 다른 셋업에 그대로 적용할 수 없다.
- 정당화하는 구현: 위치 중심의 경고와 수정 행동, 사용자 공구/프로필 기준 입력, 홀 깊이비와 접근 조건을 별도 표시.
- 제한: `6D`, 벽 두께, 허용오차 수치를 출처 없는 기본 합격선으로 고정하지 않는다. 특정 서비스의 제약을 절삭 전체의 제약으로 확대하지 않는다. 문헌의 위험 표현은 실패 확률 라벨이 아니다.

## M04 — 축방향 가시성과 공구·홀더 충돌의 구분

- 출처: Autodesk Fusion, [Shaft and Holder Modes reference](https://help.autodesk.com/cloudhelp/ENU/Fusion-CAM/files/GUIDD505C759-C325-4C99-BBDD-35FE39B3761F.htm).
- 확인한 절: 모드 목록; Detect tool length.
- 확인 내용: 공구 샤프트·홀더와 부품 사이의 간격을 별도로 지정하며, 충돌을 무시하거나 경로를 잘라내고 피하거나 필요한 길이를 계산하는 모드가 있다.
- 적용 조건: 공구·홀더 형상, 경로 전략, 지정한 여유 거리와 모드가 주어진 Fusion 작업.
- 정당화하는 구현: 지름·절삭 길이·샤프트·홀더 조건 분리, 모델에 없는 조건을 미확정으로 표시, CAM 대조 시 충돌 처리 설정 기록.
- 제한: 한 점에서 축 방향으로 빈 공간이 보이는지 검사하는 레이는 유한 반경의 공구·홀더 접근 증명이 아니다. CAM의 충돌 옵션이 꺼진 실행을 무충돌 검증으로 기록하지 않는다. Fusion 사용 설명을 실제 CAM 실행 결과로 취급하지 않는다.

## M05 — 드릴링 절삭 동작과 이동 동작

- 출처: Autodesk Fusion, [Avoid collisions when drilling holes](https://help.autodesk.com/view/fusion360/ENU/?contextId=DRILLING-COLLISION-AVOIDANCE).
- 확인한 절: Collision avoidance for drilling; Using collision avoidance for drilling.
- 확인 내용: 절삭 중 샤프트/홀더 충돌과 홀 사이 이동 중 절삭부 충돌을 서로 다른 설정으로 다룬다. 부분 경로 처리와 더 긴 공구의 후속 작업을 구분하며, 최종 경로에서 gouge 확인을 권고한다.
- 적용 조건: 모델·선택 홀·공구·샤프트/홀더·링크/복귀 설정이 명시된 드릴링 작업.
- 정당화하는 구현: 홀 축 정렬과 단순 길이 검토의 범위를 명시하고, 이동·복귀·다른 셋업을 아직 검토하지 않은 경우 추가 확인 안내.
- 제한: 홀 축이 접근축과 평행하거나 드릴 길이가 충분하다는 이유만으로 완전한 드릴링 작업을 승인하지 않는다. 충돌 회피 기능의 존재는 우리 도구에 그 기능이 구현됐다는 증거가 아니다.

## 처음 구현할 규칙의 해석 계약

다음은 위 출처와 기하적 필요조건을 바탕으로 한 개발 설계다. 구현 결과를 독립 기준 형상과 대조한 뒤 실제 지원 범위를 기록한다.

| 항목 | 계산·비교의 의미 | 사용자에게 허용되는 해석 | 확정하면 안 되는 해석 |
|---|---|---|---|
| 내부 코너와 공구 지름 | 정의된 내부 반경과 원통 공구 단면 비교 | 이 공구/단순 작업 가정에서 반경 수정 또는 공구 변경 필요 여부 | 전체 절삭 공정 불가, 안정된 최종가공 보장 |
| 포켓·홈의 폭 | 실제 공구가 들어갈 단면의 폭/여유 | 검사한 단면에서 선택 공구 폭이 맞는지 | 입구와 전 경로, 홀더·고정구까지 접근 가능 |
| 필요한 깊이·절삭 길이 | 특징의 깊이와 설정한 공구 유효 길이 비교 | 현재 공구 길이 조건과의 차이 | 처짐·칩 배출·열·공구 수명까지 적합 |
| 홀 축과 접근 방향 | CAD에서 확인한 원통/홀 축과 셋업 축 비교 | 현재 셋업에서 정렬 여부, 추가 방향 검토 필요 | 그 축으로 실제 드릴링 전 과정 가능 |
| 접근 표본 | 지정된 방향에서 관측한 차폐 여부 | 검사한 표본의 가시성/차폐 후보 | 유한 공구의 전체 접근성 또는 정확한 필요 셋업 수 |
| 특징 미인식 | 정의한 인식기의 대상과 제한 | 지원 범위 밖 또는 미확정 | 특징이 없다, 위험이 없다 |

원통면은 외부 보스일 수도 있고 내부 코너의 일부일 수도 있다. 원통 반경 하나로 구멍 또는 포켓 코너를 단정하지 않는다. 내부/외부, 인접 면, 개방 경계, 축 범위, 트림과 솔리드 관계를 검증한다. 샘플 기반 판단은 요청/유효 표본과 누락·미확정 범위를 함께 보존한다.

## 독립 검증에 포함할 반례

- 알려진 내부 반경·공구 지름의 경계 양쪽과 동일값; sharp corner와 fillet, 내부 코너와 외부 보스.
- 같은 폭·깊이지만 입구가 막힌 포켓, 층상 포켓, 오목한 바닥, 관통/막힌 홀, 교차 홀, 필렛 때문에 원통면이 분할된 형상.
- 동일 부품의 회전·이동·단위 변환·면 순서/분할, 접근 방향 반전. STEP 원본 기하와 표시용 메시를 구분한다.
- 레이는 통과하지만 공구 지름이 간섭하는 개구, 절삭부는 들어가도 샤프트·홀더가 간섭하는 형상, 이동 중 충돌.
- 손상 입력·다중 솔리드·자기 교차·인식 범위 밖 곡면에서 거짓 적합을 반환하지 않는지 확인.
- 형상 수정 전후에 기대한 지표만 어떻게 바뀌는지 확인하고, 수정이 다른 기능·공차를 훼손했는지는 별도 기록.

CAD 수식·독립 구성으로 정한 기대값과 실제 결과를 비교한다. 우리 함수 출력을 정답으로 복사하지 않는다. CAM 대조가 가능해지면 CAD/원소재/공구/홀더/고정구/셋업/전략/버전/충돌 설정을 맞추고 입력·설정·결과를 보존한다. 현재 실제 장비는 없으므로 외부 실물 자료가 없는 항목은 실물 검증 미완료로 남긴다.

## 이번 조사의 미확정 사항

- 위 공식 안내는 모든 절삭 문헌·상용 도구를 망라한 조사나 새로운 알고리즘의 독창성 증명이 아니다.
- 선삭·5축 연속 가공·EDM·복잡한 자유곡면·공구력/변형·정밀 공차·공구 수명은 별도 모델과 근거가 필요하다. 첫 3축 기하 검토가 이들 전체를 대신하지 않는다.
- 소재/공구/조건이 없는 일반 깊이비 기준으로 합격률을 학습하지 않는다. 외부 실물 데이터의 적용 가능성과 사용권은 자료 확보 시 별도로 확인한다.
- 이 기록 작성 중 확인한 Sandvik의 추정 드릴링 URL 한 개는 웹 도구에서 열리지 않았다. 읽지 못한 해당 페이지를 근거 목록에 포함하지 않았다. 위 M01~M05는 본문 확인이 완료된 별도 페이지다.
