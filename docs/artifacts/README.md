## 파일 확인과 출처

[manifest.json](manifest.json)은 각 파일의 원래 작업공간 상대 경로, 바이트 수와 SHA-256을 기록한다. `source_workspace_relative`는 이 저장소를 포함한 DFM 작업공간 기준이며, 보관 파일 위치인 `path`는 이 폴더 기준이다. 모든 복사본의 SHA-256을 원본과 대조했다. 이 색인은 과거 문서의 수치나 결론을 재검증했다는 뜻이 아니다.

동일한 프로그램을 반복 포장한 ZIP, 실행 환경, 캐시, 문서 렌더링 중간 이미지 등은 이 보관본에 포함하지 않는다. GitHub에 이미 있는 원문 PDF·DOCX·ZIP은 기존 경로에서 그대로 보존한다.
