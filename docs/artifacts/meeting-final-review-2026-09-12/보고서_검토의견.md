## 우선 수정 사항

### 2쪽 STL과 세 규칙의 상태

“원통을 추정할 수 없어”는 STL에서 원통 추정 자체가 불가능하다는 의미가 되어 부정확하다. 다음으로 교체하는 것이 좋다.

> STL에는 원통이나 곡면의 정보가 명시되어 있지 않아 별도의 특징 추정이 필요하다. 현재 수평 구멍 인식기는 미구현이며, 두께 변화와 최소 특징 검사는 오탐 가능성과 계산 부담 등을 고려하여 기본 비활성으로 둔다. STEP의 기하 정보를 활용하는 특징 분석은 후속 확장 대상으로 검토한다. STEP 입력 추가와 이를 이용한 분석 알고리즘 구현은 별도 작업이다.

4쪽 마지막의 “따라서 STEP 기반 특징 분석…”도 모든 앞선 한계가 STEP으로 해소되는 것처럼 읽힐 수 있다. 다음을 권한다.

> 곡면·구멍 등 기하 특징 분석에는 STEP 활용을 검토하고, 층보다 얇은 특징의 누락과 슬라이서 가변 선폭 차이는 별도의 단면·경로 대조로 검증한다.

### 4쪽 확인된 성능의 조건 복원

현재 표는 성과를 잘 보여주지만 조건을 지나치게 줄인 행이 있다.

- **기존 기능 유지 검사 비고:** “2026-09-09 Linux, Python 3.12.14, v2.6 기록. Windows 전체 일괄 통과와 구분.” Windows에서는 기본 55개와 해당 UI 단독 재시험 통과 기록이 있으며 이를 Linux의 222개 일괄 통과로 합치지 않는다.
- **외부 STL 처리 비고:** “비무작위 표본. 단면 계산 완료는 3D 종합 평가 통과와 다름. 원본 16개 중 점수 산출 2개.” 세부 분포는 입력 부적합 5개, 측정 근거 부족 7개, 프로필 위반 2개다. 원본과 정리 후보를 독립 부품으로 중복 집계하지 않는다.
- **규칙별 형상 검토:** “9개 규칙에서 목표 경고 확인”은 각 규칙에 대응한 시험 사례의 동작 확인이다. 모든 규칙의 검출 정확도나 해당 규칙만 단독 위반하는 형상 9개라는 뜻은 아니다. 일부 형상에서는 다른 규칙도 함께 경고한다.
- **시험 조건:** 표 아래에 적용 프로필, 단위, 방향, 층 높이, 선폭과 선택 규칙의 활성 여부를 기록한다. 선택 규칙을 켠 시험과 기본 규칙 시험을 구분한다.

실행시간은 현재 미팅의 필수 지표는 아니다. 처리 성능을 주장하지 않는 한 삭제 상태를 유지해도 된다. 대신 결과 해석에 필요한 실행 환경과 입력 조건은 남겨야 한다.

> 9월에는 대표 형상 6~8개와 경계값 변형의 설계값·측정값·판정을 비교하고, 대표 3~4개를 동일 조건의 Cura 단면·경로와 대조한다. 우선 결함 1~2건을 수정한 뒤 보정에 사용하지 않은 확인 사례를 재실행한다. 설정과 재현 절차, 남은 한계를 기록하며 STEP 기반 특징 분석과 자동 메시 복구 확대는 후속 과제로 분리한다. 사례 수는 이번 작업 범위이며 통계적 충분성을 뜻하지 않는다.

### 7쪽 밀폐공동 설명

현재 표만 보면 모든 공정에서 밀폐공동을 금지하는 것으로 읽힐 수 있다. “배출 통로 검출도…”는 실제 배출 통로 검출 기능이 존재하는 듯한 인상도 준다. 다음을 추가·교체한다.
