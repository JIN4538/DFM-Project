# 보고서를 보며 진행하는 DFM 미팅 대본

## 사용 방법

기준 자료는 「DFM Project 1차 미팅 자료_캡처부록추가.docx」 15쪽이다. 아래 쪽수는 대본이 아닌 보고서 쪽수다. 본문 설명 10~12분, 캡처 설명 6~8분, 질의와 계획 협의 20~30분을 예상한다. 시간은 화면 이동과 질문에 따라 조정한다. 따옴표 안은 읽을 대본이며, 화면 안내와 진행 메모는 읽지 않는다.

## 시작 전 준비

보고서 PDF와 이 대본을 따로 열고 보고서 창만 공유한다. 캡처는 한 페이지 전체보다 설명할 부분을 확대한다. 1~5쪽 → 10~15쪽 순서로 설명하고, 6~9쪽은 근거 질문이 있을 때 연다. 원본 캡처도 열어 두어 PDF 글자가 작으면 해당 사진을 보여준다.

## 보고서 1쪽 요약과 프로젝트 개요 2분

“오늘은 프로그램이 현재 무엇을 검토할 수 있는지, 어떤 오류를 수정했는지, 그리고 다음 검증을 어떻게 진행할지 말씀드리겠습니다.
현재 프로그램은 STL 형상을 입력받아 적층제조에서 검토가 필요한 위치와 지표를 보여주는 도구입니다. 현재 검증의 중심은 FDM입니다. 점수는 여러 규칙과 방향을 비교하기 위한 값이며, 실제 출력 성공률을 의미하지는 않습니다.
개발하면서 가장 중점적으로 수정한 부분은 잘못된 통과 판정과 측정 오류입니다. 입력이 불완전한 경우, 측정 근거가 부족한 경우, 설정한 프로필 기준에 미달하는 경우를 구분하도록 했습니다. 전체 입체 분석이 어려워도 확정 가능한 층 단면은 별도로 검토할 수 있게 했습니다.”

# 근거와 개발 경과 설명

## 보고서 2쪽 규칙의 근거 1분 30초

[화면] 3.1의 근거 유형 표를 가리킨다.
“표준은 벽두께나 오버행처럼 무엇을 고려해야 하는지를 제시합니다. 여기 나온 모든 숫자를 표준에서 직접 가져온 것은 아닙니다. 층 높이와 선폭은 사용자가 정하는 분석 조건이고, 문헌 실험값은 해당 장비와 재료 조건에서 얻어진 값입니다. 오버행 비율 30%와 같은 수치는 비교와 경고를 작동시키기 위한 잠정 기준입니다.
따라서 수치를 정한 목적과 그 숫자의 실증 여부를 구분해야 합니다. 예를 들어 오버행 비율이 커지는 정도를 비교하려고 점수 기준을 두었지만, 30%부터 출력이 실패한다는 뜻은 아닙니다.”

## 보고서 2쪽 프로그램 구성 1분

“입력 후에는 메시의 연결 상태를 진단하고, 3D 규칙 평가와 층 단면 검토를 수행합니다. 3D 평가에는 하드 게이트 네 가지와 소프트 규칙 열 가지가 있으며, 기본 FDM 설정에서는 일곱 가지 소프트 규칙을 평가합니다.
최소 특징과 두께 변화는 각각 계산 비용과 오탐 문제 때문에 기본 비활성이고, 수평 구멍은 현재 인식기가 구현되지 않았습니다. 이 항목들은 N/A로 표시합니다. STL에서 원통을 추정하는 일이 원리적으로 불가능하다는 뜻은 아닙니다.”

## 보고서 3쪽 개발 경과 2분

[화면] 버전 표는 전체 흐름만 짚고, 5.1과 5.3을 중심으로 설명한다.
“버전별 변경의 목적은 잘못된 결과를 줄이고, 어떤 근거로 판정했는지를 보여주는 것입니다. 예를 들어 특정 평판에서 두께를 73.2% 크게 측정했던 오류를 수정했습니다. 이 수치는 그 시험 사례의 오차이며, 전체 정확도가 그만큼 개선됐다는 뜻은 아닙니다.
현재는 얇다고 의심되는 면의 내부 세 지점에서 반대편 면까지 거리를 다시 확인합니다. 한 지점의 이상치만으로 판단하는 문제와, 대표값만 보다가 작은 얇은 부분을 놓치는 문제를 줄이려는 절차입니다.
층별 검토에서는 작은 후보를 삭제하기보다 별도 세부로 남기도록 했습니다. 여기서 후보는 실제 결함이 확정된 곳이 아니라, 계산상 추가 확인이 필요한 영역입니다. 작은 핀처럼 하나의 재료 성분 전체가 영향을 받으면 크기가 작아도 우선 검토에 남깁니다.”

교수님께서는 우선 검증 대상을 벽두께·간격·브리지로 잡는 것이 적절하다고 보시는지 의견을 부탁드립니다. 또 검증에 사용할 대표 부품이나 장비·재료 조건을 정할 수 있으면 좋겠습니다. STEP 확장은 어떤 대상 부품에서 먼저 필요할지도 함께 논의하고 싶습니다.”

## 질의 시간에 할 일

질문을 받은 뒤 관련 쪽만 이동한다. 답변이 확인된 사실인지 향후 계획인지 구분하고, 근거가 없는 수치를 즉석에서 정하지 않는다. 모르는 부분은 “현재 자료로는 확정하기 어렵습니다. 해당 조건으로 확인해서 결과를 정리하겠습니다”라고 답한다. 교수님의 요구를 검증 대상·조건·완료 기준으로 메모한다.

## 종료 직전 확인할 내용

“오늘 말씀해주신 내용을 바탕으로 우선 검증 대상은 ○○, 비교 조건은 ○○로 잡겠습니다. 다음 미팅에서는 계산 오차와 검출 위치, 슬라이서와의 차이, 수정 전후 결과를 가져오겠습니다.”
[진행 메모] 빈칸에는 실제 합의한 내용만 넣는다. 시간이 부족하면 11·12·15쪽은 짧게 넘기고, 13·14쪽 비교와 5쪽 계획 협의를 우선한다.
# 근거 질문에 답하는 대본

## 임계값과 가중치를 왜 그렇게 정했나 보고서 8쪽

“수치의 역할은 설명할 수 있지만, 정확히 그 숫자여야 한다는 실증은 아직 부족합니다. 오버행 비율은 위험면의 비중을 서로 다른 크기의 부품끼리 비교하려고 사용했고, 30%는 그 비율을 경고와 점수로 바꾸기 위한 초기 기준입니다. 가중치는 벽두께와 오버행을 중요하게 반영하려는 배분이지만, 0.20이 최적이라는 검증은 없습니다. 앞으로 독립 사례와 민감도 비교로 검토해야 합니다.”

## Cura로 계수를 맞췄다는 의미는 무엇인가 보고서 9쪽

“형상에서 투영 면적·둘레·대표 높이를 계산하고, Cura에서 얻은 서포트 ON/OFF의 필라멘트 사용량 차이를 부피로 환산한 대용값에 추정식이 가까워지도록 계수를 맞춘 것입니다. 실제 출력한 서포트를 직접 측정한 정답은 아닙니다. 동일한 24건에 대한 높은 적합도는 확인했지만 새로운 부품에서 별도로 비교해야 합니다.”

## 종합 점수를 막으면서 개별 점수는 왜 보여주나 보고서 7쪽과 13쪽

“종합 점수는 여러 항목을 합치므로, 필수 제약 미충족이 다른 높은 점수에 가려질 수 있습니다. 그래서 종합 점수를 제한합니다. 반면 유효하게 계산한 개별 결과는 문제 항목과 개선 방향을 파악하는 데 도움이 됩니다. 계산 자체의 근거가 부족한 항목까지 점수를 주는 것은 아닙니다.”

## 선폭 0.3 mm인데 하한은 왜 0.4 mm인가 보고서 2쪽과 8쪽

“단면 선폭은 층별 형상 검토에 쓰는 사용자 입력이고, 벽두께 하한은 별도의 공정 프로필 기준입니다. 현재는 서로 자동 연동되지 않아 선폭을 바꿔도 하한이 유지됩니다. 실제 사용하는 노즐과 슬라이서 조건에 맞게 두 설정의 의미를 함께 확인해야 합니다.”

## GB 같은 형상은 왜 거부되며 STEP이면 해결되나 보고서 4쪽

“GB는 검사에서 한 모서리에 세 개 이상 면이 연결된 곳이 원본 1,274개, 정리본에도 1,142개 남았습니다. 단순한 면 정리만으로 정상 입체가 되지는 않았습니다. 정상 CAD 원본의 STEP을 사용하면 도움이 될 수 있지만, 손상된 STL을 STEP으로 변환하는 것만으로 연결 문제가 복구되는 것은 아닙니다.”
[진행 메모] GB 수치는 이번 별도 진단 결과이며 보고서의 실적 표에 포함된 새 검증 주장으로 섞지 않는다.

## 기존 툴과의 차이 또는 연구 기여를 묻는다면

“현재 목표는 단일 부품의 위험 위치와 방향별 지표, 판단하지 못한 범위를 근거와 함께 설명하는 것입니다. 기존 툴 대비 우월성이나 새 알고리즘의 독창성을 아직 입증한 것은 아닙니다. 동일 형상과 조건으로 비교해 어떤 정보가 설계 수정에 도움이 되는지 확인해야 합니다.”
