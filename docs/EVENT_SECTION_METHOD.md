# 형상 변화 높이에 맞춘 단면 체적 검산

균등 단면 수만 늘리면 얇은 판을 놓치거나 판의 체적을 과대평가할 수 있다. 이전 냉각팬 솔리드2 검증에서 1.2 mm 끝판은 64개 균등 표본에서 누락됐고, 1,024개에서도 메시 체적과 약 −3.91% 차이가 남았다. 이 반례 때문에 형상 변화 기준 검산을 추가했다. 이 수치와 원래 균등 표본 결과는 당시 검증 기록으로 보존한다. [반례와 독립 대조](project-knowledge/CROSS_SECTION_ALIASING_2026-09-15.md).

2026-09-15 후속 개선에서는 앱의 기본 선택을 **자동**으로 변경했다. 형상 변화 기준을 먼저 시도하고, 계산 전 예산 초과가 확인될 때만 균등 단면 비교로 이어간다. 원래 검산이 완료되지 않았다는 사실과 전환 이유를 기록한다. 표현 한계로 일부 구간이 빠지면 계산한 부분합과 누락 기여 상한을 표시하되 전체 완료로 바꾸지 않는다. [외부 검토보고의 타당성 평가](project-knowledge/CLAUDE_REVIEW_VALIDITY_2026-09-15.md).

## 수학적 근거와 적용 대상

닫힌 비자기교차 삼각형 메시를 고정하고 모든 정점의 빌드 Z를 정렬한다. 이웃한 서로 다른 Z 사이에는 삼각형의 단면 교차 관계가 바뀌지 않는다. 각 모서리와 수평면의 교점 좌표는 Z의 일차식이고, 닫힌 다각형의 shoelace 면적은 이차식이다. 내부 윤곽의 면적을 빼는 재료 단면도 같은 성질을 가진다. 이 유도는 입력의 유효한 재료 경계와 닫힌 단면을 전제로 한다.

구간 (a,b)의 두 표본은 `z=(a+b)/2 ± (b−a)/(2√3)`, 각 가중치는 `(b−a)/2`다. 2점 Gauss–Legendre 규칙은 정확한 산술에서 3차 이하 다항식을 적분한다. 따라서 구간별 이차 단면적을 두 값으로 적분할 수 있다. 일반 Gauss 적분 오차와 Legendre 규칙은 [NIST DLMF §3.5(v), 식 3.5.19·3.5.21](https://dlmf.nist.gov/3.5.v)에 근거한다. 이는 고정 다면체의 기하학적 유도이며 CAD 곡면이나 적층제조 물리의 정확도 정리가 아니다.

실제 구현은 부동소수점과 단면 좌표 그리드를 사용한다. 전체 위상 검사도 모든 자기교차를 검출하는 증명은 아니다. 별도의 사면체 체적과 비교하고, 닫히지 않은 단면과 수치적으로 분리되지 않는 구간은 미확정으로 남긴다.

겹친 여러 바디의 경계 메시에는 원래 정점 이외의 높이에서도 합집합 구조 변화가 생길 수 있다. non-zero winding 단면이 재료를 합치더라도 원래 정점 높이만으로 적분의 정확성을 보장하지 못한다. 실제 두 상자 반례에서 내부 함수의 `complete`와 독립 합집합 체적이 약 0.1934% 달랐다. 사용자 입력 경로는 해당 여러 셸 STL을 이미 미확정으로 차단한다. [독립 반례와 진입 경로 확인](project-knowledge/CLAUDE_REVIEW_VALIDITY_2026-09-15.md#독립-반례-겹치는-두-정육면체).

## 측정 계약

- 현재 선택 방향과 평면 내 회전을 포함한 최종 배치를 그대로 사용한다. 입력을 축소하거나 원본을 편집하지 않는다.
- 정점 높이를 임의의 간격으로 합치지 않는다. 두 내부 표본을 서로 다르게 표현할 수 없는 구간은 `representation_limit`, 닫힌 단면을 확보하지 못한 구간은 `section_failure`, 계산 중 선분 한도는 `runtime_budget`으로 구분한다. 일부 구간이 빠지면 `status=partial`을 유지하며 전체 사건 적분값은 `None`이다.
- 부분 결과에는 계산한 구간의 합 `known_interval_volume_mm3`, 누락 높이와 XY 외곽으로 얻은 `omitted_interval_volume_envelope_mm3`, 원인별 구간 수를 제공한다. 누락 기여 범위는 입력 부동소수 좌표의 유리수 표현을 이용해 위쪽으로 반올림한다. 이것은 **누락 높이 구간의 기여만 한정**하며, 계산한 부분합의 반올림·단면 재구성·CAD 메시 근사 오차를 포함하지 않는다. `known_plus_omitted_envelope_mm3`도 전체 실제 체적의 보증 상한이 아니다. 누락이 표현 한계에만 해당하는지 별도로 기록하며 작은 비율을 임의 합격 기준으로 사용하지 않는다.
- 기본 한도는 8,192개 단면과 예상 교차 선분 150만 개다. 사건 함수는 둘 중 하나라도 넘으면 `failure_code=event_budget_exceeded`와 원인을 반환한다. 명시적 `events` 모드는 여기서 끝난다. `auto` 모드는 단면을 계산하기 전 이 예산 거부가 나온 경우에만 균등 표본을 계산하며 원래 결과를 `event_attempt`에 보존한다. 위상 실패·실행 중 예산 초과·단면 재구성 실패·시간 초과는 이 자동 전환의 대상이 아니다. 앱 작업자 실행 시간 한도는 90초다.
- 모든 필요한 단면이 확정됐을 때만 `volume_quadrature_estimate_mm3`를 제공한다. 기존 `volume_midpoint_estimate_mm3`와 별개다.
- 균등 전환 결과의 `complete`는 요청한 균등 표본의 완료다. 사건 검산의 완료나 얇은 높이 구간의 포괄성을 뜻하지 않는다. UI와 보고서에도 이를 구분하고, `requested_sampling`, 실제 `sampling`, `fallback_performed`, `fallback_trigger`, 전환 이유와 표본 수를 보존한다.
- 면적·둘레·A/P·영역 수·내부 윤곽 수·이전 확정 단면과의 대칭차를 표시한다. 불균등한 표본 간격에서 대칭차 면적은 단위 높이 변화율이 아니다.
- **두 표본의 최대 면적은 구간의 최대 면적이 아니다.** 원뿔에서도 체적 적분은 맞지만 아래 끝면의 최대 면적을 직접 찍지 않는다. UI와 보고서는 계속 ‘표본 최대’라고 표시한다.
- 체적 차이가 작더라도 국소 특징·곡면 근사·공정 합격을 보증하지 않는다. 조립체의 재료 합집합, 미확정 여러 메시, 재료 내부 없는 곡면 STEP은 별도 솔리드 선택 또는 판정 보류가 필요하다.

4개 공정에서 동일한 기하 계산을 사용하며 결과의 제조 의미는 공정별 문헌에 연결한다. VPP 박리력·흡착 컵, PBF 열변형·분말 제거 성공, FDM 압출 경로의 성공을 새 적분법으로 확정하지 않는다. [공정별 문헌 조건](research/AM_DFM_EVIDENCE_REAUDIT.md).

## 재현

`run_detail(model, profile, direction, mode="sections", sampling="events")`로 작업자 격리·시간 한도·모델/프로필/방향 일치 검사를 적용한다. 자동 선택은 `sampling="auto", sample_count=64`로 호출한다. 기존 API 호출의 기본값 `sampling="uniform"`은 유지한다. 앱에서는 ‘정밀 검토 → 단면 배치 방법’의 **자동**이 기본이며, 사건 기준과 균등 간격을 직접 지정할 수 있다.

단위 반례는 `tests_v3/test_event_sections.py`, 4공정 API와 UI 통합은 `test_cross_sections.py`·`test_app.py`에 있다. 전수 실행에서 사용한 코드 지문·대상·부분 결과는 최종 검토 기록에 별도로 보존한다.
