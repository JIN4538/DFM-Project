# 장비와 설계 목적을 반영하는 검토

처음에는 **형상 선택 → 검토 조건 입력 → 설계 검토 → 개선 카드의 위치 보기** 순서로 사용하세요. 장비가 정해지지 않았으면 ‘미확정’, 중점은 ‘종합 균형’으로 시작하면 됩니다.

## 무엇이 달라졌나요?

첫 화면의 **검토 조건 · 장비와 중요하게 볼 항목**에서 장비·재료를 입력하고 가장 중요한 항목을 선택합니다. 결과에는 적용한 조건이 표시됩니다. 중점을 바꾸면 이전 결과는 숨겨지고, 다시 검토한 결과에 새 조건이 기록됩니다.

**권장 개선 순서**의 각 카드는 관측한 내용, 할 일, 위치를 함께 보여줍니다. ‘위치와 측정값 보기’를 누르면 같은 화면 아래에서 해당 부위를 확인할 수 있습니다. 이미 자동 계산한 벽·층·단면을 보려고 정밀 검토를 다시 실행할 필요는 없습니다.

## 중점을 선택하면 실제로 무엇을 하나요?

| 선택 | 실제로 달라지는 것 | 계산하지 않는 것 |
|---|---|---|
| 종합 균형 | 공정에서 사용할 수 있는 방향 지표를 같은 비중으로 비교하고, 관측 문제부터 안내 | 물리적 최적·제조 성공률 |
| 서포트 후보 줄이기 | 하향면 지표의 비중을 다른 지표의 3배로 높여 방향을 추천하고 관련 조치를 먼저 안내 | 생성될 서포트 부피·제거 작업량 |
| 빌드 높이 낮추기 | 높이 비중을 3배로 높여 방향 추천 | 실제 출력 시간 |
| 평평한 바닥 확보 | FDM에서 평평한 바닥 면적 비중을 3배로 높임 | 접착력 |
| 강도 관련 형상 확인 | 적층에서는 관측된 벽 관련 조치를 먼저 표시. 절삭에서는 요구를 기록 | 하중 해석·강도·안전율·최적 강도 방향 |
| 치수 관련 항목 확인 | 구멍·벽·공구 반경 등 실제 계산한 치수 비교를 먼저 표시 | 공차 만족·가공 오차 |
| 표면 관련 형상 확인 | 공정별 단면·하향면 또는 오목면 관련 조치를 먼저 표시 | 표면 거칠기 |
| 비용 관련 형상 확인 | 적층의 지지 후보 관련 정보를 먼저 안내. 절삭과 고분자 PBF는 요구 기록 | 견적·가공 시간 |
| 공구 접근 확인 | 절삭에서 표면 가림·원통·포켓 조치를 먼저 안내 | 공구·홀더의 전체 경로 충돌 |

공정에 맞지 않는 항목은 기본 선택 목록에서 제외했습니다. AI가 이런 요구를 읽더라도 적용할 수 없는 이유를 표시합니다. 고분자 PBF의 방향 비교는 현재 높이 한 항목이므로 ‘높이’ 중점을 골라도 기본 순위와 같습니다.

3배 비중은 **사용자 선호를 반영하기 위한 소프트웨어 정책**입니다. 문헌에서 정한 물리 상수나 실험으로 보정한 성공률이 아닙니다. 중요한 항목 외의 기본 검사도 유지하고, 입력 형상 문제와 공간 초과를 먼저 처리합니다. 현재 방향을 바꾸기만 해서 추천 기준이 바뀌지는 않습니다.

## 장비 이름을 입력하면 기준값도 적용되나요?

장비·재료 이름과 맞는 조건 자료를 찾아 보여줍니다. **가져올 값과 적용 조건 확인**을 펼쳐 제조사·재료·판본·출처를 확인한 다음 **이 자료의 조건 가져오기**를 누르세요. 이때만 등록된 수치가 실제 검사 입력에 적용됩니다.

이름만 일치한다고 같은 재료 등급이나 출력 조건까지 검증된 것은 아닙니다. 없는 자료나 수치는 AI가 추정해 채우지 않습니다. 참고 물성만 있는 자료는 계산에 적용하는 버튼이 없습니다.

적층의 장비·재료를 AI로 변경하면 이전 수치 기준과 크기 제한을 초기화합니다. 라이브러리 조건 적용 후 이름을 직접 바꿔도 이전 자료의 기준을 초기화합니다. 중점만 바꾸면 기존 수치 조건은 유지합니다. 빌드 공간 제한은 기본적으로 꺼져 있습니다.

## AI는 어떻게 사용하나요?

1. 검토 조건 안의 **문장으로 입력 · AI 요구사항 해석**을 펼칩니다.
2. 예: ‘FDM으로 Prusa MK4S에서 PLA를 사용할 예정이고, 서포트가 적게 필요한 방향을 우선하고 싶어.’
3. **AI 연결 설정**에 OpenAI API 키를 입력합니다. 기본 모델은 `gpt-4.1-mini`이며 계정에서 사용할 수 있는 구조화 출력 지원 모델로 변경할 수 있습니다.
4. **AI로 입력 문장 해석**을 누릅니다. 해석한 장비·재료·공정·중점을 확인하고 **해석을 검토 조건에 반영**을 누릅니다. 필요하면 필드를 직접 수정할 수 있습니다.
5. 관련 조건 자료를 확인해 가져오고 **설계 검토**를 실행합니다. 방향 제안과 개선 카드에 이 요구가 반영됩니다.

AI가 수치 계산을 대신하는 구조가 아닙니다. AI는 문장을 구조화하고, 프로그램은 검증된 입력 항목·조건 자료·기하 계산으로 개선안을 만듭니다. 문장 속 임의 치수·공차·하중은 추가 요구로 기록할 수 있지만 수치 기준으로 자동 적용하지 않습니다.

키가 없으면 **AI 미연결**로 표시합니다. 장비·재료 직접 입력, 조건 검색, 중점 선택, 검토·추천은 그대로 사용할 수 있습니다. 이것을 AI가 실행된 결과라고 표시하지 않습니다.

## 연결·저장과 오류 처리

- 키는 화면의 비밀번호 입력, `OPENAI_API_KEY` 환경변수, 또는 `.streamlit/secrets.toml`에서 읽습니다. 비밀번호 입력 키는 현재 세션에만 남고, 결과 보고서에 저장하지 않습니다. ‘입력한 키 지우기’는 화면에서 입력한 키만 지웁니다.
- ‘AI로 입력 문장 해석’을 누를 때만 API를 호출합니다. 모델 회전이나 화면 전환으로 재호출하지 않습니다. 입력 문장만 보내며 CAD·측정 원자료는 보내지 않습니다. API 이용료는 연결한 계정 기준입니다.
- `store:false`로 요청합니다. 이는 모든 제공자 로그의 무보관을 보증하는 설정이 아닙니다. [OpenAI 데이터 관리 설명](https://developers.openai.com/api/docs/guides/your-data)을 참고하세요.
- 인증 실패, 시간 초과, 거부, 부분 응답, 형식 오류에는 조건을 적용하지 않습니다. 실패했다고 자동 재시도하지 않습니다.
- JSON·HTML에는 장비·재료·중점, 실제 적용값, AI 사용 시 모델·응답 식별자를 보존합니다. 직접 수정한 입력은 수동 입력으로 표시합니다.

## 검증 범위

기하 계산·조건 전달·추천 변화·오류 처리를 코드와 사용자 흐름 검사로 확인합니다. 실제 AI의 한국어 의도 해석 성능은 별도 평가입니다. 현재 개발 환경에 API 키가 없어 실제 모델 응답 시험은 수행하지 않았습니다. 준비된 평가 사례와 실행 방법은 `scripts/evaluate_ai_intent.py --help`에서 볼 수 있습니다.

어떤 방식으로 입력하든 이 툴은 현재 지원하는 **기하 제조성 검토**를 제공합니다. 실물 제조 성공률, 강도, 실제 가공 시간의 검증을 완료한 제품은 아닙니다.
