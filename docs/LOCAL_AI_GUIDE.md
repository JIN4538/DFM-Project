# 종합 결론과 개선안 사용법

1. **형상을 선택**합니다.
2. **공정·장비·재료·중점**을 설정합니다. 모르는 항목은 비워 둡니다.
3. **설계 검토**를 누릅니다.
4. **종합 결론**에서 우선 개선안을 읽습니다. 추천 방향은 버튼으로 바로 적용합니다.
5. **문제 위치 보기**를 누르면 해당 위치로 바로 이동합니다. 자세한 이유는 **판단 근거·전체 조치**에서 읽습니다.

조건을 바꾸면 이전 결과가 사라집니다. 본문이나 왼쪽의 검토 버튼을 누르면 새 조건으로 다시 계산합니다.

| 표시 | 의미 |
|---|---|
| 수정 | 측정값과 적용 규칙에서 개선할 항목이 있음 |
| 추가 확인 | 기준·계산 결과를 더 확인해야 함 |
| 확인됨 | 해당 항목의 확인을 마침 |

장비·재료 선택창은 클릭해서 고르거나 이름을 직접 입력할 수 있습니다. 벽 비교값은 공정별 기본값으로 시작하며 왼쪽 검토 기준에서 바꿀 수 있습니다.

절삭에서는 **변경할 수 있는 항목**을 고릅니다. 원래 형상을 유지해야 하면 ‘공구만’을 선택합니다. 표시된 공구 치수는 필요한 조건 제안이며, 형상 치수 수정은 CAD에서 반영한 뒤 다시 검토합니다.

**공구 치수를 몰라도 시작할 수 있습니다.** 빈 지름·날 길이·돌출 길이는 형상에서 제안하고 종합 결론에 표시합니다. 보유 공구를 비교하려면 왼쪽 **보유 공구 지정 (선택)**에 아는 값만 입력하세요. 입력한 값은 유지하고 나머지만 채웁니다. **추가 기준·출처**에서 자동 제안의 지름 비율·길이 여유를 바꿀 수 있습니다.

**다른 개선안 비교**에서 ‘이 개선안을 선호함’을 누르면 이 PC의 다음 추천에 반영됩니다. 공정·장비·재료·중점·변경 허용 조건별로 저장하며, **추천·학습 기록 → 저장한 선호 초기화**로 되돌립니다.

벽 그림의 **×**는 기준 미만 표본, **◆**는 선택한 위치입니다. 전체 부품에서 위치를 찾고, 옆이나 아래의 확대 단면에서 두 면 사이 거리와 치수선을 확인합니다. 두께를 읽기 위해 부품 전체가 얼마나 얇게 보이는지 추측할 필요가 없습니다.

모든 내장 모델은 외부 API 없이 실행합니다.

| AI 역할 | 화면에서 달라지는 점 |
|---|---|
| 딥러닝 방향 탐색 | 26방향 외의 추가 방향을 제안합니다. 큰 평면 후보와 함께 실제 기하를 계산한 뒤 비교합니다. 왼쪽 **AI 추가 방향 탐색**에서 켜고 끕니다. |
| 강화학습 순차 개선 | 절삭에서 어떤 특징·공구 치수를 어떤 순서로 바꿀지 계획합니다. 기존안과 다시 비교해 하나의 결론을 제시합니다. |
| 개선안 순위·사용자 선호 학습 | 선택한 중점과 명시적으로 저장한 선호를 추천에 반영합니다. |

**추천·학습 기록**을 열면 AI가 제안한 방향 수, 선택 출처, 절삭 수정 순서와 모델 식별자를 확인할 수 있습니다. 형상 치수 수정은 제안으로 표시되며 원본 CAD 파일을 자동으로 덮어쓰지 않습니다.
