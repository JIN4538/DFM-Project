# 한 번 검토하고, 바꿀 곳부터 확인하기

2026-10-02 현재 사용 순서는 [적층 안내](USER_GUIDE_V3.md)와 [절삭 안내](USER_GUIDE_MACHINING.md)를 따릅니다. 입력은 적층 시연용 형상 / 절삭 시연용 형상 / 업로드로 합쳤으며, 지원하는 절삭 코너는 추천 수정 적용·재검토에서 실제 STEP 전후를 확인할 수 있습니다. 아래는 2026-09-28 흐름을 설명한 상세 기록입니다.

## 가장 간단한 사용 순서

1. 형상을 선택하고 공정을 고릅니다. 알고 있는 장비·재료·공구 조건이 있다면 조건 라이브러리 또는 직접 입력으로 지정합니다.
2. **설계 검토**를 누릅니다. 적층은 기본적으로 벽·층간·단면 검토까지 자동 실행합니다. 층간 검토는 MEX에 적용됩니다.
3. 첫 결과의 **종합 방향 제안**과 **권장 개선 순서**를 읽습니다. 무엇을 먼저 확인하고 바꿀지 여기서 안내합니다.
4. **문제 위치와 측정값**에서 해당 위치를 확인합니다. 다른 화면에서 정밀 검토를 다시 실행할 필요가 없습니다.
5. 방향 변경이 제안되면 **추천 방향 적용·전체 다시 검토**를 누릅니다. 형상을 수정했다면 새 파일을 넣어 검토한 뒤 수정 전후를 비교합니다.

## 첫 결과는 어떻게 읽나요?

| 표시 | 의미 | 할 일 |
|---|---|---|
| 설계·배치 확인 | 계산한 형상에서 기준과 비교하거나 배치를 확인할 후보가 관측됐습니다. | 표시한 위치와 치수를 보고 제안한 수정·배치 변경을 검토합니다. |
| 조건 확인 | 측정값은 있어도 사용할 장비·재료 등의 기준이 부족합니다. | 필요한 조건을 입력합니다. 예를 들어 벽 거리 0.3 mm를 판단하려면 사용할 공정의 최소 벽 기준이 필요합니다. |
| 미확인 계산 | 계산 시간 또는 입력 문제로 확인하지 못한 범위입니다. | 원인을 확인합니다. 시간이 부족했다면 같은 화면의 **이 항목 추가 계산**을 누릅니다. |
| 현재 방향 유지 | 현재 방향이 기본 종합 비교에서 추천 후보와 동등하거나 더 유리합니다. | 방향을 다시 바꿀 필요가 없습니다. 남은 설계·조건 확인을 진행합니다. |

우선 조치는 최대 3개를 먼저 보여줍니다. 나머지는 **이 화면에서 바로 확인할 항목**과 **전체 검토 현황**에서 확인합니다. 주황색 위치 표시 자체가 제조 불가 판정은 아닙니다. 옆에 표시되는 측정값·기준·판단을 함께 읽어 주세요.

## 종합 방향은 어떻게 고르나요?

이제 목적을 먼저 고르지 않아도 기본 방향을 하나 제안합니다. 먼저 입력한 빌드 공간에 들어가는 후보를 고르고, 공정별로 아래 지표를 함께 비교합니다.

| 공정 | 기본 비교에 사용하는 지표 |
|---|---|
| 재료 압출 · FFF/FDM | 하향면 후보의 투영면적 합, 높이, 평평한 바닥 면적 |
| 광중합 · SLA/DLP | 하향면 후보의 투영면적 합, 높이 |
| 금속 분말베드융합 | 하향면 후보의 투영면적 합, 높이 |
| 고분자 분말베드융합 | 현재는 높이만 비교할 수 있어 제한된 제안으로 표시 |

각 지표를 후보들의 값 범위에 맞추고 같은 비중으로 비교합니다. 이는 **앱이 공개한 기본 선택 정책**이며 표준에서 지정한 가중치나 실험으로 학습한 성공 확률이 아닙니다. 예를 들어 높이가 낮아지면서 바닥 면적이 줄면 두 변화가 함께 표시됩니다. 자세한 계산 기준은 접힌 **추천 기준·같은 수준의 대안·미검토 항목**에서 볼 수 있습니다.

같은 형상·공정·설정·후보 집합이면 현재 방향만 바꿔도 고정 후보의 추천은 유지됩니다. 현재가 동등하거나 더 유리하면 현재 방향 유지를 안내합니다. 조건·형상·후보 집합을 바꾸면 추천이 달라질 수 있습니다.

별도 목적이 명확할 때는 **방향 비교**의 상세 비교에서 높이 등 특정 항목을 선택할 수 있습니다. 이 수동 비교가 첫 화면의 기본 종합 추천을 바꾸지는 않습니다.

## 벽·층간·단면은 어디서 보나요?

- **벽:** 기준보다 작게 측정된 표본 또는 가장 짧은 표본을 먼저 보여줍니다. 측정점과 거리를 확인하고, 필요한 경우 같은 화면에서 최소 벽 기준을 입력합니다. 표본의 법선 관통거리가 전체 형상의 최소 두께를 보증하지는 않습니다.
- **층간:** 후보가 있는 높이와 위치를 먼저 보여줍니다. 후보가 없으면 검토 범위를 설명합니다. 실제 슬라이서의 경로와 서포트 생성 여부는 별도 확인입니다.
- **단면:** 변화가 관측된 두 단면과 높이를 보여줍니다. 서로 다른 표본 단면의 차이이며, 그 사이의 모든 높이를 확인한 것은 아닙니다.

**정밀 검토** 화면은 자동 계산 결과를 자세히 보거나 계산 조건을 바꿔 추가 확인할 때 사용합니다. 기본 사용 순서에서 반드시 다시 눌러야 하는 단계가 아닙니다.

자동 상세 검토에는 공유 45초 계산 예산이 있습니다. 파일 읽기·기본 검토·작업 준비 시간까지 포함한 전체 실행 시간이 반드시 45초 이내라는 뜻은 아닙니다. 큰 형상에서는 일부 계산이 미완료일 수 있으며, 이를 정상으로 표시하지 않습니다. 추가 계산은 해당 항목만 시간을 늘려 재실행합니다.

## 절삭가공에서는 무엇이 달라졌나요?

첫 결과에 실제 형상 치수와 입력한 공구 치수를 비교한 **우선 확인할 설계·공구 조건**을 보여줍니다. 각 카드의 **이 위치 보기**를 누르면 관련 면·특징이 선택됩니다. 공구 치수가 없으면 결함이라고 단정하지 않고 필요한 입력을 안내합니다.

선택 방향의 표면 가림 검사는 기본 실행됩니다. 제한된 표본의 직선 가림을 보는 기능이므로, 실제 공구와 홀더의 충돌이나 CAM 경로 전체를 확인한 결과는 아닙니다.

## 이 결과로 어디까지 결정할 수 있나요?

현재 툴은 **관측된 기하 문제와 입력 조건을 근거로 설계·배치 개선의 우선순위를 정하는 도구**입니다. 열변형, 하중에 따른 강도, 실제 서포트량, 접착력, 가공 고정, 표면 품질, 실제 제조 성공 확률까지 함께 판단하지 않습니다. 확인하지 못한 조건은 결과와 HTML 보고서에도 남습니다.

일반적인 사용에서는 첫 화면의 제안을 적용하고 남은 조치를 순서대로 확인하면 됩니다. 개별 수치의 원리와 원자료가 필요할 때만 상세 화면을 펼치세요.
