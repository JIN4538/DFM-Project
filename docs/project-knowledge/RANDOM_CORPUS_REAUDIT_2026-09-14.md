# 무작위 형상 전수 검토와 공정별 근거 재감사 인수 기록

이 기록은 2026-09-14~15 후속 변경의 구현 이유·시험 범위·근거 조건을 보존한다. **현재 인수 초안이며 최신 전수 실행의 최종 상태 집계·배포 코드 지문·전체 회귀 결과는 최종 집계 후 갱신해야 한다.** 동결 전수, 최신 빠른 검토, 재사용 상세값, 새 형상 변화 단면 검산을 별도 실행으로 구분한다. 이전 개선판 및 방향 확장 기록은 당시 결과로 유지한다.

## 후속 지시와 검토 범위

사용자는 소프트웨어의 근거를 다시 조사하고, 바탕화면의 `무작위 형상 테스트` 폴더에 있는 모든 형상을 검토해 실제로 측정하는지 확인하라고 요청했다. 부품 크기에 따른 빌드 공간 제한을 두지 말고, FDM 이외 공정도 검토하며 편의성과 신뢰성을 개선하라는 지시다. 장비·재료·슬라이서는 여전히 미확정이다.

입력 목록은 형상 **26개(STEP/STP 21개·STL 4개·3MF 1개)**와 공급자 정보 등의 **TXT 5개**, 총 **31개 파일**이다. 형식별 수는 독립 입력 목록과 대조했다. 형상별 원본 SHA-256과 상대 경로, 단위, 솔리드 수, 변환 조건을 기록한다. 여러 CAD 솔리드가 있으면 전체 조립체와 각각의 솔리드를 대상으로 `MEX`, `VPP`, `PBF_POLYMER`, `PBF_METAL`을 실행한다. TXT는 형상 계산 대상이 아니며 출처 정보로 보존한다.

`build_volume_mm=None`으로 장비 공간의 합격·불합격 판정을 생략하고 원래 크기에서 필요한 공간을 측정한다. STL은 mm 가정이며 크기를 임의로 맞추지 않는다. 이 조치는 CPU·입력 파일 크기·삼각형·표본 수·시간 제한을 제거한다는 뜻은 아니다. 계산 한도에 도달하면 부분/미확정과 사유를 기록한다.

원본 부품은 로컬 비공개 자료다. 바탕화면 원본을 수정하거나 공개 저장소·외부 서비스에 업로드하지 않는다. `study/random-shape-audit/`의 입력 캐시·전수 결과·실패 로그도 로컬 작업 자료로 보존한다. 저장소에는 구현·검사·근거 문서와 필요한 비식별 집계를 둔다.

곡면 STEP에는 재료 체적·하향면 면적·벽·내측 원통면 수·밀폐 공동·재료 단면을 부여하지 않는다. 고분자 PBF 하향면 항목은 FDM 무지지 규칙이 적용되지 않으므로 곡면 입력에서도 `not_applicable`이며, 나머지 공정의 곡면 하향면은 `unknown`이다. 양쪽 모두 미측정 면적을 0으로 바꾸지 않는다. B-rep 원통면의 지름·축은 관측할 수 있지만 역할은 `unknown`이다. 임의의 면 법선 방향이나 캐시의 과거 구멍 개수가 재료 의미를 되살리지 못하도록 검사했다. 여러 메시·객체·CAD 솔리드는 기존의 합집합 및 체적 보류 조건을 유지한다.

## 새 문헌의 연결과 조건

상세 원문 확인 범위·쪽수·URL·근거 표는 [적층제조 제조성 검토의 근거 재감사](../research/AM_DFM_EVIDENCE_REAUDIT.md)에 있다. 기존 저장소 문헌에만 한정하지 않고 공개 원논문·제조사 공식 문서·표준의 공개 범위·입력 형식 규격을 대조했다. 이 문헌들을 모두 영구 기억하거나 표준 전문 전체를 확보했다고 주장하지 않는다.

| 공정·항목 | 확인한 강한 근거 | 구현에 허용되는 해석·남은 조건 |
|---|---|---|
| VPP 단면·분리 | Pan et al. 2017, PDF 물리 pp.4–8/인쇄 pp.355–359; 자체 bottom-up 장비·PDMS·LS600M/G+ | A·P·A/P를 참고 기하량으로 제공. 점도·속도·필름·간극 없이 힘 N 또는 성공률로 환산 불가 |
| VPP 벽·홀 | Formlabs Form 4, Grey Resin V5·50 µm | 장비·수지 조건별 참고. 같은 페이지의 100 µm 공차·후경화 시험과 혼합하지 않음 |
| 고분자 PBF 벽·분말 | Fuse Series/Nylon 12 공식 설계 가이드 | 분말 지지 공정에 FDM 브리지·선폭 규칙 적용 금지. 방향별 벽·배출홀은 제조사 조건이며 보편값 아님 |
| 고분자 PBF 열변형 | Li et al. 2020, EP-P3850·FS3300PA(PA12), 50×10×1 mm 시편 | 수축·휨에는 물성·스캔·냉각이 필요. 단면량 하나를 열위험 점수로 변환하지 않음 |
| LPBF 단면·열 | Mohr et al., 온라인 2024/권호 2025, 316L·SLM280HL·275 W·700 mm/s | 단면이 줄어도 층간 시간·열전달 조건 때문에 온도가 오를 수 있음. 단면 증감의 단조 위험 판정 금지 |
| LPBF 지지 | Cheng et al. 2019 공개 초록·서론; 자세한 전문 재현 미완료 | 서포트의 열 방출·기계 고정 역할을 설명. 지지량·각도만으로 응력 억제·제작 성공을 보증하지 않음 |
| 금속 분말 제거 | Hunter et al. 2020, Ti-6Al-4V L-PBF/EBSM 채널·XCT·질량 대조 | 직경뿐 아니라 길이·굴곡·분말 상태·제거법에 의존. 열린 통로나 원통면 검출은 배출 합격 아님 |

Fuse 공식 페이지의 `Maintaining Uniform Thickness` 절에 배출홀 설명이 중복된 사실을 근거 기록에 남겼다. 해당 본문을 균일 두께 규칙의 출처로 차용하지 않는다. Pan의 원통 가정 힘 식과 Mohr의 특정 열 실험을 임의 형상의 보편 예측식으로 구현하지 않았다.

## 측정값의 정확성 범위

공통 단면은 관측 높이의 재료 면적, 외곽·내곽을 합친 둘레, A/P(mm), 성분 수, 내부 루프 수, 이전 표본과의 면적 증감·대칭차·추가/제거 면적을 제공한다. 직접 겹침 없는 신생 성분을 개별 추적해 지지 필요량으로 바꾸는 기능은 구현 완료가 아니다. 내부 루프는 흡착 컵 확정이 아니며, 실제 인쇄 단계의 3D 공기·수지 연결성과 압력 평형은 미평가다.

균등 방법은 요청한 공통 단면을 모두 계산했을 때만 중점 적분 체적 `volume_midpoint_estimate_mm3`를 제공한다. 형상 변화 방법은 서로 다른 메시 정점 높이 사이에 두 개의 Gauss–Legendre 표본을 배치하고, 모든 필요한 단면이 확정됐을 때만 `volume_quadrature_estimate_mm3`를 제공한다. 두 결과를 같은 방법으로 표기하거나 서로 덮어쓰지 않는다. 실제 냉각팬 솔리드2의 1.2 mm 끝판은 균등 64개에서 누락됐고, 1,024개에서도 메시 체적 대비 약 −3.91%가 남았다. 단순히 균등 표본 수를 늘리는 처방을 넘어 새 방법을 추가한 이유다. [반례와 단면 방법](../EVENT_SECTION_METHOD.md).

고정된 유효 다면체에서 인접 정점 높이 사이의 단면 교점은 높이의 일차식, shoelace 면적은 이차식이라는 유도를 사용한다. 2점 Gauss 적분의 수학적 정확성은 정확한 산술의 다항식 적분에 대한 것이며, 부동소수점·좌표 그리드·입력 자기교차·CAD 곡면 오차까지 없앤다는 뜻이 아니다. 기본 한도 8,192단면·예상 교차 선분 150만 개·앱 90초를 넘으면 보류한다. 두 내부 표본을 구별할 수 없는 구간도 누락 사실을 남기고 전체 체적을 `None`으로 유지한다. 균등 방법으로 자동 바꾸어 완전한 사건 적분으로 보고하지 않는다.

표본 체적과 CAD/사면체 체적의 차이는 계산 경로와 관측 위치를 확인하는 자료다. 그 차이를 곧바로 CAD 커널 오류·앱 정확도·프린터 오차로 해석하지 않는다. 두 Gauss 표본의 최대값도 구간 최대가 아니므로 ‘표본 최대 면적’을 유지한다. 불균등 높이 사이 대칭차 면적은 단위 높이당 변화율이 아니며, 체적 검산이 맞아도 국소 특징이나 제조 성공을 보증하지 않는다.

앱과 독립 검사 모두 STEP 변환에 OCCT를 사용하는 부분이 남아 있다. 별도 적분 경로와 삼각형 외적·발산 계산이 일치해도 완전히 독립적인 CAD 커널 대조나 실측 검증을 대신하지 못한다. 다른 경로가 공유하는 번역 오차 가능성을 보존한다.

법선 관통거리의 관측 최소는 전체 최소 벽두께가 아니다. 구멍 후보의 원통면 수는 구멍 개수와 다르고, 축 기울기 45°는 표시 분류다. 공정 기본 오버행 45°·선폭 0.4 mm는 사용자 탐색 조건이며 표준 임계값으로 바뀌지 않았다.

## 동결 이후 변경과 실행별 증거

`test_process_evidence.py`와 `test_analysis_evidence.py`는 공정별 근거 분리, 문헌 실험 조건 보존, 입력 형식 출처, 미실행 단면 상태, 곡면 CAD 재료 판정 보류, 여러 객체의 체적·단면 보류를 검증한다. 기존 CAD·계약·단면 검사와 함께 **124개 통과(66.68초)**를 확인했다. 마지막 근거 표현 수정 후 두 신규 파일을 새 프로세스에서 다시 실행해 **63개 통과(1.49초)**했다. 전체 **396개 통과** 기록은 뒤에 설명한 고분자 PBF 곡면 상태 및 재메싱 복사 수정 이전 상태의 결과다. 이후 분석·앱 관련 30개 검사와 재메싱 대상 재검증은 후속 증거로 구분한다. 결과는 `validation/v3/random-corpus/checks-01/`의 `pytest`와 `followup` 기록을 확인하고 최종 표에 반영한다.

전수 엔진을 동결한 뒤 먼저 아래 **안내 문장 세 곳과 상태 분류 한 곳**이 현재 코드에서 달라졌다. 이 네 변경 자체는 수치 계산·임계값·기하 알고리즘·API를 바꾸지 않았다. 이후 재메싱 복사, 작업자 종료, UI 상태, 형상 변화 단면 알고리즘이 추가됐으므로 동결 이후 전체 차이를 “문구만 바뀜”으로 설명해서는 안 된다. 각 후속 검증은 위 124개/63개 및 전체 396개 기록과 구분한다.

1. `evidence.py`의 VPP 단면 action을 “신생 성분의 위치”에서 실제 계산한 “관측 최대 단면·성분 수·단면 변화의 위치”로 수정했다.
2. 같은 안내의 limitations에 성분 수·차집합이 지지 실패 판정이 아님을 명시하고, Bottom-up 등 탱크 분리 방식에 한정되는 해석임을 별도 문장으로 보존했다. 상세 결과가 reason을 갱신해도 적용 조건이 남는다.
3. `detail.py`의 비MEX 벽 결과 action에서 가변 선폭 경로를 대조하라는 FDM 전용 안내를 제거했다. MEX에만 해당 안내를 유지한다.
4. 곡면 STEP의 고분자 PBF 하향면에서 곡면 `unknown` 분기보다 공정 `not_applicable` 분기를 우선하도록 수정했다. 고분자 PBF에 FDM 지지 판정을 적용하지 않는 기존 계약을 복원하는 상태 변경이다. 미측정 하향면 면적은 계속 `None`이다. `final-01` 동결 결과에는 이전 `unknown` 상태가 남는다. 최신 빠른 검토 갱신에서는 곡면 2개의 고분자 PBF 사례에 한해 이 상태 변경을 허용하고 그 외 예상하지 않은 상태·수치·면 선택 변화는 해당 사례를 중단하도록 검사한다.

후속 CAD 수정은 `cad_worker.py`의 재메싱 후보 복사를 `BRepBuilderAPI_Copy(shape, False, False)`에서 `BRepBuilderAPI_Copy(shape, True, False)`로 바꾼 것이다. OCCT API의 `copyGeom=True, copyMesh=False`를 사용해 재시도 형상의 기하를 복사하고 기존 삼각분할 캐시를 공유하지 않도록 한다. 원본 B-rep의 설계 재료를 변경하는 작업은 아니지만 재메싱 실행 경로 수정이다. **assembly_solid와 Pump_assy의 동결/수정 코드 대조는 완료했다.** 두 입력 모두 정점·삼각형·CAD 면 번호·바디 번호 전 배열과 전체 CAD JSON이 정확히 같았고, NPZ·JSON 파일 바이트 SHA-256도 각각 일치했다. 따라서 이 두 입력에서 기존 캐시를 사용하는 근거가 생겼으며, 다른 모든 형상의 일반적 복사 동등성을 증명한 것은 아니다. [두 입력의 배열·메타데이터·코드 SHA 대조](../../validation/v3/random-corpus/independent/deepcopy-frozen-equivalence.json).

Windows의 기존 작업자 종료는 직접 부모가 자식을 만들고 먼저 끝날 때 실패했다. 0.75초 제한 반례가 4.228174초 동안 대기하고 자식이 파일을 작성했다. 수정 후 같은 반례는 약 0.755950초에 `TimeoutExpired`를 반환했고 자식 파일이 없었다. 각 작업을 이름 없는 Job에 넣기 전에는 실행하지 않으며, Job 안의 후손과 직접 프로세스 종료를 모두 유한 시간 안에 확인한다. stdout/stderr·종료 코드 계약을 유지하고 Job 할당·재개·정리 실패를 `OSError`로 노출한다. Unix는 기존 프로세스 그룹 종료를 유지하되 이번 신규 실재 검증은 Windows에 한정한다. [Windows Job 구현과 처음 실패·수정 후 시험](../../validation/v3/random-corpus/process-job/README.md).

공정 UI에서는 MEX의 Prusa MK4·PLA·1.2 mm 최소 벽·MEX 시편 출처가 VPP 선택 후에도 남아 0.3 mm 자체 CAD 판의 VPP 벽 검토에 쓰이는 반례를 확인했다. 고분자·금속 PBF에도 같은 조건이 이어졌다. VPP/PBF 화면에서 Cura·필라멘트 G-code 분석이 가능한 문제도 재현했다. 장비·재료·슬라이서·벽/홀 기준·출처·메모·각도·층높이·빌드공간·여유를 공정별 키로 분리하고 `persist_state="session"`으로 왕복 보존한다. 모델·단위·방향은 공통이며, G-code는 MEX에서만 표시한다.
