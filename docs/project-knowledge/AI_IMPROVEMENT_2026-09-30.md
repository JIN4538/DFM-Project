# AI 성능 개선 1차 결과

사용자 요청: AI 성능 개선을 시작한다. 실제 사용자에게 돌아가는 특징 인식과 최종 개선안의 품질을 먼저 개선했다. **절삭 학습 모델의 연결 수정과 정확한 최종 비교를 제품에 반영한다. 새로운 적층 탐색 실험은 우위가 불충분해 기본 제품에 반영하지 않는다.** 아래 수치는 같은 입력에서 이전·새 경로를 비교한 결과다.

## 반영한 변경

1. **절삭 특징 인식:** 공동 25종 모델이 특징의 종류·경계·바닥을 판단한다. 평면 전문가도 같은 종류라고 판단할 때만 신뢰도를 보완한다. 이전처럼 다른 모델의 종류 판단에 공동 모델용 문턱을 그대로 적용하지 않는다. 원본 CAD 면 번호·측정 치수를 유지한다.
2. **최종 추천:** 이미 계산된 후보는 공개된 학습 목표를 정확하게 비교한다. 근사 점수 때문에 더 나쁜 후보를 고르는 오류를 줄인다. 절삭에서는 원본 측정값에서 수정 치수를 재검산하고 충돌 최소화 → Pareto 비교 → 공통 비교 점수 순으로 선택한다. 강화학습 후보도 같은 기준을 따른다.
3. **현재 방향:** 기존 후보를 지배하지 않는 절충 방향도 비교에 포함한다. 현재 방향 때문에 기존 후보의 비교 척도가 바뀌지 않게 하고, 최종 점수가 같은 경우 현재 배치를 유지한다. 종합 결론·방향 비교·보고서가 같은 선택을 사용한다.

사용자가 명시적으로 선택한 대안의 선호 학습은 유지한다. 선호는 제약을 통과한 후보에만 반영한다. 화면에 새로운 설명이나 필수 입력은 추가하지 않았다.

코드: `dfm/feature_routing.py`, `amdfm/cad_worker.py`, `dfm/verified_selection.py`, `dfm/enhanced_planning.py`, `dfm/conclusion.py`. 원래 교사·순위 추론·RL 소스 계약은 바꾸지 않았다.

## 절삭의 실제 학습 모델 경로

검증 분할에서 경로를 고정한 뒤 보류 시험을 실행했다. 특징 일치는 같은 종류와 면 집합 IoU > 0.5를 사용한다.

| 보류 자료 | 정밀도 전 → 후 | 검출률 전 → 후 |
|---|---:|---:|
| MFInstSeg CAD 9,241개 | 96.340% → 97.488% | 69.396% → 71.858% |
| 그중 평면 CAD 1,006개 | 78.218% → 97.404% | 43.245% → 74.776% |
| MFCAD CAD 2,309개의 연결 의미영역 | 96.778% → 96.897% | 79.940% → 83.098% |

MF 정답 특징은 1,440개 증가하고 오검출은 459개 감소했다. MFCAD는 인스턴스 정답이 없어 연결된 의미영역을 대조한 결과이며 MF의 특징 인스턴스 성능과 합치지 않는다. 곡면 경로의 결과는 같다. 삼각 관통홈·삼각 포켓·직사각 포켓의 정밀도는 각각 0.253·0.151·0.157%p 하락했으며 모든 클래스의 정답 검출 수는 유지되거나 증가했다.

이 수치는 이전 단일 공동 모델의 97.4%/72.3% 시험과 다른 **실제 앱 경로**의 비교다. 자유곡면 81개도 미검출로 포함했다. 정밀도는 표시한 특징 중 맞은 비율, 검출률은 정답 특징 중 찾은 비율이다. 전체 앱 정확도로 부르지 않는다. 솔리드당 200면 범위와 미확정 4종 제외는 유지했다.

## 최종 선택 개선은 ML 학습 향상과 분리한다

| 비교 | 개선 / 동일 / 악화 |
|---|---:|
| 같은 보류 후보 36,087조건 | 1,653 / 34,434 / 0 |
| 공개 STEP 14개의 AM 비교 가능 208조건 | 14 / 194 / 0 |
| 공개 STEP의 CNC 비교 가능 33조건 | 0 / 33 / 0 |
| 외부 절삭 치수 120형상군·1,440조건 | 20 / 1,420 / 0 |

36,087조건은 고정 후보와 공개된 목표값에서 근사 순위를 정확 계산으로 대체한 비교다. ML이 새로운 설계 정답을 학습했다는 증거가 아니다. 공개 STEP 308조건 전체에서 AM 16조건·CNC 51조건은 미추천 상태를 보존했다. 개선 14조건은 3형상에 걸친 결과이며 14형상 모두 개선한 것으로 표현하지 않는다. 종합 결론·방향을 독립 재호출한 경우도 선택 불일치는 0이었다.

기존 후보의 정규화 범위 밖 현재 방향은 고정 척도에서 비교하고, 상수 항목은 상대 변화로 비교한다. 이는 원래 [0,1] 학습 목표의 적용 범위를 보완한 제품 정책이며 위 고정 후보 시험과 별도 반례로 검사했다. 사용자 선호가 있으면 목적이 달라지므로 선호 없는 무악화 비교와 구분한다. 새로운 후보 추가로 비교 범위가 변한 상황의 전역 무악화를 보장하지 않는다.

## 채택하지 않은 적층 실험

기존 정밀 후보 4개를 유지하고 관측 오차를 학습하여 2개 방향을 탐색하는 방식이다. 검증 형상군에서 정책을 고정하고 이전 실험에 쓰지 않은 보류 55형상군·275조건으로 시험했다. 기존 대비 11개 개선·259개 동일·5개 악화였지만 같은 추가 측정 6회의 단순 탐색보다 평균 성능이 나빴다. 기존 대비 평균 차이의 형상군 bootstrap 95% 구간도 0을 포함한다.

따라서 기존 `full_search.py`와 적층 신경망 가중치를 유지했다. `amdfm/adaptive_search.py`는 연구 스크립트·테스트에서만 사용하는 실험이다. 1,650방향의 독립 기하 대조 최대 정규화 오차는 3.608e-16이었다. 초기 실패·검증 선택·보류 시험·소스 스냅샷을 보존했다. 계획 375조건이 아니라 실제 적격 275조건으로 집계한다.

## 학습·검증 상태와 다음 순위

새 외부 원본 추가와 전역 가중치 재학습은 **0**이다. 기존 외부 가중치 학습 기록 84,513개를 늘어난 수로 다시 집계하지 않는다. 학습 모델의 합의 경로를 검증하여 연결을 수정했고, 적층의 형상별 잔차 학습은 실험했으나 미채택했다. 30모델 파일·9교사/추론 소스·양쪽 환경 로더 20회가 기존 감사와 일치했다. 앱 전체 코드가 불변이라는 뜻은 아니다.

원본 STEP 18개의 실제 worker와 인증 그래프의 종류·면 집합은 모두 일치했다. adapter·시험 경로 162개 대응과 STEP→절삭 조치 검사 29개도 통과했다. 추가 반례는 잘못된 모델 점수, 현재 절충 방향 누락, 현재 방향에 의한 척도 변경, 동률 배치 유지, 장비 공간 제외, 선호 반영, 형상·공구 유지 조건을 다룬다. 통합 검사·배포의 최종 상태는 이 폴더의 최종 검증 요약을 따른다.

최종 관련 통합 검사 **232개 통과**, 바탕화면 Python 3.13 실행 환경 검사 **57개 통과**. 변경 21파일을 이전 실행본 SHA와 대조하여 배치했고 별도 `study/ai-improvement-2026-09-30/desktop-before/`에 이전 파일을 보존했다. 새 실행본은 `http://127.0.0.1:8507/`에 다시 실행했다. 최종 검증·문서 반영 후 복사 SHA와 모델 SHA를 재확인한다. 초기 7개 실패는 새 정확 비교 대신 옛 모델 점수·출처 문자열을 기대한 검사였으며 최초 XML을 보존하고 새 동작으로 재검증했다.
