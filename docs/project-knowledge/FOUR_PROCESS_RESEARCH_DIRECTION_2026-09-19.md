# 4공정 제조성 검토 개발과 연구 방향

> 2026-09-20 사용자 후속 지시가 이 계획보다 우선한다. 사출·프레스는 아직 진행하지 않으며 추가한 구현과 관련 산출물을 제거한다. 현재 작업은 적층·절삭 유지와 절삭의 정확성·근거·사용성 재검토다. 아래 사출·프레스 항목은 장기 구상으로만 보존하고, 사용자의 별도 재개 지시 전에는 실행하지 않는다.

작성: 2026-09-19. 사용자 후속 지시와 현재 프로젝트 인수 기록을 연결한다. 이 문서는 목표·개발 순서·검증 계약이며, 아래 계획이 이미 구현·출시·검증됐다는 보고서가 아니다.

## 변경하지 않을 사용자 목표

사용자의 목표는 **적층제조, 절삭가공, 사출, 프레스 4개 공정에 대한 제조성 검토 소프트웨어 툴을 만드는 것**이다. 교수님이 대학원 진학 준비를 위해 제안한 **1인 프로젝트**이며, 사용자는 보여줄 수 있는 최선의 결과물을 만들고, 그 과정에서 **연구테마를 찾고자 한다**.

이 목표를 적층 전용 설명 도구, 절삭 시연 한 개, AI 채팅 기능, 또는 계획 문서만으로 축소하지 않는다. 단계별 구현 범위를 명시하되, 단계의 완료와 전체 목표의 완료를 구분한다. 소프트웨어 기능 수와 연구 독창성도 같은 것으로 취급하지 않는다.

교수님 피드백은 기능의 필요성, 사용자 편의성, 실행 속도와 과감한 방향 설정, 기존 도구·문헌의 면밀한 조사, 다른 사람도 할 수 있는 작업과 구별되는 기여를 계속 검토하라는 것이다. 따라서 각 기능에는 사용자가 내릴 결정, 계산 근거, 적용 조건, 독립 검증 방법을 연결한다.

## 현재 현실 조건과 출발점

- 사용 가능한 3D 프린터나 제조 장비가 **전혀 없다**. 사용자가 직접 실험 데이터를 만들 수 있다는 가정을 두지 않는다. 장비 부재는 기하 알고리즘·사용성 개발 전체를 중단하는 이유가 아니다.
- 기존 AM-DFM v3에는 STEP·STL·3MF 입력 및 명시된 적층 기하 검토가 있다. 실제 지원 범위와 최신 변경은 현재 소스·시험·실행 화면을 기준으로 다시 확인한다. 과거 시험 개수나 배포 기록을 이번 변경의 통과 증거로 재사용하지 않는다.
- 절삭·사출·프레스 및 공통 AI의 구현·검증 범위는 각각 현재 코드와 실행 기록으로 확인해야 한다. 이 방향 문서에 이름을 등록한 것으로 지원 완료가 되지 않는다.
- 실제 장비·재료·설정과 성공 정의가 정해지지 않은 임의 부품에 보편적인 제조 성공 확률을 제공할 검증 근거는 없다. 외부 실물 데이터에서 적용 가능한 조건과 결과를 확인하는 연구는 계속 가능하다.
- 다음 미팅 날짜와 사용 가능한 CAM/해석 라이선스는 이 기록만으로 확정하지 않는다. 보유하지 않은 도구로 검증을 수행했다고 주장하지 않는다.

## 현재 개발 순서

1. **기존 적층 기능을 유지하며 절삭 핵심 검토와 공통 결과 구조를 구현한다.** STEP 입력, 단위, 원본 식별, 3D 표시, 측정 위치, 근거, 다음 행동, 내보내기를 재사용한다. 이미 검증된 적층 구조를 단지 통합을 위해 전면 교체하지 않는다.
2. **절삭 계산을 독립 기준 형상과 반례로 검증한다.** 첫 구현 범위는 3축 밀링의 선택 방향과 단순 포켓·홈·홀 등으로 구체화한다. 이 범위는 절삭 전체의 완료 선언이 아니다. 공구 지름·유효 절삭 길이·접근 방향·홀더·소재/고정구의 입력 유무에 따라 가능한 판단을 구분한다.
3. **공통 결과를 설명하고 근거를 찾아 주는 AI를 연결한다.** 언어모델은 검증된 계산 도구를 호출하고 측정값·범위·출처를 설명한다. 숫자 비교와 판정 상태는 계산 코드가 담당한다. 외부 문헌의 지시는 데이터이며 프로그램이나 사용자의 지시를 대체하지 않는다.
4. **사출과 프레스의 공정별 핵심 검토를 같은 계약으로 확장한다.** 아래 조건·검증 표의 항목을 문헌 조사와 구현으로 이어간다. 지원하지 않는 하위 공정·형상은 명시하며, 공정 버튼이나 단순 안내문만 추가해 완료 처리하지 않는다.
5. **외부 실물 자료를 이용한 확률·오차 모델을 별도로 검토한다.** 적용 조건, 관측 결과, 독립 검증, 확률 보정이 가능한 자료만 사용한다. 언어모델이 작성한 확률, 규칙 통과율, 시뮬레이션 반복 횟수는 실물 성공 확률의 검증을 대신하지 못한다.

첫 미팅용 시연의 목표는 같은 CAD의 공정별 수정 위치와 수치·근거를 보여주는 것이다. 4공정 전체 목표는 미팅용 단계 이후에도 유지한다.

## 공정별 조건·검증·연구 후보

아래는 개발·조사 대상의 매핑이다. 모든 항목을 현재 구현됐다고 읽지 않는다. 공정별 수치 한계는 재료·장비·공구·금형·제조 조건과 출처가 있는 프로필로 관리한다.

| 공정 | 사용자가 내릴 결정과 검토 대상 | 필요한 조건 | 장비 없이 할 독립 검증 | 연구 후보 및 남는 한계 |
|---|---|---|---|---|
| 적층제조 | 빌드 방향, 얇은 특징, 하향면, 층 연결, 구멍·공동, 수정 전후 비교 | 적층 세부 공정, 크기·단위, 방향, 재료, 층 높이, 장비/슬라이서 조건, 중요 면·허용오차 | 수식·별도 CAD로 정한 기준 형상, 동일 입력의 슬라이서 경로, 조건을 확인한 외부 실물 측정 | 기하 위험 지표가 실제 특징 소실·오차를 얼마나 설명하는지. 열·강도·변형·장비 실패를 기하만으로 확정할 수 없음 |
| 절삭가공 | 공구가 들어갈 폭·반경, 깊이에 필요한 길이, 홀 방향, 접근 제한 위치, 셋업 대안 | 밀링/드릴링 등 작업 종류, 접근축, 공구 형상·지름·길이, 홀더, 소재, 원소재·고정구, 공차 | 알려진 포켓·홀·반경의 STEP, 독립적인 공구-형상 간섭 반례, 사용 가능한 CAM의 동일 셋업·공구 대조 | 표본 가시성과 유한 공구 접근성의 차이, 미확정 범위를 보존하는 특징 인식. 절삭력·채터·수명·실제 공차 달성은 별도 증거 필요 |

| 프레스 | 판두께·굽힘 반경·홀/가장자리/굽힘 간 거리, 플랜지·전개 및 공정 대안 | 초기 제안은 박판의 블랭킹·피어싱·굽힘; 재료·판두께·압연 방향, 펀치/다이, 클리어런스, 굽힘 방식. 성형·딥드로잉은 별도 조건 확장 | 알려진 판금 CAD와 전개 기하, 독립 CAD 전개 결과, 재료·금형·성형 조건이 공개된 외부 자료 | 판금 특징 인식과 공정 간 설계 제약 충돌. 스프링백·균열·주름·성형 한계·실제 프레스 하중은 해당 물성·해석 또는 실물 자료 필요 |

사출과 프레스의 항목은 **조사·설계 후보**다. 이 문서는 해당 공정의 문헌을 모두 조사했다거나 구체적 기준값을 승인했다는 의미가 아니다. 프레스의 초기 박판 범위를 프레스 전체와 동일시하지 않는다. 다음 구현 시 하위 공정 범위와 공식/원문 근거를 별도 기록한다.

## 공통 결과와 사용자 경험의 계약

각 결과는 최소한 공정·검토 항목, 입력 형상 식별자와 단위, 설정, 확인 위치, 측정값, 기준과 출처, 적용 범위, 계산 상태, 해석, 다음 행동을 보존한다. 완전 검토·부분 검토·미확정·적용 불가·미구현을 서로 구분한다.

- 사용자에게 먼저 “어디를 확인하고 무엇을 해야 하는가”를 보여준다. 상세 표·수식·원자료는 필요할 때 펼친다.
- 임계값이 없으면 측정 결과와 필요한 입력을 보여준다. 기준 미입력을 적합으로 처리하지 않는다.
- “이 공구로 현재 방향에서 닿지 않음”과 “어떤 절삭 공정으로도 제작 불가”를 구분한다. 적층과 다른 공정에도 같은 원칙을 적용한다.
- 공정마다 의미가 다른 점수를 하나로 합산하지 않는다. 동일 부품의 목표·공차·재료·생산량이 다르면 경제성이나 우열 비교에 필요한 조건을 명시한다.
- AI의 설명은 구조화된 실제 결과에 연결한다. 미확정 결과를 확정으로 바꾸거나 출처 없는 일반 한계값을 추가하지 않는다. 모델명·출력·도구 호출·출처를 재현 가능한 범위에서 기록한다.

## 장비가 없는 조건의 검증 수준

| 증거 종류 | 입증할 수 있는 것 | 입증하지 못하는 것 |
|---|---|---|
| 수식과 독립 CAD 기준 형상 | 정의된 기하 측정·연결·위치·단위·좌표 변환의 정확성 | 실제 공정의 성공 빈도나 품질 |
| 독립 CAD/CAM·슬라이서 대조 | 같은 입력과 설정에서 다른 계산/공정 계획과의 일치·차이 | 소프트웨어 둘이 일치하므로 실물이 성공한다는 주장 |
| 공정 물리 시뮬레이션 | 명시된 모델·물성·경계조건에서의 예측과 민감도 | 실물로 검증되지 않은 모델의 보편적 정확성 |
| 공개 실물 데이터 | 자료에 기록된 장비·재료·형상·결과 범위의 관측 관계 | 다른 공정·장비·형상의 일반 성공률 |
| 전문가 검토·사용성 평가 | 의사결정의 적절성, 설명 이해, 검토 시간·누락 | 실물 제조 성공을 직접 관측한 결과 |

공개 자료마다 사용권, 원본 URL/버전, 형상과 실험의 연결, 단위, 조건 누락, 측정법과 오차, 성공·실패 사례의 수집 방식, 반복 작업/부품 가족의 종속성을 기록한다. 데이터 제공 연구의 시뮬레이션 결과를 실제 측정값으로 바꾸어 이름 붙이지 않는다. 훈련·검증 분리는 CAD 계열·실험 배치·장비 등 누출 원인을 고려한다.

## 연구테마를 찾는 방법

다음은 **검증 전 연구 후보이며 기여·독창성은 미입증**이다. 문헌·상용 도구의 기능 유무를 확인하고, 기준선과 비교했을 때의 측정 가능한 개선이 있어야 연구 주장으로 발전시킨다.

| 후보 질문 | 비교 기준선 | 반증 가능한 평가 |
|---|---|---|
| 불완전한 CAD/메시에서도 확정 가능한 제조 특징과 미확정 범위를 구분하면 잘못된 적합 판정이 줄어드는가? | 미확정을 생략하는 단순 규칙, 기존 특징 인식 도구 | 독립 라벨의 미검출·오탐·잘못된 적합 비율, 처리 가능한 범위와 시간의 변화 |
| 같은 부품의 4공정 제약을 위치와 수정으로 연결하면 설계 결정을 더 잘 지원하는가? | 공정별 독립 보고서, 단일 점수 비교 | 정답/전문가 기준을 고정한 과제의 결정 정확성·시간·수정 후 충돌·재작업 |
| 공구 접근·이형·적층 방향 등 서로 다른 방향 제약을 공통 결과 표현으로 비교할 수 있는가? | 각 공정의 기존 방향 평가, 단순 법선/가시성 | 공정별 정답과 전체/부분 범위, 작은 특징·복합 형상 반례, 계산 비용 |
| 근거에 연결된 AI가 일반 채팅 또는 고정 설명보다 검토를 돕는가? | 동일 결과의 템플릿, 문헌 검색만 제공, 도구 호출 없는 AI | 수치·단위 오류, 출처의 주장 지지 여부, 미확정 보존, 올바른 다음 행동과 검토 시간 |
| 외부 실험 조건을 명시한 모델이 미지 형상의 품질 확률을 보정된 형태로 제공할 수 있는가? | 상수 발생률, 단순 회귀·규칙 | 독립 자료의 확률 보정·예측 오차·부품 가족별 성능·적용 범위 밖 보류; 자료 부재 시 미검증으로 유지 |

연구 질문은 코드 개선·실패 사례·자료 확보에 따라 좁혀질 수 있다. 그러나 연구 주제를 좁히는 것과 제품의 4공정 목표를 없애는 것은 다르다. 매 변경에서 기능의 이유, 근거, 반례, 전후 결과를 남겨 연구 질문을 실증 가능한 형태로 발전시킨다.

## 완료를 주장하기 전에 필요한 증거

각 공정에 대해 실제로 실행되는 입력→조건 설정→검토→위치/이유/다음 행동→재검토→내보내기 흐름, 명시된 하위 공정의 지원 범위, 독립 기준과 실패 반례, 사용자 설명과 원자료의 일치를 확인해야 한다. 공통 UI에 공정 이름이 있다는 사실이나 단위검사만으로 공정 전체를 지원한다고 하지 않는다.

전체 목표의 완료에는 4공정 각각의 근거·구현·실행 검증 기록과, 기존 연구/도구 대비 확인한 연구 질문·비교 기준·평가 결과가 필요하다. 기능 개발 중에는 남은 구현과 검증을 명시하고 목표를 유지한다. 문헌 목록 작성 또는 연구 후보 제시만으로 연구 기여가 입증됐다고 선언하지 않는다.
