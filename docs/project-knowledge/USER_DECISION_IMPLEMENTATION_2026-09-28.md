# 2026-09-28 문제 위치·개선 순서·종합 방향 추천

사용자 요청: 기본 검토 뒤 정밀 검토를 또 실행해야 하는 부담, 목적에 따라 방향 제안이 달라져 사용자가 결론을 내리지 못하는 부담을 줄인다. 현재 범위는 적층 4공정과 고정축 절삭이며 사출·프레스는 추가하지 않았다.

## 반영한 흐름

- 적층의 설계 검토 한 번에 벽·MEX 층간·단면을 실행한다. 공유 45초 예산, 벽 10초·층간 20초·단면 15초 상한이며 남은 예산으로 각 작업을 제한한다. 수치는 실행 정책이다. 원래 물리 층 높이나 계산 완전성 기준을 완화하지 않는다.
- 형상·프로필·배치 변환·코드/DB SHA가 일치하는 결과만 결합한다. 부분·실패·미실행은 보존하고 과거 성공 결과로 가리지 않는다. 추가 계산은 같은 화면에서 가능하다.
- 설계 조치에 종합 방향, 우선 조치 3개의 선택 버튼, 선택 문제의 실제 위치·측정값을 연결했다. 설명을 세로로 나열해 그림을 밀어내지 않도록 전체 조치와 추천의 상세 수치는 펼쳐서 보는 구조다.
- 관측된 설계/배치 후보, 필요한 조건, 미완료 계산을 구분한다. 우선 관측 문제를 확인하고 입력과 계산 부족을 이어서 안내한다. 입력 형상 자체 문제가 있으면 먼저 표시한다.
- 추천 적용은 자동 상세 검사를 켜고 재계산 후 설계 조치로 돌아온다. 현재와 같은 수동 방향의 재적용 버튼은 비활성화한다.
- 절삭은 제한된 표면 가림 표본을 기본 실행한다. 우선 카드에 실제 형상·공구 치수, 필요한 조치, 문제 위치 선택을 제공한다. 원래 기하 알고리즘과 계산 예산은 유지한다.
- HTML/JSON에서도 같은 추천과 개선 순서를 사용한다. 기존 전체 원자료·출처·미확정 범위는 유지한다.

## 종합 방향의 정의와 한계

`equal-geometric-regret/1`은 제조 실험에서 학습하거나 표준에서 지정한 모델이 아닌 **공개된 개발 정책**이다. 고정 후보 중 공간에 들어가고 필수 기하량이 계산된 후보를 대상으로 각 지표의 min–max 값을 같은 비중으로 합산한다. 수치상 상수인 값의 부동소수점 잡음은 증폭하지 않는다.

- MEX: 하향면 투영면적 합·높이 최소, 평평한 바닥 면적 최대.
- VPP/금속 PBF: 하향면 투영면적 합·높이 최소.
- 고분자 PBF: 높이만 사용하므로 제한된 제안으로 명시.
- 현재 임의 방향을 정규화 집합에 추가하지 않는다. 같은 고정 후보·조건에서 현재 방향만 바꿔도 대표 추천은 같다. 현재가 동등하거나 더 유리하면 유지하도록 안내한다.
- 고정 후보는 모두 공간을 초과해도 현재 임의 방향이 들어가면 현재 유지. 모든 비교 후보가 공간을 초과했다고 연속 각도 전체가 불가능하다고 하지 않는다.
- 필요한 측정값의 누락·입력 형상 문제는 추천 보류. 단위 가정 입력은 치수 미확정 범위를 표시한다.

추천에는 각 지표의 개선과 악화를 함께 보여준다. 강도·열변형·실제 서포트·접착력·실제 시간/비용·출력 성공 확률을 종합한 제조 최적이라는 뜻이 아니다. 임계값이나 물리 성능을 새로 추정하지 않았다.
