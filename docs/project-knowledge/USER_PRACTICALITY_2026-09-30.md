# 첫 사용자 관점의 사용성·실용성 개선

사용자 요청: 입력은 줄이고, 결론·문제 위치·바꿀 치수를 바로 얻을 수 있도록 적층·절삭의 전체 사용 흐름을 점검한다. 어려운 용어와 불필요한 설명을 줄이고, 현재 AI의 실질적 기여도 별도로 평가한다.

이 기록은 **화면·탐색·입력 표현 개선**을 다룬다. 이번 변경에서 수치 계산 엔진, 판정 기준값, AI 가중치를 바꾸거나 새로 학습하지 않았다. 미측정·부분 결과는 그대로 유지한다.

## 첫 사용자의 기본 흐름

1. 형상과 공정을 선택한다. 장비·재료는 몰라도 시작할 수 있다.
2. 기본 설정으로 검토한다. 적층의 벽·층간·단면 검사는 기존 한 번 검토 흐름에 포함되고, 절삭의 빈 공구 치수는 기존 자동 제안을 사용한다.
3. **종합 결론**에서 추천 개선안과 바꿀 치수를 읽는다. 확인할 다른 문제도 이 화면에서 바로 연다.
4. 선택한 위치의 그림과 측정값을 확인한다. 필요할 때만 기준·계산 방법·전체 표를 펼친다.
5. **검토 보고서 저장**을 눌러 HTML을 저장한다. 지원되는 절삭 코너 수정은 개선 STEP을 생성·다운로드한다.

장비·재료·벽/구멍 기준을 모두 채워야 시작하는 절차를 요구하지 않는다. 벽은 기존 공정별 초기값으로 시작하고, 구멍 비교 지름을 비워 두면 지름 측정을 제공하되 기준 충족 판정은 만들지 않는다.
