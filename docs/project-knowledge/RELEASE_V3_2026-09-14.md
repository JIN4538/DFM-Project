# 2026-09-14 개선판 인수 기록

## 사용자의 후속 지시와 적용 기준

사용자는 적층제조에 한정해 기존 문헌 밖의 자료도 조사하고, v2.6을 냉정하게 재평가하며, 필요하면 기능·구조를 교체하고 STEP 입력을 개발하라고 요청했다. CAD 원본·치수를 모르는 인터넷 부품 세 개를 제공했으며 필요하면 자체 CAD를 만들도록 했다. 프린터·재료·슬라이서는 **미확정**이라고 답했다.

교수님 피드백은 다음 다섯 가지다. (1) 구현된 기능이 왜 필요한지, (2) 사용자 편의, (3) 좁은 범위에만 깊이 들어가기보다 과감하게 방향을 정하고 속도를 높일 것, (4) 다른 사람도 할 수 있는 것인지 스스로 물을 것, (5) 기존 툴·논문·문헌을 면밀히 파악할 것.

이 지시는 9월 10~11일 문서의 FDM 우선 제안보다 최신이다. 기존 제안을 승인 대기 조건으로 사용하지 않았다. 새 기본 실행 경로는 `app.py` / `run_app.py`, 제품 버전은 **AM-DFM 3.0.0**이다. GitHub의 확인된 기존 최신 소스는 `AM-DFM_v2_6.zip`이며 별도의 v6을 발견했다고 주장하지 않는다.

## 제품 판단과 실제 반영

| 피드백 | 적용한 변경 | 확인할 파일 |
|---|---|---|
| 기능의 이유 | 총점·등급·AHP·보정 서포트 체적을 기본 흐름에서 제거. 각 항목을 문제 위치→측정 이유→설계 조치→출처로 연결 | `amdfm/analysis.py`, `evidence.py` |
| 편의성 | 바로 검토 버튼, 기준 CAD 14개, STEP/STL, 내부 면 투명 표시, 현재 방향 적용, 수정 전후, HTML·JSON·방향 STL | `app.py`, `presentation.py` |
| 과감함·속도 | 빠른 기하 검토와 요청 시 정밀 계산을 분리. 기존 점수 UI 대신 새 입력·결과 구조 구현. 네 공정군의 적용 범위를 명시 | `profiles.py`, `io.py`, `detail.py` |
| 차별성 | 흔한 오버행·두께 기능 자체에 신규성을 주장하지 않음. CAD 면 연결, 조건·코드·파일 추적, 비교 가능성 검사, 슬라이서 대조를 통합 | `models.py`, `comparison.py`, `gcode.py` |
| 기존 연구 파악 | 공개 표준 범위, NIST 원문, 가변 선폭 연구, 제조사 및 Autodesk/Materialise/nTop 공식 자료를 비교 | `docs/research/AM_DFM_RESEARCH_AND_DESIGN.md` |

MEX는 층간 검토와 실제 G-code 경로까지 연결한다. VPP·고분자 PBF·금속 PBF는 공통 기하와 공정별 조치를 제공하며 열·박리·수축·잔류응력 계산을 구현한 것으로 설명하지 않는다. 고분자 PBF에 MEX 지지 각도나 층 규칙을 적용하지 않는다.

## 실행 상태와 보존

- 개발 브랜치: `codex/am-dfm-evidence-review`; 출발 커밋 `1706eac`.
- 새 `.venv`는 저장소 안에 있다. 기존 `study/.venv`와 보관 소스는 유지했다.
- `src/`·`tests/`·`cura_run/`은 v2.6 보관본에서 복사했다. 원본 ZIP을 덮어쓰지 않았다. 기존 테스트의 UI 경로와 Windows UTF-8 읽기만 명시적으로 수정했다.
- 원래 추적된 24개 파일은 Git blob과 SHA-256으로 대조했다. 결과는 `validation/v3/release-cases-01/summary.json`에 있다.
- 세 외부 STL은 `examples/external/` 로컬 복사본이며 Git 추적에서 제외했다. 원본 파일 내용·실제 배율은 임의 수정하지 않았다.
- `validation/v3/`는 새 시험 영역이다. 최초 실패와 재시험을 모두 남겼다. 새 실험은 기존 폴더를 덮어쓰지 않는다.
- `START_REVIEW.cmd`로 실행한다. 로컬 주소는 `http://127.0.0.1:8507`이다.

수치와 시험별 성공·실패는 [검증 기록](../VALIDATION_V3.md)을 따른다. 기존 55개 기본검증의 통과는 **기존 엔진 회귀 유지**를 뜻한다. 과거 점수의 제조 성공 예측 타당성이 입증된 것은 아니다.

## 다음 사람이 잘못 확정하면 안 되는 것

1. STEP의 해석적 체적·원통 지름과 삼각형 하향면·표본 관통거리는 정확성 범위가 다르다. STEP 변환에는 OCCT 기본 shape processing이 들어갈 수 있다. 변환된 B-rep를 검증하며 원본의 PMI·설계 공차는 해석하지 않는다.
2. STL 표면 성분이 여러 개이면 재료 합집합과 공동 포함 관계를 자동 확정하지 않는다. 체적·두께·층 결과가 미확정인 이유를 유지한다.
3. 구의 임계 각도 투영면적은 메시 세분화에 단조 수렴하지 않았다. 관측한 약 2.18% 최대 차이를 모든 모델의 오차 상한으로 사용하지 않는다.
4. `3DP_20546_S-0039.stl`의 좌표 범위는 150×142×25,000이다. mm를 가정하면 25 m가 되며 실제 치수는 모른다. z축만 임의 보정하거나 층 간격을 바꿔 정상 사례로 만들지 않는다.
5. 가든 훅의 최소 법선 거리 표본 약 0.00676 mm와 면적 가중 5백분위 약 4.545 mm는 다른 통계다. 전자는 전체 벽두께 또는 물리적 얇은 벽의 확정값이 아니다. 단위도 가정 상태다. 원본 면·좌표를 확인한다.
6. Cura 리브 실험은 합성 CLI 설정의 **경로 생성** 실험이다. 0.15/0.3 mm 리브가 경로를 가진다는 사실로 실물 제작 성공을 확정하지 않는다. 0.08 mm의 경로 0은 그 설정에서의 관측이다.
7. 실물 출력·공차·하중·강도·열변형 검증은 아직 하지 않았다. 사용자가 장비를 정하면 동일 파일·배치·설정으로 시편과 실제 치수를 측정한다.

문헌 전체를 완전히 읽고 영구 기억했다고 표현하지 않는다. 추가 조사와 접근 범위는 조사 문서에, 기존 원문 누락·모순은 `LITERATURE.md`와 `OPEN_QUESTIONS.md`에 보존한다.
