# 현재 AI의 기여·한계와 다음 개선순위

사용자 지시: 처음 사용하는 사람이 적은 입력으로 문제 위치와 개선 결론을 이해할 수 있게 전체 흐름을 검토하고, AI 수준과 앞으로의 개선 방향을 냉정하게 평가한다. 이 문서는 코드·배포 모델·검증 JSON·원본 DB를 읽어 대조한 기록이다. 새 학습이나 모델 변경을 수행한 결과가 아니다. 사용자 화면에 같은 설명을 반복해서 추가하지 않는다.

## 현재 수준

현재 제품은 **외부 CAD에서 특징을 찾고, 기하 계산으로 확인한 개선 후보를 추천하는 보조 AI**다. 특징 인식에는 규칙과 구별되는 학습 기여가 있다. 종합 개선안의 목표값은 아직 개발자가 정의한 비교 정책이며, 외부 전문가가 선택한 개선안의 정답을 학습한 것은 아니다.

| 기능 | 실제 담당 방식 | 판단 |
|---|---|---|
| 절삭 특징·위치 | 외부 면 의미·특징 경계·바닥 라벨을 공동 학습 | 현재 가장 명확한 학습 기여 |
| 적층 방향 탐색 | 높이·하향면 기하량을 예측해 추가 방향 제안, 실제 메시로 재측정 | 기존 대비 일부 개선, 같은 계산량 대비 우위는 미입증 |
| 개선안 순위 | 프로젝트의 명시적 비교 목적함수를 회귀모델로 학습 | 정책 모사 성능과 설계 판단 성능을 구분해야 함 |
| 강화학습 | 공구·형상 변경의 순서를 제안하고 기존안과 재비교 | 현재 배포 시험에서 추가 채택 없음 |
| 빈 공구 치수 채우기 | 형상 치수와 80%·1 mm 여유 정책으로 제안 | 유용한 자동화이며 학습된 최적 공구는 아님 |
| 수정 전후 STEP | 지원 단일 포켓의 코너를 CAD 커널로 편집하고 검산 | 실제 편집 기능이며 생성형 AI의 결과는 아님 |

공구 방식은 [tool_recommendation.py](../../dfm/tool_recommendation.py)의 `recommend_tool_dimensions`, 실제 편집은 [cad_edit_pairs.py](../../dfm/cad_edit_pairs.py), 적층 국소 치수 목표는 [am_joint_planning.py](../../dfm/am_joint_planning.py)를 따른다. 적층 벽·구멍 목표는 입력 기준에서 만들어지며 모든 개선 목표를 AI가 독자적으로 발견한 것으로 설명하지 않는다.

## 확인한 성능

### 절삭 특징 위치

[선택 모델의 보류 시험](../../validation/ai-full-corpus-2026-09-30/feature-models/calibrated-evaluation.json)의 `test_panoptic`은 CAD 9,241개, 정답 특징 58,493개에서 정답 42,277개·오검출 1,125개·누락 16,216개다. 정밀도 **97.40795%**, 회수율 **72.27702%**, 면 집합 완전 일치 회수율 **71.24955%**, PQ **0.826386**이다. 특징 일치 조건은 같은 클래스이고 면 집합 IoU가 0.5보다 큰 경우다. 정밀도는 표시한 특징 중 맞은 비율이며 전체 특징을 찾은 비율이 아니다.

별도의 면 분류 정확도 97.87328%·macro F1 0.962607을 특징 위치 또는 전체 앱 정확도로 바꾸지 않는다. 클래스별 검증 문턱을 적용하면서 4종(관통 구멍·삼각 관통부·육각 관통부·원형 관통 홈)은 학습 위치 확정에서 제외했다. 관통 구멍의 기존 CAD 해석 검사는 유지된다. 미검출을 해당 형상의 부재로 해석해서는 안 된다.

실제 [CAD 입력 경로](../../amdfm/cad_worker.py)는 솔리드당 200면 이하에서 학습 특징 인식을 시도한다. 평면 CAD에는 기존 16종 의미 모델과 새 경계 모델을 함께 사용한다. 자유곡면과 범위 밖 입력도 따로 처리한다. 따라서 MFInstSeg 공동 모델의 단독 시험 수치는 이 혼합 런타임 전체 성능이 아니다. [특징 위치 구현](../../dfm/feature_localization.py)과 [모델 선택 기록](../../validation/ai-full-corpus-2026-09-30/feature-selection.json)을 함께 확인한다.

### 적층 방향

[기하 예측 시험](../../validation/ai-full-corpus-2026-09-30/am-full/evaluation.json)에서는 세 출처 모두 높이·하향면 정규화 오류가 감소했다. 다만 예측 오류 감소만으로 추천이 좋아졌다고 결론 내리지 않는다.

[최종 탐색 비교](../../validation/ai-full-corpus-2026-09-30/full-am-benchmark.json)는 보류 105형상군·525공정/목적 조건이다. 추가 후보 중 최선은 기존보다 46개 개선·479개 동일·악화 0개였다. **최종 추천 선택은 31개 개선·488개 동일·6개 악화**였다. 같은 추가 계산 6회를 무작위 탐색에 준 비교는 44개 우세·463개 동일·18개 열세였으며, 평균 목적값 차이 +0.000511856으로 AI가 조금 나빴다(작을수록 좋음). 후보 보존과 최종 추천 무악화는 다른 성질이다.

### 종합 추천·강화학습·실제 편집

[개선안 순위 시험](../../validation/ai-full-corpus-2026-09-30/plan-full/evaluation.json)의 외부 보류 32,970조건에서 새 순위 모델은 정의된 목표의 최선 31,636개, 평균 손실 0.0000715469다. 이전 모델의 손실은 0.001045882였다. 고정 비교보다 개선 28,974개·악화 643개다. **이 성과는 명시적 비교 목적에 대한 성과이며 외부 전문가의 개선안 정답에 대한 성과가 아니다.**

[학습 목표함수](../../scripts/train_plan_model.py)의 `selection_objective`는 소수의 산술 연산으로 정확히 계산할 수 있다. 현재 [최종 순위](../../dfm/plan_learning.py)는 이를 직접 평가하지 않고 모델 근사 점수로 정한다. 그러므로 기존 규칙 대비 향상 중 새로운 비교 정책 자체의 효과와 학습의 추가 효과를 분리해야 한다. 이미 정확히 계산 가능한 정책에 대한 근사 오류를 줄이는 학습만으로 설계 판단 범위가 넓어졌다고 주장하지 않는다.

[강화학습 원시 시험](../../validation/ai-full-corpus-2026-09-30/rl-full/test-summary.json)은 5,529조건에서 기존 개선안 대비 개선 7개·악화 814개다. [실제 배포 중재 시험](../../validation/ai-full-corpus-2026-09-30/rl-runtime-benchmark.json)은 120형상군·1,440조건에서 채택 0개·추가 개선 0개·악화 0개다. 중재가 기존안을 유지한 결과이며 강화학습의 추가 효용을 입증한 결과가 아니다.

[외부 수정 쌍 시험](../../validation/ai-full-corpus-2026-09-30/cad-pair-benchmark.json)은 삼각·직사각·육각 포켓 각 35개에서 104개 편집 검산 통과·1개 거부다. 이는 지원 CAD 편집의 검증이며 편집 쌍을 학습했다는 의미가 아니다. 복수 포켓·자유곡면의 자동 수정으로 확대하지 않는다.

## 데이터와 평가의 남은 공백

- [카탈로그](../../data/training/full-corpus-catalog.json)의 적격 외부 기록 120,178개·가중치 학습 84,513개는 재현 가능한 집계다. 모든 기록이 서로 다른 설계이거나 지원 범위가 충분하다는 뜻은 아니다.
- 적층 42,295기록 중 PBF 방향 자료 40,000개는 4개 생성 형상군에서 각각 10,000개다. CadQuarry 920개, Thingi10K 1,375개가 보완한다. Thingi10K는 원저작물 327그룹이며 보류 시험 183메시는 49그룹이다. 새 작성 방식·새 형상 계열의 독립 평가를 강화해야 한다.
- [적층 감사](../../validation/ai-full-corpus-2026-09-30/am-full/audit.json)의 분할 간 그룹 중복은 0이다. [절삭 감사](../../validation/ai-full-corpus-2026-09-30/mfinstseg-verified-audit.json)는 비소재 면 의미 라벨의 정렬된 다중집합으로 그룹을 나눴다. 이는 정의한 그룹의 중복 방지이며 모든 기하 유사성이나 모든 출처 간 중복을 배제한 증거는 아니다.
- 이번 읽기 대조에서 `training.sqlite`의 MFCAD 15,488개와 `mfinstseg-verified.sqlite`의 적격 62,395개 간 원본 STEP SHA 중복은 0이었다. 재내보낸 동형 CAD는 다른 SHA가 될 수 있으므로 기하 중복 검증과 구분한다.
- [공개 STEP 실행 감사](../../validation/ai-full-corpus-2026-09-30/public-runtime-audit-final/public-demo-review-audit.json)는 14파일·70공정 검토의 연결 상태를 확인했다. 문제 위치·권장 조치에 독립 정답이 붙은 대규모 최종 사용자 평가를 대신하지 않는다.

## 다음 개선순위와 통과 기준

1. **최종 추천의 일관성:** 재측정한 후보를 정확 비교 정책으로 중재하고, 학습은 후보 생성·인식·실제 사용자 선호에 집중한다. 같은 후보·같은 계산 시간에서 규칙·정확 정책·현재 모델을 비교하며, 추천 악화 수와 조건 변경에 따른 불필요한 추천 반전을 기록한다. 모델 소스 계약이 달라지면 재학습·재검증한다.
2. **현재 앱 경로 그대로 평가:** 평면/곡면 혼합 모델, 200면 경계, 복합 특징에 독립 정답을 붙인다. 문제 면 집합 일치, 검출 정밀도·회수율, 수정 후 문제 감소, 새 문제 발생을 따로 집계한다. 원본 형상군 단위 보류와 출처별 결과를 유지한다.
3. **못 찾는 특징 보강:** 확정 제외 4종, 서로 접한 특징, 복합 포켓, 큰 CAD를 우선한다. 같은 유형 수만 늘리기보다 실패 사례를 수집하고, 정밀도를 유지하면서 회수율과 지원 범위가 늘어나는지 검증한다.
4. **추천 정답의 질 개선:** 독립 검산한 수정 전후, 명시적 사용자 선택, 실제 공구 규격을 연결한다. 단순 규칙 모사·검산 결과·사용자 선호를 구분하고, 보류 형상에서 기존안보다 적은 변경으로 같은 문제를 줄이는지 평가한다.
5. **강화학습은 후순위:** 동일 시간·동일 후보 자원에서 기존 탐색보다 유효한 추가 개선을 입증한 뒤 역할을 넓힌다. 현재는 채택 0인 결과를 제품 강점으로 내세우지 않는다.

사용성 평가는 모델 수치와 별도로 수행한다. 첫 사용자에게 파일 선택부터 결론·문제 위치·수정안 저장까지의 과제를 주고 **필수 입력 수, 클릭 수, 완료 시간, 용어 오해, 재검토 횟수**를 측정한다. 결론·위치·바꿀 수치를 먼저 보여주고, 근거와 계산 상세는 요청할 때 펼치는 구조를 유지한다.
