# 문제 위치 직접 이동·딥러닝 탐색·강화학습 계획

상태: 구현·검사·바탕화면 실행본 반영 완료. 검사한 코드 버전과 마지막 표시 수정의 범위는 아래 기록을 따른다.

## 사용자 요청

종합 결론의 문제 위치 버튼을 누르면 바로 해당 위치를 보여준다. 작은 부품보다 큰 축·화살표, 서로 겹치는 표본 표시를 개선한다. 기존 지도학습을 넘어 딥러닝과 강화학습의 실용적 역할을 확장한다. 현재 범위는 적층·절삭이며 평가 대상은 측정·규칙에 따른 문제 탐지와 개선안 품질이다.

## 화면 변경

- AM/CNC 위치 버튼은 선택 항목을 열고 해당 제목으로 스크롤·키보드 초점을 옮긴다. 일반 재실행이나 수동 위치 변경 때는 이전 이동을 반복하지 않는다.
- 벽은 실제 부품 위치도와 선택 측정선을 지나는 확대 단면으로 나눈다. 동일 배율의 단면에 입구·반대 면·거리선을 표시한다.
- 기록된 법선·거리·대상 삼각형을 대조한 끝점만 그린다. 누락되거나 형상과 맞지 않는 점에서 임의의 단면을 만들지 않는다.
- 기준 미만 ×, 선택 ◆를 기본으로 보여준다. 다른 표본은 선택해서 추가한다. HTML에도 같은 검증을 사용하는 오프라인 SVG를 넣는다.

## AI 책임과 재검산

| 단계 | 방식 | 결과를 확정하는 방법 |
|---|---|---|
| 문제 검출 | 기존 기하 엔진과 명시된 기준 | 원래 측정·부분/미확정 상태를 유지 |
| 적층 추가 방향 | 다층 신경망이 새 방향의 높이·하향면 지표를 예측해 탐색 후보 선택 | 실제 메시에서 방향별 지표를 다시 계산; 예측치를 측정값으로 넣지 않음 |
| 절삭 수정 순서 | 행동별 다음 상태를 사용하는 Double DQN | 매 단계와 최종 치수 변경을 원래 측정과 대조; 잠금·CAD 면·미해결 항목 보존 |
| 최종 추천 | 기존 순위 모델·명시적 선호와 새 제안 비교 | 새 절삭안이 수치 충돌을 늘리면 제외; 기본 추천은 기존안의 최소 충돌·변경비용과 비교 |

큰 평면을 찾는 방향 후보는 기하 알고리즘이며 신경망 성과로 합산하지 않는다. 강화학습 환경도 문헌을 자율 독해하거나 원본 CAD에서 특징을 새로 인식하는 모델이 아니다. 이미 측정된 특징의 수정 순서를 학습한다. 상세 모델·생성 데이터·분할·실패 사례는 이번 검증 폴더에 보존한다.

기존 `plan_learning.py`와 기존 모델 학습 소스는 바꾸지 않는다. `enhanced_planning.py`가 새 후보와 이전 후보를 같은 수치 검사로 비교한다. 명시적 사용자 선호는 기존과 같은 로컬 범위별 pairwise 학습에 새 검증 후보를 포함한다.

## 방법 근거

- Mnih et al., *Human-level control through deep reinforcement learning* (2015): 신경망 Q 함수, 경험 재사용, 표적망의 방법 근거. 이 논문의 게임 성능은 본 도구의 설계 검토 성능 근거가 아니다.
- van Hasselt, Guez, Silver, [*Deep Reinforcement Learning with Double Q-learning*](https://arxiv.org/abs/1509.06461): 다음 행동 선택과 표적 평가를 분리하는 갱신 방법.
- Li et al., [*A Numerical Evaluation of an Infill Sampling Criterion in Artificial Neural Network-Based Optimization*](https://www.ijcte.org/papers/874-F031.pdf): 신경망 대리모델로 다음 평가 지점을 고르는 접근의 참고. 본 도구의 형상·목적·탐색 정책은 별도 구현·평가 대상이다.

## 검증 원칙

후보 중 얻을 수 있는 최선과 실제 최종 추천을 별도로 평가한다. 큰 면 후보를 같은 수만큼 주고 나머지 신경망·무작위·균등 탐색의 계산 예산을 맞춘다. 초기 실패를 보존하고 개발에 사용한 시험을 독립 시험으로 재분류하지 않는다. 강화학습은 미학습망·탐욕·기존 후보와 비교한다. 절차 생성 시나리오와 실제 STEP 실행 검증을 구분한다.

원본 검증 경로: `validation/neural-localization-2026-09-29/`. 최종 모델과 실행 코드가 동결된 뒤 전체 회귀검사, 바탕화면 환경 검사, 브라우저 확인을 기록한다.

## 학습·평가 결과

### 적층 딥러닝

학습은 192개 생성 형상의 20,922개 방향 측정, 모델 선택은 별도 48개 형상의 5,204개 측정으로 했다. 동일 형상의 방향이 양쪽 분할에 섞이지 않는다. 학습 방식은 지도학습이며 모델 구조가 다층 신경망인 딥러닝이다. [방법·반례·전체 비교](../../validation/neural-localization-2026-09-29/orientation/METHOD.md).

새로운 120개 생성 형상·960조건에서 기존 26방향 대비 최종 추천의 공개 비교값은 개선 643, 동일 287, 악화 30건이었다. 추가 후보를 남겼다고 모든 추천이 더 좋다는 뜻은 아니다. 또한 큰 면 방향을 추가한 효과가 크므로 이를 전부 신경망의 기여로 설명하지 않는다. 같은 큰 면 후보와 계산 예산에서 후보 최선의 평균 후회값은 무작위 0.009835, 균등 0.010640, 보간 0.005502, 신경망 0.004287이었다. 이 값은 프로젝트의 비교 목적함수이며 일반 정확도 백분율이 아니다.

최종 실제 입력 감사는 STEP 47개 × 적층 4공정 = 188조건을 통과했다. 원질의 후보 1,860개를 독립 재계산하고, 미세 높이 선별 정책에 따른 2개를 제외한 1,858개를 비교 목록에 남겼다. 최종안의 같은 공개 정책 비교에서는 낮은 비용 17·동일 107·악화 0·직접 비교 미적용 64조건이었다. 낮은 비용 17조건 중 15는 후보 집합의 정규화가 달라져 기존 방향을 다시 선택한 것이고, 신경망이 찾은 새 방향은 같은 외부 STEP의 VPP/금속 PBF 2조건이었다. 해당 방향은 높이를 48.055835→45.909263 mm로 낮추지만 하향면 투영 합은 663.085140→848.545634 mm²로 늘리는 교환관계다. 이를 모든 지표의 동시 개선이나 독립 부품 2개의 개선으로 표현하지 않는다. [실제 STEP 감사](../../validation/neural-localization-2026-09-29/cad-audit/am-run-003/README.md).

### 절삭 강화학습

실제 Double DQN을 36,000 episode·156,277 transition 동안 학습했다. 검증용 시나리오로 체크포인트를 선택했으며, 최종 시험 490개 중 140개는 학습에서 제외한 특징 조합 가족이다. [최종 평가와 실패 사례](../../validation/neural-localization-2026-09-29/rl/FINAL_RESULTS.md).

순수 DQN 제안은 기존 후보 최저비용안보다 개선 0, 동일 339, 악화 151건이었다. 미학습 신경망보다 좋아졌지만 기존 기하·규칙 기반 조합보다 일반적으로 우수하다고 주장하지 않는다. 앱의 실제 비교 경로에서는 재검산을 거쳐 기존보다 나쁜 제안을 교체 추천하지 않았고, 490개 모두 기존안이 유지됐다.

실제 STEP 감사에서는 별도 효과가 있었다. 33 STEP × 공구 2종 × 변경 허용 3종 × 접근축 3종의 594조건에서 채택안 개선 1, 동일 121, 직접 비교 미적용 466, 64특징 예산 초과로 기존안 유지 6건이었다. 비교된 조건의 악화는 0건이다. Pump housing의 +Z·공구 지름 4 mm 조건에서 기존 돌출 길이 10→30 mm 변경 대신, 돌출 10→13 mm와 CAD 면 57 원통 구간 30→13 mm를 조합해 수치 충돌 0개를 유지하면서 공개 변경 비용을 0.617623→0.596363으로 낮췄다. 이는 치수 제안의 수치 검산이며 CAD 파일 자동 수정이나 모든 연결 형상의 재측정은 아니다. [594조건 원자료·해석](../../validation/neural-localization-2026-09-29/cad-audit/cnc-run-003/README.md).

절삭 33 STEP는 적층 47 STEP에 포함된다. 감사한 고유 STEP는 47개이며 이를 80개 독립 파일로 합산하지 않는다.

## STEP 메시 정밀도에 비해 미세한 높이 차이

실제 구 STEP는 정확한 높이가 모든 방향 20 mm이다. 추가 방향에서 측정 메시의 높이가 0.001395 mm 낮아지는 현상을 발견했다. 이를 새로운 설계 개선처럼 추천하지 않도록, 높이만 비교하는 고분자 PBF의 STEP 추가 후보에 작은 감소량 선별 정책을 연결했다.

기준은 `min(2 × 선택 솔리드의 유효 선형 편차, 기존 최소 높이 × 0.001)`이다. 유효 편차가 없으면 요청 편차를 사용한다. 이 값은 인증된 CAD 오차 한계가 아니라 공개된 추천 선별 정책이다. 상대값 상한을 둬서 작은 평면 부품의 실제로 큰 개선을 보존한다. 현재 방향만 바꿔도 선별 기준이 흔들리지 않으며, 기존 후보가 지정 공간에 들어가지 않으면 새로 들어가는 후보를 이 정책으로 제거하지 않는다.

원측정값과 질의 기록은 유지하고 추천 대상에서만 제외한다. 기존 기본 방향 전체에 오차 보증을 추가한 것은 아니다. 다른 공정은 높이 외 항목도 비교하므로 이 높이 전용 정책을 적용하지 않는다. 관련 반례·현재 방향 독립성·다중 솔리드·구 STEP 검사는 `test_ai_search_resolution.py`에 있다.

## 실행 환경

새 두 모델의 추론은 NumPy와 저장된 JSON 가중치만 사용한다. 외부 API·GPU·학습용 scikit-learn 설치가 필요하지 않다. 모델/계산 소스/입력 계약 SHA를 실행 때 확인한다. 적층은 기본 추가 12방향·100,000면·측정 사이 8초 예산, 절삭은 64특징·24단계 예산을 사용하며 초과 조건은 기존 경로를 유지한다.

## 최종 검사와 배치

- 전체 `tests_v3 tests`: **1,405개 통과**, 573.11초, `full-final.xml`. 기존 영체적 회귀 사례에서 trimesh 경고 1개가 있었으며 테스트 실패는 없다.
- 바탕화면 Python 3.13.15·Streamlit 1.63.0: 새 AI·상세 화면·위치 이동·결론·선호·앱 관련 **108개 통과**, 114.67초, `desktop-final.xml`. 이 환경에는 학습용 sklearn이 설치되지 않았다.
- 위 두 검사 후 실제 좁은 창에서 매우 얇은 부품의 3D 그림이 잘리는 현상을 발견했다. 마지막 수정은 `wall_visual.py`의 **표시 축 비율**뿐이며 측정·AI·선택 코드는 변경하지 않았다. 최대 표시 길이를 정규화하면서 모든 축에서 1 mm의 표시 배율을 같게 유지했다. 이 변경 후 저장소와 바탕화면 환경에서 벽 그림·단면·보고서·화면 **각각 20개 검사**를 다시 통과했다(`wall-framing-final.xml`, `desktop-wall-final.xml`). 전체 1,405개를 이 마지막 표시 변경 후 다시 돌렸다고 해석하지 않는다.
- 전체/바탕화면 108개 검사 당시 계산 코드 식별자: `04ba33c513121166a9527a47e00d052e6bc15e5334e56ef467ae52d37304f95c`. 마지막 표시 변경 후 식별자: `a9148fdddce5c474a6a051198a9ca463be6133511801b25335447ef2045cf56a`.
