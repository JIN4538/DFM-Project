## 저장 범위와 읽기 방법

- PDF 전체239쪽 가운데79쪽은 스캔/캡처 기반4개 KS 파일이다. 페이지 번호는 원칙적으로PDF 물리 페이지를 뜻한다. 인쇄 쪽번호와 다를 수 있다.
- R04 Table3(p21~23),R14 Eq.3(p4),R11 흐름도(p8~10),R10 시험편 표(p6),R09 부속서A(p8) 등은 이미지를 추가 대조했다. 이미지로만 남은 모든 그래프를 수치 데이터로 복원한 것은 아니다.
- 원본 DOCX4개의 구조화된 본문·표·머리말/꼬리말을 읽었다. 새 DOCX를 생성하거나 원본의 레이아웃을 편집하지 않았다.
- 소스의 실제 기준은 ZIP 내 파일이다. v2.6 핵심 실행 모듈을 읽고 과거 코드/보고서/패치를 대조했다. 테스트 실행 성공만으로 모든 코드 경로를 이해하거나 검증했다고 간주하지 않는다.
- [CODE_INDEX.json](CODE_INDEX.json)은 버전별Python 파일 해시·함수 위치의 기계 생성 색인이다. 색인 생성은 의미 검토 완료의 증명이 아니다.
- 작업용 전사/이미지/격리 소스/실행환경은 저장소 밖 `../study/`에 있다. 이 폴더가 없어도 원본 ZIP/PDF로 재생성할 수 있다. 전체 문헌을 메모리로 대체하지 않고 수정할 규칙의 원문을 다시 확인한다.
- Git 원본24개 파일의SHA-256이 검토 전후 동일함을 확인했다. 새 지식 문서만 추가했으며 커밋·푸시는 하지 않았다.
