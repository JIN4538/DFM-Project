### 숫자의 코드상 의미까지 설명하는 방법

오버행 0.30은 단지 문서의 숫자가 아니다. 현재 점수 함수에서는 비율 0.15 이하는 100점, 0.30은 50점, 0.60 이상은 0점이 된다. 서포트 비율은 0.25 이하 100점, 0.50에서 50점, 1.0 이상 0점이다. 종횡비는 3 이하 100점, 10에서 50점, 20 이상 0점이다. **이 곡선도 제조 실험으로 보정한 것이 아니다.** 함수의 경계에서 점수가 연속적으로 변하도록 만든 구조와, 정확한 기준값의 타당성은 구분한다.

빌드 점유율은 코드상 40% 이하 100점, 80%에서 50점, 100%에서 0점이다. 여기서 100%와 점수 0의 대응은 코드로 확인할 수 있지만, 80%를 고른 역사적 판단 근거까지 기록돼 있는 것은 아니다.

벽두께 3점 확인은 한두 레이가 같은 모서리·수치 문제에 영향을 받을 수 있어 근거를 강화한 것이다. 실제 코드는 대향 법선 코사인 0.85, 공간 범위 `max(하한/4, 10×수치 epsilon)`, 최대 후보 면 128개를 사용한다. 이 값들도 표준 규정이 아닌 기하 검증·계산량 관리 휴리스틱이다. 3점으로 모든 얇은 부위를 반드시 찾는다는 뜻은 아니다.

### 교수님께 답할 때의 공통 문장

> 이 지표는 문헌이 지적하는 위험을 비교하기 위해 넣었습니다. 다만 문헌이 이 숫자까지 정해준 것은 아닙니다. 현재 값은 초기 프로필의 잠정 기준이고, 코드에서는 이런 방식으로 경고와 점수에 반영됩니다. 독립 부품과 실제 조건을 대조해 값을 조정하기 전에는 보편적인 제조 한계로 주장하지 않겠습니다.

“안전계수로 정했다”, “경험적으로 최적이다”, “교수님들이 보통 쓰는 값이다”라는 설명은 실제 기록·실험이 없으면 덧붙이지 않는다. 기존 기록에 없는 이유를 사후에 만드는 것보다 적용 범위를 명확히 하는 것이 낫다.

## 5. 1시간 이내 온라인 미팅에 맞는 구성

현재 문서는 **본문·참고문헌 9쪽 + 부록 5쪽**이다. 사전 제출용으로 불가능한 분량은 아니지만, 본문도 개발 이력과 표가 많아 화면 공유로 전부 따라가기는 길다. 발표 시간을 계산식으로 확정한 것은 아니며, 다음 배분을 권한다.

| 시간 | 내용 |
|---|---|
| 0~3분 | 어떤 사용자 문제를 해결하는지, 현재 주장 가능한 범위 |
| 3~8분 | 입력 진단·3D 규칙·단면 검토의 역할과 실제 결과 화면 |
| 8~13분 | 가장 중요한 개선 3개: 잘못된 통과 방지, 얇은 영역 근거 강화, 단면 경고의 보존·분류 |
| 13~18분 | 확인한 성능과 아직 확인하지 못한 제조 타당성 |
| 18~20분 | 다음 검증 계획과 교수님께 결정받을 사항 |
| 20~25분 | 짧은 시연 또는 저장해 둔 결과 화면 설명 |
| 25~50분 | 질의응답 |
| 50~60분 | 대상 장비·평가 목표·다음 산출물 합의와 여유 시간 |

본문은 5~6쪽 수준으로 줄이고 상세 버전별 변화·규칙 10개·회귀 모델 비교를 부록에서 찾게 하면 좋다. 14쪽을 유지하더라도 설명할 쪽과 참고할 쪽을 구분한다. 첫 화면에 전체 처리 흐름, 다음에 같은 부품의 3D 위험 위치와 단면 예시를 보여주는 것이 표만 읽는 것보다 이해하기 쉽다.

**실제 출력에서 확인한 편집 문제:**

- 3쪽에는 프로그램 구성 표의 머리글만 남고 내용이 4쪽으로 넘어간다. 제목과 표 첫 데이터 행을 함께 배치한다.
- 8~9쪽에서 참고문헌 한 항목이 쪽을 넘어 분리된다. 문헌 항목별 문단 유지가 필요하다.
- 여러 표가 본문 폭보다 넓다. A4의 현재 본문 폭은 9,826 twip인데 다수 표의 열 폭 합은 10,500~11,000 twip이다. 특히 10·13쪽 등은 표가 오른쪽 여백을 침범하고 일부 테두리가 페이지 끝으로 나간다. ‘창에 맞춤’ 등으로 본문 폭 안에 맞춘 뒤 PDF를 다시 확인한다.
- 14쪽은 용어표의 나머지 부분만 있어 여백이 크다. 용어표를 한 쪽에 모으거나 축약하면 정돈된다.

## 6. 교수님이 물을 가능성이 높은 질문과 답변

### 1. 이 소프트웨어의 핵심 기여가 무엇인가?

“STL과 명시된 FDM 조건에서 검토할 위치·관련 규칙·판단 불가 범위를 함께 보여주는 설계 검토 도구입니다. 현재의 성과는 계산과 판정의 결함을 줄이고 부분 단면 검토를 제공한 것입니다. 기존 도구보다 제조 위험을 더 정확히 찾는다는 기여는 다음 독립 비교로 입증해야 합니다.” 연구의 신규성을 이미 입증했다고 말하지 않는다.

### 2. Cura나 PrusaSlicer를 쓰면 되지 않는가?

“슬라이서는 경로 생성과 출력 준비가 중심입니다. 이 도구는 경고의 위치와 근거, 입력 한계, 방향별 검토 결과를 설명하는 데 초점을 둡니다. 다만 슬라이서에도 유사 기능이 있으므로 어떤 작업에서 검토 시간이나 해석을 개선하는지 비교할 필요가 있습니다.”

### 3. 표준이 실제로 어디까지 보장해 주는가?

“무엇을 고려해야 하는지와 관련 절을 연결합니다. 0.4 mm, 30%, 가중치, A등급은 표준의 인증 기준이 아닙니다. 문헌 시험값도 원래 조건 범위 안에서 차용했습니다.”

### 4. 임계값 근거가 없으면 점수는 의미가 없는 것 아닌가?

“현재 점수는 같은 프로필에서 형상의 검토 우선순위를 비교하는 잠정 지표입니다. 성공확률이나 보증값으로 사용할 근거는 없습니다. 그래서 개별 측정값·경고 위치·근거 유형·평가 범위를 같이 제공합니다. 점수 순위가 실제 판단과 맞는지는 별도로 검증할 계획입니다.” 같은 프로필이라도 평가 규칙의 범위가 다르면 직접 비교를 주의한다.

### 5. 왜 30%, 50%, 종횡비 10인가?

“초기 비교 기준으로 설정했고, 정확한 값은 실험으로 도출하지 않았습니다. 코드에서도 그 한계를 기록했습니다. 비율별로 어떤 경고·점수 변화가 생기는지 공개하고, 검증 부품군과 실제 요구 조건으로 조정하겠습니다.” ‘대략 합리적이어서 검증됐다고 볼 수 있다’는 답은 하지 않는다.

### 6. 0.4 mm보다 얇으면 정말 출력할 수 없는가?

“그렇게 단정할 수 없습니다. 기본 프로필을 참고한 하한이고, 실제 경로는 가변 선폭과 슬라이서 설정에 따라 달라집니다. 현재 코드는 해당 기준 위반을 기하적으로 확인하는 것이며 출력 실패를 직접 실험한 것은 아닙니다.”

### 7. 왜 벽두께를 세 점에서 다시 확인하는가?

“한 레이의 이상치나 가까운 모서리 영향을 줄이기 위해서입니다. 처음 의심된 면의 내부 세 점에서 반대편 비인접 면을 다시 찾고 거리가 기준보다 작은지, 일정 공간에 걸쳐 있는지 확인합니다. 그래도 전역 최소 두께를 완벽하게 검출하는 알고리즘은 아닙니다.”

### 8. 222개가 통과했다면 정확도가 검증된 것 아닌가?

“정해 놓은 계산·불변성·회귀·UI 계약을 통과했다는 뜻입니다. 222개의 독립 출력 시험이 아니므로 실제 제조 위험의 정밀도·재현율을 뜻하지 않습니다. 환경과 당시 코드 버전을 함께 제시하겠습니다.”

### 9. R² 0.978이면 서포트 예측이 충분히 정확한가?

“네 형상의 여섯 방향, 24건에 계수를 맞춘 적합도입니다. 그 자료에서의 설명력은 높지만 새 부품 예측 성능은 아직 모릅니다. 새 부품 전체를 분리해 절대 오차와 상대 오차, 형상별 편향을 확인해야 합니다.”

### 10. 경고 수를 줄인 것이 오류를 숨긴 것 아닌가?

“작은 후보를 삭제하지 않고 작은 세부로 분류해 위치와 면적을 보존했습니다. 성분 자체가 소실되는 경우는 작은 크기라도 검토 대상으로 남깁니다. 다만 재분류가 제조 관점에서 옳았는지는 별도 정답 자료로 확인해야 합니다.”

### 11. 열린 메시에서도 단면 검토가 되면 입력 문제가 해결된 것 아닌가?

“전체 솔리드로 신뢰할 수 없는 입력이라도 특정 평면에서 닫힌 재료 영역을 확정할 수는 있습니다. 그 범위에서만 결과를 제공하는 것입니다. 메시 복구, 전체 체적 확정, 실제 제조 가능 판정이 완료됐다는 뜻은 아닙니다.”

### 12. 정답 자료는 어떻게 만들 것인가?

“CAD 치수·해석식으로 단면의 기하 정답을 먼저 만듭니다. 다음으로 같은 설정의 슬라이서 경로와 대조하고, 제조 위험을 말하려면 실제 시편의 치수·처짐·특징 소실 등을 측정합니다. 세 단계의 정답 의미를 구분하고, 조정용 부품과 최종 확인용 부품을 처음부터 분리하겠습니다.”

### 13. 다음 단계의 성공 기준은 무엇인가?

“먼저 대상 장비·재료·설정과 허용 품질을 정하겠습니다. 기하 계산에는 치수/면적 오차, 경고에는 독립 라벨 대비 오탐·미검출, 서포트에는 새 부품의 부피 오차, 사용성에는 검토 소요 시간과 원인 설명 가능성을 쓰겠습니다. 허용 수치는 교수님과 사용 목적에 맞춰 정하고 평가 전에 고정하겠습니다.” 수치를 이미 검증한 것처럼 새로 만들지 않는다.

### 14. 왜 지금 AI나 절삭 기능을 먼저 추가하지 않는가?

“현재 규칙의 출력을 정답으로 학습하면 오류까지 학습합니다. 우선 독립 기준과 FDM 범위를 검증한 뒤 필요한 부분에 AI를 적용하겠습니다. 절삭은 별도의 공구 접근·고정·공차 조건이 필요하므로 AM 점수의 타당성을 대신하지 못합니다.”

### 15. 미팅에서 교수님께 무엇을 결정받을 것인가?

“우선 FDM의 어느 장비·재료를 대상으로 할지, 논문의 핵심을 경고 정확도·검토 효율·방향 비교 중 어디에 둘지, 시편 출력과 측정에 접근할 수 있는지를 결정받고 싶습니다. 이에 맞춰 다음 검증의 수용 기준과 범위를 확정하겠습니다.”
