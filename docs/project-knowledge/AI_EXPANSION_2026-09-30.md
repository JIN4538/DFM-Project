# 공개 데이터 추가 학습과 종합 개선안 확장

사용자의 후속 지시: 공개 적층·절삭 데이터를 더 수집하고 실제 학습해 성능을 올린다. 장비 선택을 확대하고 외부 공개 STEP을 시연에 제공한다. 적층·절삭만 지원한다. 최신 상태는 이 문서를 우선하며 아래 이전 학습 기록은 당시 결과다.

## 반입과 실제 학습을 구분한 기록

새 원본 41,000개를 `study/ai-expansion-2026-09-30/public-expansion.sqlite`에 저장했다. 원본 ZIP/Parquet와 파일 SHA·출처·라이선스·분할은 같은 작업 폴더에 보존한다. 원본 Python CAD 생성 코드는 메타데이터로만 저장하고 실행하지 않았다.

| 자료 | 보관 원본 | 이번 학습·평가에 사용한 범위 | 권리·원 출처 |
|---|---:|---|---|
| PBF-LB/M orientation | STL 40,000개 | 해시로 선택한 2,000개 중 적격 1,906개 | 저자 Apache-2.0 표기, [데이터](https://huggingface.co/datasets/sebius/pbflbm-part-orientation), revision `24d4f3f5f05cad5488fcf9a4cbc95e28ff528a8a` |
| CadQuarry | STEP/STL 쌍 1,000개 | 적격 메시 801개 | CC0-1.0, [저자 데이터](https://huggingface.co/datasets/jacobjennings/cadquarry), revision `be52b95de212431d995c3ebd25bdd9d56a5c96bf` |
| Thingi10K | 이전 원본 유지 | 기존 적격 메시 1,051개를 함께 사용 | 이전 반입·개별 출처 기록 유지 |
| MFInstSeg | 이전 STEP 62,495개 유지 | 대응 검사 5,000개 중 4,996개 인증 | [저자 AAGNet](https://github.com/whjdark/AAGNet), 저자 CC0 선언; 원본·SHA는 이전 기록 |
| MFCAD | 이전 STEP 15,488개 유지 | 기존 면 라벨 그래프를 MFInstSeg 학습에 함께 사용 | 이전 반입·분할·출처 기록 유지 |

MFCAD++는 공식 접근 403으로 반입·학습 0이다. CADSynth도 접근 실패로 사용하지 않았다. 표본 4,996개를 전체 MFInstSeg 학습으로 표현하지 않는다. 기존 43개 문헌·928쪽의 규칙 근거는 계속 사용하며, 표준의 서술을 전문가 개선안 정답쌍으로 간주하지 않는다.

PBF 원 저자의 기준 회전을 최적 제조 방향 정답으로 복사하지 않았다. 논문 *Learning automatic part orientation for powder bed fusion of metal from part data* (Wenger 외, 2025, DOI `10.1007/s40964-025-00960-6`)과 데이터 구조를 확인하고, 우리 기하 지표를 각 방향에서 독립 계산해 학습 표적을 생성했다.

## 학습과 성능

### 적층

총 3,758개 적격 메시를 형상 그룹으로 분리했다. 학습 2,666개/2,067그룹, 검증 523개/452그룹, 보류 시험 569개/446그룹이다. 같은 형상의 회전본과 동일 바이트가 학습·시험에 섞이지 않도록 그룹과 SHA를 검사했다. 품질 검사를 통과하지 못한 신규 293개는 제외 사유를 보존했다.

높이·하향면을 예측하는 MLP 두 개를 50 epoch 학습하고 portable NumPy 모델로 내보냈다. 보류 시험 136,560 방향·각도 쿼리에서 기존 모델과 같은 입력으로 비교했다.

| 정규화 지표 MAE | 이전 | 추가 학습 | 감소율 |
|---|---:|---:|---:|
| 높이 | 0.0245064 | 0.0233108 | 약 4.9% |
| 하향면 투영 면적 합 | 0.0341862 | 0.0290175 | 약 15.1% |

이 수치는 방향별 기하 지표 예측 오차이며 최종 종합 추천 정확도가 아니다. 각 데이터군에서도 MAE가 감소했다. 독립 공식과 런타임 측정의 최대 차이 2.78e-16을 확인했다.

같은 12개 후보 예산의 진단 비교 75그룹·300조건은 17개 개선/11개 악화/272개 동일이었다. 새 모델 단독 교체를 채택하지 않고 **기존 12개 후보 유지 + 새 모델 최대 6개 후보 추가**, 총 8초 시간 예산의 앙상블로 배포한다. 예측 치수를 결과값으로 쓰지 않고 모든 후보를 기하 엔진에서 재측정한다.

앞 진단에서 사용하지 않은 보류 65그룹·260조건의 추가 비교에서는 정의된 정규화 minimax/가중 평균 후보 목적값이 18개 개선/0개 악화/242개 동일이었다. 이는 후보 집합 비교이며 추가 계산 예산을 사용한 결과다. 최종 사용자 선호·종합 계획의 일반 우위를 입증한 결과로 확대하지 않는다. 과거 결과와 반례는 삭제하지 않는다.

`train_am_expansion.py`의 평가 반복문이 타이머 변수를 덮어 써 최초 경과시간이 음수였다. 원 로그는 `evaluation-invalid-timing.json`에 보존하고 게시 평가의 시간은 null로 정정했다. 지표 값은 영향 없었으며 코드 타이머는 수정했다.

### 절삭

MFInstSeg의 원 면 순서를 신뢰하고 바로 학습하지 않았다. 저자 AAG와 가져온 STEP의 면 종류·등방 스케일을 적용한 중심/면적·모든 유향 인접 관계를 대조했다. 중심 허용 오차 1e-5, 면적 상대 오차 1e-4, 인접 관계·종류 일치를 요구했다. 4개 불일치 원본과 사유를 보존하고 제외했다.

인증 4,996개를 학습 3,540 / 검증 728 / 시험 728 형상으로 분리했다. 기존 MFCAD 그래프 및 독립 stock 반례와 함께 25종 특징 GNN을 50 epoch 학습했다. MFInstSeg 보류 시험 728형상·20,037면에서 **면 분류 정확도 93.63%, macro F1 0.89384**다. 클래스별 성능 편차는 `mf-evaluation.json`에 모두 공개했다. stock 반례 150개·500면에서는 잘못된 가공 특징 0개, Torch/NumPy 차이는 최대 1.54e-6이었다. 확률 0.75 기준은 검증 분할에서 선택했다.

기존 평면 MFCAD 16종 모델을 유지하고, 인증 가능한 곡면이 있는 200면 이하 솔리드에는 새 25종 모델을 적용한다. 자유곡면·면 수 초과·표면 모델은 범위 밖으로 남긴다. GNN이 선택한 특징 면의 치수는 OCCT로 다시 측정한다. 분류 확률을 치수 정확도나 종합 판정 확률로 표시하지 않는다.

## 사용자가 받는 변화

- 종합 결론에 추천 배치와 **측정한 벽/원통 구멍의 목표 치수**를 하나의 개선안으로 묶는다. 예: `벽 보강 + 현재 배치 유지`, `0.3 → 1.2 mm`. 목표는 선택 공정의 비교 기준이며 CAD를 자동 재생성한 결과가 아니다. 부분 표본·구멍 축 미확정은 함께 확인할 항목으로 유지한다.
- 절삭 공구 자동 제안 전에 검증된 외부 특징을 연결한다. 삼각·육각 포켓은 단순 폭이 아닌 **진입 내접원**을 지름 한계로 사용한다. 날 길이·돌출 길이는 재측정 깊이를 사용하며 사용자 입력은 유지한다. 날카로운 코너의 잔여 수정도 남긴다.
- 장비·빌드 공간·층 설정은 기존 단일 입력 상태를 공유한다. 새 장비를 선택하면 동일한 편집 가능한 빌드 치수에 적용된다. 별도 중복 입력을 만들지 않고 크기 제한은 사용자가 켠 경우만 적용한다.
- 불필요한 기본 벽 기준 출처 문장을 본 화면에서 제거했다. 출처와 학습 기록은 데이터와 펼치는 상세에 남긴다.

## 장비와 공개 STEP

제조사 페이지에서 모델별 사양을 확인해 장비 **20종**을 추가했다. Bambu A1/A1 mini/P1S/P1P, UltiMaker S7/S5/S3/2+ Connect, Creality Ender-3 V3/V3 SE/V3 KE, ELEGOO Saturn 4 Ultra 12K, Anycubic Photon Mono M7 Pro, EOS P396/M400-4, 3D Systems DMP Flex 350 Dual, Tormach 1100M/770M/1100MX/770MX이다. 전체 라이브러리는 82프로필 중 장비 35종이다. 절삭 이동거리를 가공 가능 부품 크기로 자동 적용하지 않는다. 접근 실패 Haas 및 PCNC440 값은 추가하지 않았다.

최초/후속 장비 캡처의 같은 이름으로 저장된 HTML 1건은 후속 응답으로 덮어써 최초 HTML을 복원할 수 없었다. 최초 감사 기록을 보존하고 최종 출처 SHA는 마지막 캡처와 대조했다. 향후 파일명에는 내용 해시를 붙이도록 수정했다. 원본 학습 ZIP/DB는 이 문제의 영향을 받지 않았다.

공개 STEP **14개**를 `examples/public_demo`와 바탕화면 `DFM_공개_STEP_시연`에 준비했다. 13개는 CadQuarry CC0, 1개는 미국 정부 NIST 공개 시험 형상이다. 앱 입력 `공개 STEP 시연`에서 선택·다운로드한다. CadQuarry 시연은 학습 제외 test 분할에서 선택했다. 13개 솔리드와 1개 케이스 표면 모델이며, 표면 모델은 부피·벽 미확정 처리 시연용으로 이름에 표시했다.

14개 입력을 적층 4공정 + 절삭으로 총 **70회 검토**했다. 벽 정밀검토는 브래킷·판·케이스 범위이며 절삭 시선 검사는 이 감사에서 비활성이다. 원 저자 hole_d와 실제 원통 치수 비교가 가능한 2개는 2/2 일치했다. 이 제한된 대조를 모든 치수의 정확도 검증으로 표현하지 않는다. 공개 원본 SHA와 이용조건을 파일별 manifest에 보관했다.

## 검증·재실행·배포

전체 `tests_v3` 최초 실행은 1,351 통과/4 실패였다. 앙상블 도입 후 테스트 mock이 이전 함수를 가리킨 것, 새 STEP 16파일의 전역 목록 누락, 바뀐 통합 결론의 옛 문자열 기대를 수정했다. 빌드 크기 제한 후 결과 탭 누락 1건은 단독·후속 관련 회귀에서 재현되지 않았다. 최초 실패는 숨기지 않고 원 로그를 보존한다. 후속 XML과 바탕화면 검증 결과가 최종 실행 증거다.

최종 전체 재실행은 **1,357 통과/실패 0, 724.47초**다 (`validation/ai-expansion-2026-09-30/full-final.xml`, `full-tests-final.log`). 중간 관련 재검사는 30개 통과했다. 바탕화면 Python 3.13 환경의 72개 범위는 최초 71 통과/형상 목록 1 실패였으며, 과거 검증 STEP 원본이 배포본에 빠져 있음을 확인했다. 전체 144형상을 SHA 대조 후 복사하고 해당 4개 형상·선택 검사 재실행이 모두 통과했다. 이를 서로 중복되는 검사를 합쳐 75개 고유 검사로 표현하지 않는다.

실제 바탕화면 서버 `http://127.0.0.1:8507/`에서 공개 브래킷·포켓 블록을 읽었다. Bambu A1 mini 선택 시 같은 입력에 180³ mm가 연결되고 크기 제한은 꺼진 상태를 유지한다. 공구를 비운 블록 + Tormach 1100M 검토는 인식 특징 4곳, 자동 지름 3.44 mm/날 길이 27.4 mm/돌출 길이 27.4 mm를 표시한다. 0.3 mm 판은 `벽 보강 + 현재 배치 유지`, `0.3 → 1.2 mm`를 먼저 표시하고 위치 버튼으로 선택 벽과 실제 확대 단면을 바로 연다. 브라우저 DOM·화면·미확정 항목은 `browser-verification.json`과 작업 폴더 PNG에 보존했다.

신규 독립 검사는 곡면 특징·원통 stock 오인식·강체 변환·삼각 진입 지름·국소 목표/부분 범위·앙상블 재측정·공개 STEP 무결성·새 장비 입력 흐름을 다룬다. 원본 128파일 목록에 새 공개 STEP 14개와 독립 삼각/육각 STEP 2개를 덧붙여 144파일/138 SHA를 검사한다.

학습 명령은 `scripts/train_am_expansion.py`, `verify_mfinstseg_graphs.py`, `train_mfinstseg_features.py`의 인수를 따른다. 학습 의존성은 `requirements-training.txt`, 런타임 모델 SHA는 `data/training/expansion-catalog.json`이다. 실제 배포는 `deploy_ai_expansion.py`가 기존 바탕화면 파일을 먼저 백업하고 복사 후 바이트 SHA를 대조한다. 작업 폴더의 원 DB는 Git에 복제하지 않고 휴대 가능한 모델·반입/분할·평가 기록을 저장소에 남긴다.

바탕화면 실행본의 소스·모델·설정·STEP·목록·최신 인수 문서 **378파일**을 대조 배포했다. 기존 파일 백업과 파일별 SHA는 `study/ai-expansion-2026-09-30/desktop-before-expansion` 및 `desktop-deployment.json`에 있다. 기존 Python 환경을 바꾸거나 원 데이터/옛 실행 로그를 삭제하지 않았다. 이번 턴에는 Git 커밋·푸시를 수행하지 않았다.

한계: 전문가가 작성한 형상 전후 개선 정답쌍은 신규 공개 데이터에 없다. 따라서 특징 분류와 기하 지표 학습의 실제 개선을 확인했고, 개선안 생성·선택은 기존 학습 순위/강화학습 제안과 치수 재검산을 결합했다. 새 데이터를 받았다는 이유로 강화학습 자체의 우위나 모든 종합 결론의 정확도가 검증됐다고 주장하지 않는다. 미확정과 부분 검사를 0이나 정상으로 바꾸지 않는다.
