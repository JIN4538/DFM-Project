# 코드 구조와 근거 연결

기준은 v2.6 ZIP 내부 `dfm2/`이다. 파일·함수의 위치는 `CODE_INDEX.json`에서 찾고, 수정 전에는 실제 파일을 다시 읽는다. 아래는 현재 구현의 해석이며 물리적 타당성을 자동 보증하지 않는다.

## 실행 흐름

`run_app.py → src/ui/app.py → model_loader.load_model → AMRuleEngine.evaluate`

평가는 먼저 `_evaluate_geometry`로 입력/3D 규칙을 평가한 뒤, FDM이면 독립적인 `inspect_layers`를 실행한다. 3D 게이트 실패가 확정 가능한 단면을 없애지 않으며, 단면 실패가 기존3D 결과를 없애지 않는다. 설정 자체가 잘못된 경우에는 예외가 반환될 수 있으므로 호출자가 정상 결과와 구분해야 한다.

| 모듈 | 책임과 중요한 계약 |
|---|---|
| `model_loader.py` | 명시적 단위→mm, STL 로드·진단, 샘플 불리언 생성. 다중 껍질의 내부 공동 부호 보존 |
| `mesh_diagnostics.py` | 좌표·인덱스·연결·중복·퇴화 진단, 면 위치, 해시, 보수적 정리 후보 |
| `geometry_analyzer.py` | 빌드 좌표, 오버행, 표본 레이 두께/간격/지지 높이, 배치, 공동, 복셀 특징, cusp, 두께 변화 |
| `processes/additive.py` | 프로필·근거·게이트·규칙 점수·N/A 가중치·상태·설명 조합 |
| `sections.py` | 방향 있는 삼각형-평면 교차에서 단면 재료·진단 생성 |
| `section_index.py` | 면 높이 후보와 winding ray의 공간 후보 조회·작업 예산 |
| `section_components.py` | 단순 윤곽의 빠른 경로와 손상에서 분리된 성분 추출 |
| `layer_regions.py` | 의미 있는 잔여, 우선/작은 세부, 성분 전체 영향, 인접 미확정 범위 제외 |
| `layer_review.py` | 전체 요청 층 순회,3개 지표,부분 범위와 총계 |
| `scoring.py` | 6방향,동점·규칙집합 비교·파레토,형상1회 기반 가중치 민감도 |
| `weights.py` | AHP·전문가 집계·로지스틱 회귀 중요도. 경험 가중치의 실제 제조 타당성은 별도 |
| `cura_records.py` | 읽기 전용 CSV·단위·조건·해시 검증,저장/현재 결과 분리 |
| `validation_metrics.py` | 중심화 R²·오차·동점 상관·계수 적합·부품별 교차검증 |
| `reproducibility.py` | 실행 버전·의존성·코드 해시·표준 JSON·새 파일만 저장 |
| `ui/app.py` | 평가한 메시와 설정의 일치,위치표시,부분결과,단면캐시,결과내보내기 |
| `cura_check.py` | 새 실험 STL/CSV 게시,과거/현재 분석,입력 진단 CLI |
| `audit_models.py` | 외부 원본/정리 후보의 독립 평가와 입력 해시 보존 확인 |

## 3D 결과 상태

| 상태 | 의미 |
|---|---|
| `eligible` | 구현한 입력/프로필 조건에서 점수 계산 대상. 실제 출력 성공을 의미하지 않음 |
| `blocked` | 프로필 제약 미충족 근거. 공정 전체의 물리적 불가능을 증명하지 않음 |
| `invalid_input` | 현재3D 분석을 지지할 입력 조건 부족. 가능한 외곽/단면 결과는 별도로 제공 |
| `indeterminate` | 핵심 측정 실패 또는 근거 불충분. 종합 점수와 자동 최고점 추천 보류 |

`feasible=False`를 언제나 ‘인쇄 불가능’으로 번역하지 않는다. 게이트에도 pass/fail/unknown이 있다. 하위 규칙 N/A는100점이 아니며 가중치를 활성 규칙에 비례 재분배한다. 기본 FDM은10규칙 중7개 활성이다. 검사 범위가 다른 방향들의 총점을 비교하지 않는다.

## 층 단면의 의미와 수치 정책

삼각형 모서리의 정점 순서를 통일해 교차점을 계산한다. 반개구간 교차와 방향 있는 선분,non-zero winding으로 겹친 재료를 합치고 반대 내부껍질 공동을 유지한다. 방향이 잘못된 쉘의 의도를 항상 복원할 수는 없다.

격자는 모델 크기에 따라1e-10~1e-6mm,단순화는2grid 이내다. 평면 계산의 수치 정책이며 제조 허용오차가 아니다. 미확정 경계와 경계상자가 겹치는 닫힌 성분은 연쇄적으로 제외한다. 고립된 정상 성분만 부분 검사하며, 미확정 이웃의 영향 범위도 현재 성분에서 제외한다.

- 선폭 위험: 반선폭 안쪽 오프셋 후 바깥 복원의 잔여. 곡률/모서리도 검출되며3D두께와 다르다.
- 지지/브리지 검토: 현재 단면에서 이전층을 `Δz/tan(α)`만큼 확장한 영역을 뺀 값. 실제 서포트 필수 판정이나 지지 부피가 아니다.
- 한 층 영역: 현재에서 위/아래 이웃의 합을 뺀 값. 중간 평면 사이에 놓인 특징은 미검출 가능하다.
- `0.01×선폭²`는 표시 하한. 전체 성분 영향이면 작은 값도 우선 검토. candidate=major+minor를 유지한다.
- 개별 세부는 면적순50개까지,전체 수와 면적 합은 모든 후보를 포함한다.
- 완전한 층들의 `area×실제층두께` 합만 전체 근사 부피로 제공한다. 부분 결과에는 전체 분모가 없다.

기본 예산: 최대2000층,누적교차선분2,000,000,개별단면선분60,000,winding 후보8,000,000. STRtree가 최악의 복잡도를 제거하는 것은 아니다. 단면 방법 버전 `fdm_layer_review_v3`.

단면 상태 `complete/partial/unavailable`와 각 검사 `risk/details_only/clear_in_layers/unresolved`를 함께 읽는다. `clear_in_layers`는 검사된 층에서 미검출이라는 뜻이다. 단면 결과의 `total_score`는None이다.

## 재현성과 UI

UI는 평가한 메시 사본,원본 파일 해시,분석 메시 해시,단위,공정,장비,방향,옵션,전처리 모드와 버전을 보존한다. 변경하면 과거 결과 동작을 멈추고 재평가하도록 한다. UI의 ‘원본’은 파일 바이트 그대로가 아니라 `trimesh.load`의 기본 처리와 로더의 법선 일관성 처리 뒤 메시다. 원본 파일은 별도 SHA로 식별한다.

단면 캐시는 메시·방향·실제Z·앱버전을 키로 쓴다. 자원4개/데이터64개,TTL900초. 향후 같은 APP_VERSION으로 계산 의미를 바꾸면 오래된 캐시/결과와 섞일 수 있으므로 버전을 함께 갱신한다.

6방향 비교는 활성 규칙 집합을 확인하지만 일반 API에 들어온 모든 프로필·가중치의 동일성을 증명하는 범용 비교기는 아니다. 양수 가중치에 무관한 우세는 모든 활성 규칙에서 지배/동점 조건이 있을 때만 성립한다. AHP UI는5항목 내부 설문이며 평가에 자동 적용하지 않는다. CR<.1은 응답 일관성이고 실제 제조 타당성은 아니다.

Cura 환산은 `(ON-OFF)m×1000×π(d/2)²` mm³. 저장 예측 오차와 재적합·현재 재계산을 구분한다. 부품 단위 교차검증도 고정2항식을 사용하며 모델 선택 자체가 독립된 외부 시험은 아니다. JSON null은0과 다르며 미측정/적용불가/정의불가 이유와 함께 읽는다.

## 후속 코드 점검 후보

아래는 이번 정적 검토에서 찾은 검토 후보다. 별도 반례와 요구사항 없이 곧바로 결함 확정·수정하지 않는다.

- `mutation_test.py`는 과거 코드 문자열에 의존한다. 예를 들어 `if n_below >= 2:`와 이전 메시 게이트 문자열은 현행 구현과 달라 변이를 적용하지 못할 수 있다. 과거9/10을 현행 버전 검증값으로 재사용하지 않는다.
- `verify.py`는 일부 항목에서 점수None을 방어하지 않는다. 자원 부족/판정 보류가 시험의 비교 예외가 되며 실제 게이트 이유를 잃을 수 있다.
- near-hit 제거 정책·부분 표본·면 순서·grid 위상·임계 높이에서 작은 실제 특징을 놓칠 가능성을 독립 형상으로 확인한다.
- cusp/층높이 비율 점수는 층높이 변화 효과를 상쇄한다. 물리 단위의 표면 허용오차가 정해지기 전 임의의 새 점수를 만들지 않는다.
- 로지스틱 중요도 함수의 표본수 경고는 사건수 기반EPV 검증과 다르고,수렴/분리 진단도 제한적이다. 출력된 절댓값 가중치를 제조 근거로 바로 채택하지 않는다.
- 일부 주석·검증 기대문구의 ‘정확’,‘인쇄 불가’,‘모두 자기 일관성’ 설명은 현재 코드의 보수적 의미보다 강하다. 수정할 때 근거와 제품 표현을 함께 정리한다.
