## 적용할 때의 공통 원칙

- 규칙의 필요성, 수식의 정의, 실험 조건별 임계값, 개발자의 점수·가중치·표시 정책을 별개로 관리한다.
- 노즐 지름, 압출 선폭, 층 높이, 벽 두께, 구멍 지름, 반지름, 간격, 브리지 길이는 서로 다른 물리량이다.
- 수평면 기준 경사각, 수직축 기준 경사각, 면 법선과 빌드 방향의 각도를 명시한다. 각도 45°만으로는 정의를 특정할 수 없다.
- 기하학적 계산 완료 ≠ 슬라이서 경로의 출력 가능성 ≠ 실제 출력 성공 ≠ 구조 강도/제품 인증.
- 논문의 한 장비·재료·속도·냉각·허용오차에서 구한 값은 다른 조건의 보편 한계가 아니다.
- 소프트웨어 근사량(레이 두께, 투영 면적, cusp, convexity, morphological opening)을 실제 최소 두께·Ra·서포트 질량·강도라고 부르지 않는다.

## R01 — Kerbrat, Mognol, Hascoët (2011)

**A new DFM approach to combine machining and additive manufacturing**, Computers in Industry 62, 684–692. DOI: 10.1016/j.compind.2011.04.003. 9쪽, 본문 전체 읽음.

목표는 단일 공정을 고집하지 않고 제품을 모듈로 나눠 절삭과 AM을 조합하는 설계 검토다. 표면을 적응형 octree 경계 셀로 표현하여 전역·국소 제조 난이도를 계산한다. 값은 0~1이며 **높을수록 어려움**이다. 현재 프로젝트의 높은 점수=좋음 체계와 방향이 다르다.

- p3 Table 1: 절삭 전역 지표는 치수·제거량·재료 경도·거칠기, 국소 지표는 공구 유연성. AM 전역은 최대 치수·체적·표피 면적, 국소는 높이·플랫폼 중심으로부터 거리.
- p5 Eq.1: 국소 평균은 셀 체적으로 가중한 평균. p6 Eq.2: 모듈별 지표의 가중 합. Eq.3: 모듈 체적/전체 모듈 체적을 가중치로 사용. 국소 최대값은 평균과 별도로 유지한다.
- 절차: 원 CAD 평가 → 공정·분할 대안 선정 → 모듈 CAD 생성 → 재평가 → 비교. SolidWorks VBA/Excel 기반 사례.
- 금형 코어 사례에서 칩 제거 지표 약 60%, 국소 유연성 최대 약 45%, 평균 약 53% 감소. 이는 지표의 변화이며 실제 원가·시간 감소의 실증값은 아니다.
- 630×182×100 mm 금형 사례는 절삭 기반 위에 AM을 결합한다.
- p8: 서로 다른 공정의 지표는 동일 척도가 아니므로 그대로 총합할 수 없다. 조립비·연결부·전체 제품 사양은 충분히 정량화되지 않았다.

프로젝트 연결: 장기 하이브리드 제조성 검토와 국소 위험 위치의 근거. 지금 구현한 FDM 단일 부품 평가가 이 논문의 전체 분해 최적화라는 설명은 금지.

## R02 — Ko et al. (2025), D-ECOmposer

**D-ECOmposer: Sustainable part decomposition for additive manufacturing using machine learning based life cycle assessment**, Additive Manufacturing 103, 104759. DOI: 10.1016/j.addma.2025.104759. 19쪽, 본문·표·참고문헌 읽음.

빌드 공간보다 큰 모델을 grid로 분할하고, 재사용할 공통 모듈과 새로 생산할 맞춤 모듈을 구분한다. 모델의 grid 내 평행이동·회전을 GA로 최적화한다. 원래 한 번에 제작 가능한 부품에서의 이득을 일반 보장하지 않는다.

### 데이터와 LCA

- pp5–7: Baumann/Thingiverse 약 3만 STL에서 10 MB 초과·길고 얇은 형상 등을 제거하고 **14,000개** 사용. 최대 치수 정규화 후 30–90 mm로 스케일. 필터링은 산업·위상최적화 형상 일반화의 한계다.
- Blender: X/Y/Z 치수, 모델 체적, 45° 기준 지지 체적. Tweaker 방향 선정. PrusaSlicer G-code: 재료량·제작 시간. openLCA: 탄소발자국 라벨.
- Table 1 p7: FDM/ABS, infill 100%, 평균 속도 50 mm/s, 장비 전력 0.5 kW. 층 높이는 고정했다고 설명하지만 이 표에 수치가 없다. 임의 보충 금지.
- Cradle-to-Gate: 원재료 생산 → 필라멘트 생산 → AM 제조. Ecoinvent 3.8, TRACI 2.1의 GWP/CO2e. 조립·후처리·사용·폐기 및 반복 재사용 효과는 범위 밖.
- 전력은 제작 시간×고정 장비 전력으로 추정한다. 실제 시간대별 소비전력 계측이 아니다.

### 예측·최적화

- 5개 기하 입력, 2개 은닉층, ReLU, 1개 출력의 ANN. AutoKeras, Adam, RMSE; Python 3.11.3/TensorFlow 2.13.0/Keras 2.13.1.
- 학습/시험 8:2; 학습 집합의 20%를 검증에 사용했다고 기술. 유사 모델 가족 단위 분리 여부는 제시되지 않는다.
- p8 Table 2: 5-fold 평균 R² ANN 0.9266±0.0235, 선형회귀 **0.9321±0.0169**, RF 0.9035, XGBoost 0.7883, GBM 0.7974, LightGBM 0.8113, SVR 0.9070. ANN이 모든 비교모델보다 우수하다는 결론은 표와 다르다.
- p8의 “R²는 0~1” 설명은 일반적으로 맞지 않는다. 나쁜 예측에서는 음수 가능. p9의 1,000회 Monte Carlo 입력 민감도와 실제 예측오차를 구분한다(일부 시험점 오차 20–40% 이상도 언급).
- F1=공통 모듈 수 최대화; F2=맞춤 모듈 지지 체적 최소화; F3=맞춤 모듈 예측 탄소발자국 합 최소화. F3는 공통 모듈의 새 제조 부담을 제외하는 재사용 가정이다.
- GA: population 30, crossover 0.7, mutation 0.02, 최대 100세대, 20연속 세대 변화가 tolerance 이하면 종료. Trimesh/DEAP/PyVista 활용.
- Armadillo/Bunny/Dolphin/Moai, grid 10/15/20/25/30. 작은 모듈은 공통 모듈 체적의 10% 미만.
- pp12–13 Table 4: F3가 대체로 탄소발자국 감소에 유리하나 Armadillo grid 10에서 F1=140, F3=141로 예외가 있다. 같은 p13의 “all cases” 서술을 그대로 인용하지 않는다.
- Table 6: Dolphin 세대당 시간 grid10 2411.73 s → grid30 159.12 s. 크기만이 아니라 형상·분할 수 영향. p13은 Dolphin 246,329 mm³를 Armadillo 227,873 mm³보다 작다고 써 수치와 서술이 모순된다.
- Table 7: 20% infill은 100% 대비 시간·재료·탄소 감소 사례. 구조 성능 동등성은 검증하지 않았다. 표의 carbon footprint 단위(g)와 앞 표·LCA 단위 연결은 재검증 대상이다.
- 조립 연결은 나사/일체 체결/접착/에너지 접합을 논의하나 접합 성능·조립 LCA 최적화를 완료한 것은 아니다. 여러 장비는 경과 시간을 줄여도 총 에너지 감소를 보장하지 않는다.

프로젝트 연결: AI 보정 전에 고정된 공정 조건, 라벨 정의, 독립 시험 집합이 필요하다. 지지량을 줄였다는 이유만으로 친환경 점수를 높일 수 없다. 현재 프로젝트는 LCA/ANN/GA 분해 미구현.

## R03 — Medellín-Castillo & Zaragoza-Siqueiros (2019)

**Design and Manufacturing Strategies for Fused Deposition Modelling in Additive Manufacturing: A Review**, Chinese Journal of Mechanical Engineering 32:53. DOI: 10.1186/s10033-019-0368-0. 16쪽.
