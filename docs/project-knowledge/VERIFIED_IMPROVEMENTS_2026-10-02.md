# 형상 선택 통합·실제 CAD 수정 학습·공정한 비교

이번 제품 변경은 **입력을 세 가지로 합치고, 결론에서 실제 STEP 수정과 치수 재검토까지 연결**한 것이다. 아래 실험은 새 합성 CAD에 대한 초기 연구 결과이며, 전체 부품에서 AI가 더 우수하다는 선언이 아니다.

## 사용자가 달라졌다고 느낄 부분

- 입력: **적층 시연용 형상 / 절삭 시연용 형상 / 업로드**. 기준 CAD·공개 STEP·시험 부품은 목적별 하나의 검색 가능한 목록에 합쳤다.
- 시연 형상은 적층 57개, 절삭 56개 선택지다. 두 목록에 같은 부품이 포함될 수 있으므로 113개 독립 부품이라는 뜻은 아니다.
- 영문 부품 제목을 한글로 표시하고 다운로드 이름도 한글로 제공한다. 출처와 SHA를 추적할 원본 파일명·바이트는 보존한다.
- 절삭: **추천 수정 적용·재검토** 한 번으로 지원하는 홈 코너를 실제 STEP으로 수정한다. 바뀐 파일을 다시 읽어 코너 반경·깊이·부피·보호 조건을 검사하고, 같은 확대 범위에서 전후 형상을 표시한다.
- 기존 인식 모델이 놓친 닫힌 삼각·사각·육각 홈은 면 연결 관계로 검산해 보완한다. 이미 검산된 홈을 동시에 ‘치수 미확정’으로 표시하던 중복도 정리한다. 원래 신경망 출력과 기본 인식 결과는 원자료에 남긴다.

## 1. 독립 정답과 보호 조건

새 CAD는 삼각형·사각형·육각형 홈, 외부 구멍 0–3개, 종횡비 1/1.4/1.8/2.6, 각 형상군 5개 회전·크기 변형으로 구성한다. 늘어난 사각형은 마름모일 수 있으며, 직사각형만으로 간주하지 않는다. 학습은 종횡비 1/1.4, 검증은 1.8, 시험은 2.6을 사용한다.

수정 허용 항목은 **홈 안쪽 코너 반경** 하나다. 외곽 크기, 홈 깊이, 구멍 개수·지름·깊이를 보호한다. 원본의 홈 면적은 생성 다각형의 shoelace 식, 체적은 외곽 체적−홈 체적−구멍 체적으로 계산한다. 둥근 코너의 증가 체적은 각 코너 내각 θ에 대해 `Σ[cot(θ/2)−(π−θ)/2] × R² × 깊이`로 별도 계산한다.

수정 파일을 다시 읽고 홈 바닥 면적, 실제 원통 코너 반경, 축 방향 벽 높이, 기존 원통면의 반경·면적·중심, 외곽 AABB를 검사한다. 보호 조건은 이 명시된 기하 범위이며 임의 부품의 기능을 자동 추정한 것이 아니다. 반경 상·하한은 연구용으로 고정한 후보 조건이며 표준의 보편적 설계 한계가 아니다.

실제 수정에는 [OCCT 필렛 API](https://occt3d.com/dev/doc/refman/html/class_b_rep_fillet_a_p_i___make_fillet.html)를 사용한다. API 호출 성공만으로 검산을 대신하지 않고, 저장한 STEP의 재측정 결과를 별도로 확인한다.

## 2. 무엇을 새로 학습했는가

`cad_edit_surrogate_v1.json`은 은닉층 32/16의 MLP 두 개다. 입력은 변 개수, 크기로 정규화한 깊이·반경·면적·둘레, 내각·변 길이 요약 등 11개다. 하나는 수정 절차의 유효/거절, 하나는 수정 STEP에서 측정한 정규화 재료 증가량을 예측한다.

가중치 학습은 **600개 요청(120 CAD × 5)**이다. 유효성 모델은 유효·거절 모두, 부피 모델은 유효한 480개만 사용한다. 검증 300개 요청으로 세 seed 중 73을 선택했고, 시험 300개 요청은 가중치·seed 선택에 사용하지 않았다. 수정 전 STEP을 반복 보관한 파일 수를 추가 독립 CAD 수나 추가 학습 사례 수로 세지 않는다.

시험의 수정 유효/거절 분류 정확도는 **94%**, 잘못 유효하다고 한 요청 0개, 유효한데 거절 예측한 요청 18개다. 재료 증가량의 `log1p(증가량/원본 홈 체적)` MAE는 **0.19257**이다. 전문가가 선호하는 설계를 배운 모델은 아니다. 거절 라벨 240개는 CAD 연산 전 진입원 조건에 걸린 요청으로, 모두 OCCT의 수치 연산 실패라고 부르지 않는다.

최종 추천 순위에는 새 모델을 적용하지 않았다. 수정 검산 상세의 선택적 예측 기록과 연구용 후보 순서 비교에만 남긴다. 모델·원본 manifest·라벨 SHA, seed 선택 과정, 최초 실행 실패를 보존한다. 현재 런타임 검사 보완 이후의 소스와 학습 당시의 소스 SHA가 다른 점도 남긴다.

## 3. 절삭 실제 경로와 동등 예산 결과

처음 실제 앱 경로로 60개 보류 CAD를 검사했을 때, 구멍 치수는 60개 모두 맞았지만 홈 인식·치수는 **20/60**이었다. 늘어난 사각·육각 홈의 신경망 후보가 다른 특징으로 분류된 것이 원인이었다.

닫힌 단일 바닥, 안쪽 수직 벽, 같은 높이의 열린 바깥 테두리, 직선 경계와 볼록성을 확인하는 기하 보완 후, 같은 진단 CAD에서 **홈·구멍 치수 60/60, 수정·재검토 60/60**을 얻었다. 이 시험을 보고 보완했으므로 수정 후 60/60은 새로운 손대지 않은 시험 정확도가 아니다. 신경망 자체의 검출률 향상으로도 보고하지 않는다. 보스·밀폐 공동·열린 채널·섬·둥근 바닥·복수 솔리드 반례를 별도 회귀검사에 포함한다.

후보 반경·보호 조건을 고정하고 비싼 CAD 질의 수를 맞춘 비교는 다음과 같다. ‘최소 변경’은 고정 후보 중 유효하고 추가 재료량이 가장 작은 선택을 뜻한다.

| 방법 | CAD 질의 예산 | 유효 선택 | 최소 변경 선택 |
|---|---:|---:|---:|
| 규칙·작은 반경 우선 | 1 | 60/60 | 60/60 |
| 새 MLP 순서+CAD 검산 | 1 | 60/60 | 43/60 |
| 규칙·작은 반경 우선 | 2 또는 3 | 60/60 | 60/60 |
| 새 MLP 순서+CAD 검산 | 2 또는 3 | 60/60 | 60/60 |
| MLP 선택만 | 0 | 60/60 | 43/60 |

한 번 질의에서는 **17개가 더 큰 변경**이므로 새 순위를 최종 추천에 채택하지 않는다. 2/3 예산에서 조건을 만족하는 후보가 하나뿐인 경우는 추가 질의를 쓰지 않아 각 방법 총 90회다. 보고한 시간은 기록된 실제 연산 시간과 추론 시간의 캐시 재생 합이며 전체 앱 처리시간이나 속도 우위가 아니다. 최소 재료량은 이 연구의 목적함수이며 전문가 최적 설계와 동일하지 않다.

## 4. 적층도 같은 비용으로 비교

새 CAD 중 validation/test 120개, 24개 형상군을 기존 적층 모델의 추가 재학습 없이 검사했다. 제품에서 사용하는 **v4 모델 SHA `68ec8e…ccd64`**를 명시했다. 각 방법 모두 초기 26방향 측정 비용을 포함하고, 추가 6/12/24회로 총 32/38/50회다. 고정 256개 Fibonacci 방향과 주요 면 방향을 공유하며, 높이·하향 투영면적·접촉면적을 같은 초기 비교 기준으로 평가한다.

규칙/균등, 무작위, 저비용 기하 후보, 신경망 후보+재측정, 기하·신경망 결합, Gaussian Process의 expected improvement 탐색을 비교했다. [Goguelin 등(2021)](https://researchportal.bath.ac.uk/en/publications/bayesian-optimisation-of-part-orientation-in-additive-manufacturi/)은 방향 최적화의 BO 비교 근거이며, 이번 구현이 논문의 지지대 길이 목적함수·실험을 완전히 재현했다는 뜻은 아니다.

이번 단순 프리즘 계열에서는 기하 후보가 120개 모두 고정 이산 기준의 최솟값을 얻었고, **v4 신경망·결합도 120개 모두 같은 결과**다. 모든 예산에서 AI의 추가 우위는 없었다. 고정 기준은 연속 공간의 전역 최적해가 아니다. GP hyperparameter를 별도 최적화하지 않은 초기 비교이며 곡면·유기 형상으로 일반화하지 않는다.

최초 실행의 잘못된 import, v2 구성요소를 사용한 선행 비교(9/120 악화), 이를 바로잡은 v4 결과를 모두 보존했다. 최종 제품의 기존 24회 추가 측정과 최대 6회 보완 정책·가중치는 이번 보류 결과로 교체하지 않았다.

## 보관·재현·다음 연구

자료는 `validation/verified-improvements-2026-10-02/`에 있다. `cad/manifest.json`, `labels.json`, `pairs/`, `cnc-comparison.json`, `runtime-02/03`, `am-equal-budget-v4-03/`, `logs/`, `browser/`를 구분한다. 이전 실패 로그를 통과 로그로 덮어쓰지 않는다. 전체 원본·요청·전후 STEP·SHA를 함께 보관한다.

새 빈 폴더를 사용해 다음 순서로 재현한다. 기존 보관본에 실행 출력을 덮어쓰지 않는다. 의존성은 현재 저장소 실행환경을 따른다.

```powershell
python scripts/run_verified_edit_study.py generate <new-cad-folder>
python scripts/run_verified_edit_study.py labels <new-cad-folder> --workers 2
python scripts/run_verified_edit_study.py train <new-cad-folder> --model <new-model.json>
python scripts/run_verified_edit_study.py compare <new-cad-folder> --model <new-model.json>
python scripts/audit_independent_edit_runtime.py <new-cad-folder> <new-runtime-folder>
python scripts/run_equal_budget_am_study.py <new-cad-folder> <new-am-folder>
python scripts/run_user_flow_audit.py <new-user-flow-folder>
```

학습 전 분할의 대용량 원본은 바이트 그대로 공개하고, 새 재현 STEP의 export 타임스탬프가 기존 SHA와 같다고 기대하지 않는다. 기존 SHA는 보관본 무결성 검사에 사용한다. 형상 수식·분할·치수 조건은 새 재현 결과에도 별도로 확인한다.

전문가 비교용 `expert_pairs.csv`는 두 허용 후보가 있는 시험 CAD 30개다. 선호·이유·평가자는 **공란**, 전문가 라벨 0개다. [평가 절차](../research/VERIFIED_EDIT_EVALUATION_PROTOCOL.md)에 독립 평가자와 첫 사용자 과제를 정리했다. 앞으로는 복잡한 곡면·교차 특징의 새 CAD와 전문가 선호를 확보하고, 이번 개선에 사용하지 않은 시험군으로 일반화·추천 가치를 평가해야 한다.

최종 회귀검사는 **1,672개 통과**, 바탕화면 설치본의 관련 검사는 **31개 통과**다. 실제 배포 파일의 해시를 대조했고, 세 가지 자동 사용 과제는 수치 직접 입력 없이 완료했다. 전체 상태는 같은 보관 폴더의 `completion.json`을 따른다. 개발 중 코드 변경을 병행한 최초 전체 검사에서 상세 결과 누락 1건과 새 형상 다운로드 버튼을 결과 다운로드로 간주한 옛 테스트 2건이 실패했다. 최초 기록을 보존하고 입력 변경 후 오래된 결과 다운로드가 없어야 한다는 계약은 유지해 테스트를 수정했다. 코드를 고정한 후 전체 검사를 다시 통과했다.
