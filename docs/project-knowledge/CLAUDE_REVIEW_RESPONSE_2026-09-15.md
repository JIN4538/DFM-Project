# 외부 검토를 대조한 개선과 검증

사용자가 제공한 [Claude 검토보고 원본](../../validation/v3/claude-review-20260915/input_report.md)을 `ae2a868`의 구현·문헌·독립 반례와 대조했다. [항목별 타당성 판단](CLAUDE_REVIEW_VALIDITY_2026-09-15.md)에 채택 여부를 기록했다. 긍정적 평가도 구현 정확도나 독창성의 보증으로 사용하지 않았다.

## 반영한 변화

- **단면 자동 모드:** 기본으로 형상 변화 단면을 시도한다. 사전 표본·교차 선분 예산 거부(`event_budget_exceeded`)인 경우에만 균등 표본으로 이어간다. 원래 시도와 거부 사유, 요청 방법과 실제 방법을 별도 저장한다. 균등 결과가 완료돼도 전체 사건 적분 완료로 표시하지 않는다. 위상·실제 단면 실패·시간 초과를 자동으로 우회하지 않는다. 기존 API 기본 `uniform` 및 명시적 `events`의 계약은 유지했다.
- **부분 체적:** 계산된 구간의 부피 합과 빠진 높이 구간의 부피 기여 상한을 화면과 HTML에서 함께 제공한다. 수치 표현 한계만 있는 경우와 실제 단면 실패를 구조화된 원인으로 구분한다. 기존 `partial`, 전체 체적 `None`은 유지한다. 누락 기여 상한은 원래 float 좌표의 정확한 유리수 산술로 구해 위쪽 반올림하지만 계산된 단면의 수치 오차까지 한정하지는 않는다.
- **체적 차이의 해석:** 사건 적분과 메시 체적의 차이가 있으면 수치·단면 재구성·재료 경계를 확인하도록 안내한다. 균등 방법의 차이는 얇은 구간 누락 가능성을 먼저 설명한다. 차이만으로 자기교차를 확정하는 임의 문턱은 추가하지 않았다.
- **바닥·각도 경계:** 기존 접촉 면적과 하향면 후보의 수치는 유지한다. 점·선으로 닿는 기울어진 면, 기준 각도 부근의 수치 경계면을 별도로 알린다. 경계면 안내가 전체 요약에서 사라지지 않게 했다. 투영면적 합에는 중복 포함을 라벨에 표시했다. [정의와 독립 반례](../ORIENTATION_METRIC_CONTRACT.md).
- **벽 자동 확인:** 선택할 수 있는 초기 실행 옵션으로 삼각형 10,000개 이하 단일 형상의 벽 표본을 함께 확인한다. 작업자 계산 한도는 5초이며 입력 준비·캐시·정리 시간을 포함한 UI 전체 응답 시간 보증은 아니다. 시간 부족 시 수동 검토의 60초 한도로 다시 실행할 수 있다. 캐시는 형상·전체 프로필·방향·코드 식별자를 구분한다. 임계 삼각형 수는 실행 비용 정책이며 제조 기준이 아니다.
- **시작과 근거:** 무작위 형상 입력 이름을 `검증용 예제`로 바꿨다. 고정 Cura 예제는 별도 연습 선택으로 분리했고 내보낸 JSON에도 출처·파일명·현재 모델과의 관계를 남긴다. 시편의 조건·반복·측정법·불확도·허용기준을 기록하는 [CSV 양식](../templates/calibration_measurements.csv)을 제공한다. 자체 CAD 예제를 ISO/ASTM 52902 표준 시험물이라고 부르지 않는다.
- **미실행과 실패:** 기존 벽·층 요약의 미실행/실패 구분을 유지하고 전체 표도 같은 설명을 사용한다. 자동 실행 전에 종료된 결과에 균등 계산 방법을 임의로 붙이지 않도록 고쳤다.

## 실제 CAD 19개 대조

STEP 21개 중 표면 전용 2개를 제외하고, 각 파일의 CAD 체적이 가장 큰 솔리드를 +Z로 배치했다. 이전 전수 감사의 원본 SHA가 기록된 메시 캐시를 재사용했다. 새 STEP 변환 시험으로 설명하지 않는다. 작업자별 90초, 사건 표본 8,192개·선분 150만 개·균등 64개 조건이다.

| 상태 | 개수 | 개선 후 제공 내용 |
|---|---:|---|
| 사건 전체 구간 계산 완료 | 5 | 사건 적분과 단면 비교 |
| 수치 표현 한계만 있는 부분 계산 | 5 | 계산한 부피·누락 기여 상한·단면 비교 |
| 실제 단면 실패가 포함된 부분 계산 | 1 | 계산한 범위와 실패 사유; 전체 완료로 승격하지 않음 |
| 사건 사전 예산 초과 | 7 | 원래 거부 기록과 균등 64개 계산 결과 |
| 위상 조건 미충족 | 1 | 미확정 사유 |

외부 보고서의 5/6/7/1 분포는 재현됐다. 자동 계산의 7개 균등 완료를 사건 체적 정확도 개선으로 합산하지 않는다. [원본별 실제 결과·코드 SHA](../../validation/v3/claude-review-20260915/event-corpus/summary.json), [재현·캐시 범위](../../validation/v3/claude-review-20260915/event-corpus/README.md).

**보고서 패치의 `known + envelope = 전체 체적 상한`은 성립하지 않는다.** Raspberry Pi 부분합의 독립 사면체 적분 대비 상대차는 약 4.35×10⁻¹⁰이지만 누락 기여/부분합은 약 8.82×10⁻¹⁵다. 누락 높이만의 한계는 계산된 구간의 단면 오차를 포함하지 않는다. 이 때문에 임의의 1e-9 문턱으로 `complete`로 바꾸거나 전체 오차 상한으로 이름 붙이는 패치는 채택하지 않았다.

겹치는 두 상자에서는 내부 사건 함수의 `complete` 결과가 독립 합집합 기준과 약 −0.1934% 달랐다. 실제 사용자 STL 경로는 이미 이 다중 셸을 미확정으로 차단한다. 내부 함수의 한 성공 사례를 일반 합집합 정확성으로 확대하면 안 되는 [반례와 사용자 경로 검사](../../validation/v3/claude-review-20260915/overlap_counterexample.json)다.

## 검증 기록의 구분

이벤트 계산 36개 검사는 Python 3.12·3.13에서 각각 통과했고, 방향·CAD 관련 94개 검사도 통과했다. 개발 중 새 HTML 테스트의 입력 메타데이터 누락과 UI 테스트의 모호한 버튼 선택이 발견돼 실제 파일 로더·명시한 실행 버튼을 사용하도록 고쳤다. 방향 반례의 선택 의존성 문제도 독립 사각형 공식으로 바꿔 검증했다. 실패한 실행을 성공한 실행으로 덮어 쓰지 않았다.

최종 Windows Python 3.12.14·3.13.15에서 각각 전체 658개 검사와 기본 수치 검증 55개가 통과했다. 두 환경의 의존성 검사도 통과했다. 기존 겹침 반례에서 trimesh의 0 체적 경고 1건은 남아 있으며 해당 검사는 통과했다. 전체 검사·기본 수치 검증·배포 범위는 [통합 검증 기록](../../validation/v3/claude-review-20260915/integration.json)에 남긴다. 19개 감사는 그 실행 시점의 코드 SHA를 보존하며 이후 표시 문구 수정과 구분한다. 이번에는 실물 출력이나 장비별 기준 보정을 수행하지 않았다.
