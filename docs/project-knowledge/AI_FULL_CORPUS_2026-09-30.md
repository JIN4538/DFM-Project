# 공개 데이터 전수 학습·위치·수정 전후 검증

사용자 지시: 데이터 일부만 사용하던 제한을 해소하고 적층·절삭의 특징 인식, 문제 위치, 치수, 종합 개선안을 강화한다. 지원 범위는 적층·절삭이다. 이 문서는 이전 `AI_EXPANSION_2026-09-30.md`의 후속 기록이다.

## 데이터 수

| 구분 | 적격 원본 기록 | 가중치 학습 | 검증 | 보류 시험 |
|---|---:|---:|---:|---:|
| 적층 | 42,295 | 29,943 | 6,097 | 6,255 |
| 절삭 | 77,883 | 54,570 | 11,763 | 11,550 |
| 합계 | 120,178 | 84,513 | 17,860 | 17,805 |

적층은 PBF 형상 40,000, CadQuarry 920, Thingi10K 1,375이다. 절삭은 MFInstSeg 62,395와 MFCAD 15,488이다. 원본 128,981개 중 제외 8,803개를 기록했다. MFCAD++와 CADSynth는 여전히 확보 0이며 숫자에 포함하지 않는다. 동일 형상의 방향 표본, 수정 조건, 강화학습 반복 횟수를 원본 수에 더하지 않는다. 출처별 기록 수이며 모든 자료가 서로 다른 물리 설계라는 의미가 아니다.

원본·큰 SQLite·학습 배열·체크포인트는 `study/ai-full-corpus-2026-09-30/`에 별도 보존한다. 제품은 JSON 가중치로 추론하며 실행 때 PyTorch나 원본 DB가 필요하지 않다. 카탈로그는 `data/training/full-corpus-catalog.json`, 감사와 성능은 `validation/ai-full-corpus-2026-09-30/`이다.

## 검증하고 배운 내용

- 적층: 원본 메시의 높이와 하향면 투영면적을 48방향·5각도로 학습한다. 기존 가족별 500개·12,000면 제한을 해제했다. 최대 1,742,892삼각형도 원본 그대로 사용했다. 모든 적격 메시를 런타임 기하 엔진과 독립 대조했으며 최대 차이는 2.165e-15, 분할 간 형상군 중복은 0이다.
- 절삭: 저자의 CAD 면 라벨을 그대로 믿지 않고 모든 면의 유형·면적·중심·인접 관계를 대조했다. 원본 62,495개 중 소스 격리/누락 42, 면 대응 불일치 58을 제외했다. 25종 면 의미 외에 인접 면이 같은 특징에 속하는지, 바닥면인지를 공동 학습한다. 원본 CAD 면 번호를 보존해 위치로 연결한다.
- 치수: 라벨로 제안된 포켓을 OCCT 평면·모서리·꼭짓점과 별도 기하식으로 재측정한다. 삼각·직사각·육각의 볼록 프리즘 47,828개/33,418형상을 인증했다. 공구 진입원 지름은 단순 폭과 구분한다. 숫자를 신경망 예측값으로 대신하지 않는다.
- 개선안 순위: 학습 후보 493,573행, 보류 외부 비교 32,970조건이다. 목표값은 공개된 프로젝트 비교 정책이며 외부 전문가의 최적 수정 라벨은 아니다. 기존 v2 대비 평균 목표값 손실은 .00104588 → .0000715469이다. 고정 규칙 비교보다 좋아진 28,974조건, 나빠진 643조건을 모두 보존했다.
- 강화학습: Double DQN 32,070에피소드, 외부 학습 시나리오 23,470개를 모두 방문했다. 원시 제안은 기존 개선안보다 좋은 7/5,529, 나쁜 814/5,529로 단독 우위를 입증하지 못했다. 기존안과 수치 재검산 후 비교하는 보조 역할을 유지한다. 실제 배포 중재 120시험 형상군·1,440조건은 채택 0, 악화 0이다. 이 결과를 강화학습의 유효한 추가 개선 1,440건이라고 설명하지 않는다.

## 적층 성능과 선택

기하 예측 v4의 보류 시험 MAE는 높이에서 PBF .024692→.024149, CadQuarry .022398→.021863, Thingi .019473→.018740으로 감소했다. 하향면에서는 .029061→.027389, .029842→.027531, .026174→.023922로 감소했다. 정규화 기하량 오류이며 mm 오류나 종합 정확도 백분율로 바꾸지 않는다.

v4는 구면 후보와 국소 연속 각도 탐색을 추가하고 각 후보를 실제 메시로 재측정한다. 기본 방향 목록을 유지하며 기존 AI 추가 18후보에 최대 6개를 더해 AI 추가 방향을 최대 24개 비교한다. 105보류 형상군·5공정/목적 조건=525검토에서 최선 기하 후보는 개선 46/동일 479/악화 0이다. 같은 추가 계산 6회를 무작위 탐색에 준 비교는 개선 44/동일 463/악화 18, 평균 차이 +.000512로 AI가 항상 우월하지 않았다. 최종 순위 선택은 개선 31/동일 488/악화 6이다. 후보 보존을 최종 추천 무악화 보장이라고 설명하지 않는다.

새 절삭 순위 모델을 적층에도 적용한 검증에서 기존 적층 순위 모델보다 나빴다(.001368 대 .002026). 적층은 재학습한 기본 순위 모델을 유지한다. 같은 모델을 모든 역할에 무조건 적용하지 않는다.

## 위치와 실제 수정 형상

특징 위치 보기에서 면 번호만 전달되고 강조가 빠지던 경로를 수정했다. 선택 특징은 파란색, 기존 검토에서 조치가 필요한 면은 주황색으로 표시한다. 작은 특징은 주변 범위를 확대하며 계산 원본 메시와 보고서는 바꾸지 않는다. 선택 포켓은 바닥과 측벽을 함께 표시한다.

하나의 인증 포켓 코너 반경 수정은 선택적으로 실제 STEP을 생성한다. 수정 전 날카로운 코너는 빨간 선, 수정 후 새 원통면은 주황 면으로 같은 범위에서 비교한다. 단일 솔리드 유효성, 외곽 크기 유지, 코너 수, 재료 부피 변화를 독립 공식과 대조한다. 원본을 덮어쓰지 않는다. 복수 형상 수정이나 비프리즘 특징에는 이 자동 편집을 적용하지 않는다.

보류 외부 형상군의 삼각·직사각·육각 각 35개, 총 105개 편집에서 104개가 검산을 통과했다. 1개 직사각 포켓(`20221124_154714_16635`)은 부피 대조 불일치로 거부했고 실패 원본과 계산 기록을 보존했다. 이 104쌍은 독립 검증용이며 가중치 학습 수에 포함하지 않는다.

직접 생성한 3종의 수정 전후 STEP 6개는 `examples/learning_validation/corner_edits/`와 바탕화면 `DFM_개선전후_STEP`에 있다. 앱의 ‘절삭 검증 형상’에서 바로 선택할 수 있다. 저자 자료를 수정한 외부 STEP을 GitHub에 자동 재배포하지 않는다.

## 근거·실패 보존

MFInstSeg는 [AAGNet 공식 저장소](https://github.com/whjdark/AAGNet)의 의미·인스턴스·바닥 라벨을 사용한다. 저장소 MIT 코드와 저자 페이지의 데이터 CC0 선언을 구분한다. [FeatureFox 논문](https://arxiv.org/abs/2604.26770)의 면 경계/특징 분리 발상을 참고했으며 비공개 코드·산업 데이터 도입이나 논문 재현이라고 주장하지 않는다. 연속 방향 탐색은 [SciPy L-BFGS-B](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-lbfgsb.html), 순위 학습은 [HistGradientBoostingRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)를 사용한다.

전체 클래스에 같은 신뢰도 한계를 적용해서는 특징 정밀도 97% 검증 조건을 통과하지 못했다. 클래스별 검증 기준을 고정하고 지원되지 않는 클래스는 미확정으로 남긴다. 확정 후보의 정밀도와 전체 특징 회수율을 따로 기록한다. 평면 CAD는 기존 MFCAD 전문가 모델을 함께 사용하므로 MFInstSeg 공동 모델 수치를 혼합 런타임 전체 정확도로 제시하지 않는다.

128폭 실험은 면 분류를 개선했지만 특징 인스턴스 검증 PQ/회수율이 64폭보다 낮았다. MFCAD의 추가 기하 입력을 0으로 채웠던 초기 공동 실험을 발견해 원본 CAD 측정으로 교체하고 두 폭에서 다시 학습했다. 기존 22기하 특징과 외부 라벨 학습은 초기 실험에도 포함됐지만, MFCAD 추가 경계·노드 기하는 포함되지 않았다. 3실험 중 검증 특징 정밀도≥97% 조건에서 PQ가 가장 높은 초기 64폭(.826867)을 위치 인식용으로 선택했다. 재학습 64폭은 .823684, 128폭은 .819829였다. 보류 시험을 모델 선택 기준으로 쓰지 않았다. 특징 일치는 같은 클래스에서 면 집합 IoU>0.5로 평가했으며, 면 집합 완전 일치 회수율은 .712496이다. 선택 모델의 보류 특징 정밀도 .974080, 회수율 .722770, PQ .826386이다. 전체 25클래스 면 분류 정확도 .978733·macro F1 .962607과 서로 다른 지표다. 미확정 클래스 4종(through_hole, triangular_passage, 6sides_passage, circular_through_slot)은 학습 위치 확정에서 제외하며 기존 CAD 구멍 검사는 유지한다.

모델 선택과 배포 SHA는 최종 카탈로그를 따른다. 학습 중단·초기 전역 기준 실패·자원 경쟁으로 발생한 CAD 시간 제한·UI 구문 오류·파일명 오입력 검사 실패와 재시험을 `study/*full*.log`에 보존한다.

일반 자유곡면·홀더 충돌·모든 특징의 자동 CAD 편집을 이번 시험 범위에 포함시키지 않는다. 판단 목표는 자료에 근거한 기하 문제와 개선안이며, 검증하지 않은 성능을 ‘충분’이라는 표현으로 대신하지 않는다.

공개 STEP 14개에 적층 4공정+절삭 70검토를 실행했다. 저자 파라미터와 비교 가능한 구멍 지름 2건은 CAD 해석값과 일치했다. 솔리드가 없는 enclosure 1개는 절삭 입력 수정 대상으로, 271면 NIST 형상은 학습 그래프 범위 밖으로 구분했다. 모든 70검토가 기하 치수 정답을 갖춘 정확도 시험이라는 의미는 아니다. 전체 학습/시험 파일 SHA와 이 실행 감사는 함께 보존한다.

## 최종 실행 검증·배치

최종 선택 모델을 고정한 전체 회귀검사 1,553항목 중 1,552개가 통과했고, 공정별 조건을 왕복하는 AppTest 1개는 90초 시간 제한에 걸렸다(전체 1,162.56초). 코드를 변경하지 않고 해당 파일을 별도 실행해 4개 모두 93.20초에 통과했다. 최초 시간 제한을 삭제하거나 최초 전체 실행이 모두 통과했다고 기록하지 않는다. `full-suite.xml`과 `process-ui-recheck.xml`에 두 결과가 있다.

바탕화면 Python 3.13 실행 환경에서 특징 위치·외부 기하·방향 탐색·실제 코너 수정·미리보기·예제 선택·종합 추천 관련 39개 검사가 모두 통과했다(57.27초). 최초 검사 파일명 오입력으로 실행되지 않았던 XML도 별도 보존한다. 코드와 JSON 모델·예제·안내 파일은 427개를 동기화하고 파일별 SHA를 대조했다. 바탕화면 서버의 `8507/_stcore/health` 응답은 `ok`다.

실제 8507 화면에서 자체 삼각 포켓 예제를 선택해 치수 입력 없이 공구 Ø8/날 길이 7/돌출 길이 7 mm를 제안하는 흐름을 확인했다. 종합 결론의 문제 위치 버튼은 해당 제목으로 초점을 이동하고 포켓 바닥·측벽을 표시한다. 코너 수정 버튼으로 R0→R4 STEP이 실제 생성되고, 수정 전 빨간 코너 표시와 수정 후 주황 둥근 면·상단 경계를 확인했다. 수정 STEP 다운로드와 검산 상세는 같은 결과에 있다.

모델 선택 후 공개 STEP 14개·70공정 검토를 다시 실행했고, `public-runtime-audit-final/public-demo-review-audit.json`에 그 실행 시점의 모든 모델 SHA를 함께 기록했다. 앞선 실험 모델로 수행한 감사는 `public-runtime-audit/`에 별도 보존한다. 전체 원본 DB·학습 체크포인트는 `study/ai-full-corpus-2026-09-30/`, 제품 모델·소형 검증 결과는 저장소 안에 있다.
