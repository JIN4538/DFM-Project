# 미해결 근거와 검증 과제

**2026-09-21 갱신:** 아래 KS의 큰 페이지 누락은 새 캡처로 해소됐다. [표준 감사](../research/literature-update-2026-09-21/STANDARDS_AUDIT.md)에 남은 워터마크·52902 PDF 44쪽 해설 하단 잘림을 기록했다. 확보한 52902는 2019 기반 KS이며 국제 2023판 전문 미확보는 별개다. R12의 원 논문·그림 미확보, 논문 내부 수치 모순, 실제 제조/공정 검증 과제는 계속 유효하다. 아래 항목은 최초 기록을 보존한 것이다.

작성: 2026-09-11. 이 목록의 항목은 모두 결함이 확정됐다는 뜻이 아니다. 확인한 제한,문헌 모순,검증 후보를 구분한다.

## 원문 확보가 필요한 항목

- **R08 KS52902:** 현재PDF는5절부터 시작하며1~4절,부속서A/B,C일부,앞뒤 페이지 등이 빠졌다. 완전한 표준으로 취급할 수 없다. ISO52902:2019는 국제판2023으로 대체됐지만 KS의 채택·현행 상태를 그 사실만으로 추정하지 않는다. [ISO52902:2023](https://www.iso.org/standard/79683.html).
- **R09/R10 KS52903-1/-2:** 캡처의 툴바/워터마크가 실제 문자를 가린다. R10 인장시험편 표 주석b와 일부 공정/문서화 항목을 정확한 문장으로 인용하지 않는다. 참고문헌 등 원문 페이지가 빠졌다.
- **R11 KS52910:** 본문과 설계 흐름은 검토했으나 가린 글자와 누락된 참고문헌 페이지가 있다. ‘모든 조항의 정확한 원문 확보’ 상태가 아니다.
- **R12 3D-annotated CAD:**5쪽 한국어 편집본,원본 그림1~33이 제공되지 않았다. 출판연도/권호/DOI가 확인되지 않았다. 다른 Mochizuki 논문으로 임의 대체하지 않는다.

## 문헌 내부에서 해결되지 않은 내용

- R05의 최소 특징 크기 설명5노즐지름과 표의2.5노즐지름,브리지 본문/표의시험속도 표기가 다르다. 형상·측정 정의까지 원문과 함께 확인해야 한다.
- R13의 cantilever 본문≤2mm와 표의1.5mm성공/2mm실패,draft각 본문70°와 표50°경계가 다르다. 수직/수평각 정의도 구분한다.
- R14 Eq.3의 부등호와 sharpness 설명을 임의 정정하지 않는다. NIST 소개 페이지와 제공PDF의 성능 수치를 섞지 말고 인용할 판본/표를 특정한다.
- R02의 모델 비교표에서는 선형회귀 평균R²가ANN보다 높다. 일부 탄소/체적 비교의 표와 서술도 다르다. ‘항상 우수’라는 표현을 그대로 가져오지 않는다.
- R03의 경험식 변수/단위 표기,R04의 문헌 집계는 해당 원출처 확인 전 일반 공식/전 공정 한계로 승격하지 않는다.

## 프로젝트 조건이 아직 필요한 항목

목표 사용자의 의사결정,실제 사용할 장비·재료·노즐·슬라이서·속도·온도·냉각·허용오차,사용 가능한 출력/측정 장비,실제 일정은 이 자료만으로 합의됐다고 확정하지 않는다. 기능 변경에 필요한 시점에 사용자와 구체화한다. 이 인수 작업에서는 임의로 새 장비나 일정 목표를 정하지 않았다.

## 검증과 코드 후속 과제

1. 독립적인 기준 형상과 층/각도/크기 경계의 기대값을 정의한다. 검출 알고리즘의 결과를 그대로 라벨로 만들지 않는다.
2. 동일STL·같은단면높이·같은선폭정책으로 슬라이서 윤곽/압출경로를 대조한다. 현재 고정 선폭 잔여와 실제 가변 선폭의 출력 차이를 기록한다.
3. 문헌조건과 목표 장비조건의 차이를 시편으로 보정한다. 형상 누락·치수 과대·처짐·연결/제거성을 구분한다.
4. 법선 레이의 표본 누락,근접교차 필터,테셀레이션,복잡한 공동/자기교차,부분성분의 보수성에 대한 반례를 추가한다.
5. 메모리 부족 시 측정결과·게이트 이유를 보존하고 시험 하네스가None의 숫자 연산으로 중단되지 않도록 하는 변경을 검토한다. 이번 최초T13 원인은 미확정이며 단독구/기본검증 재시험은 통과했다.
6. 기존 문자열 기반 뮤테이션이 현행코드에 실제 적용되는지 먼저 확인한다. 구 버전9/10을 새버전의시험 성능으로 재사용하지 않는다.
7. 기존 Cura24조건 외의 부품 가족을 잠금 시험으로 확보한다. 29파일 보존과 통계 재현은 슬라이서재실행·제작품검증과 다르다.

우선순위와 판단 근거는 [개발 방향](DEVELOPMENT_DIRECTION.md)을 따른다. 위 목록 전체를 한 번에 구현하는 계획은 아니다.
