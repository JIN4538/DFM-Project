# 개발 방향 판단과 우선순위

**후속 지시 반영:** 2026-09-14 사용자가 STEP·공정 범위·새 사용자 흐름을 포함한 과감한 개선을 요청했고 3.0을 구현했다. 현재 방향과 범위는 [최신 인수 기록](RELEASE_V3_2026-09-14.md)을 따른다. 아래 제안은 이전 시점의 판단으로 보존한다.

작성: 2026-09-10~11. 기준: 저장소 `1706eacf03ca30a59f83805dd0c46753e8852a24`의 자료와 v2.6 보관 코드. 아래 수용 기준 설계는 이번 검토의 제안이며, 문헌이 정한 의무나 사용자와 합의한 일정이 아니다.

## 판단

**적층제조 제조성 검토 소프트웨어라는 방향은 타당하다. 현재 단계에서 가장 설득력 있는 목표는 특정 FDM 조건에서 형상 위험의 위치·이유·대안을 설명하는 설계 지원 도구다.** 초기 오류를 고친 뒤 입력 불확실성을 유지하며 층 단면 검토로 확장한 방향은 이 목표와 맞는다. 현재 점수·등급을 출력 성공 확률, 실제 강도 또는 표준 적합 인증으로 해석할 근거는 없다.

표준의 고려사항을 계산 지표로 옮기는 연구적 정당성과, 지금 구현한 지표·임계값의 실증적 타당성은 따로 판단해야 한다. 전자는 문헌으로 지지되지만 후자는 앞으로 검증해야 한다. 기존 구조를 폐기할 이유는 없으며, 다음 개발의 중심은 지표와 실제 결과의 대응을 확립하는 데 둔다.

## 유지할 설계

- 입력 유효성, 측정 보류, 프로필 미충족, 측정 가능한 규칙 점수를 구분한다.
- 3D 솔리드 분석과 FDM 층 단면 분석을 독립적으로 유지한다. 단면을 계산했다고 메시 전체가 복구되거나 3D 점수가 유효해지는 것은 아니다.
- 원본 파일과 정리 후보를 분리하고 해시·단위·방향·설정·코드 버전을 결과에 보존한다.
- 작은 영역은 표시 우선순위를 낮춰도 집계에서 숨기지 않는다. 작은 독립 핀 전체의 소실은 계속 검토 대상으로 남긴다.
- 위치, 측정량, 미확정 이유를 제공한다. 사용자에게 총점만 보여주는 방식으로 되돌아가지 않는다.

## 다음 개발의 순서

### 1. 검증할 제품 범위와 프로필을 고정

먼저 FDM/재료 압출의 한 장비·한 재료·명시된 슬라이서 버전을 기준으로 삼는다. 노즐 지름, 실제 선폭 정책, 층 높이, 속도, 온도, 냉각, 방향, 서포트·브리지·접착 설정, 모델의 단위를 기록한다. 이 값은 장비가 정해졌을 때 채우며 현재 기본값을 실제 장비 조건으로 가정하지 않는다.

‘얇아서 경로가 생기지 않음’, ‘슬라이서가 원형상보다 넓혀 경로를 생성함’, ‘경로는 있지만 출력 후 치수가 허용오차를 벗어남’을 구분한다. 세 경우는 다른 설계 문제다. [Prusa의 Arachne 문서](https://help.prusa3d.com/article/arachne-perimeter-generator_352769)는 가변 압출 폭과 작은 특징의 확대/생략 정책을 설명한다. 따라서 노즐 0.4mm보다 얇으면 무조건 출력 불가라는 전제를 사용하지 않는다.

### 2. 현재 단면 지표의 정답과 실패 조건을 고정

우선 약 20개 기본 형상 계열로 작은 검증 세트를 설계한다. 개수는 시작 규모의 제안이며 통계적 충분성을 뜻하지 않는다. 각 계열에서 매개변수·층 위상을 바꾼다.

- 평판·핀·리브·곡면 벽·좁은 틈·공동: 알려진 단면적/폭/연결 관계.
- 경사면·양단 브리지·한쪽 고정 보·떠 있는 섬·얇은 수평 판: 지지 및 층간 관계.
- 열린 면·뒤집힌 면·반대 중복·손상 공동·분리된 정상 성분: 잘못된 확정 방지.
- 면 분할·면 순서·회전·이동·mm/cm/inch·층 중간에 놓이는 특징: 표현과 샘플 위치에 따른 안정성.

예상값은 수식이나 독립적인 CAD/검토 절차에서 정한다. 현재 구현의 출력값을 복사해 정답을 만드는 방식은 피한다. 수치 허용오차와 물리적 허용오차를 별도로 둔다. 메모리·시간 한도 초과는 미확정으로 기록하고 완료율의 분모에서 숨기지 않는다.

### 3. 슬라이서 단면과 경로를 직접 대조

동일 방향의 동일 STL 바이트, 동일 높이의 단면으로 비교한다. 현재 코드는 층 중간 평면을 사용하므로 G-code의 노즐 Z와 기하 단면의 기준 높이를 먼저 대응시킨다. 슬라이서의 메시 보정도 기록한다.

기하 재료 윤곽의 면적·구멍·성분·경계 거리와, 압출 경로가 덮는 영역을 구분한다. 경로 중심선을 곧바로 재료 외곽선으로 비교하지 않는다. Arachne 같은 가변 선폭에서는 구간별 폭까지 고려한다. 얇은 특징의 누락/확대, 지지되지 않는 구간, 브리지로 처리한 구간을 위치별로 대조한다. `.3mf`, G-code, 슬라이서 설정, 입력·출력 해시를 남긴다.

슬라이서는 공정 계획의 비교 기준이지 실물 정답은 아니다. 단면 일치율과 실제 출력 품질을 별도 평가한다.

### 4. 소수 시편으로 실제 결과와 연결

임계값 전후의 형상을 반복 제작하고 실제 치수·처짐·연결 여부·제거 가능성을 기록한다. 사용 목적에 필요한 허용오차와 합격 정의를 먼저 정한다. 출력 실패 하나를 기하 형상만의 원인으로 단정하지 않고 접착·온도·재료·장비 상태를 함께 기록한다.

R06처럼 조건과 허용오차가 있는 시험을 통해 장비별 프로필을 보정한다. 동일 조건 반복과 다른 조건의 일반화 시험을 구분한다. 이 단계 전에는 실제 출력 정확도나 성공 확률을 주장하지 않는다.

### 5. 설명 가능한 대안 추천

검증된 원시 지표로 현재 6방향을 비교한다. 지지량, 높이/시간, 형상 누락, 중요 면 품질은 서로 상충할 수 있으므로 파레토 후보와 차이를 보여준다. 분석 범위가 다른 후보의 총점 비교는 보류한다. 사용자 요구가 없으면 임의의 단일 최적 방향을 확정하지 않는다.

점수 포화로 여러 방향이 100점일 때는 원시 측정값도 비교한다. 최적화를 추가할 때는 개선 전후 형상과 실제로 바뀐 위험 위치를 제시한다. 검증되지 않은 목적함수를 GA로 최적화하는 작업은 이 단계 뒤다.

### 6. 근거가 준비된 항목만 확장

STEP/PMI는 설계 의도·공차·특징 정보를 활용할 필요가 분명할 때 도입한다. STEP 파싱만으로 정확한 두께나 모든 구멍 인식이 해결되지는 않는다. SLA/SLS/DMLS는 공정별 지지·열·배출·재료 현상의 별도 검증이 필요하다. 절삭·사출·프레스 확장은 FDM과 별도 적용 범위·지표·검증 자료를 가진 모듈로 설계한다.

AI는 독립 관측 라벨이 쌓인 후 오차 보정·위험 우선순위·조건별 임계값 추정에서 비교한다. 단순 규칙/회귀 기준선과 비교하고 보정에 사용하지 않은 부품 가족을 시험에 남긴다. 정확도 향상이 없으면 복잡한 모델을 채택할 이유가 없다.

## 무엇으로 개선을 입증할 것인가

| 검증 대상 | 확인할 지표 | 혼동하지 않을 것 |
|---|---|---|
| 입력/단면 해석 | 정답 면적·연결 관계·경계 오차, 미확정 원인, 단위/테셀레이션 안정성 | 계산 완료율을 제조 정확도로 부르지 않음 |
| 위치 검출 | 검토자가 정한 위치 라벨에 대한 오탐·미검출, 정밀도·재현율, 위험 크기별 분해 | 현 표시 하한을 정답 라벨로 사용하지 않음 |
| 지지량 | 부품별 MAE/RMSE·편향·잔차, 0-0 포함/제외, 부품 가족별 독립 시험 | 같은 부품 6방향을 독립 부품 6종으로 세지 않음 |
| 대안 선택 | 추천 전후 측정 위험·추가 재료·시간 변화와 사용자 선택 | 총점 상승만으로 실제 개선을 확정하지 않음 |
| 실물 | 명시된 허용오차 내 치수/처짐/연결/제거성, 반복 변동 | 한 번의 성공을 다른 장비·재료의 보증으로 확대하지 않음 |
| 실행 품질 | 대표 입력별 시간·메모리·중단/보류 동작, 동일 환경 반복 | 실패한 빠른 실행과 성공한 전체 계산의 시간비를 비교하지 않음 |

합격 숫자는 데이터와 용도 없이 임의로 95% 등으로 정하지 않는다. 설계상 놓치면 안 되는 결함, 허용 오탐, 사용자 검토 부담을 먼저 정하고 잠금 시험 전에 수용 기준을 확정한다.

## 연구 기여의 후보

‘손상 또는 복잡한 STL에서 확인 가능한 층 성분만을 보수적으로 해석하고, FDM 형상 위험을 위치와 불확실성으로 설명하여 설계 대안을 비교한다’는 연구 문제로 좁힐 수 있다. 기존 슬라이서 및 제조성 검토 방법과의 체계적인 비교 전에는 독창성이 입증됐다고 주장하지 않는다.

가장 가까운 다음 산출물은 새 공정 버튼이나 새 총점이 아니라 **근거가 독립적인 기준 형상 세트와 슬라이서 대조 보고서**다. 여기에 검출 실패를 고친 변경과 전후 결과를 연결하면 코드 개선과 연구 결과가 함께 축적된다.
