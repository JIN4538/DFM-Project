# 처음 사용하는 사람을 위한 검토 흐름: 조사와 설계 근거

작성일: 2026-09-15. 사용자 요청은 개별 숫자의 설명을 넘어 프로그램 전체에서 현재 판단과 다음 행동을 바로 이해하게 만드는 것이다. 이 문서는 `398e6a2` 기준 화면 구조를 독립적으로 검토한 설계 근거다. 실제 반영 범위와 실행 검증은 이번 변경 기록을 따르며, 아래 제안을 모두 구현했다고 뜻하지 않는다.

## 판단

기존 화면은 측정과 한계를 성실하게 보존하지만, 사용자가 그 의미를 직접 해석해야 한다. 특히 `측정됨`, `complete`, 후보 면적 `0`, 최소 관통거리 `4 mm`는 서로 다른 사실인데도 검토 단계와 다음 행동이 연결되지 않는다. 기능을 설명하는 문장만 늘리기보다 **현재 판단 → 확인할 위치 → 다음 행동 → 필요한 경우 측정 상세** 순서를 일관되게 적용해야 한다.

상용 도구를 참고할 부분은 조건·형상·조치를 연결하는 방식이다. 타사 도구와 동등한 알고리즘, 정확도, 실물 검증 또는 공정 해석을 확보했다는 근거로 사용하지 않는다. PrusaSlicer는 오픈소스 슬라이서이며 이 문서에서 유료 상용 소프트웨어로 분류하지 않는다.

## 사용자가 읽을 판단의 계약

- **검토 필요:** 입력 기준에 못 미친 관측값 또는 확인할 기하 후보가 있다. 무엇을 어디에서 확인할지 연결한다.
- **입력 기준 이상으로 측정됨:** 명시된 기준과 유효한 관측 범위에 대한 문장이다. 기준의 출처와 표본 한계를 가까이 표시한다.
- **후보 미검출:** 실제로 계산한 범위에서 해당 후보가 없었다. 이 상태를 출력 성공으로 요약하지 않는다.
- **기준 입력 필요:** 측정 결과는 있으나 비교 기준이 없다. 사용자가 바로 조건을 입력할 수 있게 한다.
- **검사 전 / 일부 미확인 / 계산 불가:** 아직 실행하지 않은 것, 일부 누락, 유효한 결과가 없는 것을 서로 구분하고 가능한 재시도·입력 확인 행동을 안내한다.
- **해당 없음 / 제한 미적용:** 공정상 적용되지 않는 검사와 사용자가 의도적으로 끈 장비 공간 검사를 각각 설명한다.

단순한 초록·노랑·빨강 전체 등급은 위 상태들을 표현하기 어렵다. 색과 함께 짧은 상태 문장, 범위, 행동을 제공한다. 사용자가 명확한 판단을 원한다는 이유로 없는 기준이나 검증 결과를 만들지 않는다.

## 후속 확인에 사용할 독립 시나리오

1. 브래킷 벽 표본 최소 4 mm, 기준 없음: 숫자만 보여주지 않고 기준 입력 행동이 보이는가.
2. 동일 측정에 기준 1 mm: 관측 범위의 기준 미만 후보 없음과 가장 짧은 표본 강조가 모순 없이 설명되는가.
3. 기준 5 mm 또는 일부 유효 표본 누락: 기준 미만 후보와 미확인 범위를 둘 다 보존하는가.
4. 200층의 세 지표가 모두 유효한 0: 첫 화면에서 후보 미검출과 다음 행동을 이해하고 불필요한 0 그래프를 읽지 않아도 되는가.
5. 한 개 값이 None이거나 한 층이 빠짐: 모든 후보 없음 또는 완료로 요약하지 않는가.
6. 아주 작은 양수 후보: 반올림된 0이나 정상 상태로 사라지지 않고 위치를 찾을 수 있는가.
7. MEX에서 VPP·PBF로 변경: 이전 공정의 결과와 추천 행동이 남지 않는가.
8. 방향 적용·기준 변경·다른 파일 선택: 화면·보고서·배치 STL이 같은 조건을 가리키며 이전 결과를 현재 결과처럼 내보내지 않는가.
9. 기준 저장 직후와 수정 파일 검토 후: 다음 행동 및 실제 비교의 차이를 이해할 수 있는가.
10. 보고서만 받은 사용자: 프로그램을 열거나 원시 JSON을 읽지 않아도 검토한 내용과 남은 조치를 이해할 수 있는가.

이 시나리오는 사용성 확인과 상태 오해 방지를 위한 수용 기준이다. 실제 사용자 관찰 실험이나 프린팅 검증을 이미 수행했다는 뜻은 아니다.
