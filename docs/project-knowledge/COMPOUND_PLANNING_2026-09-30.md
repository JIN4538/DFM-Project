# 복합 절삭 특징의 학습 제안과 부위별 수정

작성: 2026-09-30. **새 학습 모델 1개를 실제 학습했다.** 서로 다른 구멍·포켓·코너가 함께 있을 때, 모든 부위에 같은 수정 방식을 적용하던 후보를 보완한다. 작은 탐색은 정확하게 모두 계산하고, 공구 조합이 많을 때만 학습 모델로 유망한 8개를 먼저 고른다. 선택한 조건마다 부위별 수정안을 계산한 후 기존 치수 검사로 검산한다.

## 무엇이 달라졌나

기존 후보는 전체 구멍을 확대하거나 전체 깊이를 줄이는 등 전역 수정 방식의 조합이었다. 새 후보는 같은 공구 조건에서도 한 구멍은 지름을 늘리고 다른 구멍은 깊이를 줄이는 식의 조합을 허용한다. 공구 지름·날 길이·돌출 길이에는 원래 측정된 개구부와 깊이에서 나온 중간 치수도 포함한다.

부위별 목표 치수와 새 공구 조건을 제안하는 기능이다. 이 모듈이 STEP를 다시 만드는 것은 아니다. 실제 코너 STEP 편집은 별도 CAD 편집 경로에서 지원 여부를 확인한다.

## 학습과 정확 계산의 역할

- **학습:** Gradient Boosting 회귀 모델이 공구 치수 조합의 최종 수정 비용을 예측한다. 예측 순위 상위 8개를 정확 계산할 후보로 사용한다.
- **정확 계산:** 각 후보에서 형상 변경량과 변경 개수를 함께 보존하는 동적계획으로 부위별 수정 조합을 선택한다. 원래의 `evaluate_changes`가 변경 전 값·CAD 면 ID·허용 변경·잔여 치수 충돌을 다시 확인한다.
- **최종 선택:** 기존 후보와 기존 DQN 후보를 유지한 채 새 후보를 추가한다. 최소 충돌 수, 네 항목의 Pareto 비교, 공개된 비용 함수 순으로 선택한다. 네 항목은 형상 변경량·공구 변경량·돌출/지름 비·변경 개수다.
- **작은 문제:** 공구 조합 64개 이하에서는 모델 예측 없이 전수 계산한다. 검증 자료에서 이 경로가 더 빨랐다. 64개를 넘으면 학습한 8개 후보를 사용한다.

학습 대상은 프로젝트에서 정의한 치수 개선 비용이다. 실제 외부 전문가의 최종 설계 선택을 정답으로 사용한 모델은 아니다. 기존 기하 기준·문헌 조건을 새 임계값으로 바꾸지 않았다. 공구와 코너·개구부·깊이 관계의 근거와 적용 범위는 [기존 절삭 근거 기록](../research/MACHINING_EVIDENCE.md)을 따른다.

고정 공구 조건에서 형상 변경량은 부위별로 합산되고, 변경 개수 항은 8개에서 포화된다. 각 변경 개수별 최소 변경량을 보존하면 선언한 이산 목표 치수 집합의 최선 비용을 유지할 수 있다. 연속적인 모든 CAD 설계 공간의 최적화를 뜻하지 않는다.

## 새 학습 데이터와 분리

| 구분 | 독립 형상 조건 그룹 | 중점별 검토 조건 |
|---|---:|---:|
| 가중치 학습 | 320 | 960 |
| 모델 선택 | 80 | 240 |
| 최종 보류 시험 | 224 | 672 |

- 새 가중치 학습에 사용한 공구 조합 행: **15,912개**.
- 모두 치수가 정의된 절차 생성 특징 조건이다. 실제 CAD 파일 개수나 신규 외부 다운로드 수로 합산하지 않는다.
- 한 형상에서 파생된 중점·변경 허용 조건은 같은 분할에 남긴다. 시험에는 학습·모델 선택에 없던 특징 구성 2종의 64그룹·192조건이 포함된다.
- GB 80/깊이 3, GB 120/깊이 4, Extra Trees 96/깊이 10을 검증 세트에서 비교하여 GB 120/깊이 4를 선택했다. 테스트 결과를 보고 모델을 다시 선택하지 않았다.
- 고정 난수 시드와 단일 학습 스레드를 사용했다. Python 학습기와 휴대형 JSON 추론의 최대 차이는 선택 모델에서 0이었다.

`run-01`은 학습 후보와 소규모/대규모 탐색 시간을 검증한 기록이다. 64개 이하 전수 계산 정책은 이 검증 결과로 정했다. 소스 계약을 변경한 뒤 `run-02`에서 다시 실제 학습하여 최종 모델을 만들었다. 시험 672조건은 `run-02` 선택이 끝난 다음 최초 평가했다. 두 실행과 최초 실패 로그를 모두 보존했다.

## 보류 시험 결과

비교 기준은 **기존 전역 후보를 Pareto 필터 이전부터 복구하고 기존 DQN 후보를 더한 정확 선택**이다. 원래 세 항목 Pareto에서 변경 개수까지 네 항목으로 복구한 효과를 새 모델 성과에 포함하지 않았다. 같은 추가 후보 계산 예산의 대조군에도 동일한 기존 후보를 제공했다.

| 추가 탐색 방법 | 기존 추천보다 개선 | 동일 | 악화 | 평균 추가 탐색 시간 | 정확하게 완성한 공구 조합 |
|---|---:|---:|---:|---:|---:|
| 학습 순위 8개 | 74 | 598 | 0 | 27.72 ms | 4,194 |
| 탐욕 순위 8개 | 51 | 621 | 0 | 9.38 ms | 4,194 |
| 무작위 8개 | 33 | 639 | 0 | 4.31 ms | 4,194 |
| 전체 조합 정확 계산 | 76 | 596 | 0 | 43.84 ms | 30,543 |
| 제품용 혼합 방식 | **74** | **598** | **0** | **17.71 ms** | **8,094** |

학습 제안과 탐욕 제안을 직접 비교하면 **32조건에서 학습 제안이 좋았고 1조건에서는 나빴다**. 무작위 제안과는 50조건 우위·1조건 열세다. 기존 추천을 함께 보존하여 최종 추천의 기존 대비 악화는 없었다. 따라서 새 학습의 추가 기여는 확인됐지만 모든 형상에서 단순 탐색보다 우수하다는 뜻은 아니다.

제품용 혼합 방식은 전체 조합 정확 계산과 670/672조건에서 같은 최종 품질이다. 나머지 2조건에서는 더 좋은 신규 조합을 찾지 못해 기존 추천을 유지했다. 비용 차이는 각각 약 0.02029와 0.01384였다. 전체 조합 대비 평균 시간은 약 2.48배 빠르고, 정확 완성 조합 수는 73.5% 줄었다. 이 시간은 해당 CPU 실행의 계획 단계 측정이며 전체 앱·CAD 읽기 속도가 아니다.

학습한 계열과 같은 구성의 새 형상 480조건에서는 50개 개선, 보지 않은 특징 구성의 192조건에서는 24개 개선했다. 혼합 방식이 실제 학습 모델을 사용한 시험 조건은 162개이고, 나머지 510개는 작은 조합의 정확 전수 계산이었다.

## 실제 CAD와 제품 연결

최종 `enhanced_planning` API에서 복합 제안 기능을 끈 경우와 켠 경우를 별도로 호출해 보류 시험을 재생했다. **224그룹·672조건에서 74개 개선·598개 동일·악화 0**으로 독립 비교와 일치했다. 추천 가능 상태가 사라진 조건은 없으며, 실행 시작·종료 시 주요 계획 소스가 같다. [제품 경로 재생 결과](../../validation/ai-next-2026-09-30/compound-runtime-01/evaluation.json)에 변경 전후 치수와 선택 출처를 보존했다.

실제 STEP는 공개 14개, 기존 절삭 예제 12개, 새 세 포켓 형상의 수정 전·후 2개로 **28개**를 읽었다. 자동 공구/명시 공구 2조건, 중점 3종, 형상 유지 여부를 조합해 **504조건**을 검토했다. 모든 파일 실행을 완료했고 오류는 없었다. 두 경로 모두 추천을 낸 198조건 중 **1개 개선·197개 동일·악화 0**이었다. 나머지 306조건의 미추천 상태는 보존했다. 실행은 138.781초였으며 기록된 주요 소스의 시작·종료 해시가 같다. [실제 CAD 결과](../../validation/ai-next-2026-09-30/compound-cad-01/evaluation.json)를 따른다.

개선 사례는 공개 `cadquarry_flanged_flanged_462c.step`에 공구 지름 12 mm, 날 길이 4 mm, 돌출 길이 6 mm를 지정하고 균형·형상 변경 허용 조건으로 검토한 경우다. 기존 추천은 공구 지름과 원통 구간 7개를 바꾸는 8개 수정이었다. 새 추천은 공구 지름 4.3 mm, 돌출 길이 6.9 mm, 긴 원통 구간 1개의 목표 길이를 제안하는 3개 수정으로 6개의 짧은 원통 구간 변경을 피했다. 치수 충돌은 두 경우 모두 0이고 공개 정책 비용은 0.596145에서 0.538126으로 줄었다. 형상 기능의 보존을 판정한 결과가 아니라 입력한 변경 허용 조건과 비용 정책에 따른 비교다.

**이 실제 CAD 사례들은 모두 공구 조합 64개 이하였으므로 학습 예측 경로를 사용한 조건은 0개다.** 실제 사례는 부위별 조합 탐색의 추가 가치를 보여주며, 같은 계산 예산에서 학습이 더 좋은 후보를 고르는 효과는 앞의 별도 보류 시험으로 검증했다. 두 성과를 혼합하지 않는다. 세 포켓 STEP의 실제 반경 수정·측정은 별도의 복수 포켓 CAD 편집 검증 기록을 따른다.
