# 종합 결론·개선안 비교·선호 학습

상태: 구현·전체 회귀검사·바탕화면 배치와 실제 브라우저 점검 완료. Git 커밋·푸시는 이번 후속 작업에서 수행하지 않았다.

## 사용자 요구

분산된 카드와 설명 대신 종합 결론을 먼저 제공하고 근거를 요청 시 보여준다. 장비·재료는 검색 가능한 선택창 하나로 입력한다. 벽 비교값은 공정별 기본값을 두고 편집을 허용한다. 실제 제조 가능성·성공률 반복 안내와 불필요한 중점 설명은 제거한다. AI는 규칙 복제에 머물지 않고 여러 개선안을 비교하고 선택하는 데 실제로 관여해야 한다.

## 구현 구분

1. 기하 측정·기준 위반 검출: 기존 검증 엔진을 유지한다. 누락·부분 계산을 정상으로 바꾸지 않는다.
2. 개선안 생성: AM은 실제 계산한 방향 후보, CNC는 공구 치수·특징 치수의 수정 조합을 만들고 비교 가능한 수치 조건을 다시 계산한다. CNC 수정안은 치수 변경 제안이며 CAD 파일 자체를 변경한 결과가 아니다.
3. 초기 학습 모델: 새로 공개한 프로젝트 선택 목적에 맞추어 후보 점수를 학습한다. 목적함수 자체는 개발 정책이다. 이 모델이 그 함수를 근사하는 것은 독립적인 전문가 판단을 배웠다는 뜻이 아니다.
4. 명시적 선호 학습: 사용자가 대안의 ‘이 개선안을 선호함’을 누르면 선택한 후보와 다른 후보의 상대 차이를 로컬에 보관하여 추천에 반영한다. 장비·재료·공정 범위를 구분하고 초기화를 지원한다. 자동 클릭 수집이나 CAD 업로드는 하지 않는다.
5. 결론 화면: 하나의 제목, 선택한 개선안, 남아 있는 우선 조치. 전체 항목·측정값·후보와 학습 기록은 접힌다. AM/CNC HTML도 같은 결론 함수를 사용한다.

## 평가 원칙

- 같은 형상의 공정·방향·중점 변형은 학습과 시험에 나누어 넣지 않는다.
- 기존 순위, 새 목적함수의 직접 계산, 학습 근사, 모델 제거 결과를 구분한다.
- 정책을 변경한 이득을 AI 자체의 정확도 향상으로 표현하지 않는다.
- 평가 시 동점 처리도 배포 함수와 같아야 한다.
- 사용자 선호가 실제 선택을 바꾸는지, 다른 장비·재료와 섞이지 않는지 검사한다.
- 학습 소스는 시작할 때 고정하고 저장 직전에 해시가 같은지 확인한다.

## 공정별 벽 초기 비교값

| 공정 | 초기값 | 채택한 자료와 조건 |
|---|---:|---|
| MEX/FFF | 1.2 mm | Formlabs 일반 설계 안내의 0.4 mm 노즐 예시 |
| VPP | 0.4 mm | Form 2·Clear Resin·층 높이 0.1 mm의 연결/비연결 벽 권고 |
| 고분자 PBF | 0.6 mm | Fuse 1·Nylon 12의 수직 벽 0.6 / 수평 벽 0.3 mm 중 큰 값 |
| 금속 PBF | 0.4 mm | EOS M290·316L_Surface_1.X·층 높이 0.02 mm의 0.3–0.4 mm 범위 상단 |

앱의 시작 비교값이다. 해당 장비·재료 이외에 보편적으로 적용되는 표준 한계라고 분류하지 않는다. 출처·원조건·선택 이유는 `dfm/defaults.py`에 보존한다. 명시적인 라이브러리 조건과 사용자 수정값을 구분한다. API에서 사용자가 `None`을 지정하면 기준 미입력으로 유지한다.

## 독립 감사에서 찾은 수정 대상

- 현재 방향 유지 시 후보의 수치를 현재 결과처럼 표시하는 모순.
- CNC 부분 미확정 범위와 원본 CAD 면 번호의 소실.
- 손상된 사용자 선호 파일의 자료형 처리.
- 평가 코드와 배포 코드의 동점 선택 불일치.
- 학습 실행 도중 소스가 바뀌면 잘못된 소스 해시를 기록할 가능성.
- 원래 최종 결론, 새 추천안, 일반 개선 문장이 서로 중복되거나 모순되는 표시.

최초 실패와 수정 후 결과는 별도 파일로 보관하며, 이전 완료 검증 수와 새 결과를 합산하지 않는다.

## 마지막 사용자 흐름 감사

- 장비·재료는 검색·직접 입력·목록 선택을 지원하는 한 창으로 통합했다.
- 첫 화면에 하나의 종합 결론과 우선 개선안을 제시한다. 새 검토가 완료되면 해당 제목으로 이동한다.
- 측정값·문제 위치는 버튼 또는 토글로 열며, 방향 비교와 종합 결론은 같은 개선안을 사용한다.
- 절삭의 ‘형상·공구 모두 / 공구만 / 형상만’ 선택을 실제 후보 생성 제약과 선호 저장 범위에 전달한다.
- 선호는 명시적인 버튼 선택만 학습한다. 대안이 하나인 후속 형상에서도 ‘추천·학습 기록’에서 초기화할 수 있다.
- 추천 변경이 4개보다 많으면 ‘전체 변경 N개’에서 빠짐없이 읽을 수 있다. 원본 CAD 면 식별자도 표시한다.
- 현재 방향만 공간에 들어가 후보가 없는 경우의 방향 비교 예외, 과거 선형 가중치를 새 모델의 비중처럼 표시하던 항목, 모든 대안을 동점이라 부르던 문구를 수정했다.

추가 UI 계약 검사: 선호/제약/전체 변경 표시 6개, 현재 방향만 적합한 화면 2개 통과. 전체 프로그램과 바탕화면 환경의 최종 결과는 아래에 기록한다.
