검토 기간: 2026-09-10~11. GitHub `JIN4538/DFM-Project`, 기준 커밋 `1706eacf03ca30a59f83805dd0c46753e8852a24`. 이 문서들은 다음 작업에서도 근거와 경과를 다시 불러오기 위한 지속 기록이다. 대화 모델이 모든 원문을 영구적으로 정확히 기억한다는 약속을 대신하지 않는다.

후속 검토: [2026-09-11 새 미팅 보고서 검토와 예상 질의응답](MEETING_REPORT_REVIEW_2026-09-11.md). Downloads의 `AM-DFM_1차_미팅_보고서 (1).docx`를 현재 코드·문헌·검증 기록과 대조했다. 3점 벽두께 확인, 성능 수치 출처, 임계값의 실제 근거와 미확정 범위, 1시간 이내 미팅 구성을 정리했다. 원본 보고서와 소스코드는 수정하지 않았다.

## 현재 확보한 것과 미확정인 것

원본24개는 PDF14개239쪽,DOCX4개,ZIP3개,MD3개다. PDF의 추출 가능한 본문과 스캔의 OCR을 읽고 핵심 수식·표·흐름도 이미지를 대조했다. 다만4개 KS 캡처에 누락·가림이 있고 R12는 그림과 서지가 빠진 편집본이다. **‘참고문헌의 모든 내용이 완전히 확보·확정됐다’고 보고할 수는 없다.** 모순과 미확인 내용을 노트에 남겨 이후 코드의 근거로 잘못 굳어지지 않게 한다.

v2.6의 핵심 실행 코드를 읽고 보고서·변경 기록·과거 코드와 대조했다. 실제 실행으로 과거 결과와 현재 환경을 구분했다. 원본 자료·애플리케이션 코드·Cura측정값은 변경하지 않았으며 인수인계 파일만 저장소에 추가했다. Git 커밋·푸시는 수행하지 않았다.

이번 Windows 시험은 최초 기본검증 중단,회귀167개 중1개 실패가 있었고 UI 실패 과정의 MemoryError가 기록됐다. 이후 기본55/55와 해당UI1개 단독 시험은 통과했다. 이를 전체222개가 한 번에 통과한 것으로 합쳐 설명하지 않는다. 상세는 개발 경과와 원본 로그를 따른다.

## 다음 작업에서 지킬 기준

- 먼저 현재 코드를 확인한다. ZIP 이름·주석·과거보고서보다 실제 함수와 SHA를 우선한다.
- 변경할 규칙의 원문 페이지와 해당 프로필 조건을 다시 읽는다. 노트에 없는 값을 기억이나 추측으로 보충하지 않는다.
- 정의/표준 고려사항/장비별 실험값/개발 휴리스틱/측정 결과를 구분한다.
- 결과None·N/A·부분범위·미확정 이유를 보존한다. 높은 점수나 완료율을 얻기 위해 검사 범위를 숨기지 않는다.
- 변경 이유,근거 문헌/쪽수,수용 기준,실패 반례,전후결과,실행 환경을 함께 기록한다.

작업용 폴더는 저장소 옆 `study/`다. `versions/AM-DFM_v2_6/dfm2`에 읽기/시험용으로 압축을 풀었고 `.venv`는 이번 검토용 환경이다. 개발 소스의 향후 정식 배치·패키징 변경은 별도 작업에서 결정한다.
