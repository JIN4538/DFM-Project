# Raspberry Pi STEP 솔리드67: 폐메시의 국소 자기교차

`final-01`의 `Raspberry Pi 4 Model B.step` 솔리드67은메시1,068삼각형이며 폐곡면/면 방향 검사를 통과했다. 그러나 +Z 빌드 방향의64개 공통 단면 중40번, Z=5.84338339749941mm에서 열린 선분 잔여가 검출돼63개 단면만 확정됐다.4공정에서 같은 결과였고 해당 전체 체적 적분은미확정으로 남겼다.

독립 삼각형-평면 교선과2D 선분 교차로 원인을 추적했다. 문제 높이 및±0.000001/±0.0001mm의총5높이에서 교선 루프가 자기교차했다. 문제 높이의 겹침 선분은각약0.000352515mm인3개였고, 합계는제품의 미해결 길이0.001057545mm와선언 좌표 그리드 범위에서 일치했다.

- CAD 면2083의메시 삼각형465/466이 겹친다.
- CAD 면2084의삼각형551/585 및583/584가 겹친다.
- 이 구간은CAD 면2103/2104의교선과도선분 내부 접점을 만든다.

폐곡면과일관된 면 방향은기하적 자기접촉이 없다는 보증이 아니다. 이번 결과는**저장된 테셀레이션에서 검출한 국소 현상**이다. 원래 STEP B-rep 자체의 문제인지,테셀레이션 근사 또는변환 영향인지는확정하지 않았다. 원본과메시를자동 수정해 결과를 완료로 바꾸지 않았다.

같은 대상에서법선 거리도481표본 중478개만유효했다. 이누락3개의원인을위교선 겹침으로단정하지 않는다. MEX층 검토의단면 높이는공통64중점과다르므로 MEX층이완료됐다는사실이이번높이의국소현상을반증하지도않는다.

공개 [진단 JSON](../../validation/v3/random-corpus/pi-body67-section-diagnostic.json)은원본 SHA,코드 SHA,문제 높이,면번호,잔여 길이만담고원형상·정점·단면 외곽선을포함하지않는다. 전체재현 코드와추적값은저장소 옆 `study/random-shape-audit/diagnose_pi_67.py`, `pi-body-67-crossing-diagnosis-01.json`에있다. 상세 원결과는 `final-01/file_026/body_067_MEX_sections.json`이다.
