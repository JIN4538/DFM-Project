## 독립 반례: 겹치는 두 정육면체

각각 10×10×10 mm인 두 상자를 만든다. 첫 상자는 원점에 두고, 두 번째는 Y축으로 0.5 rad 회전한 뒤 `[1, 0, 1]` mm 이동한다. 두 경계 메시를 불리언 합집합 없이 연결한다. 보고서가 칭찬한 내부 함수처럼 이 연결 메시를 직접 사건 적분에 전달한다.

독립 기준은 Y 방향 깊이가 두 형상 모두 10 mm라는 성질을 사용한다. XZ 사각형 두 개의 교집합을 반평면 클리핑으로 구하고 shoelace 식으로 면적을 계산한다. `합집합 체적 = 2000 − 교집합 면적 × 10`. 이 기준은 `section_mesh`, Shapely, 3D 불리언 연산을 재사용하지 않는다. 부동소수 산술이라는 한계는 유지한다.

| 측정 | 결과 |
|---|---:|
| 독립 교집합 면적 | 80.09975544706701 mm² |
| 독립 합집합 체적 | 1199.0024455293299 mm³ |
| `ae2a868` 내부 사건 적분 | 1196.6831714466223 mm³ |
| 상대차 | −0.1934336407% |
| 내부 계산 상태·누락 높이 기여 상한 | `complete` · 0 mm³ |
| 실제 STL 입력→상세검토 상태 | `unknown` · 여러 셸의 겹침·공동 관계 미확정 |

교차한 경계의 합집합에는 원래 정점에 없던 높이에서 다각형 구조가 바뀌는 사건이 생긴다. 따라서 원래 정점 높이만 자르면 한 구간 전체의 면적이 하나의 이차식이라는 전제가 깨질 수 있다. 이는 누락 높이 기여 상한이 0이어도 전체 오차가 0이라는 뜻이 아님을 보여준다.

**이 반례를 사용자 화면이 잘못된 합집합 체적을 정상 제공하는 결함으로 보고하지 않는다.** `load_model`은 두 표면 성분을 기록하고, `run_detail`/작업자는 여러 STL 셸의 관계를 미확정으로 차단한다. 같은 차단 분기는 검토 대상 커밋에도 있다. 이 반례의 목적은 보고서의 긍정적 일반화를 반박하고, 내부 함수를 직접 사용하는 개발자도 적용 전제를 지키도록 하는 것이다.

실행 환경은 Python 3.12.14, NumPy 2.3.5, Trimesh 5.1.0, Shapely 2.1.2 / Windows다. [재현 스크립트](../../validation/v3/claude-review-20260915/overlap_counterexample.py)와 [실제 결과·소스 해시](../../validation/v3/claude-review-20260915/overlap_counterexample.json)를 보존했다. 스크립트는 대상 커밋의 사건 적분 모듈을 Git에서 읽고, 형상은 메모리에서 생성하며 원본 형상 파일을 수정하지 않는다. 내부 단면 의존성은 실행 시점 저장소 코드이고 해당 `src` 영역은 이 검토에서 변경되지 않았다. 사용자 경로 결과에는 실행 당시 관련 파일의 SHA를 별도로 기록했다.

같은 환경에서 `tests/test_cura_records.py::CuraRecordsRegression::test_old_csv_retains_nist_measurements_and_recovers_directions`를 재실행해 **1 passed**를 확인했다. 이는 기존 `d.csv` 방향 복원 계약의 확인이며 새 슬라이서 실험은 아니다.

## 시편으로 기준을 얻는 경로의 범위

ISO/ASTM 52902:2023 공식 소개는 시험물의 기하 성능 평가, 측정 항목과 측정 불확도 요구를 다룬다. 특정 제조 설정이나 하나의 측정법을 대신 정해 주는 규정은 아니다. 따라서 이 표준을 인용했다는 이유만으로 현재 예제나 입력한 기준이 표준에 적합해지는 것은 아니다. 현재 저장소의 KS 캡처에는 누락된 절·부속서가 있다는 기존 기록도 유지한다. [ISO 공식 범위](https://www.iso.org/standard/79683.html).

NIST의 시험물 안내는 사용하는 시스템에서 시험물을 제작하고 공정·장비 설정을 문서화한 뒤 적절한 방법으로 측정하여 기준 형상과 비교하는 흐름을 제시한다. 공개 시험물과 도면·검사 시트가 있지만, 사이트는 해당 파일이 실험적 설계라는 점도 명시한다. 원문을 확인할 경로로 제공할 수 있으며 자체 예제를 이 시험물로 바꿔 부르지 않는다. [NIST 시험물과 검사 자료](https://www.nist.gov/el/intelligent-systems-division-73500/production-systems-group/nist-additive-manufacturing-test), [Moylan et al. 2014 연구 소개](https://www.nist.gov/publications/additive-manufacturing-test-artifact).

프로필 입력으로 이어질 최소 기록은 다음과 같다.

1. 목표 공정·장비·재료·슬라이서와 시험물 버전·원본 SHA를 기록한다.
2. 확인하려는 벽·홀·경사 등의 명목 치수, 제작 방향·위치와 허용오차를 정한다. 장비에 맞지 않는 형상은 무조건 출력하지 않는다.
3. 층 높이·선폭 또는 해당 공정 설정, 서포트·후처리·반복 조건을 기록하고 제작한다.
4. 측정기·방법·불확도와 실제 치수·누락·연결·처짐을 기록한다. 검사 방법이 관측 가능한 형상인지도 확인한다.
5. 요구조건을 만족한 **시험 조건 범위 내 기준**을 프로필에 입력하고 기록 파일을 연결한다. 실패·불확정 결과도 함께 남긴다. 다른 재료·장비·방향으로 적용 범위를 확대할 때 다시 확인한다.

이는 제품 흐름의 개선안이며 이번 소프트웨어 검토에서 새 실물 제작·치수 측정·표준 적합성 평가를 수행했다는 뜻이 아니다.
