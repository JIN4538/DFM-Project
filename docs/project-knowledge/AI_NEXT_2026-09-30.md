# 복합 특징·부위별 개선안·적층 후보 선택 개선

작성: 2026-09-30. 이전 단계의 모델·학습 자료·시험 원본을 보존하면서, 놓치는 특징과 복합 형상의 개선 조합을 보완했다. 새 모델은 기존과 다른 파일 이름으로 저장한다. 같은 후보의 산술 선택 교정과 실제 학습의 추가 기여를 구분한다.

## 사용자에게 달라지는 점

- 중간 절삭으로 벽이 떨어진 관통 특징도 하나의 위치로 묶어 표시한다.
- 형상마다 공구·깊이·지름을 같은 방식으로 일괄 변경하던 후보 외에, 부위별로 다른 조합을 제안한다.
- 검산된 여러 포켓 코너를 한 번에 수정하고 STEP으로 받는다. 포켓별 확대 전후 그림을 제공한다.
- 결론을 먼저 보여주는 기존 흐름을 유지하며 새 모델의 설명을 기본 화면에 추가하지 않는다.

## 최종 선택과 실제 수정 검산

최종 비교 정책 v2는 CNC 형상 변경량·공구 변경량·돌출/지름·변경 개수의 네 항목을 Pareto 비교한다. 기존 교사 파일을 바꾸지 않고 필터 이전 후보를 복구한다. 변경 개수는 원래 정확 비용 함수에 포함돼 있었으므로 이를 빠뜨리면 약간 큰 형상 변경이지만 더 단순한 안을 배제할 수 있다. 독립 두 홀 치수 반례로 이 문제를 검사했다. 추가 후보는 원래 치수·CAD 면 ID·변경 허용 조건을 다시 확인하고 충돌이 더 적은 기존안보다 우선하지 않는다.

실제 코너 STEP 편집은 최대 8개 검산된 서로 다른 포켓을 지원한다. 모든 원래 포켓을 재측정하고 각각 수정의 기하 공식을 대조한 뒤 하나의 OCCT 연산으로 수정한다. 면/모서리 공유와 부피 간섭은 거부한다. 수정 후 단일 솔리드 유효성·바깥 크기·각 수정 부피의 합을 검사한다. 내보낸 STEP을 다시 읽어 부피와 강조할 면 ID를 확인한다. 원본 파일은 바꾸지 않는다. 코너 외 치수 변경이 섞인 제안은 미리보기를 제공하지 않는다.

삼각/사각/육각 포켓의 서로 다른 깊이·반경으로 만든 독립 세 포켓 CAD에서 13모서리 수정·합산 해석 부피 일치를 검증했다. 회전한 CAD에서도 검사했다. 확대 그림은 각 포켓의 실제 공구축 방향을 사용한다. 정상 사용자 흐름에서 자동 공구→검토→전후 보기→포켓 전환·STEP 결과 유지를 검사했다. 시연 파일은 `examples/learning_validation/compound_edits`이며 학습 자료가 아니다.

## 적층과 최종 검증

새 다운로드 없이 공개 DB 원본 300그룹·601,855후보/공정 사례로 트리 앙상블 3개를 실제 학습했다. 45개 다른 그룹으로 선택한 뒤 이전 검색 시험에 등장하지 않은 58그룹·290조건에서 시험했다. 후보 자체의 평균 품질은 좋아졌으나 기존 44개 측정에 추가할 때 더 단순한 방식보다 낮아 **새 가중치를 채택하지 않았다**.

동일 6쿼리 연구에서는 기존 신경망의 하향면 예측에 원본 메시에서 정확히 구한 높이·평면 접촉을 결합하여 마지막 6방향을 골랐다. 먼저 측정한 26+18방향을 유지하고, 선택한 6개를 다시 기하 계산했다. 고분자 PBF 높이 조건에서는 이 마지막 선택에 신경망을 쓰지 않는다. 이 연구 결과를 그대로 최종 제품의 성능으로 표시하지 않는다.

저장된 각 방법의 실제 측정값으로 최종 `enhanced_planning`을 실행했을 때 기존 대비 **48개 개선·240동일·2악화**다. 같은 6회 blind 대조보다 58개 개선·5악화다. 기하만 쓰는 대조 대비 38개 개선·12악화이고 평균 차이의 그룹 신뢰구간이 0을 포함한다. 따라서 **기존 방식보다 좋아진 결과와 신경망 자체의 독립적인 기여를 구분**한다. 새 앙상블은 이 결합 방식보다 실제 최종 선택에서도 낮았다.

마지막 6개 준비/측정 단계 중앙값은 기존 0.634초·결합 0.673초다. 6회가 같아도 정확 높이·접촉 보조 계산 비용이 추가되며 이를 시간에 포함했다. 기존 44개 준비 시간은 이 숫자에서 제외다. 원래 후보 최선값, 실제 방법별 정규화의 최종 선택, 고정 대조 참조의 선택을 별도 기록했다. 검증/시험 방법 수가 달랐던 초기 정규화 기록도 보존했다.

제품 API는 검증된 45°·5개 공정·중점 조합(MEX 균형/서포트, VPP 균형, 금속 PBF 균형, 고분자 PBF 높이)·빌드 공간 미지정·정상 체적 메시·10만 면 이하·기존 v4 모델 SHA에서만 적용한다. 그 밖에서는 기존 검색을 유지한다. 사용자 현재 방향의 중복을 제외한다. 새 API와 제품 수식/측정·분리·원본 SHA·후보 풀 동일성을 검사했다. [적층 학습·비채택·동일 예산 대조 기록](../research/AM_QUERY_SELECTOR_2026-09-30.md), [연구 상태](../../validation/ai-next-2026-09-30/am-selector-final-status.json)를 따른다.

최초 제품 연결은 기존 마지막 6방향을 교체했다. 공개 STEP 14개·70조건의 실제 실행(`guided-public-02`)에서 비교 가능한 65조건 중 1개 개선·62동일·2악화가 있어 이 연결을 수정했다. 새 연결은 **기존 24개 추가 측정을 모두 보존하고 남은 원래 8초 예산 안에서 최대 6개 보완 측정**을 더 한다. GUIDE 이전 실제 후보를 비교 기준으로 고정하여 추가 후보가 기존 점수 범위를 바꾸지 않도록 했다. 기본 정책의 동일 기준 결과 보존이며, 명시적으로 저장한 사용자 선호가 다른 절충안을 선택할 수 있다. 8초는 계산 단계 사이에 검사하는 제한이며 단일 네이티브 계산을 강제 중단하는 보장이 아니다.

따라서 최종 제품의 추가 쿼리 성과는 같은 6쿼리 연구와 계산량이 다르다. 고분자 PBF의 순수 높이 보완 쿼리는 신경망 집계에서 제외하고, STEP 메시 정밀도에 따른 기존 높이 필터를 동일하게 적용한다. 일부 새 쿼리 뒤 실패해도 기존 비교 기준을 보존한다. 화면과 HTML 저장 보고서가 같은 최종 추천 경로를 사용하고, 선택 기준 설명도 같은 고정 범위를 사용한다.

실제 새 제품 경로로 공개 STEP 14개·70조건을 다시 실행한 `guided-public-04`는 비교 가능한 65조건에서 **1개 개선·64동일·악화 0**, 나머지 5조건은 미추천 상태를 유지했다. 결론/방향 표시 불일치 0, 실행 211.01초, 실행 중 소스 SHA 변경 0이다. 기존에 사용한 공개 예제이므로 이 시험은 새로운 독립 일반화 검증이 아니라 제품 통합 회귀다. 처음 실패한 교체 방식 기록과 불완전한 `guided-public-01/03`을 삭제하지 않았다.

배포·통합 검증은 아래 완료 기록을 따른다. 다음 학습은 후보 자체의 regret보다 **이미 측정한 후보에 추가했을 때의 개선량**, 반복 홀의 의미 누락, 검산된 관통부 치수 연결을 우선한다. 이번 보류 시험을 다시 모델 선택 자료로 사용하는 경우 새 독립 시험을 마련한다.
