# 처음 사용하는 AM-DFM

이 도구는 적층제조를 준비할 때 **어디를 확인하고 무엇을 바꿀지** 정하는 데 사용한다. 파일을 넣으면 형상과 조건을 측정하고, 입력 기준과 비교할 수 있는 항목은 그 결과를 설명한다.

## 처음 시작하기

1. 왼쪽에서 내 STEP/STL/3MF 또는 CAD 기준형상을 고른다. 표시된 크기가 의도한 크기인지 확인한다. STL에는 단위가 없으므로 단위와 배율을 직접 정한다.
2. 공정과 위로 향할 방향을 선택한다. 프린터가 정해지지 않았다면 장비와 재료는 미확정으로 두어도 된다. 장비 크기 제한을 켜지 않으면 부품 크기를 제한하지 않는다.
3. **이 형상으로 설계 검토 시작** 또는 왼쪽 **설계 검토**를 누른다.
4. 결과 맨 위의 **먼저 할 일**을 읽고 바로 아래 버튼을 누른다. 다른 항목은 **설계 조치 → 전체 검토 현황**에서 확인한다.

## 결과를 읽는 법

| 표시 | 의미 | 할 일 |
|---|---|---|
| 확인할 후보 있음 | 입력한 기준보다 작거나 확인할 기하 특징이 관측됐다. | 이유를 읽고 강조된 위치를 확인한다. 필요한 경우 방향·형상을 바꾼다. |
| 입력 기준 미만 없음 | 검사한 표본이 내가 넣은 기준 이상이다. | 표시된 검사 범위를 확인하고 다음 항목으로 진행한다. |
| 후보 미검출 | 실제로 검사한 범위에서 해당 종류의 후보가 없었다. | 이 항목에서 우선 수정할 후보가 없다는 뜻으로 읽는다. |
| 기준 미입력 | 측정은 했지만 비교할 기준이 없다. | 장비·재료의 최소 기준과 출처를 입력한다. |
| 검사 전 / 일부 미확인 / 계산 불가 | 미실행, 일부 누락, 결과 없음은 서로 다른 상태다. | 화면이 안내하는 검사를 실행하거나 입력 형상을 확인한다. |
| 크기 제한 미적용 | 장비 크기로 제한하지 않도록 설정했다. | 장비가 정해지면 실제 공간을 입력한다. |

초록색 문장은 **그 문장에 적힌 검사 범위**에 대한 결과다. 주황색 형상은 관측 위치이며 불량 색상이 아니다. 특히 벽 기준 미만이 없을 때에도 가장 짧게 측정한 표본 위치를 주황색으로 표시한다.

## 정밀 검토: 질문부터 선택하기

### 벽 — 입력한 최소 기준보다 얇은가?

**벽 검토 실행**을 누르면 표면의 표본 위치에서 안쪽 법선 방향으로 반대 면까지 거리를 잰다. 화면은 측정 최솟값과 입력 기준을 나란히 보여준다.

예를 들어 브래킷 표본에서 가장 짧은 거리가 **4 mm**라면 다음과 같이 읽는다.

| 입력 조건 | 읽을 결과 | 다음 행동 |
|---|---|---|
| 벽 기준 없음 | 벽은 측정됐지만 비교 기준이 없다. | 같은 화면의 **비교할 최소 벽 기준**을 입력한다. |
| 기준 1 mm, 요청 표본 모두 측정 | 검사한 표본에서 1 mm 미만이 없다. | 가장 짧은 위치를 확인하고 다른 검토로 진행한다. |
| 기준 5 mm | 5 mm보다 짧은 구간이 있다. | 강조 위치가 실제 벽인지 확인하고 두께 증가·형상 수정을 검토한다. |
| 일부 표본 누락 | 측정된 값은 있으나 일부 위치가 미확인이다. | 미확인 구간은 CAD에서 직접 확인한다. |

1 mm와 5 mm는 설명용 예시이며 권장 제조 기준이 아니다. **이 기준으로 벽 다시 검토**를 누르면 새 기준으로 결과를 다시 계산한다. 기준 출처는 왼쪽 **장비·재료와 검토 기준**에 기록한다.

평행한 벽에서는 이 거리를 두께로 해석할 수 있다. 곡면·모서리에서는 다른 의미의 짧은 거리일 수 있고 표본 밖의 더 얇은 위치를 놓칠 수 있다. 따라서 **부품 전체의 최소 두께**라고 읽지 않는다. 하위 5% 거리와 표본 좌표는 측정 방법 펼침 영역에서 볼 수 있다.

### 층간 — 층마다 놓치거나 받쳐 줄 곳이 있는가?

이 검사는 **MEX(FDM)** 전용이다. 실제 슬라이서에서 사용할 층 높이·선폭을 왼쪽 설정과 맞추고 실행한다.

- **선폭보다 가는 단면 후보:** 경로가 빠지거나 원하는 모양대로 채우기 어려울 수 있는 곳이다. 슬라이서 미리보기에서 경로가 남아 있는지 확인한다.
- **아래층 지지 부족 후보:** 이전 층과 설정한 경사 허용 범위를 벗어난 곳이다. 브리지·서포트 경로와 방향 변경을 검토한다.
- **한 층에만 나타나는 후보:** 바로 위·아래 측정 단면에 없는 곳이다. 얇은 돌출부가 설계 의도인지 확인하고 필요하면 두께나 층 높이를 바꾼다.

200층의 세 지표를 모두 확인했고 전부 0이면 **검사한 200개 층에서 세 종류 후보 미검출**을 표시한다. 빈 그래프를 읽을 필요가 없다. 일부 계산이 빠진 경우는 같은 결론을 내리지 않는다.

후보가 있으면 해당 층만 먼저 표시한다. 층을 선택하면 형상 안에 후보가 있는 위치의 경계 상자를 보여준다. 이 상자는 실제 결함 윤곽이나 생성된 서포트가 아니다. 위치 기록은 종류별 최대 50개이고 작은 양수 후보도 면적에서 지우지 않는다.

층 번호는 1부터다. 표시 높이는 층 중간의 검사 평면이므로 슬라이서의 노즐 Z와 층 기준을 맞춰 비교한다. 전체 표의 **미확정**은 0이 아니며 **일부 범위** 값은 그 층 전체에 대한 값이 아니다.

### 단면 — 어느 높이에서 모양과 넓이가 바뀌는가?

단면은 높이별 재료 모양과 넓이를 보는 보조 검사다. **형상 변화 기준**은 검사 높이를 자동으로 정하고 메시 체적을 검산한다. **균등 간격**은 지정한 수의 높이 표본을 비교한다.

실행 후 변화가 가장 크게 관측된 두 단면을 먼저 본다. 파란 점선은 이전 단면, 주황 실선은 현재 단면이다. 점 그래프의 점 하나는 계산한 단면 하나다. 가장 큰 관측 변화가 실제 발생한 정확한 높이나 전체 최대값을 뜻하지는 않는다.

공정별 다음 행동을 함께 확인한다. 예를 들어 VPP에서는 접점·박리 방향·배출구, 금속 PBF에서는 열전달·고정·후가공 접근성을 별도로 검토한다. 이 단면 화면 자체가 힘이나 열변형을 계산하는 것은 아니다. 작은 체적 상대차는 계산 방법 간 일치 정도로 읽고 제작 적합으로 읽지 않는다.

## 방향 선택, 수정 비교, 전달

**방향 비교**에서는 높이 감소·하향면 후보 감소·평평한 바닥 증가 중 목적을 고른다. 먼저 비교할 후보를 선택하면 현재 대비 증감과 배치 모양을 볼 수 있다. 적용하면 해당 방향으로 새 검토가 실행된다. 높이는 출력 시간, 투영면적 합은 실제 서포트량, 접촉면은 접착력을 직접 나타내지 않는다.

**수정 전후**에서는 현재 결과를 변경 전 기준으로 저장하고, 수정한 파일을 같은 조건으로 검토한다. 같은 파일이면 아직 비교할 변경이 없다고 안내한다. 조건이 다르면 무엇을 맞춰야 하는지 알려준다.

**근거·내보내기**에서 사람에게 공유하려면 HTML, 슬라이서로 보내려면 현재 방향 STL, 전체 측정값·설정을 보관하려면 JSON, 원본 CAD를 수정하려면 STEP 입력 원본을 선택한다. HTML에는 미실행·미확인 항목도 함께 기록된다.

실물 제작 전에는 장비·재료·공정 조건과 실제 슬라이서 경로를 확인한다. 이 도구의 기하 검토는 출력 성공이나 강도 검증을 대신하지 않는다.
