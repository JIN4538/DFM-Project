# 적층 검토를 처음 사용할 때

**형상을 고르고 검토를 시작하면, 첫 화면에서 문제와 추천 방향을 확인할 수 있습니다.** 장비·재료를 모르면 기본 설정으로 시작하세요.

1. 왼쪽 **입력 → 적층 시연용 형상**에서 예제를 고릅니다. 내 파일은 **업로드**에서 STEP/STP, STL, 3MF를 넣습니다. 목록은 검색하거나 스크롤해서 고를 수 있습니다.
2. 공정을 선택합니다. 장비·재료·검토 중점은 선택 사항입니다. STL처럼 단위가 없는 파일은 크기를 확인합니다.
3. **이 형상으로 설계 검토 시작**을 누릅니다. 벽·층간·단면의 해당 검토도 함께 진행합니다.
4. 맨 위 **종합 결론**의 우선 조치와 바꿀 수치를 봅니다. **문제 위치 보기**를 누르면 해당 위치가 바로 표시됩니다.
5. 방향 변경을 제안하면 **추천 방향 적용**을 누릅니다. 같은 조건으로 다시 검토한 결과가 나옵니다.
6. **검토 보고서 저장**으로 결과를 보관합니다. 수치를 더 보고 싶을 때만 근거·정밀 검토를 펼칩니다.

| 보고 싶은 것 | 어디서 보나요? | 어떻게 읽나요? |
|---|---|---|
| 먼저 고칠 곳 | 종합 결론 | 표시한 문제와 우선 수정 수치를 봅니다. |
| 얇은 벽 | 문제 위치 → 벽 | 선택한 위치의 거리와 ‘너무 얇다고 볼 벽 두께’ 기준을 비교합니다. 기준은 변경할 수 있습니다. |
| 받침이 필요한 후보 | 문제 위치 → 하향면 | 표시한 면을 보고 추천 방향과 비교합니다. |
| 층 사이의 변화 | 층간 검토 | FFF/FDM에서 층별 선폭·미지지 후보를 살펴봅니다. |
| 높이에 따른 형상 | 단면 | 실제로 계산한 두 높이의 윤곽과 면적을 비교합니다. |
| 방향을 바꾸는 이유 | 방향 비교 | 현재와 추천 방향의 높이·하향면·바닥을 같은 화면에서 비교합니다. |
| 판단의 근거 | 판단 근거·학습 기록·원본 데이터 | 필요할 때 펼쳐 계산 방법과 출처를 확인합니다. |

**수정할 후보가 없다는 결론과 계산하지 못한 항목은 구분합니다.** 미확인 항목은 위치 화면에서 이유를 보고 추가 계산할 수 있습니다. 자동 계산을 이미 마쳤다면 정밀 검토를 다시 누를 필요는 없습니다.

입력 조건을 바꾸면 이전 결과를 숨깁니다. 새 기준으로 **설계 검토**를 다시 눌러주세요. 시연 파일은 **형상 다운로드**에서 한글 이름으로 받을 수 있습니다.
