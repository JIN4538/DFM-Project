# AM-DFM 시연용 형상

2026-09-12 직접 생성한 기하 기능 시연 모델이다. 문헌의 공인 시험편이나 출력 검증 시편은 아니다. 애플리케이션 코드와 기존 자료는 변경하지 않았다.

## 파일과 설정

- `AM_DFM_demo.stl`: 기본 시연용. 벽 두께 0.8 / 1.2 / 2.0mm.
- `AM_DFM_demo_thin_0p3.stl`: 첫 벽만 0.3mm로 바꾼 비교형.
- `preview.html`: 브라우저에서 회전·확대 가능한 기본형 미리보기. 인터넷 연결 불필요.
- `build_demo.py`: 재현용 생성 및 평가 코드. 기존 validation.json을 덮어쓰지 않으므로 재실행 시 새 출력 폴더를 사용한다.
- `validation.json`: 이번 Windows 실행 환경, 코드·STL SHA, 진단 및 평가 원기록.

STL에는 단위 정보가 없으므로 **mm**, 공정 **FDM**, 적층 방향 **+Z**, 장비 **250×250×250mm**, 층 높이 **0.2mm**, 단면 선폭 **0.4mm**로 사용한다. 크기 변경 없이 원본 모드로 먼저 분석한다. 다른 설정에서는 결과가 달라질 수 있다.

전체 외곽은 약 86×67.25×31mm, 베이스는 86×64×3mm이다. 경사 부재 끝이 베이스 밖으로 일부 돌출된다. 불리언 합집합으로 연결한 단일 바디이며, 내보낸 STL을 다시 읽어 검사했다. 두 모델 모두 삼각형 644개이고 열린 경계·비다양체 모서리·중복 면·퇴화 면이 0개이며 면 방향이 일관된다. 검사 통과를 자기교차 전수 검사나 실제 출력 성공으로 해석하지 않는다.

## 형상 배치

| 위치 | 특징 | 설계 치수 |
|---|---|---|
| 앞쪽 Y=5~20 | 세 개의 수직 벽 | 두께 0.8(비교형 0.3), 1.2, 2.0mm |
| 가운데 Y=27~33 | 양끝이 지지된 세 브리지 | 지지점 사이 간격 6, 12, 20mm; 아래 면 높이 Z=21mm |
| 뒤쪽 Y≥40 | 세 개의 경사 부재 | 아래 면의 수평면 기준 각도 30°, 45°, 60° |
| 뒤 오른쪽 | 곡면 천장을 가진 관통 아치 | Y방향 관통 원통 구멍 지름 12mm, 중심 Z=19mm |

이 치수는 기능 차이를 보여주기 위한 설계 선택이다. 제조 가능 한계를 규정하는 문헌값이 아니다. 관통 아치는 곡면·지지 검토용이며 현재 구현하지 않은 수평 구멍 자동 인식 기능의 검증으로 제시하지 않는다.

## 권장 시연 순서: 약 5~7분

1. 기본형을 열고 3D 회전으로 벽·브리지·경사면·아치를 소개한다. “복잡한 연결 구조가 정상인 입력에서 기능을 확인하기 위한 모델”이라고 설명한다.
2. 메시 무결성 통과와 종합 평가 결과를 보여준다. 이번 실행은 eligible, 90.5점이었다. 이 점수는 현재 규칙과 가중치의 결과이며 출력 성공률이 아니다.
3. 단면 슬라이더로 Z≈10mm에서 벽과 경사 부재, Z≈21.1mm에서 브리지 아래 영역, Z≈24~25mm에서 아치 천장 주변을 살펴본다. 지지·브리지 후보를 켜고 실제 표시 위치를 확인한다. 모델이 얇은 베이스와 단순 면을 포함하므로 총점 하나보다 위치 표시를 중심으로 설명한다.
4. 비교형을 같은 설정으로 연다. 메시 무결성은 계속 통과하지만 최소 벽두께 게이트는 0.3mm 벽 때문에 실패한다. 이번 실행은 blocked, 총점 null이었다. “정상 메시와 제조성 기준 충족은 서로 다른 문제”라고 설명한다.
5. 비교형에서 얇은 단면 특징을 켜고 첫 벽을 보여준다. 이번 실행은 얇은 영역이 80개 층에서 검출됐다. 기본형은 이 지표에서 검출 층이 0개였다.

두 파일 모두 단면 155/155층 완료, 지지·브리지 검토 위험 74개 층, 한 층에만 나타나는 영역 1개 층이었다. 마지막 지표는 경사진 부재의 끝부분 등 층간 차이를 나타내며, 이를 독립된 실제 박막이나 출력 실패로 단정하지 않는다.

## 설명의 한계

이는 실제 v2.6 엔진 실행 결과이며 브라우저 UI 조작, 슬라이서 경로 및 실물 출력까지 검증한 기록은 아니다. 촬영 전에 사용 중인 앱에서 같은 설정으로 열어 표시 위치와 조작 순서를 확인한다. 단면 계산 완료는 요청한 평면의 계산 범위를 뜻한다. 이 모델은 기능 시연용이며 알고리즘의 일반적 정확성 검증에는 별도의 독립 형상과 슬라이서·시편 대조가 필요하다.
