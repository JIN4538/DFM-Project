# 이전 버전의 시험 형상과 원본 결과

현재 검토 프로그램은 저장소 루트의 `app.py`와 `amdfm/`을 사용합니다. 이 폴더는 이전 개발 단계에서 만든 시험 형상, 생성 코드, 당시 결과를 원본 바이트 그대로 보존합니다. **여기에 있는 점수·PASS/FAIL·게이트·권장 수치는 당시 버전의 출력이며, AM-DFM 3.0의 현재 판정이나 보편적인 제조 기준이 아닙니다.**

| 폴더 | 형상 | 목적과 출처 |
| --- | ---: | --- |
| [demo-2026-09-12](demo-2026-09-12/) | STL 2개 | 벽·브리지·경사면·수평 구멍을 한 부품에서 비교하는 자체 제작 시연 형상. 원래 작업공간의 `deliverables/demo-2026-09-12/` 전체 파일을 보존했습니다. |
| [rule-models-2026-09-12](rule-models-2026-09-12/) | STL 18개 | v2.6 규칙별 동작을 관찰하기 위해 만든 자체 제작 대조·반례 형상. 원래 `deliverables/rule-models-2026-09-12/` 전체 파일을 보존했습니다. |
| [am-dfm-v1](am-dfm-v1/) | STL 2개 | 원본 `AM-DFM_v1.zip`의 `data/sample_bad.stl`, `data/sample_moderate.stl`. 나중 버전의 동명 파일과 바이트가 달라 별도로 보존했습니다. |

2026-09-12에 자체 제작한 STL은 **mm** 단위로 설계했습니다. STL에는 단위가 내장되지 않으므로 파일 입력 시 mm를 선택해야 합니다. v1의 파일도 단위 정보가 내장되지 않습니다. 과거 파일명에 `bad`, `FAIL`, `gate`, `NA`가 있어도 현재 공정의 제조 가능 여부를 뜻하지 않습니다. 특히 `14_mesh_integrity_FAIL.stl`은 삼각형 하나가 빠진 의도적인 손상 반례입니다.

각 폴더의 `사용안내.md`, JSON, CSV와 생성 스크립트는 **2026-09-12 당시 설명과 계산 결과**입니다. 현재 기능의 사용법은 [AM-DFM 3.0 사용자 안내](../../docs/USER_GUIDE_V3.md)를 따릅니다. 당시 실행 실패나 수치가 현재 버전에서 재현된다고 간주하지 않습니다.

## 생성 코드와 재현

`build_demo.py`, `build_rule_models.py`, `package_models.py`는 원본 보존용입니다. 과거 작업공간의 `study/versions/AM-DFM_v2_6/dfm2` 경로 및 디렉터리 배치를 참조하므로 **이 위치에서 바로 실행하는 명령이 아닙니다.** 기존 출력이 있는 곳에서 실행하지 말고, 재실험 시 별도 빈 출력 폴더와 사용할 엔진 버전·환경을 명시해 실행 경로를 조정한 사본을 사용합니다. 수정한 사본과 새 결과는 원본과 구분해 저장합니다.

v1 원본 압축파일은 저장소의 [AM-DFM_v1.zip](../../AM-DFM_v1.zip)이며 SHA-256은 `e74b3d0b94120d48db41852b536598bb4a40f852e5eed0c811ad7a86a29518c6`입니다. `data/sample_good.stl`은 현재 [cura_run/_samples/sample_good.stl](../../cura_run/_samples/sample_good.stl)과 바이트가 같아 중복 복사하지 않았습니다.

[SOURCE_MANIFEST.json](SOURCE_MANIFEST.json)에 복사한 모든 원본 파일의 작업공간 상대 경로, 저장소 경로, 크기와 SHA-256을 기록했습니다. 복사 후 원본과 SHA-256이 같은지 대조했습니다.
