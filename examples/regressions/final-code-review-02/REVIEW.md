# 최종 독립 코드 검토

범위는 `amdfm/three_mf.py`, `cross_sections.py`, `processes.py`, `detail.py`의 단위·변환·partial/null·timeout 계약이다. 프로덕션 파일을 수정하지 않았으며, 합성 반례와 결과를 이 폴더에 보존했다. 검토한 파일의 SHA-256은 `results.json`에 있다.

## 재현된 문제

**[P2] 직접 부모가 먼저 종료되면 작업 시간 제한이 자식을 종료하지 못한다.** `processes.py`의 timeout 처리에서 `taskkill /PID <직접 부모> /T /F`를 호출한 뒤 제한 없는 `proc.communicate()`로 출력을 배수한다. 직접 부모가 자식을 생성하고 즉시 종료하면 부모 PID가 이미 없어 taskkill이 자식을 찾지 못한다. 자식이 stdout을 상속하면 pipe가 열린 채 남아 두 번째 communicate는 자식이 종료할 때까지 기다린다.

실행 반례는 timeout 0.75초, 직접 부모 즉시 종료, 자식 4초 후 파일쓰기다. 결과는 **4.228174초 후 TimeoutExpired**이며, `orphan-after-timeout.txt`가 작성됐다. 자식이 끝나지 않으면 이 경로에 별도 상한이 없다. 26개 실제 부품에서 이 문제가 발생했다고 주장하지 않지만 작업자·후손을 시간 안에 종료한다는 함수 계약은 재현 가능하게 깨진다.

기존 회귀검사의 직접 부모는 30초 동안 살아 있어 taskkill이 process tree를 찾을 수 있으므로 이 반례와 조건이 다르다. 종료된 부모의 PID 조회에만 의존하지 않는 자식 소유·종료 방식과 출력 배수의 제한을 검토하고, “직접 부모 즉시 종료”를 별도 회귀검사로 추가해야 한다. 이번 재현의 자식은 4초 후 자연 종료했다.

## 통과한 독립 반례

| 반례 | 독립 기준과 결과 |
|---|---|
| 3MF 변환 | 2단계 반사 + 전단 + 비균등 크기 변경 + 3단계 평행이동 + inch 단위. 좌표를 직접 열벡터 행렬식으로 계산해 비교, 최대 좌표 차이 0 mm. 예상 체적 9,438,948.864 mm³ 대비 약 1e-8 mm³ 차이 |
| 테이퍼 단면 | 높이 8 mm, 아래 변 10 mm·위 변 2 mm의 정사각뿔대. 각 높이 면적 `(10-z)^2`, 둘레 `4(10-z)`와 16개 표본 대조, 차이 0. 중점 적분 체적도 직접 합산과 일치 |
| 단면 partial/null | 선분 예산을 20으로 제한해 2개 표본 후 `partial`; 표본 최대는 보존하고 전체 체적은 null 유지 |
| 상세 timeout 재실행 | 성공한 VPP 단면 결과 뒤 0.001초 timeout으로 재실행. 상태 `unknown`, 이전 최대 단면 수치 제거 확인 |

첫 실험 폴더 `final-code-review-01`은 테스트 도구가 `numpy.bool_`를 JSON으로 직렬화하지 못해 중단됐다. 이는 앱 오류가 아니며 첫 기록을 남기고 수정한 실험을 `final-code-review-02`에서 실행했다. 최종 반례 스크립트의 종료 코드 0은 기록을 끝냈다는 뜻이며, `results.json`의 마지막 `passed=false`가 발견된 계약 위반이다.

```powershell
.venv/Scripts/python.exe ../study/random-shape-audit/final-code-review-02/probe.py
```

기록을 덮어쓰지 않으려면 재시험은 스크립트를 새 폴더로 복사한 뒤 실행한다. 이는 제한된 코드 리뷰이며 모든 3MF 규격, 모든 운영체제·하드웨어·임의 형상에 대한 완전 검증이 아니다.
