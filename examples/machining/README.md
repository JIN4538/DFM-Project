# 절삭 기하 검토 기준형상

직접 작성한 OCCT 매개변수 형상입니다. `manifest.json`의 기대값은 생성 치수와 독립 수식이며, 실제 가공 실험·품질 보증 자료가 아닙니다.

재생성: `.venv/Scripts/python.exe scripts/generate_machining_examples.py <새 폴더>`

기존 형상과 SHA 기록을 보존하기 위해 비어 있는 폴더에만 생성합니다. STEP 헤더의 생성 시간이 달라지므로 재생성 파일의 바이트 SHA까지 동일하다는 뜻은 아닙니다.

- 직사각 포켓 바닥 검증: 01, 02, 11. 11의 검토 방향은 +X입니다.
- 반경 비교: 03의 부분 원통면 R3. 곡선 포켓 전체를 인식했다는 뜻은 아닙니다.
- 원통면 구간: 04, 05. 길이는 해당 원통면의 축 구간이며 전체 드릴 깊이가 아닙니다.
- 오인식·미지원 반례: 보스, 밀폐 공동, 열린 채널, 섬이 있는 포켓, 단순 블록.
- 다중 솔리드: 12. 부품 선택 전에는 절삭 특징 검토를 보류합니다.
