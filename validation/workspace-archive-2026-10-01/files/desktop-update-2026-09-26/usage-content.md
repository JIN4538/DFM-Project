# DFM 처음 사용자 안내 — 적층제조·절삭가공

작성 기준: 2026-09-26 저장소의 실제 UI 코드. 최종 제작자는 바탕화면 폴더명·실행 바로가기·실제 실행 검증 결과를 확인하여 1쪽에 넣는다. 아래의 ‘쪽’ 표시는 10쪽 편집안이며 실제 조판에 맞춰 조정할 수 있다. 이미지·설정값을 넣더라도 제조 권장값으로 바꾸어 쓰지 않는다.

## 1쪽 | 이 프로그램으로 무엇을 하나요?

**형상을 넣고, 제조할 때 먼저 확인할 위치와 바꿀 점을 찾는 도구입니다.**

적층제조에서는 얇은 부위, 아래를 향한 면, 출력 방향에 따른 차이와 층별 형상을 살펴봅니다. 절삭가공에서는 선택한 공구와 구멍·모서리·포켓의 치수를 비교하고, 공구 쪽에서 가려지는 표면을 찾습니다.

처음에는 다음 순서만 기억하세요.

**형상 선택 → 조건 입력 → 검토 실행 → 결과 문장 → 위치 확인 → 다음 행동 → 보고서 저장**

이 도구는 ‘그냥 만들어도 된다’는 승인서를 주는 프로그램은 아닙니다. 예를 들어 ‘벽 기준 미만 없음’은 **검사한 위치에서 내가 입력한 벽 기준보다 작은 값이 없었다**는 뜻입니다. 출력 성공률, 강도, 치수 공차 달성 여부까지 확인한 결과는 아닙니다.

### 실행하기

1. 업데이트된 바탕화면 DFM 폴더에서 **START_REVIEW.cmd**를 실행합니다. 이미 설치된 이 컴퓨터에서는 보통 설치를 다시 할 필요가 없습니다.
2. 브라우저에 앱이 열립니다. 기본 주소는 **http://127.0.0.1:8507**입니다.
3. 왼쪽 맨 위 **제조 공정**에 **적층제조 / 절삭가공**이 있는지 확인합니다.
4. 새 컴퓨터의 처음 설치는 폴더 전체를 준비하고 **INSTALL.cmd → START_REVIEW.cmd** 순서로 진행합니다. 실행 파일만 따로 복사하면 필요한 파일을 찾지 못합니다.

제작 중인 이 버전의 범위는 적층제조와 고정축 밀링입니다. 선삭·연속 5축 절삭·사출·프레스 기능은 제공하지 않습니다. 제조 장비가 없어도 예제로 사용법과 형상 변화의 영향을 확인할 수 있습니다.

### 처음 연습할 형상

| 연습 | 왼쪽 입력 | 형상 선택 |
|---|---|---|
| 적층제조 | CAD 기준형상 | 브래킷 · 두께 4 mm |
| 절삭가공 | 절삭 검증 형상 | 직사각 포켓 · 20×12 / 깊이 8 mm |

이 예제들은 계산을 확인하기 위해 만든 CAD 형상입니다. 특정 장비로 제조 성공이 확인된 시편은 아닙니다.

## 2쪽 | 내 형상 넣기와 결과 읽기

### 파일은 무엇을 넣나요?

왼쪽 **입력 → 내 파일**에서 파일을 올립니다.

| 파일 | 이 도구에서 사용하는 정보 | 사용자가 확인할 것 |
|---|---|---|
| STEP / STP | CAD 면·곡면·솔리드, 단위와 형상 치수 | CAD 치수 측정에 권장. 조립체라면 검토할 솔리드 하나를 선택합니다. |
| STL | 삼각형으로 표현한 표면 | 단위가 없습니다. ‘STL 좌표 단위’와 필요 시 ‘최장 외곽 길이 지정’을 설정합니다. |
| 3MF | 메시, 파일에 선언된 단위와 배치 변환 | 슬라이서의 재료·서포트 설정까지 가져오는 것은 아닙니다. |

**절삭 특징의 치수 검토에는 단일 솔리드 STEP/STP을 사용하세요.** STL/3MF에 없는 CAD 원통·포켓 정보를 추측하여 표시하지 않습니다. STEP에 형상이 있다고 해서 도면의 모든 공차·기하공차·표면 요구가 자동으로 읽히는 것도 아닙니다.

STL의 실제 크기를 모른다면 표시된 mm 값은 가정값입니다. **이 치수·배율로 검토하는 것을 확인함**은 선택한 가정을 기록하는 기능이며 원래 치수를 복원하는 기능이 아닙니다. 최장 길이는 전체를 같은 배율로 바꿉니다.

여러 부품이 있는 STEP은 **CAD 솔리드 · 체적순**에서 부품을 하나 고릅니다. **전체 조립체 (배치 미리보기)**는 단일 부품의 정밀 검토와 구분됩니다. STEP의 **CAD 메시 정밀도 → 목표 선형 편차**는 곡면을 화면·메시 계산용 삼각형으로 만드는 정밀도입니다. 작게 설정할수록 계산량이 커질 수 있으므로 처음에는 기본값으로 시작하세요.

### 숫자보다 먼저 읽을 세 가지

**현재 판단 → 확인할 위치 → 다음 행동**을 읽습니다. 원자료 표와 계산 상태는 세부 확인이 필요할 때 펼칩니다.

| 화면의 결과 | 쉬운 뜻 | 다음 행동 |
|---|---|---|
| 확인할 후보 있음 / 조건 확인·수정 검토 | 설정과 비교했을 때 살펴볼 위치가 있습니다. | 위치를 보고 방향·형상·공구를 바꿀지 결정합니다. |
| 입력 기준 미만 없음 / 후보 미검출 | 검사한 범위에서는 해당 문제가 발견되지 않았습니다. | 검사 범위를 확인하고 다음 항목으로 갑니다. |
| 기준 미입력 / 판단에 필요한 정보 부족 | 비교할 기준이 없거나 검사가 끝나지 않았습니다. | 기준을 알면 입력하고, 모르면 미확정으로 둡니다. |
| 일부 미확인 / 계산 불가 | 전부 또는 일부를 측정하지 못했습니다. | 원인과 빠진 범위를 확인합니다. ‘문제 없음’으로 읽지 않습니다. |

주황색은 모든 화면에서 같은 뜻이 아닙니다. 벽 화면의 **주황 ◆는 선택한 점**, 단면 화면의 **주황 실선은 현재 단면**입니다. 항상 범례와 결과 문장을 함께 읽으세요. 3D 그림을 드래그하면 보는 각도만 바뀝니다. 실제 검토 방향은 왼쪽 설정에서 바꿉니다. 마우스 휠은 문서를 스크롤하며 모델 확대는 그림 도구 모음을 사용합니다.

## 3쪽 | 적층제조: 설정하고 전체 결과 보기

1. **제조 공정 → 적층제조**를 선택합니다.
2. 형상을 고르고 표시된 크기를 확인합니다.
3. **적층제조 공정**과 **위로 향할 모델 방향**을 정합니다.
4. **설계 검토** 또는 **이 형상으로 설계 검토 시작**을 누릅니다.
5. 결과 맨 위의 **먼저 할 일**을 읽고 안내 버튼으로 이동합니다.

### 어떤 공정을 고르나요?

| 화면 이름 | 뜻 | 이 도구에서 주로 확인할 내용 |
|---|---|---|
| 재료 압출 · FFF/FDM | 노즐로 재료를 쌓는 방식 | 벽·하향면·바닥·층간·선폭·G-code |
| 액조 광경화 · SLA/DLP | 액상 수지를 빛으로 굳히는 방식 | 벽·하향면·단면 변화·내부 빈 공간 |
| 고분자 분말 베드 융해 · SLS | 고분자 분말을 융합하는 방식 | 벽·단면 변화·내부 공간과 분말 제거 검토 위치 |
| 금속 분말 베드 융해 · LPBF | 금속 분말을 융합하는 방식 | 벽·하향면·단면 변화·내부 공간 |

장비가 아직 없다면 **장비·재료·슬라이서**는 미확정으로 둡니다. **최소 벽·홀 검토 기준**은 아는 값만 입력합니다. 제조사의 같은 재료·장비 조건이나 적용 가능한 측정 자료를 근거로 쓰고, **기준 출처·시편 기록**에 출처를 적습니다. 모르는 값을 채우기 위해 임의의 합격선을 만들지 않아도 형상 측정은 가능합니다.

**빌드 공간과 층 설정 → 장비 크기 제한 적용**은 기본적으로 꺼져 있습니다. 이 상태에서는 부품 크기에 제한을 두지 않습니다. 장비를 정했을 때 켜고 X/Y/Z 공간과 경계 여유를 입력하세요. 입력한 250 mm 등이 보이더라도 체크가 꺼져 있으면 제한으로 적용하지 않습니다.

### ‘설계 조치’에는 무엇이 나오나요?

| 항목 | 있는 이유 / 사용자가 할 일 |
|---|---|
| 입력 형상·실제 크기 | 잘못된 단위, 닫히지 않은 형상, 여러 부품 때문에 결과를 잘못 읽지 않도록 확인합니다. |
| 빌드 공간과 배치 | 지정한 공간에 부품의 외곽이 들어가는지 봅니다. 서포트·래프트 공간까지 보증하지 않습니다. |
| 하향면과 지지 검토 | 선택 각도보다 완만하게 아래를 향한 면을 찾아 방향·경사·지지를 검토합니다. 고분자 SLS에는 FDM의 자립 각도 규칙을 적용하지 않습니다. |
| 바닥 접촉 | FDM에서 평평하게 바닥에 닿는 기하 면적을 봅니다. 실제 접착력은 아닙니다. |
| CAD 원통면·구멍 후보 | 원통의 지름과 방향을 보고 작은 내부 특징을 확인합니다. 원통면 개수는 구멍 개수가 아닙니다. |
| 밀폐 공동·재료 제거 | CAD 안의 닫힌 빈 공간을 찾아 수지·분말 제거를 검토할 곳을 알려줍니다. 배출 성공을 계산하지 않습니다. |
| 얇은 벽·세부 특징 / 단면 | 추가 계산이 필요한 항목입니다. 정밀 검토로 이어갑니다. |

**전체 검토 현황 · 끝난 확인과 남은 확인**을 펼치면 아직 실행하지 않은 검사를 빠뜨리지 않을 수 있습니다.

## 4쪽 | 방향 비교: 무엇을 개선하려고 바꾸나요?

**방향 비교 → 이번에 개선하고 싶은 항목**에서 목적을 선택합니다.

- **높이를 낮추기**: 같은 형상을 더 낮게 배치할 후보를 봅니다.
- **하향면 후보 줄이기**: 지지 검토가 필요한 아래쪽 면의 투영면적 합을 줄일 후보를 봅니다. 해당 값을 사용하는 공정에서만 나옵니다.
- **평평한 바닥 넓히기**: FDM에서 평평한 바닥을 넓힐 후보를 봅니다.

화면 왼쪽은 현재 방향, 오른쪽은 비교 방향입니다. 큰 숫자는 **비교 방향**의 값이고, 증감은 현재 방향과의 차이입니다. 한 목적의 첫 후보라고 모든 조건에서 더 좋은 것은 아닙니다. 부품 높이는 작아지지만 하향면은 늘어날 수 있습니다.

1. 첫 후보의 그림과 수치를 봅니다.
2. **비교할 방향 · 적용 전 미리보기**에서 다른 후보도 선택합니다.
3. 채택하려면 **이 방향으로 검토**를 누릅니다. 미리보기 선택만으로 적용되지는 않습니다.

기본은 대각선을 포함한 26방향 비교입니다. **대각선 포함 26방향 비교**를 끄면 기본 6축을 비교합니다. 현재 지정 방향도 포함되며 **주요 면 방향까지 비교**를 켜면 주요 면에 맞춘 후보가 추가됩니다. 모든 연속 각도를 탐색하여 최적 방향을 찾는 기능은 아닙니다.

**위로 향할 모델 방향 → 직접 각도 입력**도 가능합니다. 기울기 0°는 모델 +Z, 90°는 XY 평면, 180°는 −Z입니다. 방위각은 모델 +X에서 +Y 쪽으로 잽니다. 예를 들어 기울기 45°·방위각 0°는 모델 +X와 +Z 사이 방향을 프린터의 위쪽으로 향하게 합니다.

### 이 숫자는 무엇을 뜻하지 않나요?

| 숫자 | 해석 |
|---|---|
| 높이 | 부품의 배치 높이입니다. 실제 출력 시간은 아닙니다. |
| 하향면 투영면적 합 · 중복 포함 | 후보 면을 바닥 쪽으로 투영해 합한 값입니다. 겹친 면적을 중복 포함할 수 있고 실제 서포트량은 아닙니다. |
| 평평한 바닥 면적 | 기하학적으로 바닥과 평평하게 만나는 면적입니다. 첫 층 접착력은 아닙니다. |
| 탐색 각도 45° | 사용자가 후보를 찾기 위한 조건입니다. 모든 프린터의 출력 한계가 아닙니다. |

방향을 정했다면 **정밀 검토**로 이동합니다. 방향·공정 조건을 바꾼 뒤에는 그 조건으로 검토를 다시 실행해야 합니다.

## 5쪽 | 정밀 검토 ① 벽: 기준보다 얇은 곳이 있나요?

**정밀 검토 → 벽 → 벽 검토 실행**을 누릅니다. 표면의 여러 위치에서 안쪽 방향으로 반대 면까지 거리를 재고, 입력한 벽 기준과 비교합니다.

이 검사의 목적은 **가장 먼저 확인할 얇은 위치를 찾는 것**입니다. 평행한 벽에서는 두께에 해당하지만 곡면·모서리에서는 벽두께와 다른 짧은 거리를 잴 수 있습니다. 모든 점을 재지 않으므로 화면 최솟값을 부품 전체의 최소 두께라고 단정하면 안 됩니다.

### 브래킷으로 연습하기

1. **CAD 기준형상 → 브래킷 · 두께 4 mm**를 고릅니다.
2. **재료 압출 · FFF/FDM**, **+Z**를 선택하고 **설계 검토**를 실행합니다.
3. **정밀 검토 → 벽**에서 결과를 확인합니다. 결과가 없거나 일부만 계산됐다면 **벽 검토 실행**을 누릅니다.
4. **표본에서 가장 짧게 측정한 거리**를 봅니다. 기준형상에서는 4 mm를 확인하는 연습입니다.
5. **이 화면에서 벽 기준 입력·변경 → 비교할 최소 벽 기준 (mm)**에 5를 넣고 **이 기준으로 벽 다시 검토**를 누릅니다. 4 mm가 5 mm보다 작기 때문에 확인 후보가 생깁니다.
6. 같은 방식으로 기준을 1로 바꾸면, 요청 표본이 모두 측정된 경우 ‘검사한 표본에서 1 mm 미만 없음’으로 읽습니다.

**여기서 1 mm와 5 mm는 화면을 익히기 위한 가정값이며 제조 권장 기준이 아닙니다.** 기준을 낮춰 표시가 달라져도 부품을 두껍게 만든 것은 아닙니다. 실제 설계 개선은 CAD 형상을 바꾸고 다시 비교해야 합니다.

### 어디를 보나요?

**확인할 측정 위치 · 짧은 거리순**에서 점을 고릅니다. 주황 ◆와 숫자가 선택한 점입니다.

- 기준 미입력: 짧은 거리는 진한 파랑, 긴 거리는 옅은 파랑입니다.
- 기준 입력: 붉은 ◆는 기준 미만, 회색 ●는 기준 이상으로 측정된 점입니다.
- **반대쪽·내부 표본도 보기**를 켜면 내부 점을 찾기 쉽습니다.

**측정 방법·표본과 기준 출처**에는 유효 표본 수, 좌표, 하위 5% 거리 등이 있습니다. 하위 5%도 측정 표본의 통계이며 부품 전체 두께 분포를 뜻하지 않습니다.

작은 단일 형상은 첫 설계 검토에서 자동으로 벽을 함께 확인할 수 있습니다. 자동 계산 예산은 5초, 수동 벽 검토는 60초입니다. 계산 준비·화면 표시 시간은 별도입니다. 시간 초과는 ‘기준 만족’이 아닙니다.

장비가 없어 기준을 모를 때는 값을 비워 두고 측정 위치를 확인하세요. **실측으로 최소 벽·홀 기준을 정하는 방법**과 CSV는 향후 외부 시험·측정 자료를 정리할 때 사용할 수 있습니다. CSV 작성만으로 기준이나 성공률이 자동으로 정해지지는 않습니다.

## 6쪽 | 정밀 검토 ② 층간: 출력 경로를 확인할 곳은 어디인가요?

**정밀 검토 → 층간**은 **재료 압출 · FFF/FDM 전용**입니다. 다른 공정에서는 벽과 단면을 사용합니다.

1. 왼쪽 **빌드 공간과 층 설정**에서 실제 슬라이서와 같은 **층 높이**와 **MEX 명목 선폭**을 입력합니다.
2. 설정을 바꿨다면 **설계 검토**를 눌러 적용합니다.
3. **정밀 검토 → 층간 → 층간 검토 실행**을 누릅니다.

장비가 없으면 기본 층 높이 0.2 mm·선폭 0.4 mm를 탐색용으로 사용할 수 있지만 실제 장비의 검증된 값으로 설명하지 않습니다. 층간 검토는 입력한 층 높이에 맞춘 검사이며 슬라이서의 실제 경로를 만드는 기능은 아닙니다.

| 찾는 후보 | 왜 살펴보나요? | 다음 행동 |
|---|---|---|
| 선폭보다 가는 단면 | 가는 부분이 경로에서 빠지거나 다르게 채워질 수 있습니다. | 슬라이서 미리보기에서 그 부분의 압출 경로가 남아 있는지 봅니다. |
| 아래층 지지 부족 | 이전 층과 설정한 경사 범위를 기준으로 받침이 부족할 수 있는 부분입니다. | 브리지·서포트 경로를 보고 방향이나 형상을 바꿀지 검토합니다. |
| 한 층에만 나타나는 부분 | 이웃 검사 단면에 없는 얇은 형상이 관측됐습니다. | 설계 의도인지 확인하고 두께·층 높이를 검토합니다. |

후보가 있으면 **확인할 층만 모았습니다 → 위치를 확인할 층**에서 고릅니다. 그림의 사각형은 후보가 있는 범위이며 실제 결함이나 서포트 형상이 아닙니다. 표시 높이는 층 중간의 검사 평면이므로 슬라이서 노즐 Z와 층 기준을 맞춰 봅니다.

모든 층에서 세 지표가 0이고 빠진 계산이 없다면 ‘검사한 층에서 세 종류 후보 미검출’입니다. 일부가 **미확정**이면 같은 결론을 내리지 않습니다. 0과 빈 값은 다릅니다.

### 실제 슬라이서 경로와 대조하기

FDM의 정밀 검토 화면 아래 **슬라이서 경로 확인 · G-code**를 펼칩니다.

1. **근거·내보내기 → 현재 방향 STL · mm**를 저장합니다.
2. 사용할 슬라이서에서 mm로 읽고 같은 방향·배율로 슬라이싱합니다.
3. 정밀 검토 화면으로 돌아와 **Marlin 계열 G0/G1 G-code**에 파일을 올립니다.
4. **필라멘트 지름**을 맞추고 **노즐 Z (mm)**를 골라 경로를 확인합니다.

그림의 선은 압출 경로 중심선입니다. 실제 비드 폭·출력물·강도를 보여주는 것은 아닙니다. ‘일부 명령 해석 불가’가 나오면 원래 슬라이서에서도 확인합니다. 모델과 G-code의 파일·배율·방향 일치는 자동 검증하지 않습니다.

**사용법 연습 · 현재 부품과 무관한 Cura 예제 보기**는 조작 연습용입니다. 이 예제의 경로를 현재 부품의 결과로 읽지 마세요. 필요한 경우 **G-code 검토 JSON**으로 경로 읽기 결과를 보관합니다.

## 7쪽 | 정밀 검토 ③ 단면: 어느 높이에서 모양이 달라지나요?

**정밀 검토 → 단면 → 단면 검토 실행**을 누릅니다. 단면은 형상을 수평으로 잘라 본 재료의 모양과 넓이입니다. 넓이가 갑자기 달라지는 높이, 얇은 분기, 내부 공간을 확인하는 데 씁니다.

처음에는 **단면 계산 방법·표본 수 → 자동 · 가능한 방법으로 단면 확인**을 그대로 사용합니다.

| 방법 | 언제 사용하나요? | 주의할 점 |
|---|---|---|
| 자동 · 가능한 방법으로 단면 확인 | 처음 사용할 때 | 형상 변화 기준을 먼저 시도하고, 계산 전 예산이 부족하면 균등 표본으로 전환합니다. 전환 이유가 결과에 나옵니다. |
| 형상 변화 기준 · 체적 정밀 검산 | 형상 구간을 반영한 단면과 부피 검산이 필요할 때 | 계산 한도가 있으며 복잡한 형상에서 완료하지 못할 수 있습니다. |
| 균등 간격 · 높이별 비교 | 정해진 개수로 높이별 모양을 살펴볼 때 | 표본 사이의 아주 얇은 높이 구간을 놓칠 수 있습니다. 실제 출력 층 수가 아닙니다. |

### 결과는 이 순서로 읽으세요

1. **계산 상태**: 요청한 단면을 모두 계산했는지 확인합니다.
2. **형상에서 확인한 내용**: 비교한 높이와 면적 변화를 읽습니다.
3. **다음에 할 일**: 선택 공정에 맞춰 무엇을 확인해야 하는지 읽습니다.
4. **변화가 가장 크게 관측된 두 단면 보기** 또는 **살펴볼 단면 · 높이와 넓이로 선택**으로 위치를 고릅니다.

왼쪽은 단면 모양입니다. **파란 점선은 이전 단면**, **주황 실선은 현재 단면**입니다. 오른쪽 그래프는 높이와 단면 넓이입니다. **■ 이전 단면, ◆ 현재 단면, ● 다른 단면**이며 점 하나가 실제 계산한 표본입니다. 두 점 사이의 정확한 변화 높이까지 확인한 것은 아닙니다.

**전체 측정값 · 항목 뜻과 미확정 사유**에는 면적, 둘레, 떨어진 재료 영역 수와 빈 공간 경계 수가 있습니다. ‘앞 단면과 달라진 넓이’는 두 모양을 겹쳤을 때 서로 겹치지 않는 넓이로, 위험 점수가 아닙니다. 면적/둘레의 단위는 mm이며 벽두께나 힘이 아닙니다.

**계산 확인 · 부피 검산과 적용 범위**의 부피 차이가 아주 작으면 같은 메시를 두 방법으로 계산한 값이 잘 맞는다는 뜻입니다. 출력 합격률이 아닙니다. 부분 결과의 ‘확인한 구간의 부피 합’과 ‘빠진 높이 구간의 부피 기여 상한’도 전체 CAD 정확도를 보증하는 오차 범위는 아닙니다.

### 같은 단면이라도 공정에 따라 다음 행동이 다릅니다

| 공정 | 단면에서 확인한 뒤 이어갈 일 |
|---|---|
| FDM | 가는 부위·천장·분기를 층간 검토와 슬라이서 경로에서 확인합니다. |
| SLA/DLP | 장비의 분리 방식, 서포트 접점과 수지 배출 경로를 확인합니다. 단면만으로 박리력·흡착을 계산하지 않습니다. |
| SLS | 두껍고 얇은 부분의 전환, 분말 제거 통로와 냉각 조건을 확인합니다. FDM 지지 규칙을 적용하지 않습니다. |
| 금속 LPBF | 열전달·고정용 서포트, 제거와 후가공 접근성을 확인합니다. 온도·잔류응력을 계산한 값은 아닙니다. |

## 8쪽 | 절삭가공: 공구를 정하고 포켓을 확인하기

왼쪽 **제조 공정 → 절삭가공**을 선택합니다. 현재 범위는 **원통형 엔드밀을 사용하는 고정축 밀링의 기하 검토**입니다.

1. **입력 → 절삭 검증 형상 → 직사각 포켓 · 20×12 / 깊이 8 mm**를 선택합니다.
2. **공구가 오는 방향 → +Z · 위쪽에서**를 선택합니다. 화살표는 부품에서 공구 쪽을 향하고 공구는 그 반대쪽으로 들어옵니다.
3. 공구 치수를 입력하고 **절삭 설계 검토**를 누릅니다.

| 입력 | 뜻 | 처음 연습할 가정값 |
|---|---|---|
| 엔드밀 지름 (mm) | 원통형 절삭 공구의 지름 | 4 |
| 날 길이 (mm) | 실제 절삭날이 있는 축방향 길이 | 10 |
| 장착 후 돌출 길이 · 끝~홀더 (mm) | 장착한 공구 끝에서 홀더 앞면까지의 거리 | 15 |

**4 / 10 / 15 mm는 사용법을 위한 가정이며 추천 공구가 아닙니다.** 실제 공구를 모르면 비워 두어도 CAD 특징은 측정됩니다. 재료·장비명은 기록용이며 절삭력·처짐을 자동 계산하는 입력이 아닙니다. 출처는 **재료·장비·근거와 추가 기준 → 공구·기준의 출처**에 기록합니다.

결과 상단 **이 결과에 적용된 공구 조건**으로 사용한 값을 확인합니다. 새 값을 입력한 뒤에는 **절삭 설계 검토**를 다시 눌러야 적용됩니다.

### 포켓 결과에서 무엇을 읽나요?

**확인할 항목 → 직사각 포켓 바닥과 내부 직각**을 선택합니다. 이 예제의 폭은 12 mm, 길이는 20 mm, 국소 벽높이는 8 mm입니다. 예제 공구는 지름 4 mm로 폭보다 작고, 날 10 mm·돌출 15 mm는 벽높이 8 mm보다 깁니다. 하지만 포켓의 날카로운 내부 직각은 둥근 엔드밀로 그대로 만들 수 없어 확인 항목이 남습니다.

**다음 행동:** 모서리를 둥글게 바꾸거나 코너 여유를 설계하고, 실제 진입 경로·고정·가공 요구를 확인합니다. ‘치수표의 초과 여부가 모두 아니오’라고 해도 전체 가공 통과가 아닙니다.

### 공구 변경 효과를 보는 추가 연습

**둥근 포켓 · 모서리 R3 / 깊이 8 mm**를 선택합니다. +Z에서 엔드밀 지름만 8 mm로 바꾸어 실행합니다. **공구축과 나란한 오목 원통면**에서 공구 반경 4 mm가 형상 반경 3 mm보다 크다는 차이를 봅니다. 지름을 4 mm로 바꾸고 다시 실행하면 이 반경 비교의 문제는 없어집니다. 전체 진입과 실제 가공 성공까지 검증된 것은 아닙니다.

둥근 포켓은 현재 ‘직사각 포켓의 폭·깊이’ 인식 범위 밖입니다. 오목 원통면 반경은 별도 항목으로 측정됩니다. 이것은 한 부품의 모든 특징이 같은 수준으로 인식되지 않을 수 있다는 예입니다.

## 9쪽 | 절삭가공: 각 항목과 가림 결과 읽기

**확인할 항목 → 결과 문장·다음 행동 → 치수표 → 확인할 위치** 순서로 봅니다.

| 항목 | 확인하는 내용 | 결과 다음에 할 일 |
|---|---|---|
| 절삭 검토 입력 | 단일 솔리드 STEP인지, CAD를 해석할 수 있는지 | 조립체라면 부품 하나를 선택합니다. 입력이 불명확하면 먼저 CAD를 확인합니다. |
| CAD 면 정보와 특징 인식 범위 | 읽은 면과 인식하지 못한 경계·곡면 | 미인식 특징을 CAD/CAM에서 직접 확인합니다. |
| 원통형 내부 특징과 공구 | 내부 원통면의 지름·축 구간과 공구 방향·지름·돌출 길이 | 다른 접근 방향이 필요한지, 공구가 너무 큰지 확인합니다. 원통면 수는 홀 수, 구간 길이는 전체 홀 깊이가 아닙니다. |
| 공구축과 나란한 오목 원통면 | 형상의 오목한 반경과 공구 반경 | 공구가 크면 작은 공구나 큰 설계 반경을 검토합니다. 모든 오목면을 포켓 코너로 확정하지 않습니다. |
| 직사각 포켓 바닥과 내부 직각 | 직선 4변 바닥·같은 높이 네 수직 벽의 폭과 국소 벽높이 | 내부 직각, 폭, 날 길이, 돌출 길이를 함께 봅니다. 섬·곡선·분할 경계 포켓은 범위 밖입니다. |
| 선택 방향의 표면 가림 | 선택한 표면 점에서 공구 방향으로 향하는 직선이 다른 면에 막히는지 | 다른 셋업과 실제 공구·홀더 충돌을 CAM에서 확인합니다. |

**확인할 위치**에서 CAD 면을 선택하면 해당 위치가 강조됩니다. 파랑은 측정·추가 확인 위치, 주황은 해당 항목에서 조건 확인이 필요한 위치입니다. 회색은 가공 통과 표시가 아닙니다.

### ‘날 길이’와 ‘돌출 길이’는 왜 따로 있나요?

날 길이는 실제로 깎는 날의 길이입니다. 돌출 길이는 홀더 앞면부터 공구 끝까지 밖으로 나온 길이입니다. 전체 공구 길이와 서로 다를 수 있습니다. 벽이 날보다 높아도 여러 단계로 깎거나 목부 공구를 사용할 수 있어 그 이유 하나로 가공 불가라고 정하지 않습니다. 돌출 길이가 충분해도 홀더가 주변 형상·고정구와 부딪힐 수 있습니다.

표의 **수치 경계**는 숫자 계산 오차 수준에서 같은 값이라는 뜻입니다. 공구 지름이 포켓 폭과 같다고 실제 가공 여유가 있다고 보장하지 않습니다. **내부 바닥 후보·치수 미확정**도 열린 포켓을 확인했다는 뜻은 아닙니다.

**원통 구간 길이/지름 검토 기준 (선택)**은 원통면에서 측정한 길이÷지름을 비교할 사용자 기준입니다. 전체 홀 깊이의 비율이 아니며, 적용할 근거가 없으면 비워 둡니다.

### 가림 검사는 어떻게 실행하나요?

왼쪽 **선택 방향에서 가려진 표면도 확인**을 켜고 **절삭 설계 검토**를 다시 누릅니다. **확인할 항목 → 선택 방향의 표면 가림**에서 **표시할 표본**을 고릅니다.

| 표본 | 읽는 방법 |
|---|---|
| 앞이 가려진 표본 | 다른 면이 앞을 막습니다. 다른 방향·순서를 검토합니다. |
| 공구 반대쪽을 향한 표본 | 반대쪽 셋업이 필요한 면인지 봅니다. |
| 공구축과 평행한 면의 표본 | 측면 가공과 공구 반경·진입 방법을 따로 봅니다. |
| 계산 미확정 표본 | 원인과 계산 범위를 확인합니다. 가림 없음으로 바꾸어 읽지 않습니다. |
| 직선이 가려지지 않은 표본 | 검사한 점의 직선이 막히지 않았습니다. 실제 굵기가 있는 공구·홀더의 통과를 확인한 것은 아닙니다. |

이 검사는 직선 표본 검사입니다. 부품 전체의 가공 가능 면적률이나 성공 확률을 계산하지 않습니다. 미표본 면 수와 **이 결과가 확인한 범위**를 함께 확인하세요.

## 10쪽 | 비교·저장·자주 생기는 문제

### 설계를 바꿨다면

적층제조의 **수정 전후 → 현재 결과를 변경 전 기준으로 저장**을 누릅니다. 수정한 CAD를 같은 공정·기준·방향·배율로 검토한 뒤 다시 **수정 전후**를 엽니다. 조건이 다르면 개선량을 비교할 수 없다는 안내가 나옵니다. 부피나 벽 거리가 늘었다고 기능·강도가 좋아졌다고 자동 판단하지 않습니다. 이 전후 비교 화면은 현재 적층 기능입니다.

### 어떤 파일로 저장하나요?

| 목적 | 적층제조: 근거·내보내기 | 절삭가공: 근거와 내보내기 |
|---|---|---|
| 사람이 읽을 보고서 | 검토 보고서 HTML | 절삭 검토 HTML |
| 측정값·조건의 원자료 보관 | 전체 결과 JSON | 절삭 검토 JSON |
| 원본 CAD 수정·보관 | 입력 원본 | 입력 형상 원본 |
| 슬라이서로 가져갈 배치 | 현재 방향 STL · mm | 해당 기능 없음 |

**HTML과 JSON을 함께 저장하세요.** HTML은 브라우저에서 읽는 보고서이고, JSON은 계산값·설정·미확인 범위를 남기는 기록입니다. HTML 안의 형상 참고도는 정밀 도면을 대신하지 않습니다. 추가 정밀 검토를 실행하면 그 뒤에 내려받은 보고서에 새 결과가 반영됩니다.

근거 목록에서는 각 문헌을 **왜 인용했는지·어느 범위에 쓰는지·어느 쪽을 확인했는지** 볼 수 있습니다. 표준을 인용했다는 것과 실제 부품이 표준에 적합하다는 것은 다릅니다.

### 막혔을 때

| 상황 | 바로 해볼 일 |
|---|---|
| 절삭가공 메뉴가 없다 | 업데이트한 폴더의 START_REVIEW.cmd를 실행했는지 확인합니다. 오래된 바로가기는 이전 폴더를 열 수 있습니다. |
| 포트 8507 사용 중 | 같은 폴더의 정상 앱은 새 시작 파일이 재사용합니다. 다른 앱이 사용 중이면 기존 작업을 함부로 종료하지 말고 다른 포트로 실행합니다. 예: START_REVIEW.cmd --port 8508 |
| 설치 창이 닫히거나 실패 | logs 폴더의 install 로그와 폴더 전체가 있는지 확인합니다. 설치·시작 파일 하나만 따로 실행하지 않습니다. |
| 숫자가 이상하게 크거나 작다 | STL 단위·배율을 먼저 봅니다. 원래 치수를 모르면 결과도 가정값입니다. |
| 조건을 바꿨는데 결과가 예전 값이다 | 설계 검토 또는 절삭 설계 검토를 다시 누르고 적용 조건을 확인합니다. |
| 표가 0이거나 미확정이다 | 0은 해당 검사 범위의 후보 없음, 미확정은 판단하지 못함입니다. 서로 바꾸어 읽지 않습니다. |
| 복잡한 파일에서 오래 걸린다 | 단일 솔리드를 선택하고, 단면은 자동 방법으로 시작합니다. 표시된 계산 한도와 빠진 범위를 확인합니다. |

장비가 없는 지금은 **형상·방향·공구 조건을 바꾸면 측정 결과와 확인 위치가 어떻게 바뀌는지**를 중심으로 사용하세요. 실제 제조를 의뢰할 때는 이 보고서와 원본 CAD를 공정 담당자에게 전달하고, 남은 공차·재료·고정·경로·품질 요구를 함께 확인하면 됩니다.

- 실제 코드 확인: app.py의 공통 sidebar, 적층 입력/결과 5탭, 정밀 검토 3질문, G-code, 전후·내보내기; amdfm/detail_view.py·section_view.py·profiles.py·evidence.py·analysis.py; dfm/machining_view.py·machining.py; CAD 및 machining manifest. 기존 두 사용 안내서를 코드와 대조함.

- CNC의 ‘날 길이 비교’는 포켓의 국소 벽높이이며 원통 전체 드릴 깊이 비교로 설명하면 틀림. 원통 구간 길이/지름 추가 기준은 선택 입력이며 보편적 합격선 없음.

- AM 브래킷 표본4mm 사례는 현재 USER_GUIDE 및 예제 정의/코드와 일치. 5/1mm 기준은 가정이며 실제 제조 권장값 금지.
