# DFM 사용 안내

적층제조와 절삭가공 · 2026년 9월 26일 바탕화면 업데이트 기준

이 도구는 “어디를 확인하고, 어떤 조건이나 형상을 바꿀지” 찾는 설계 검토 도구입니다. 형상 측정과 조건 비교를 제공하며, 실제 제작 성공 여부나 성공 확률을 판정하지는 않습니다.

### 처음에는 이 순서로 시작하세요

**1. 실행** 바탕화면 AM-DFM_v3_0 폴더에서 START_REVIEW.cmd를 더블클릭합니다. 이미 설치된 현재 PC에서는 INSTALL.cmd를 다시 실행할 필요가 없습니다.

**2. 공정과 형상 선택** 왼쪽 제조 공정에서 적층제조 또는 절삭가공을 고릅니다. 처음에는 내장 예제로 연습하고, 익숙해지면 내 STEP 파일을 넣습니다.

**3. 조건 확인 후 검토** 방향과 알고 있는 조건을 입력하고 설계 검토 또는 절삭 설계 검토를 누릅니다. 모르는 장비·공구 기준은 비워 둡니다.

**4. 결과를 행동으로 연결** 먼저 할 일 또는 다음 행동을 읽고 표시된 위치를 확인합니다. 필요한 조건·형상을 바꾸어 다시 검토한 뒤 결과를 저장합니다.

### 필요한 쪽만 찾아 읽으세요

| 궁금한 내용 | 쪽 |
| --- | --- |
| 파일 선택, 크기, 장비가 없는 경우 | 2 |
| 적층 결과와 방향 비교 | 3 |
| 정밀 검토: 벽 / 층간·G-code / 단면 | 4 / 5 / 6 |
| 절삭 시작과 공구 입력 / 절삭 결과 해석 | 7 / 8 |
| 수정 전후 비교, 저장, 자주 생기는 문제 | 9 |


**읽기 팁** 브라우저를 넓게 열고 왼쪽 설정을 마쳤으면 사이드바를 접으세요. 모델은 드래그로 회전하고, 확대·축소는 그림의 Zoom 도구를 사용합니다.

## 1  파일과 검토 조건 준비

### 내 파일은 STEP부터 사용하세요

| 입력 | 어떻게 사용하나요? |
| --- | --- |
| STEP / STP | 두 확장자는 같은 STEP 형식입니다. CAD 곡면·솔리드를 활용하므로 절삭의 홀·반경·포켓 검토에 적합합니다. 선언된 단위를 읽어 mm로 변환합니다. |
| STL | 삼각형 표면 형상입니다. 단위가 없으므로 STL 좌표 단위와 배율을 확인해야 합니다. 적층 기하 검토에 사용할 수 있습니다. |
| 3MF | 형상과 선언된 단위를 읽습니다. 절삭에서 STEP과 같은 CAD 특징 치수 분석을 제공하는 것은 아닙니다. |


STEP에는 형상의 실제 크기가 들어 있습니다. 그러나 원래 CAD의 설계 이력·치수 구속·공차 표시가 모두 전달되는 것은 아닙니다. 현재 도구는 설계 공차와 PMI를 해석하지 않습니다.

### 형상 선택 후 확인할 세 가지

**1. 크기** 표시된 가로·세로·높이(mm)가 의도한 크기인지 봅니다. 인터넷에서 받은 형상의 실제 크기를 모르면 화면에 나온 크기를 확정 설계치수로 믿지 않습니다.

**2. 부품 수** 조립체 STEP은 CAD 솔리드 · 체적순에서 검토할 부품 하나를 고릅니다. 여러 부품 전체를 하나의 부품처럼 판단하지 않습니다.

**3. 화면의 입력 안내** 단위·닫힌 형상·CAD 유효성 관련 안내를 확인합니다. CAD 메시 정밀도를 높이면 곡면 표현이 촘촘해질 수 있지만 계산량도 늘며, 파일 자체의 오류를 고치지는 않습니다.

### 장비가 없어도 이렇게 검토할 수 있습니다

장비·재료는 미확정으로 두고, 모르는 최소 벽·홀 기준이나 공구 치수는 비워 둡니다. 먼저 측정값과 위치를 확인하고, 가정 조건으로 비교할 때는 기준 출처에 “설명용 가정”이라고 적습니다.

적층의 빌드 공간과 층 설정에서 장비 크기 제한 적용을 끄면 부품 크기를 제한하지 않습니다. X·Y·Z 공간 숫자가 보이더라도 제한을 켜지 않았다면 크기 합격 기준으로 적용하지 않습니다.

**다음 단계** 실제 조건이 생기면 제조사의 해당 장비·재료 조건이나 공구 자료를 입력하고 출처를 기록합니다. 입력만 바꾼 뒤 이전 결과를 읽지 말고 실행 버튼을 다시 누르세요.

## 2  적층 결과와 방향 비교

왼쪽에서 적층제조 공정과 위로 향할 모델 방향을 고르고 설계 검토를 실행합니다. 결과 보기 메뉴는 설계 조치 → 방향 비교 → 정밀 검토 → 수정 전후 → 근거·내보내기로 이어집니다.

### 설계 조치에서 먼저 볼 것

맨 위 판단과 먼저 할 일을 읽습니다. 강조할 검토 항목을 고르면 이유·수치·위치를 함께 볼 수 있습니다. 전체 검토 현황에는 끝난 확인과 남은 확인이 나옵니다.

| 표시 | 사용자 입장에서의 뜻 |
| --- | --- |
| 확인할 후보 있음 | 강조된 위치를 확인하고, 이유에 맞게 조건·방향·형상 수정을 검토합니다. |
| 후보 미검출 / 입력 기준 미만 없음 | 검사한 범위에서 해당 후보가 없다는 뜻입니다. 다른 항목의 검사와 미확인 범위는 남을 수 있습니다. |
| 기준 미입력 / 검사 전 | 측정값과 비교할 기준을 넣거나 해당 검사를 실행해야 합니다. |
| 일부 미확인 / 계산 불가 | 완료하지 못한 범위를 확인합니다. 빈칸을 0 또는 통과로 읽지 않습니다. |


검토 항목은 하향면·지지, 벽, CAD에서 인식한 홀·내부 형상, 배치 크기 등입니다. STEP과 STL처럼 입력 형식이 다르면 확인 가능한 항목도 달라집니다. 주황색은 선택 항목의 확인 위치이며, 색만으로 제작 불가를 뜻하지 않습니다.

### 방향 비교는 목적을 먼저 정합니다

**1. 목적 선택** 이번에 개선하고 싶은 항목에서 목적을 고릅니다. 높이를 낮추기, 하향면 후보 줄이기, 평평한 바닥 넓히기 등이 있으며 공정에 따라 제공되는 목적이 다릅니다. 바닥 넓히기는 FDM에서 표시됩니다.

**2. 현재와 비교 방향 대조** 비교할 방향 · 적용 전 미리보기의 큰 수치는 비교 방향의 값입니다. 증감은 현재 방향과의 차이입니다. 두 모델과 다른 지표도 함께 봅니다.

**3. 적용** 이 방향으로 검토를 눌러야 새 방향이 현재 검토에 적용됩니다. 첫 후보가 모든 조건에서 최적인 방향이라는 뜻은 아닙니다.

기본 26방향 외에 주요 면 방향까지 비교하거나 직접 각도를 입력할 수 있습니다. 선택한 모델 방향이 프린터 위쪽을 향합니다. 기울기 0°는 모델 +Z, 90°는 XY 평면, 180°는 −Z입니다.

**수치의 의미** 낮은 높이 = 짧은 출력 시간, 작은 하향면 투영면적 = 적은 실제 서포트, 넓은 평평한 바닥 = 강한 접착력으로 바로 바꾸어 읽지는 않습니다.

## 3  정밀 검토  벽

**사용 목적** 질문: “내가 입력한 최소 기준보다 짧게 측정된 곳이 있는가?”

**1. 벽 화면 열기** 정밀 검토 → 벽을 선택합니다. 작은 형상은 첫 설계 검토 때 자동 측정될 수 있습니다. 아직 결과가 없거나 일부만 확인했다면 벽 검토 실행을 누릅니다.

**2. 측정값과 기준 비교** 표본에서 가장 짧게 측정한 거리와 내가 입력한 최소 벽 기준을 봅니다. 기준을 모르면 우선 값과 위치만 확인합니다.

**3. 기준 적용** 이 화면에서 벽 기준 입력·변경을 펼쳐 비교할 최소 벽 기준을 넣고 이 기준으로 벽 다시 검토를 누릅니다. 기준 출처는 왼쪽 장비·재료와 검토 기준에 기록합니다.

**4. 문제 위치 확인** 확인할 측정 위치 · 짧은 거리순에서 점을 고릅니다. 실제 벽인지, 모서리나 곡면에서 짧게 잰 거리인지 원본 CAD와 함께 확인합니다.

### 4 mm 브래킷으로 연습하기

입력 → CAD 기준형상 → 브래킷 · 두께 4 mm를 선택합니다. 아래 1 mm와 5 mm는 사용법 설명을 위한 가정값이며 장비 권장 기준이 아닙니다.

| 설명용 조건 | 기대하는 해석 / 다음 행동 |
| --- | --- |
| 기준을 비워 둠 | 표본에서 4 mm를 관측했지만 적합 여부를 비교할 기준은 없습니다. |
| 기준을 5 mm로 설정 | 4 mm는 기준보다 짧습니다. 해당 위치를 확인하고 실제 요구 기준 또는 두께 수정을 검토합니다. |
| 기준을 1 mm로 변경 | 전체 요청 표본이 유효하다면 검사한 표본에서 기준 미만이 없습니다. 부품 전체의 제조 가능 판정은 아닙니다. |


### 색과 측정값을 이렇게 읽으세요

주황 마름모는 선택한 측정점입니다. 기준이 있으면 빨간 마름모는 기준 미만, 회색 원은 기준 이상입니다. 기준이 없으면 파랑의 진하기로 거리 차이를 보여줍니다. 색은 표본 점에 대한 표시입니다.

**측정의 범위** 표면의 여러 점에서 안쪽 방향으로 반대 면까지 거리를 잽니다. 평행한 벽에서는 두께처럼 읽을 수 있지만 곡면·모서리에서는 다를 수 있고, 표본 사이의 더 얇은 곳은 놓칠 수 있습니다.

측정 방법·표본과 기준 출처에서 표본 수와 하위 5% 거리를 확인할 수 있습니다. 실측으로 최소 벽·홀 기준을 정하는 방법에는 시편 기록 CSV가 있습니다. CSV는 기록 양식이며 자동 기준 보정이나 성공률 계산 기능은 아닙니다.

## 4  정밀 검토  층간과 G-code

**사용 목적** 질문: “층으로 나누었을 때 놓치는 부분이나 받쳐 줄 곳이 있는가?”

층간 검토는 재료 압출(MEX, FFF/FDM) 전용입니다. 다른 공정에 같은 선폭·지지 규칙을 적용하지 않습니다.

**1. 설정 맞추기** 빌드 공간과 층 설정에서 층 높이와 MEX 명목 선폭을 정합니다. 실제 슬라이서가 있다면 그 설정과 맞춥니다. 설계 검토를 눌러 적용합니다.

**2. 계산 실행** 정밀 검토 → 층간 → 층간 검토 실행을 누릅니다. 먼저 후보 유무와 확인한 층 수를 읽습니다.

**3. 층과 위치 확인** 후보가 있으면 위치를 확인할 층을 선택합니다. 전체 층 측정값·계산 범위에서 누락된 계산이 있는지도 봅니다.

| 검출 후보 | 어떻게 확인하고 바꾸나요? |
| --- | --- |
| 선폭보다 가는 단면 | 슬라이서에 압출 경로가 남는지 확인합니다. 필요하면 형상 두께·선폭 설정을 검토합니다. |
| 아래층 지지 부족 | 아래층과 설정한 경사 허용 범위를 벗어난 부분입니다. 브리지·서포트 경로 또는 빌드 방향을 검토합니다. |
| 한 층에만 나타나는 형상 | 위·아래 검사 단면에 없는 작은 특징입니다. 설계 의도인지 보고 특징 두께·층 높이를 검토합니다. |


모든 요청 층의 세 지표가 계산되고 전부 0일 때만 “검사한 층에서 세 종류 후보 미검출”로 읽습니다. 미확정은 0이 아닙니다. 위치 상자는 후보를 찾기 위한 범위이며 실제 결함 윤곽이나 서포트 형상이 아닙니다.

### G-code로 슬라이서 결과와 대조하기

**1. 현재 배치 내보내기** 근거·내보내기에서 현재 방향 STL · mm를 저장하고 사용할 슬라이서에서 처리합니다.

**2. 경로 파일 열기** 정밀 검토의 슬라이서 경로 확인 · G-code를 펼쳐 파일을 넣습니다. 현재는 Marlin 계열 G0/G1 경로를 읽습니다. 필라멘트 지름을 맞추고 확인할 노즐 높이를 고릅니다.

**3. 같은 부품인지 확인** 모델·단위·배율·방향이 맞는지 직접 확인합니다. 층간 화면 높이는 층 중간의 검사 평면이므로 노즐 Z와 기준이 다를 수 있습니다.

G-code의 선은 이동 중심선이며 실제 비드 외곽이 아닙니다. 사용법 연습용 Cura 예제는 현재 부품의 결과가 아니므로 검증 자료로 혼용하지 않습니다. 경로 기록은 G-code 검토 JSON으로 저장합니다.

## 5  정밀 검토  단면

**사용 목적** 질문: “어느 높이에서 재료의 모양과 넓이가 달라지는가?”

**1. 실행** 정밀 검토 → 단면에서 단면 검토 실행을 누릅니다. 처음에는 자동 · 가능한 방법으로 단면 확인을 사용하세요.

**2. 계산 범위 확인** 계산 완료인지, 일부 미확정인지 먼저 봅니다. 자동 모드는 계산 전 예산이 부족하면 형상 변화 기준 대신 균등 간격 표본으로 전환할 수 있습니다.

**3. 두 단면 비교** 가장 큰 변화가 관측된 두 단면을 먼저 봅니다. 높이·넓이로 단면을 선택하고 겹쳐진 윤곽을 확인합니다.

**4. 설계 의도와 대조** 판에서 기둥으로 바뀌는 정상적인 형상인지, 의도하지 않은 얇은 판·돌출부인지 봅니다. 필요한 경우 CAD나 슬라이서에서 해당 높이를 더 자세히 확인합니다.

### 화면에서 무엇을 봐야 하나요?

| 표시 | 읽는 방법 |
| --- | --- |
| 이전 / 현재 단면 | 이전은 파란 점선·네모, 현재는 주황 실선·마름모로 구분합니다. 색은 두 단면의 구분이며 위험 등급이 아닙니다. |
| 높이별 재료 단면적 | 점 하나가 실제 계산한 단면 하나입니다. 점 사이의 형상이 모두 확인됐다는 뜻은 아닙니다. |
| 형상 변화 면적 | 서로 겹치지 않는 단면 영역을 봅니다. 큰 변화 자체가 불량은 아니며 형상과 공정에 맞춰 해석합니다. |
| 체적 상대차 | 같은 메시를 다른 방법으로 집계한 계산 검산입니다. 0에 가까워도 실제 출력 성공이나 원본 CAD와의 완전한 일치를 보장하지 않습니다. |


균등 간격은 표본 사이의 얇은 특징을 놓칠 수 있습니다. 부분 부피는 계산한 구간의 합이며, 누락 상한은 빠진 구간의 기여만 제한합니다. 전체 오차 보증은 아닙니다.

### 공정에 따라 다음 행동이 달라집니다

| 공정 | 단면·형상을 보고 이어서 확인할 것 |
| --- | --- |
| FFF/FDM · 재료 압출 | 얇은 경로, 아래층 지지, 브리지와 서포트. 층간 검토와 슬라이서로 이어갑니다. |
| VPP · 광경화 | 접점·박리 방향·배출구. 이 도구가 박리력이나 출력 성공을 계산하는 것은 아닙니다. |
| 고분자 PBF | 벽·단면·분말 제거 조건. FDM의 자립 각도 규칙을 그대로 적용하지 않습니다. |
| 금속 PBF | 열전달·고정·분말 제거·후가공 접근. 열변형이나 잔류응력은 별도 검증 대상입니다. |


## 6  절삭 검토 시작하기

현재 절삭 기능은 원통형 엔드밀을 사용하는 고정축 밀링의 일부 기하 검토입니다. “이 방향·이 공구로 확인할 형상이 무엇인가?”를 찾습니다.

**1. 공정과 부품** 제조 공정 → 절삭가공을 선택합니다. 입력 → 절삭 검증 형상으로 연습하거나 내 파일에서 단일 부품 STEP/STP을 읽습니다.

**2. 접근 방향** 공구가 오는 방향을 고릅니다. +Z는 위쪽에서 진입하는 경우입니다. 화면 화살표는 부품에서 공구 쪽으로 향하고, 공구는 그 반대로 들어옵니다. 직접 각도 입력도 가능합니다.

**3. 공구 치수** 알고 있는 치수를 mm로 입력합니다. 모르면 비워 두어도 CAD 특징은 측정할 수 있지만 해당 공구 비교는 보류됩니다.

| 입력 | 뜻과 확인할 자료 |
| --- | --- |
| 엔드밀 지름 | 절삭하는 원통형 공구의 지름입니다. 코너 반경 비교에는 이 값의 절반을 사용합니다. |
| 날 길이 | 실제 절삭날이 있는 축방향 길이입니다. 공구 전체 길이나 목부 길이와 다릅니다. |
| 장착 후 돌출 길이 | 장착한 공구 끝에서 홀더 앞면까지 거리입니다. 카탈로그의 Reach/LBS와 항상 같은 값은 아닙니다. |


**4. 추가 조건** 재료·장비·근거와 추가 기준에 출처를 기록합니다. 원통 구간 길이/지름 기준은 알고 있을 때만 넣습니다. 표면 가림도 보려면 선택 방향에서 가려진 표면도 확인을 켭니다.

**5. 실행과 읽기** 절삭 설계 검토를 누릅니다. 이 결과에 적용된 공구 조건을 확인하고 확인할 항목 → 다음 행동 → 확인할 위치 순서로 봅니다.

### 첫 연습: 직사각 포켓

직사각 포켓 · 20×12 / 깊이 8 mm, 방향 +Z를 선택합니다. 사용법 연습으로 지름 4 mm, 날 길이 10 mm, 돌출 길이 15 mm를 가정합니다. 이 값은 실제 권장 공구 조건이 아닙니다.

실행하면 바닥 폭 12 mm, 길이 20 mm, 벽 높이 8 mm를 확인할 수 있습니다. 폭이 공구보다 넓어도 내부 직각은 둥근 엔드밀로 그대로 만들 수 없어 수정 검토 후보가 됩니다. 다음 행동은 코너 반경 또는 코너 여유를 검토하는 것입니다.

장비·재료명은 현재 조건 기록용입니다. 입력만으로 재료별 절삭력·처짐·진동을 계산하지 않습니다. 공구를 바꾸었다면 반드시 절삭 설계 검토를 다시 누르세요.

## 7  절삭 결과를 행동으로 바꾸기

### 특징별로 이렇게 읽으세요

| 검토 항목 | 의미 / 다음 행동 |
| --- | --- |
| 원통형 내부 특징 | 내부 원통면의 지름·축 구간과 공구 조건을 비교합니다. 원통면 개수는 홀 개수가 아니고, 축 구간은 전체 드릴 깊이가 아닙니다. 축이 다르면 다른 접근 방향을 확인합니다. |
| 오목 원통면 반경 | 공구축과 나란한 오목 원통면의 반경보다 공구 반경이 크면 작은 공구나 더 큰 설계 반경을 검토합니다. 모든 오목면이 포켓 코너로 확정되는 것은 아닙니다. |
| 직사각 포켓 | 직선 4변 바닥, 같은 높이의 네 수직 벽, 열린 입구 조건을 확인한 포켓입니다. 폭·국소 벽 높이·내부 직각을 봅니다. 둥근·분할·섬 포켓의 전체 폭·깊이는 이 기능 범위 밖입니다. |
| 내부 바닥 후보·치수 미확정 | 안쪽 바닥은 보이지만 포켓 조건을 확정하지 못했습니다. 채널·밀폐 공동일 수도 있으므로 “열린 포켓” 또는 “포켓 없음”으로 단정하지 않습니다. |


표의 아니오는 해당 치수가 입력값을 초과하지 않았다는 뜻입니다. 가공 통과가 아닙니다. 벽 높이가 날 길이보다 길어도 공구 목부·여러 절입 등 실제 방법을 봐야 하므로 곧바로 가공 불가가 되지는 않습니다.

파란색은 측정·추가 확인 위치, 주황색은 해당 항목에서 조건 확인이 필요한 위치입니다. 색만 보지 말고 비교값과 다음 행동을 함께 읽으세요.

### 표면 가림은 선택한 점에서 앞이 막히는지 보는 검사입니다

선택 방향에서 가려진 표면도 확인을 켜고 다시 실행합니다. 확인할 항목에서 선택 방향의 표면 가림을 고릅니다. 표시할 표본에서 분류별 점을 볼 수 있습니다.

앞이 가려진 표본은 다른 방향·가공 순서를, 반대쪽을 향한 표본은 다른 셋업을 검토합니다. 공구축과 평행한 면은 측면 밀링과 진입 방법을 별도로 확인합니다. 미확정 표본은 검사 결과가 없는 점입니다.

가려지지 않았다는 결과는 검사한 점에서 뻗은 직선이 막히지 않았다는 뜻입니다. 공구 지름·샤프트·홀더·고정구 전체가 통과한다는 뜻은 아닙니다. 표본 비율은 가공 가능 면적률이나 성공 확률이 아닙니다.

### 두 번째 연습: 공구를 바꾸면 무엇이 달라지나?

둥근 포켓 · 모서리 R3 / 깊이 8 mm에서 +Z, 지름 8 mm, 날 10 mm, 돌출 15 mm를 가정합니다. 공구 반경 4 mm가 R3보다 커서 반경 확인 후보가 됩니다. 지름만 4 mm로 바꾸고 다시 실행하면 이 반경 충돌은 사라집니다. 포켓 전체 접근과 실제 가공 성공은 여전히 별도 확인입니다.

**현재 범위** 선삭·연속 5축 경로·CAM 경로 생성·고정·절삭력·공차·표면 품질·시간·비용은 현재 검토 범위에 포함되지 않습니다.

## 8  비교하고 저장하기

### 적층 형상을 수정했다면 전후를 비교하세요

**1. 변경 전 저장** 기존 파일을 검토한 상태에서 수정 전후 → 현재 결과를 변경 전 기준으로 저장을 누릅니다.

**2. 수정본 검토** 외부 CAD에서 수정한 파일을 불러와 같은 공정·방향·설정으로 검토합니다. 이 도구가 CAD 형상을 자동 수정하는 것은 아닙니다.

**3. 차이 해석** 조건 차이 안내를 확인하고 같은 조건끼리 수치를 비교합니다. 결과는 전후 비교 JSON으로 저장할 수 있습니다. 절삭은 각 조건의 보고서를 따로 저장해 비교합니다.

### 어떤 파일을 저장해야 하나요?

| 목적 | 적층 / 절삭에서 선택할 파일 |
| --- | --- |
| 사람에게 설명·공유 | 검토 보고서 HTML / 절삭 검토 HTML. 브라우저에서 열 수 있고 이유·다음 행동·적용 조건을 볼 수 있습니다. |
| 측정값과 조건 보관 | 전체 결과 JSON / 절삭 검토 JSON. 재검토용 상세 원자료입니다. 나중을 위해 HTML과 함께 저장하세요. |
| 슬라이서로 전달 | 적층의 현재 방향 STL · mm. 선택한 배치로 보냅니다. 슬라이서에서도 단위·방향을 확인하세요. |
| CAD 원본 수정 | 입력 원본 / 입력 형상 원본. 원래 STEP을 넣었다면 그 파일을 내려받아 CAD에서 수정합니다. |


적층은 근거·내보내기, 절삭은 근거와 내보내기를 펼칩니다. 문헌 제목과 적용 범위도 여기서 확인합니다. HTML의 형상 그림은 참고도이며 정밀 도면은 아닙니다.

### 자주 생기는 문제

**실행** 브라우저가 열리지 않으면 http://127.0.0.1:8507/ 에 접속합니다. 실행 중인 프로그램을 닫으면 화면도 사용할 수 없습니다. 정상 실행 중인 같은 폴더의 앱은 START_REVIEW.cmd 재실행 시 재사용합니다.

**포트 오류** 포트 8507 사용 중이라는 오류가 나오면 먼저 기존 주소의 화면을 확인합니다. 다른 프로그램이 쓰는 경우에는 그 프로그램을 무작정 종료하지 말고 실행 로그와 경로를 확인합니다.

**결과 없음** 값을 바꾼 뒤에는 검토 버튼을 다시 누릅니다. 검사 전·시간 한도·계산 불가 안내가 있으면 미확인 사유를 읽고 단일 부품과 원본 CAD를 확인합니다.

**판단 순서** “측정값은 무엇인가 → 어떤 기준과 비교했나 → 어디를 확인해야 하나 → 다음 행동은 무엇인가” 순서로 읽으세요. 완료율이나 색 하나보다 이 네 가지가 실제 설계 판단에 중요합니다.

장비가 없는 현재는 형상·방향·가정 조건 비교까지 진행할 수 있습니다. 실제 제작 성공 확률은 현재 제공하지 않습니다. 사출·프레스도 현재 지원 범위가 아닙니다.
