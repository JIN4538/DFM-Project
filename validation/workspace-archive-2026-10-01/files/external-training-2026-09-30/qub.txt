                        <div class="rendering rendering_dataset rendering_detailsportal rendering_dataset_detailsportal"><h2 class="subheader">Description</h2><div class="textblock">Machining feature recognition dataset for deep learning consisting of B-Rep CAD models labelled on each B-Rep face with a machining feature. Dataset for paper: "Hierarchical CADNet: Learning from B-Reps for Machining Feature Recognition, Computer-Aided Design"<br /><br /><br />- The MFCAD++ dataset is a machining feature recognition dataset containing B-Rep CAD models.<br />- Each CAD model has been saved as a STEP file.<br />- The CAD models were automatically generated using the PythonOCC CAD software.<br />- For each CAD model, a machining feature class label is given on each B-Rep face.<br />- These labels can easily be extracted from the STEP files.<br />- The labels are given in "feature_labels.txt".<br />- The dataset has been split into "train", "val" and "test" directories using a 70:15:15 split as per the original paper.<br />- These splits are given in the files: "train.txt", "val.txt" and "test.txt".<br />- There are training_set=41766, val_set=8950 &amp; test_set=8949 samples, with 59665 samples in total.<br />- For more information on hierachical B-Rep graphs store in H5DF files see "h5_structure.h5".<br /><br />If used please reference the paper: <br />Colligan AR, Robinson TR, Nolan DC, Hua Y, Cao W. Hierarchical CADNet: Learning from B-Reps for Machining Feature Recognition, Computer-Aided Design</div><div class="dataset"><table class="properties"><tbody><tr><th scope="row">Date made available</th><td><span class="date">12 Feb 2022</span></td></tr><tr><th scope="row">Publisher</th><td><span>Queen's University Belfast</span></td></tr><tr><th scope="row">Date of data production</th><td><span class="date">27 Apr 2021</span><span class="datasetDateSeparator"> - </span><span class="date">13 May 2021</span></td></tr></tbody></table></div></div>
