# 절삭 특징 위치: 실제 입력 경로 개선

가중치 증설 전에 기존 평면 CAD 경로의 실제 성능을 확인했다. 기존 경로는 25종 공동 모델의 특징 경계에 16종 평면 전문가의 분류를 연결하고, 25종 점수로 정한 문턱을 그대로 적용했다. MFInstSeg 공동 모델의 단독 성능을 이 혼합 경로의 성능으로 사용할 수 없었다.

## 변경

[새 adapter](../../dfm/feature_routing.py)는 공동 모델이 특징 종류를 결정하고, 평면 전문가가 같은 종류로 동의할 때만 해당 점수를 보완한다. 다른 종류를 제안하는 평면 모델이 공동 모델의 분류를 덮어쓰지 않는다. [CAD worker](../../amdfm/cad_worker.py)에서 이 경로를 호출한다. 원본 면 번호·독립 치수 재측정·200면 제한·자유곡면 제외·확정 제외 4종은 유지한다. 기존 특징 모델 가중치와 클래스별 문턱은 변경하지 않았다. 정책 식별자는 `cad-feature-agreement-v1`이다.

## 선택과 시험

[선택 기록](feature-routing-selection.json)은 새 보류 시험을 실행하기 전에 고정했다. 검증 MFInstSeg 9,424 CAD와 MFCAD 2,339 CAD에서 종류 판단·경계 분리·합의 경로를 비교했다. 동일 문턱에서 두 출처의 전체 정밀도·회수율이 기존보다 낮지 않고 MFInstSeg 정밀도 97% 이상인 경로를 선택했다. 무조건 공동 모델로 전환하면 MFCAD 회수율이 감소했으며, 의미가 다른 면의 경계를 추가 분리하면 오검출이 늘어 해당 대안들은 채택하지 않았다.

| 보류 시험 | 정밀도 전→후 | 회수율 전→후 | 정답/오검출 변화 |
|---|---:|---:|---:|
| MFInstSeg 9,241 CAD 전체 | 96.3402% → 97.4881% | 69.3963% → 71.8582% | 정답 +1,440 / 오검출 −459 |
| 그중 평면 1,006 CAD | 78.2178% → 97.4044% | 43.2450% → 74.7756% | 정답 +1,440 / 오검출 −459 |
| 그중 곡면 8,235 CAD | 97.4955% → 동일 | 71.6111% → 동일 | 동일 |
| MFCAD 2,309 CAD 의미영역 | 96.7784% → 96.8970% | 79.9396% → 83.0978% | 정답 +324 / 오검출 동일 |

MFInstSeg는 저자의 인스턴스 라벨에서 같은 종류·면 집합 IoU>0.5로 대조했다. 원본 CAD 면 순서가 인증된 그래프를 배포용 NumPy 추론과 실제 CAD 입력의 범위 조건으로 평가했다. 자유곡면이 포함돼 입력 경로에서 제외되는 81개도 정답 특징 분모에 남겼다. 따라서 이전 공동 모델 단독 시험의 97.4%/72.3%와 직접 전후 비교하지 않는다.

MFCAD에는 저자 인스턴스 라벨이 없어 연결된 같은 의미 라벨의 면 영역을 별도 평가했다. 이 수치를 MFInstSeg 인스턴스 수치와 합산해 종합 정확도로 부르지 않는다.

## 검증과 남은 한계

- [비교 JSON](feature-routing-comparison.json)은 전체/평면/곡면 수치, 클래스별 반례, 소스 SHA와 원본 모델 무변경 확인을 보존한다.
- [MF 보류 결과](feature-routing-test-001/summary.json), [MFCAD 보류 결과](feature-routing-mfcad-test-001/summary.json)에 종류별 결과가 있다. 어느 클래스도 정답 검출 수는 줄지 않았지만, MF 삼각 관통홈·삼각 포켓·직사각 포켓의 정밀도는 각각 약 0.253·0.151·0.157%p 감소했다. 전체 개선을 모든 클래스의 정밀도 보장으로 설명하지 않는다. 보류 결과를 본 뒤 문턱을 재조정하지 않았다.
- 162개 보류 그래프에서 실제 adapter의 종류·원본 면 번호·점수가 벤치마크와 일치했다.
- [원본 STEP 18개 감사](feature-routing-raw-cad-audit.json)는 해시 순으로 고른 MF 평면 6개·곡면 6개와 MFCAD 6개를 실제 격리 CAD worker로 다시 읽었다. 모든 특징 종류·원본 면 집합이 인증 그래프 경로와 일치했다. STEP 원본 SHA도 대조했다.
- [연동 검사](feature-routing-integration-tests.xml) 29개가 통과했다. 독립 생성한 삼각·직사각·육각 포켓의 실제 치수, 기본 소재의 오검출, 모델 간 불일치, 미확정 클래스, 원본 면 번호와 전체 STEP→절삭 조치 연결을 포함한다.

재현 도구는 [그래프 평가](../../scripts/benchmark_feature_runtime_routing.py), [원본 STEP 감사](../../scripts/audit_feature_routing_cad.py)다. 그래프별 원자료는 각 실행 폴더의 gzip 파일, 최초 대안과 검증 결과는 `*-validation-001/002`에 보존했다. 대규모 자유곡면·200면 초과·확정 제외 4종의 범위를 확장한 작업은 아니다.
