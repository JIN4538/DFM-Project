# 실제 브라우저 확인 — 2026-09-20

Codex 내장 브라우저의 숨김 테스트 탭에서 작업 저장소의 Streamlit 앱 `http://127.0.0.1:8512/`를 확인했다. 기본 뷰포트는 1280×720이었다. 사용자 8507 탭이나 바탕화면 앱을 대체하지 않았다. CUA의 실제 UI 조작·접근성 트리·DOM·스크린샷을 사용했으며 화면 이미지는 도구 응답에서 직접 확인했다. 이 폴더에 PNG를 저장했다는 기록은 아니다.

## 확인한 흐름

1. **공정 범위:** 제조 공정 목록에 적층제조·절삭가공 두 항목만 존재했다. 사출·프레스 메뉴가 없었다.
2. **반경 문제:** 둥근 포켓 R3, +Z, 지름 8 / 날 10 / 돌출 15 mm로 실행. 먼저 확인할 항목에 오목 원통면이 표시되고 4개 면의 반경 3과 공구 반경 4, 차이 −1, 초과 ‘예’가 일치했다.
3. **위치 연결:** 확인할 위치에서 CAD 면 7을 선택. 다른 오목면까지 무조건 같은 선택으로 칠하지 않고 해당 위치를 표시했다. 같은 항목에서 면 7·9·11·13을 선택할 수 있었다.
4. **해소 후 행동:** 지름만 4로 변경·재실행. 적용 조건 4 mm, 표의 공구 반경 2, 차이 1, ‘아니오’, 작은 반경 0개가 일치했다. 다음 행동은 공구를 더 줄이라는 문장에서 진입 경로·홀더·가공 여유 확인으로 바뀌었다. 수정 후 선택 면은 파란색으로 표시됐다.
5. **수치 경계:** 지름 6으로 변경·재실행. 공구와 형상 반경의 수치 경계, 실제 가공 여유를 별도로 확인하라는 안내가 표시됐다.
6. **휠 동작:** 최초 확인에서 3D 그림 위에서 문서를 스크롤하려 하자 모델이 작아졌다. CNC 차트의 `scrollZoom=False`를 적용하고 카메라를 초기화한 뒤 문서 스크롤과 정상 형상 크기를 확인했다.
7. **소수 각도:** 직접 입력에서 0.005°가 포커스를 벗어나면 0.01°로 표시되는 문제를 재현했다. 표시 형식을 수정한 뒤 0.005000°를 유지하며 결과 방향 X≈8.72665e−05, Y=0, Z≈1과 일치하는 것을 확인했다. 계산의 정확한 벡터는 별도 AppTest에서 독립 삼각함수와 대조한다.
8. **새 형상·방향:** 변경 중에는 이전 결과와 내보내기를 숨기고 다시 실행하도록 안내했다. 재실행 후 항목 선택 표시와 본문이 일치했다.
9. **표면 가림:** 단순 블록, +Z에서 12개 표본을 계산했다. 가려짐 0, 반대쪽 2, 축과 평행한 면 8, 직선이 가려지지 않은 표본 2, 미확정 0을 표시했다. 전체 가공 가능 면적·성공률로 표시하지 않았다.
10. **가림 필터:** ‘공구 반대쪽을 향한 표본’을 고르면 반투명 형상에 보라색 사각형 2개와 해당 범례가 남았다. 전체 면을 위험 면으로 칠하지 않았다.
11. **적층 복귀:** 제조 공정을 적층제조로 바꾸자 절삭 조건·보고서가 사라지고 적층 공정·방향·설계 검토 흐름으로 복귀했다.

마지막 확인에서 적층 제목이 실제 표시되고 절삭 실행 버튼은 0개였으며, 해당 탭이 수집한 브라우저 오류 로그는 빈 목록이었다. 이것이 모든 환경에서 오류가 없다는 보장은 아니다.

확인 후 임시 탭과 직접 실행한 8512 서버를 정리했다. 종료 대상은 명령행·부모 프로세스로 확인한 해당 서버와 자식뿐이다. 사용자 기존 앱은 조작하지 않았다.

## 관찰상의 제한

Streamlit 실행 직후 접근성 트리가 새 본문과 이전 표를 잠시 함께 반환하는 경우가 있었다. 실행이 끝난 뒤 트리와 화면을 다시 확인하여 지속적인 불일치와 구분했다. 빠르게 여러 선택을 연속 조작하던 중 자동화의 약 3초 선택자 대기가 한 번 끝났고, 새 상태를 읽어 아직 열린 형상 메뉴에서 다시 선택한 뒤 진행했다. 이를 제품의 계산 실패나 최종 통과로 숨기지 않았다.

이번 기록은 한 브라우저·기본 해상도의 개발자 수행 QA다. 실제 초보 사용자의 과제 성공률·소요 시간·접근성 보조기기 평가, 모든 화면 폭 시험은 아니다. HTML의 한글 조건·SVG·정밀값·미입력·안전한 링크 및 위치/색과 원자료의 불변성은 `tests_v3/test_machining_ux_reaudit.py`에서 별도로 검사한다. 해당 시험 수를 실제 사용자 수로 해석하지 않는다.
