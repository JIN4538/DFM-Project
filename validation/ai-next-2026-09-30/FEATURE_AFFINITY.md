# 분리된 절삭 특징의 학습 통합 · 2026-09-30

## 반영한 변경

중간 절삭으로 떨어진 면들이 하나의 관통 특징인데, 기존 인접 그래프가 여러 특징으로 나누는 오류를 보정했다. 새 MLP는 고정 GNN 임베딩과 상대 기하에서 **두 면 집합이 같은 특징인지** 학습한다. 규칙의 판단 결과가 아니라 MFInstSeg 저자의 특징 인스턴스 라벨을 사용했다.

- 기존 `feature_routing.py`와 기존 모델 30파일·교사/추론 소스 9파일을 보존했다. [SHA 검사](affinity-preservation.json)
- 새 [`feature_instance_refinement.py`](../../dfm/feature_instance_refinement.py)는 기존 20종 후보를 그대로 두고, 미확정이던 관통홀·삼각 관통·육각 관통·원형 관통 슬롯만 추가한다.
- [`external_feature_affinity_v1.json`](../../data/models/external_feature_affinity_v1.json), SHA `605024a6a36636bf267aaf41f40e2455ffa6edfe9d01d40ba288765769cf6050`. 별도 manifest와 원본 모델 의존 SHA를 검사한다.
- API: `recognize_refined_features(graph, model_path=None)`. `cad_worker.py` 연결 확인. 모델 누락·손상 시 기존 경로로 복귀한다. 바탕화면 배포 완료는 상위 작업 기록을 따른다.

## 학습과 선택

원본 증설은 없다. 기존 train 43,730 CAD에서 예측 면 집합 13,435쌍(동일 특징 4,251쌍)을 추출해 새 162→64→32→1 MLP를 학습했다. 기존 GNN 가중치는 고정했다. validation 9,424 CAD·3,014쌍에서 BCE가 가장 낮은 19번째 epoch를 선택했다. 이후 클래스별 정밀도 98.5%·TP 100 이상 조건으로 연결 및 표시 임계값을 정했다.

검증 분할은 이전에도 사용한 자료다. [선택 계획](affinity-selection-plan.json), [학습 이력](affinity-training-history.json), [검증 선택](affinity-validation-selection.json), [시험 전 모델 고정](affinity-model-freeze.json)을 보존한다. 이번 버전의 시험 결과를 보고 임계값을 바꾸지 않았다.

## 실제 경로 결과

MFInstSeg의 원본 CAD 면 대응이 인증된 test 9,241개, 정답 특징 58,493개. 같은 종류이며 면 집합 IoU > 0.5일 때 정답이다. **이 test는 앞 단계에서 사용했으므로 이번에는 회귀시험이며 새 독립 시험으로 부르지 않는다.** 자유곡면·200면 초과의 실행 제한을 적용한 수치다.

| 범위 | 기존 정밀도 → 변경 | 기존 검출률 → 변경 | 정확 면 집합 검출률 → 변경 |
|---|---:|---:|---:|
| 전체 | 97.488 → 97.645% | 71.858 → 83.803% | 70.856 → 82.750% |
| 평면 | 97.404 → 97.705% | 74.776 → 85.767% | 74.338 → 85.308% |
| 곡면 포함 | 97.496 → 97.640% | 71.611 → 83.637% | 70.562 → 82.533% |

정답 6,987개와 **오검출 99개가 함께 추가**됐다. 기존 20종의 후보는 변경하지 않았다. 이전에 정밀도가 소폭 낮아졌던 삼각 관통 슬롯·삼각/사각 포켓 3종을 이번에 해결한 것은 아니다. [전체 비교](affinity-runtime-comparison.json), [클래스별 원자료](affinity-test-evaluation.json)

## 새 독립 CAD와 사용자 기능 검증

모델 평가 전에 seed와 생성기를 고정한 OCCT CAD 60개·특징 90개를 만들었다. 독립 커터의 평면·원통식으로 원래 면 정답을 확인했으며 학습에 넣지 않았다. 단일·반복 관통부와 중간 횡단 절삭을 포함한다.

- 삼각·육각 관통: 각 30/30 정확 면 집합, 오검출 0.
- 관통홀: 12/30 정확 면 집합, 오검출 0. 특히 반복 홀은 **2/20만 검출**되어 의미 분류/표시 임계값의 일반화 문제가 남는다.
- 전체: 보정 제거 37정답·70오검출 → 보정 적용 72정답·0오검출. 원형 관통 슬롯은 이 독립 생성기에 포함되지 않았다. [결과](affinity-independent-cad.json)
- source CAD 45개에서 평가 코드와 실제 새 API의 면 ID·종류 일치 및 기존 후보 보존, 원본 STEP 12개 재입력에서 동일 위치 확인. [실행 감사](affinity-runtime-audit.json)
- 기존 특징·포켓 검사와 신규 계약·STEP 검사를 함께 실행해 **38개 통과**. 새 삼각/육각 관통의 강조 메시가 실제 커터 벽에만 놓이고, 횡단 절삭의 빈 공간을 강조하지 않는지 확인했다. [검사](affinity-integration-tests.xml)

새 네 종류는 현재 **위치와 CAD 면 넓이**에 연결된다. 기존 포켓의 공구 진입원·깊이 검증기가 이 관통부의 치수를 임의로 만들지 않는지 검사했다. 관통부의 공구 추천·형상 변경안을 새로 완성한 것은 아니며, 원통 홀의 기존 해석적 검사는 유지한다. MFCAD에는 저자 인스턴스 라벨이 없으므로 그 연결 의미영역을 이번 분리 특징 정답으로 대체하지 않았다.

## 속도·범위·다음 과제

실제 CAD 45개(최대 94면)의 추론 중앙값은 기존 17.2ms → 54.1ms, p95는 21.8ms → 68.5ms다. 단일 CPU/BLAS 스레드이며 CAD 읽기·기하 추출 시간은 제외한다. 200면·자유곡면 제외 제한은 유지한다. 이론적 최대 19,900쌍의 수치 스트레스에서 특징 배열 12.9MB, 계산 약 3.25초이며 이는 CAD 정확도 시험이 아니다. [예산 시험](affinity-pair-budget-stress.json)

다음 우선순위는 반복 원통 홀·가까이 붙은 같은 종류·공유 경계의 독립 정답을 확대하고, 새 관통 위치를 별도 기하 검산으로 공구 치수와 연결하는 것이다. 기존 3종의 정밀도 저하, 큰 CAD·자유곡면은 별도 과제로 남는다.

방법 참고: [FeatureFox 원문](https://arxiv.org/html/2604.26770v1)은 경계 분류와 성분 전체 분류를 제안하고, 떨어진 면 집합을 하나의 특징으로 처리하지 못한다는 한계를 명시한다. 회사 정책으로 코드·데이터가 비공개이므로 그 구현을 반입하거나 논문 수치를 우리 성능으로 사용하지 않았다. 이 문서의 수치는 모두 위 자체 실행 파일에 근거한다.
