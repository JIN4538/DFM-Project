# 적층 방향 탐색 신경망: 구현과 검증

2026-09-29. 이 기능은 **새로운 방향을 어디부터 계산할지 선택하는 딥러닝**이다. 기존 방향 후보의 순위를 정하는 모델과 역할이 다르다. 신경망이 고른 방향의 높이·하향면·바닥·장비 수용 치수는 기존 기하 엔진으로 다시 계산한다.

## 사용자가 보는 변화

- 기존 26방향에 최대 12개 방향을 추가한다.
- 이 중 최대 6개는 실제 큰 면을 바닥으로 놓는 `면 탐색`, 나머지는 신경망이 고른 `AI 탐색`이다. 큰 면 후보가 6개보다 적으면 남은 예산을 신경망에 배정한다.
- 방향 비교와 종합 결론은 추가 후보의 **재측정된 값**을 사용한다. 예측값은 선택 근거 기록에만 남는다.
- 기존 후보를 삭제하지 않는다. 현재 방향을 바꾸어도 같은 형상·같은 조건의 탐색 대상은 유지한다.

## 어떤 신경망인가

지도학습과 딥러닝은 서로 배타적인 분류가 아니다. 이번 모델은 지도학습으로 훈련한 3개 은닉층 신경망 두 개다.

| 모델 | 입력 | 은닉층 | 학습 목표 |
|---|---|---|---|
| 높이 | 기존 26방향 높이, 질의 방향의 1·2차 성분 | 64 → 48 → 24 | 높이 / 형상 경계상자 대각선 |
| 하향면 | 기존 26방향 높이와 하향면 투영 합, 질의 방향, 탐색 각도 | 96 → 64 → 32 | 하향면 투영 합 / 전체 메시 표면적 |

ReLU·Adam·제곱오차를 사용한다. 표준화 통계는 학습 분할에서만 계산했다. 5학습회마다 별도 형상의 검증 오차를 확인하고, 검증 오차가 가장 낮은 가중치를 보관했다. 입력 표준화와 비선형 MLP의 구현 근거는 [scikit-learn 공식 신경망 문서](https://scikit-learn.org/stable/modules/neural_networks_supervised.html)를 따른다.

방향별 학습 목표는 `measure_orientation`이 산출한 기하량이다. 문헌의 문장을 직접 이해한 모델, 새로운 설계 기준을 발견한 모델, 원시 CAD를 직접 해석하는 모델이라고 설명하지 않는다. 기하 엔진·문헌 조건은 별도이며, 이 모델은 그 엔진이 제공한 방향별 반응을 근사한다.

## 예측과 검산의 분리

1. 고정된 26방향을 실제로 측정한다.
2. 구면의 384개 방향과 최대 24개 주요 면 방향으로 추가 후보 풀을 만든다. 중복 방향은 제외한다.
3. 최대 6개 주요 면은 구조적 기본 후보로 남긴다. 바닥 접촉과 바닥 면 제외는 특정 면 방향에서 불연속이므로 매끄러운 신경망 예측에 맡기지 않는다.
4. 남은 예산은 신경망이 예측한 높이·하향면의 비교값과 10° 방향 분산 조건으로 고른다.
5. 선택한 후보를 기존 엔진으로 다시 측정한다. 원래 보고서와 같은 단위·방향변환·장비 수용·미확정 규칙을 유지한다.
6. 기존 개선안 순위 모델이 원래 후보와 추가 후보의 실측 결과를 함께 비교한다.

여기서 비교 가중치·정규화·예산은 프로젝트의 공개된 탐색 정책이다. 신경망은 해당 정책의 검색을 보조한다. 대리모델과 실제 평가를 분리하는 접근은 [Blank·Deb의 surrogate-assisted optimization 연구](https://arxiv.org/abs/2204.05855)에서도 다루지만, 이 코드는 해당 연구의 알고리즘 전체를 재현한 것은 아니다.

평평한 바닥 면적은 학습 목표에 포함하지 않는다. 해당 값은 실제 면 방향 후보의 재측정과 최종 방향 비교에서 반영된다. 따라서 전체 개선을 모두 신경망의 성과로 설명하면 안 된다.

## 학습 데이터와 분할

새 생성 seed `202609293`을 사용했다. 기존 학습 스크립트의 형상 생성 함수를 재사용했으나 치수·회전이 다른 메시를 생성했다.

- 훈련: 192개 메시, 20,922개 방향 측정.
- 모델 선택용 검증: 별도 48개 메시, 5,204개 방향 측정.
- 상자·원통·원뿔·브래킷·얇은 판·환형체·리브 프리즘·타원체를 훈련에 사용했다.
- 쐐기·토러스는 해당 신경망의 훈련과 검증에 넣지 않았다.
- 한 메시의 모든 방향은 같은 분할에 둔다. 크기·임의 회전·오버행 각도 25/35/45/60/75°를 포함한다.
- 고분자 PBF는 높이 신경망만 사용한다. 다른 세 적층 공정은 높이와 하향면 신경망을 사용한다. VPP와 금속 PBF는 현행 방향 측정 항목이 같지만 공정 전체를 동일하다고 보는 것은 아니다.

`run-001/training_data.npz`에 표본을, 각 실행의 `groups.json`에 생성 인자·회전·메시 SHA를 보존했다. 최종 학습은 소스가 바뀌지 않았음을 확인한 `run-003-frozen`이다. `training-data-reference.json`은 재사용 데이터의 SHA와 최초·최종 가중치의 완전 일치를 기록한다. 배포 모델의 SHA는 다음과 같다.

`38b1a7c479f5f33d7375310ab1f2a722289ddd884593af15de37a72d78c61e34`

## 최초 실패를 반영한 검색 예산

`run-001`의 신경망 단독 12방향 검색은 기존 26방향보다 나아지는 사례가 있었지만, 같은 예산의 단순 후보 선택보다 평균이 나빴다. 큰 평면이 바닥에 정확히 놓이는 특수 방향을 충분히 선택하지 못한 것이 핵심이었다.

그 결과를 보고 **큰 면 기본 후보 + 신경망 추가 탐색**으로 구조를 바꿨다. 최초 실패 결과를 삭제하거나 최종 성과에 합산하지 않았다. 수정 후에는 새로운 seed `202609294`의 메시로 평가했다. 그 결과를 보고 신경망을 다시 조정하지 않았다.

## 후보 탐색 자체의 비교

`run-002-hybrid-fresh`: 새 메시 120개, 공정·중점을 바꾼 960개 비교. 동일한 최대 6개 면 후보와 동일한 총 추가 측정 예산 12개를 사용한다. 표의 후회값은 전체 유한 후보 풀에서 얻은 최선의 공개 비교값과의 차이며 작을수록 좋다. 연속 공간 전체의 최적해를 안다는 뜻은 아니다.

| 후보 검색 방법 | 평균 후회값 |
|---|---:|
| 기존 26방향 | 0.208923 |
| 26방향 + 큰 면 기본 후보만 | 0.011868 |
| 큰 면 + 무작위 추가 선택 | 0.009835 |
| 큰 면 + 후보 풀 균등 선택 | 0.010640 |
| 큰 면 + 인접 방향 보간 | 0.005502 |
| **큰 면 + 신경망 선택** | **0.004287** |

개선의 큰 부분은 실제 큰 면 방향을 포함한 결과다. 신경망의 추가 기여는 큰 면 후보만 사용했을 때의 0.011868에서 0.004287로 줄어든 부분, 그리고 같은 예산의 다른 추가 선택 방법과 비교한 차이로 판단한다.

신경망은 균등 선택보다 98개에서 좋고 27개에서 나빴으며 835개는 같았다. 인접 방향 보간과 비교하면 66개에서 좋고 80개에서 나빴으며 814개는 같았다. 평균 개선이 모든 형상의 우위를 뜻하지 않는다. 세부 형상·공정·중점별 수치는 `evaluation-cases.json`에 있다.

예측 자체의 평균 절대오차는 높이가 경계상자 대각선의 0.030477, 하향면 투영 합이 메시 표면적의 0.053036이었다. 이 오차 때문에 예측값을 최종 측정값으로 사용하지 않는다.

## 실제 종합 결론까지 연결한 비교

위 표는 좋은 후보를 얼마나 찾았는지에 대한 평가다. 앱의 기존 개선안 순위 모델이 그 후보를 실제로 선택하는지는 별도로 측정했다.

동일한 `run-002`의 120개 메시·960개 조건에서 `recommend_plan`의 최종 선택을 대조했다. 초기 신경망 결과를 보고 추가 튜닝하지 않았다. 원래 26방향 대비 최종 선택은 **643개 개선, 287개 동일, 30개 악화**였다. 평균 후회값은 **0.215143 → 0.009381**이다. 최선 후보의 0.004287을 최종 사용자 추천 성능처럼 보고하지 않는다.

이 평가는 원래 개선안 순위 모델과 신규 후보 생성의 조합이다. 사용자별 선호 기록은 넣지 않았다. 전체 후보 구성에 따라 상대 정규화와 학습 순위가 달라질 수 있어, 원래 후보를 남기는 것만으로 최종 선택이 모든 비교 기준에서 좋아진다고 보장할 수 없다. 악화된 30개도 `run-002-hybrid-fresh/final-recommendations.json`에 보존했다.

## 실행과 유지 계약

- 실행은 NumPy와 JSON 가중치를 사용한다. sklearn·외부 AI API·GPU가 필요하지 않다.
- 모델/manifest SHA, 측정 엔진 SHA, 특징 순서·표준화·forward 함수의 계약 SHA를 확인한다. 캐시에도 현재 소스 SHA가 포함되므로 이미 읽은 모델이 이후 소스 변경을 무시하지 않는다.
- 모델 파일 누락·손상, 26방향 측정 누락, 해당 하향면 분석에 필요한 법선 미확정, 학습 각도 범위 밖에서는 원래 측정을 그대로 남긴다.
- 100,000개 면 이내, 기본 추가 후보 12개, 기본 시간 8초이다. 시간 확인은 각 측정 사이에 하며, 진행 중인 한 방향의 계산을 강제로 중단하지 않는다.
- 완료한 일부 후보는 부분 결과로 남긴다. None을 0으로 바꾸지 않고 장비 수용 True/False/None을 그대로 보존한다.

전용 검사 18개는 모델 tensor·SHA, 정확한 재측정, 임의 방향과 현재 방향 독립성, 크기·이동 정규화, 법선 미확정, 고분자 PBF 비적용 값, 장비 초과, 부분 계산, 모델 손상·소스 변경·가중치 기여를 확인했다. 전체 제품 통합검사는 상위 작업 기록에서 확인한다.

단일 실행 시간 기록 `benchmark-001.json`: 단순 판에서 추가 검색 0.103초/전체 후보 계산 0.143초, 토러스 0.110초/0.366초, 81,920면 타원체 0.322초/8.320초였다. 공통 26방향 계산은 양쪽에서 별도다. 이는 현 환경의 개별 측정이며 일반적인 속도 배수를 보장하는 결과로 사용하지 않는다.
