# 실제 CAD의 신경망·강화학습 통합 감사

최종 실행은 **AM `am-run-003`, CNC `cnc-run-003`**이다. 두 실행 모두 소스·가중치 해시가 실행 중 바뀌지 않았고 통합 계약 검사를 통과했다. 고유 STEP는 47개이며, CNC의 33개는 그 안에 포함된다.

| | AM 방향 탐색 | CNC 순차 개선안 |
|---|---:|---:|
| STEP / 조건 실행 | 47 / 188 | 33 / 594 |
| 실제 선택안의 정책 비용 감소 | 17 | 1 |
| 동등 / 악화 | 107 / 0 | 121 / 0 |
| 비교 선택안 없음 | 64 | 466 |
| 별도 예산 초과 fallback | — | 6 |
| 수치 재검산 | 방향 후보 1,860개 | 전후 개선안 244개 |

AM의 17건 중 **15건은 기존 방향의 재선택**, 새 신경망 방향은 **한 부품의 두 공정 조건에서 2건**이다. 후보군이 바뀌면서 기존 정책의 정규화도 바뀌었으므로 17건 모두를 새 신경망 방향의 성과로 세면 안 된다. 새 방향은 높이 감소와 하향면 투영 합 증가를 맞바꾼다. CNC의 1건은 공구 변경과 특정 원통 구간 단축을 조합한 제안이다. 수치와 해석은 아래 기록에 있다.

- [AM 최종 결과·구 테셀레이션 반례](am-run-003/README.md)
- [CNC 최종 결과·실제 혼합 조치 사례](cnc-run-003/README.md)
- [재현 스크립트](../../../scripts/audit_neural_cad.py)

이 표는 실제 제품 경로의 **통합·불변성·정책 계산 검사**다. 예측 모델의 일반 정확도와 구분한다. 같은 형상의 공정·공구·잠금·접근 방향 조합은 서로 독립된 부품이 아니다. 원시 결과, 미적용 상태, 입력 SHA와 실행 스크립트는 각 실행 폴더에 보존했다.

AM 1차 실행은 소스 변경으로 중단, AM 2차 실행은 미세 높이 차이의 추천 문제를 발견한 수정 전 기록이다. CNC 1차 실행은 중간 wrapper 기록, CNC 2차 실행은 예산 초과를 검사기가 재계산하려던 실패 기록이다. 이 파일들을 최종 성공 기록으로 덮어쓰지 않았다.
