빌드 공간은 제한하지 않았다. 공통 벽 비교값은 명시적인 감사 설정 1.2 mm이고, 개인 선호 파일은 사용하지 않았다. 추가 후보는 최대 12개, 추가 탐색 시간 예산은 8초다. 메시 면 수 예산을 넘는 입력에서는 대규모 기본 방향 스윕을 생략하고 원래 입력/검토 상태를 유지했다. 단일 솔리드만 있다고 가장하거나 조립체를 자동으로 하나의 부품처럼 확정하지 않았다.

## 실제 달라진 방향

`examples/corpus/191223275-19-e_00300_010_a/E_00300_010_A.stp`의 VPP와 금속 PBF에서 같은 새 신경망 방향이 선택됐다.

| 측정값 | 기존 선택 | 새 선택 |
|---|---:|---:|
| 높이 | 48.0558346 mm | 45.9092632 mm |
| 하향면 투영 면적 합 | 663.0851401 mm² | 848.5456342 mm² |
| 공개된 비교 정책 비용 | 0.769885781 | 0.734105612 |

새 방향 벡터는 `[-0.4872168268, 0.7417252758, 0.4609375]`다. 높이가 2.1465713 mm 줄고 하향면 투영 합이 185.4604941 mm² 늘어난다. **모든 항목이 동시에 좋아진다는 결과가 아니라 공개된 균형 정책의 교환관계**다. 두 독립 부품의 성공으로 세지 않는다.

나머지 15건은 이미 기본 방향 목록에 있던 방향의 재선택이다. 후보가 추가되면 후보군의 범위가 바뀌고 정규화된 비교값도 바뀐다. 이 15건을 새로운 신경망 방향 발견으로 설명하지 않는다. 그중 구의 MEX/VPP/금속 PBF 3건은 메시의 방향별 미세 차이로 생긴 기존 방향 재선택이므로 정확한 구 CAD의 설계 개선으로 세지 않는다.

## 구에서 발견해 수정한 미세 차이

기준 구는 `scripts/generate_cad_examples.py`의 `BRepPrimAPI_MakeSphere(10)`이다. 정확한 높이는 모든 방향에서 20 mm다. 입력 STEP의 요청/실효 선형 편차는 0.05 mm, 각도 편차는 0.15 rad이며 3,536개 삼각형 중 정확한 0면적 셀 2개를 제외한 3,534개로 분석했다.

수정 전 `am-run-002`의 고분자 PBF에서 신경망 방향의 메시 높이는 19.9711958972 mm, 기존 방향은 19.9725906951 mm였다. **차이는 0.00139479792 mm, 약 1.395 µm**다. 정확한 구의 방향 이득이 아니며 작게 남은 범위를 정규화하면 정책 점수 차이만 커질 수 있었다.

최종 wrapper는 STEP 고분자 PBF의 추가 방향에서 `0 ≤ 기존 최저 높이 − 새 높이 ≤ min(2 × 선형 편차, 0.001 × 기존 최저 높이)`에 해당하는 작은 개선을 추천 목록에서 제외한다. 현재 방향만 추가된 행은 기준 최저값에서 제외하고, 공간 제한이 있으면 실제 적합 확인된 기본 후보만 기준에 사용한다. **이 값은 제안 선별 정책이며 인증된 기하 오차 한계가 아니다.** 원 측정값은 수정하지 않는다.

최종 감사에서 구의 해당 후보를 제외했고 기존 +Y 방향을 유지하여 높이 차이는 0이 됐다. Submodel의 면 방향 후보에서 나온 0.0000743926 mm 차이도 제외했다. 제외된 2후보도 원 질의 수치 재검산에 포함했고, 제외 사유·높이 차이·선택목록에서의 제거를 검사했다.

## 검사의 의미와 재현

- 제품 로더와 검토·후보 추가·실제 최종 계획 함수를 호출했다. 후보 최솟값만 찾아 모델 성능으로 대신하지 않았다.
- 원 질의 측정값은 `measure_orientation`를 직접 다시 호출해 대조했다. 선택목록에 남은 행은 높이, 투영 합, 접촉 면적, 배치 변환, 크기와 적합 상태까지 대조했다. 동일 기하 엔진의 별도 호출이므로 모든 기하 공식을 독립 구현으로 검증했다는 뜻은 아니다.
- 최종 선택의 전후 비용은 두 결과의 공통 후보군에서 `.7 × 최대 정규화 손실 + .3 × 평균 정규화 손실`로 계산했다. 물리량의 변화도 따로 기록했으며, 비용 감소를 모델의 일반 정확도로 해석하지 않는다.
- 추가 탐색이 완료된 155조건의 소요 시간은 평균 0.1423초, 95백분위 0.2607초, 최대 0.3708초였다. STEP 읽기와 기존 스윕 시간은 제외한다. 전체 실행은 336.7초이며 동시 작업이 있는 로컬 환경의 관측값이다.
