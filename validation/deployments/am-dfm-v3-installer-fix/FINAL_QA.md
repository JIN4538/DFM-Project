# Windows 설치 수정 전달 확인

- 원인: Python 런처에는 3.13만 등록되어 있으나 구 INSTALL.cmd가 3.12를 강제했고 실패 시 pause 전에 종료했다.
- 바탕화면 `C:/Users/JIN/Desktop/AM-DFM_v3_0`의 원래 배포본을 확인한 뒤 수정했다. 변경 전 실행 파일은 `installer-backup-20260914/`에 보존했다.
- 새 설치 파일로 위 폴더에 Python 3.13.15 가상환경과 고정 의존성을 실제 설치했다. 종료 코드 0, pip check 통과, 앱 및 STEP import 통과.
- 설치 후 재실행 진단에서 기존 Python 3.13.15 환경 재사용을 확인했다.
- 실제 CMD 오류·경로·로그·pause 반례 5개 통과.
- 새 Python 3.13.15 환경으로 현재 소스의 전체 테스트 230개 통과(132.69초). 기존 체적 0 반례 RuntimeWarning 1개를 보존했다.
- 수정 소스 커밋: `63f0d3b`. 기존 GitHub PR #1에 반영했다. GitHub CI는 Python 3.12/3.13을 검사하도록 설정했으며 이번 기록은 위 로컬 실행 결과다.
- 새 소스 ZIP은 198개 파일 CRC 및 SHA 검증을 통과했다. 바탕화면 소스 198개와 새 release_manifest의 불일치가 0개임을 확인했다.
- 현재 앱 주소: http://127.0.0.1:8507/ . 설치를 다시 할 필요가 없다. 앱 서버가 종료된 이후에는 바탕화면 폴더의 START_REVIEW.cmd로 시작한다.

기존 3.0 배포 ZIP은 이력 보존을 위해 유지했다. 다시 배포할 때는 이 폴더의 수정 ZIP을 사용한다.
