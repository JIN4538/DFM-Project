## 모델 선택과 데이터

각 항목에서 결정트리와 24개 트리의 랜덤포리스트를 실제 학습했다. 항목당 검증용 1,000개 시나리오의 행동 클래스 일치율로 선택하고, 동률이면 작은 모델을 선택했다. 최종 검증에서는 모두 동률이므로 **11개 결정트리**를 채택했다. 복잡한 알고리즘이라는 이유로 포리스트나 딥러닝을 우선하지 않았다.

- 학습 55,000개, 모델 선택용 검증 11,000개.
- 별도 일반 시험 16,500개, 수치 경계 시험 5,500개, 미학습 치수 규모 시험 5,500개.
- 데이터는 재현 가능한 **수치 측정 시나리오**다. CAD 형상 93,500개를 만들어 학습한 것으로 설명하면 안 된다.
- 분리는 독립 시드로 생성한 조건 조합이다. 시나리오 ID가 다르다는 사실을 형상 가족 단위 분리로 해석하지 않는다. 동일한 기본 값이 여러 집합에 나올 수 있다.
- 실제 CAD에서 발생하는 측정 분포와 특징 인식 범위는 별도 실제 형상 감사로 확인한다.

위 일치율은 scikit-learn 원모델과 현재 수치 교사 간의 비교다. 실행 시 학습 범위 밖 입력은 이 일치율과 관계없이 모델 판단을 보류하고 규칙 계산으로 확인한다. JSON 추론과 원모델의 범위 내 예측 차이는 세 시험 모두 0건이었다.

**더 까다로운 별도 경계 시험에서는 모델 오차가 남는다.** 동결 뒤 9개 치수 규모에서 `nextafter`로 만든 인접 부동소수점 36조건을 CNC의 실제 `_length_comparison`과 비교했다. 원모델은 13조건에서 행동이 달랐고, 재검산 후 알려진 문제를 잘못 지운 경우는 0건이었다. 기록은 `numeric-nextafter-stress.json`이다. 이 시험은 재학습이나 모델 선택에 사용하지 않았다. 위 무작위 경계 100%를 모든 경계에서의 정확성으로 확대하지 않는다.

모델·수치 경계·미확정·공정 범위·잘못된 JSON·출처 변경·보고서 누락을 포함한 71개 회귀검사가 통과했다. `model-tests-adapter-recheck.txt`와 XML에 기록했다. 강제로 틀린 예측을 넣어도 이미 측정된 문제를 지우지 않는지 검사한다.

## 재검산이 필요한 이유

`analyze_report`는 원모델 예측을 보존하고 현재 규칙으로 다시 비교한다. 예측과 규칙이 다르거나 학습 범위 밖이면 `rule_fallback`을 반환한다. 이를 AI 자체의 정답으로 합산하지 않는다. 일부 측정에서 발견한 후보는 유지하며, 일부 측정의 미검출을 전체 `clear`로 바꾸지 않는다.

다음 파일의 SHA가 학습 시점과 다르면 학습 결과 사용을 중단하고 규칙으로 확인한다: `amdfm/analysis.py`, `amdfm/detail_summary.py`, `amdfm/orientation.py`, `dfm/machining.py`, `dfm/accessibility.py`, `dfm/learned_review.py`. 따라서 규칙·입력 특징 변경 뒤에는 명시적으로 재학습해야 한다.

## 개발 기록 보존

`training-001`에서 일반 조건의 일치율은 높았지만 경계 시험은 61.44%였다. 이 결과를 보고 연속 수치 특징과 경계 표본을 보완했다. `training-001`~`training-final-005`는 개발 자료이며 최종 독립 시험으로 취급하지 않는다. 각 실행의 데이터, 모델 파일, 지표와 시드를 보존했다. 최종 006의 모델 선택에도 앞선 시험 성적을 직접 입력하지 않았으며 새로운 시드의 시험을 사용했다.

실제 CAD 감사에서 발견한 두 가지 결과 연결 문제를 고쳤다. 공간 제한이 없으면 추가 조건 요구 대신 미적용으로 표시하고, 접근 표본의 상태가 누락되면 완료로 처리하지 않는다. 입력 특징·교사 수식은 바꾸지 않았다. `training-recheck-007`은 **006과 같은 시드·같은 데이터를 재실행**한 기록이며, 새로운 독립 평가로 합산하지 않는다. 11개 모델의 트리·입력 범위·전체 평가 결과와 비압축 데이터 SHA가 006과 동일함을 확인했다. 바뀐 코드 출처 SHA를 포함한 최종 모델과 이 관계는 `adapter-recheck-provenance.json`에 기록했다.

두 연결 수정 전 006 모델에서 벽 한 항목과 미실행 층간 게이트를 처리하는 300회 warm 추론의 중앙값은 1.71 ms, 95백분위수 2.16 ms였다. 교사 소스 SHA 확인을 포함하며, CAD 읽기·기하 계산·전체 검토 시간은 아니다. `warm-inference.json`에 당시 모델 SHA와 환경 범위를 기록했다.

이 단계의 성과는 **명시된 규칙을 학습해 수정 행동을 선택하고, 측정값으로 재검산하는 내부 AI**다. 형상 특징 인식 자체를 학습한 모델이나 임의의 새 CAD를 생성하는 모델은 아니다.
