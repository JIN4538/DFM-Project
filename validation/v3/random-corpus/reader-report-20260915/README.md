# 바탕화면 형상 검토 결과 요약 보관

보관일: 2026-09-15. 사용자에게 전달했던 바탕화면 `AM-DFM_무작위형상_검토결과/`의 `index.html`, `summary.json`, `배포_검증기록.json`을 원본 바이트 그대로 보존했다. [archive_manifest.json](archive_manifest.json)에 원래 위치, 크기, SHA-256을 기록했으며 세 파일 모두 원본과 대조했다.

`index.html`은 당시 사용자용 결과 요약이다. **상세 결과 링크는 원래 바탕화면과 작업공간의 상대 위치를 전제로 한다.** 예를 들어 `../../Documents/ChatGPT/DFM/study/random-shape-audit/event-final-02/records/…`를 참조하므로, GitHub나 다른 위치에서 열면 해당 링크가 동작하지 않을 수 있다. 내부 파일별 바로가기와 본문은 보존돼 있지만, 이 폴더만으로 전체 상세 결과를 제공하는 독립 웹사이트는 아니다.

링크를 현재 결과에 맞추어 바꾸거나 계산 값을 수정하지 않았다. 상세 재현에는 당시 `study/random-shape-audit/`에 보존한 기록과 입력 형상, 코드·환경 정보가 필요하다. 이 보관은 과거 결과를 다시 계산했다는 뜻이 아니며, 현재 기능·검증 범위는 [프로젝트 인수인계](../../../../docs/project-knowledge/README.md)에서 확인한다.
